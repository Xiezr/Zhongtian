# 换世界观参考 · 时代背景与故事方案（v89.211 · 老板 4）

> 目的：为**整个故事更换背景**。
> 方法：按**玩法元素**（机制）而非史实做映射 —— 先把三国皮"剥掉"、只留机制骨架，
> 再看哪些时代/世界观能把这些机制讲圆。给出 **6 套候选** + 故事参考 + 转换成本 + 落地建议。

## 二、六套候选世界观

### 候选 A · 仙侠「宗门争鼎」（东方修仙）

**一句话**：诸宗并立，你是一宗之主 —— 以洞天福地为城、以道兵为军、以灵根为资质，争的是天地气运。

| 机制 | 仙侠形态 |
|---|---|
| 城池 / 48 格 | 山门 / 洞天福地（殿宇、丹房、剑阁…） |
| 外城地块 | 灵田 / 灵林 / 石场 / 灵矿 |
| 资源 | 灵谷(粮) · 灵木 · 玄石 · 精铁 + 灵石(金) + 弟子(人口) |
| 兵种 | 杂役→练气道兵→剑修/体修/符修；灵骑/灵兽骑；傀儡(床弩)/机关兽(冲车)/雷车(投石车) |
| 将领 | 修士：资质 = **灵根**（凡品→天授 ⇌ 伪灵根→天灵根，五档天然对应）；内功 = 功法 |
| 装备双轨 | 护道法器(军) / 本命法宝(修)；百炼 = 炼器；**蕴养 = 祭炼（名字都不用改）** |
| 门派 → | 六大道统（剑/丹/符/阵/驭兽/器），或六大宗门盟友 —— 提供被动与声望 |
| 民心 / 创伤 | 香火 / 怨气；香火归零 → 气运尽失、山门被拆（失城） |
| 爵位 21 档 | 道途阶梯：炼气→筑基→金丹→元婴… 或宗门位阶（记名→外门→内门→真传→长老→峰主→宗主） |
| 州 5 | 五域（东荒/南疆/西漠/北原/中州）；州志 = 域志；岁贡 = 上供灵石 |
| 据点 / 前哨 | 坊市 / 镇魔塔；野地 = 灵脉、秘境入口 |
| 年号 / 赛季 | 灵气潮汐（丰潮/枯潮）；时代之志 = 天道大誓 |
| 游历 | **秘境探幽**（现有「江湖游历」直改名字） |
| 战斗 | 阵法对战：城墙 = 护山大阵（环山）、箭塔 = 剑阵石塔、斗将 = 斗法 |
| 收藏 73 | 天材地宝图鉴 / 名剑谱 / 名士录（“美女”类改“红颜知己/仙子录”，措辞注意分寸） |

**故事参考**：主线 —— 末法之世，最弱山门的弟子以半卷残经起家，收灵根、炼法宝、据五域，
重立仙庭（或渡劫飞升）。三幕：① **立足**（重建山门、驱逐妖修散修）② **争锋**
（气运之争：占域枢、开秘境、结道统）③ **天道之变**（灵气潮落 / 上界收割 → 终极对抗）。
叙事钩子：香火 ↔ 民心天然同构；「年号」= 大劫倒计时。

**灵感参照**：宗门经营流修仙（资源-境界-秘境三段结构）、《凡人修仙传》式草根崛起。
**转换成本：低—中**。理由：门派 / 蕴养 / 灵力 / 灵草 / 丹药 / 功法 / 游历**已经半仙侠**；
主要工作在兵种与城建的命名 + 头像作风。**风险**：题材红海，需靠「香火/气运」做出差异化。

### 候选 B · 星际「银河拓殖」（科幻）

**一句话**：你是边境星区的总督 —— 以星球为城、以舰队陆战军为军、以基因位阶为资质，争的是星门与资源带。

| 机制 | 星际形态 |
|---|---|
| 城池 / 48 格 | 拓殖星 / 轨道城（区块制） |
| 外城地块 | 矿脉 / 气田 / 水冰 / 晶矿 |
| 资源 | 合成粮 · 合金 · 晶体 · 燃料 + 信用点(金) + 移民(人口) |
| 兵种 | 陆战队 / 装甲兵 / 无人机群 / 悬浮骑兵；机甲；轨道炮(床弩)/破城钻机(冲车)/重型榴弹(投石车) |
| 将领 | 指挥官：指挥/火力/战术/后勤/机动/耐力（六维一一对应）；资质 = 基因位阶 S/A/B… |
| 装备双轨 | 制式装备 / 灵能装备；百炼 = 军械改装；宝具 = 植入义体/模块 |
| 门派 → | 六大星际商会 / 军团派系 |
| 民心 / 创伤 | 殖民地支持率 / 厌战度；归零 → 殖民地哗变独立 |
| 爵位 21 档 | 军衔+行政衔：尉→校→将→元帅→总督→星区公爵 |
| 州 5 | 五个星区 / 航线节点；岁贡 = 定期税赋 |
| 据点 / 前哨 | **前哨站 / 太空站（“前哨”本就是原词）**；野地 = 资源带 |
| 天候 | 空间天气（太阳风/磁暴 → 命中/通信修正） |
| 年号 / 赛季 | 星历纪年；时代之志 = 复兴计划 |
| 侦察 | 分层扫描（探测器）；斗将 = 王牌对决 / 电子战 |
| 收藏 73 | 星图鉴 / 前纪元遗物 |

**故事参考**：主线 —— 远征舰队残部在边境星区重建基地，联合或征服诸派，对抗远古机械文明「收割者」。
三幕：① 立足（一星一矿、抵御掠夺者）② 星区一统（星门争夺战）③ 远敌压境。
**灵感参照**：《群星》（星区/前哨/派系结构）、《基地》（边陲建政叙事）。
**转换成本：中—高**。机制万全（前哨/侦察/器械拆工事天然科幻），但**视觉几乎全量重做**
（飞船/机甲/星图）；不做视觉会「名字科幻、图还是古代」。**风险**：美术投入最大。

### 候选 C · 蒸汽「煤铁纪」（蒸汽朋克）

**一句话**：烟囱与齿轮的年代 —— 你是自治工业城邦的执政官，用煤与铁、步枪与装甲列车，争夺大陆工业命脉。

| 机制 | 蒸汽形态 |
|---|---|
| 城池 | 工业城邦（厂区 / 街区格） |
| 资源 | **煤 · 铁 · 木 · 石（几乎照旧）** + 金 |
| 兵种 | 线列步兵 / 线膛枪手 / 骠骑 / 装甲列车(器)；臼炮 / 攻城炮 / 破城车 |
| 将领 | 六维照旧；资质 = 才具评级；内功 = 军事操典 / 工程手册 |
| 装备双轨 | 制式军械 / 以太装置；百炼 = 兵工坊精修 |
| 门派 → | 六大学会（工程/火药/蒸汽/冶炼/航运/情报） |
| 民心 / 创伤 | 市民支持 / 工潮厌战；归零 → 议会政变失城 |
| 爵位 21 档 | 官衔 + 贵族头衔（文书→科长→市长→…→公爵）——**爵位体系在近代最自然** |
| 州 5 | 五大工业区（煤都/钢城/港区/林区/旱区） |
| 据点 / 前哨 | 哨站 / 要塞；野地 = 煤田、铁矿露头 |
| 年号 / 赛季 | 纪年；赛季 = 工业博览会 |
| 科技树 | 直接就是革命史：蒸汽→电气→内燃（现有「车轮技术」等原词可用） |
| 收藏 73 | 发明图鉴 / 实业名人卡 |

**故事参考**：主线 —— 被旧帝国封锁的内陆城市，靠一台蒸汽机翻身：铺铁路、造炮舰，成为大陆仲裁者。
**灵感参照**：工业革命史观 + 蒸汽朋克美学（齿轮/黄铜/飞艇）。
**转换成本：中**。资源 + 市场 + 行会 + 爵位原生；主要改建筑/兵种/战斗文案（城防 = 炮台/堑壕）。
**风险**：火器与「城墙/箭塔」语义要重写。

### 候选 D · 废土「余烬纪元」（末世重建）

**一句话**：大崩坏百年后，你带着一群幸存者从废墟里站起 —— 聚落为城、拾荒为业，抵御掠夺者与变异潮。

| 机制 | 废土形态 |
|---|---|
| 城池 | 幸存者聚落 / 避难所 |
| 资源 | 净水 · 废金属 · 药品 · 罐头 + 货币(瓶盖/信用) |
| 兵种 | 民兵 / 步枪手 / 猎手 / 机车骑兵 / 改装战车(器) |
| 民心 / 创伤 | **士气 / 绝望值（战争创伤系统原生）**；归零 → 聚落暴动被夺 |
| 爵位 | 威望等级：无名者→队长→总管→执政→废土之王 |
| 门派 → | 六大幸存者派系（秩序/科技/商队/武力/教团/互助会） |
| 州 5 | 五大废墟区；岁贡 = 供给配额 |
| 天候 | 辐射风暴 / 酸雨（现有天候机制直用：命中/行军减益） |
| 年号 / 赛季 | 余烬纪；时代之志 = 重建蓝图 |
| 据点 / 前哨 | 安全屋 / 瞭望塔 |
| 收藏 73 | 旧世界遗物图鉴 |

**故事参考**：主线 —— 从一间避难所出发，结盟或吞并诸聚落，查明「大崩坏」真相，点亮文明余烬。
**灵感参照**：《辐射》聚落/派系结构、生存群像叙事。
**转换成本：中**。民心/创伤/掠夺/据点高度原生；但视觉全换 + **题材尺度要把控**（暴力/黑暗描写分寸）。
**风险**：与现有暖色古风素材几乎不通用。

| 门派 → | 六大公会 / 教团 / 骑士团 |

**风险**：与现貌差异最小 —— 若期待「焕然一新」可能不够惊艳。

### 候选 F · 山海「万邦异兽」（东方神话）

**一句话**：九洲山海之间，诸国以驭兽立邦 —— 你牧一邦、训异兽为军，踏遍神山诡域，收拢山海遗珍。

| 机制 | 山海形态 |
|---|---|
| 兵种 | 山民 / 巫兵 / 弓手照旧；骑兵 → 虎骑 / 鹿骑；**器械 → 巨兽**（驮弩犀/撞山犀/投石巨猿）——最大亮点 |
| 将领 | 牧兽师 / 巫祝；资质 = 血裔巫脉；内功 = 巫典 / 兽语 |
| 装备双轨 | 骨甲(军) / 巫器(修)；百炼 = 骨坊；蕴养 = 巫祭 |
| 门派 → | 六大巫脉 / 兽族盟约 |
| 民心 / 创伤 | 族望 / 神怒；归零 → 神怒迁邦 |
| 爵位 | 邦位：族人→祝→大巫→邦君→霸主 |
| 州 5 | 五域山海（东山/南海/西荒/北原/中州） |
| 天候 / 事件 | 照旧 + 「异兽潮」事件（可与外敌来袭机制合并） |
| 收藏 73 | 山海异兽图鉴（收藏系统最契合的题材） |

**故事参考**：主线 —— 小邦少年大巫，收异兽、平兽潮、探神山，揭开《山海图》背后的远古文明。
**灵感参照**：《山海经》母题、《怪物猎人》生态叙事。
**转换成本：中**。战斗「器械→巨兽」需改图标 + 少量文案；其余照旧；异兽素材量大。
**风险**：异兽图标是硬成本。

## 四、落地建议（无论选哪个：三层换皮）
