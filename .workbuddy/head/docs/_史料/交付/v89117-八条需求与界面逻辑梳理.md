## 2️⃣ 城主 / 守将不可出征（老板：「城主和守将不能执行出征动作」）


| 层 | 处置 |

| 界面 | 下拉**列出但置灰** + 写明原因（比藏起来好：一眼看出"他在当城主"） |

## 6️⃣ 弹窗闪烁 + 层级返回（老板：「点击操作时会闪烁…关闭的时候不回到上一级界面」）

**先取证**（`probe_v89117_flicker.js`，真浏览器 + MutationObserver）：

| 症状 | 实测证据 | 机制 |
|---|---|---|
| 闪烁 | 连点 4 次换页 → **mask 元素被销毁重建 4 次** | `openModal` 走 `root.innerHTML = …` —— 整个遮罩重建，入场动画（`mModalIn .13s` + `mModalRise .15s`）每次重播 |
| 层级丢失 | 铁匠铺 Lv3 →「套装效果一览」→ 关闭 → **弹窗全没了**（落到城池视图） | 没有"层"的概念：`closeModal` 一律清空 `#modal-root` |

**改法**（判别放在**唯一入口**，不动上百个调用点）：

```
ui.openModal：
  · 没有弹窗 → 建 mask 并播入场动画（就这一次）
  · 已有弹窗 → **只换 inner-panel 内容**（mask 与 .modal 元素保留 → 动画不重播 = 不闪）
      ├ 标题相同 → 同级刷新（replace，不入栈）
      └ 标题不同 → **压栈**（记 HTML 快照 + 尺寸类 + 标题 + 认窗标记）
ui.closeModal：有上级 → **弹栈回上一级**（并还原认窗标记）；顶层才真关（并做收尾：战场转后台/回放停表）
ui.closeAllModals：一次关净（脚本 / 测试 / 一键回城用）
```
✕ 的提示语随层级变：有上级 → `title="返回《⚒️ 铁匠铺 · Lv3》"` + 角上一个 `↩` 意符。

**实测**（截图 `v89117-modal-stack.png`）：
`{title:"📖 套装效果", depth:1, xTitle:"返回《⚒️ 铁匠铺 · Lv3》", hasUp:true, behind:"⚒️ 铁匠铺 · Lv3"}`

> **诚实缺口**：压栈保存的是上一级的 **HTML 快照**，不是"重新调用它的开启函数"——
> 若下级改了上一级要显示的数据（例如在详情里拆解了装备），回退时那一屏数字可能是旧的。
> 要"回退即重算"得给每个开启函数加重开钩子（`opts.reopen`），本轮未做。

## 🔟 诚实缺口

1. **弹窗栈回退不重算**（见 ⑥）——回退显示的是快照，若下级改了上一级的数据可能显示旧值。
2. **字体只做了"字号/字重/行高/数值族"四件事**：字距（letter-spacing）、字色语义未系统化（各面板仍各自写）；
   正文字号仍是 13px 一档（未按"长文/表单"再分档）。
3. **行高收敛取"就近 + 平局取小"**：`1.15/1.2 → 1.25`、`1.5 → 1.6`、`1.75 → 1.85` 各有一处**变大**，
   已用 44 弹窗审计确认无溢出，但**观感变化**需老板过目（这是"更松"的方向）。
4. **战场两侧列在 ≤1280 视口**会压到约 200px（下拉框可能截断）——未做窄屏专项（项目一直是 1440×900 画布口径）。
5. **`GAME.expBlockOf`（经验道具上限）只有测试引用**，疑似没接进 `useItem` —— 本轮**未动**（避免范围蔓延），
   已写进档案"遗留与待确认"。
6. **铁匠铺"点选"未做键盘/双击快捷**：要造多件仍是一件一点。
7. **背包筛选状态不落档**（刷新页面回默认）——与其他视图筛选一致（`ui._*` 都是会话级）。
