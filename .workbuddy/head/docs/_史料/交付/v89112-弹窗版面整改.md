## 一、先取证：审计工具为什么"全绿"却满屏滚动条

系统里有骨架体检工具 `audit_v89105_modals.js`（44 项全绿），但它**只在小数据量下验证**：
- 判据 = 「正文区 `scrollHeight − clientHeight` > 2px 才算坏」；
- 数据 = 自己造的少量样本（几份战报、几件物品）。

**真机不是这样**。本轮新写 **载荷体检** `audit_v89112_pressure.js`（真浏览器 + 真实试玩存档）：

| 载荷 | 来源 |
|---|---|
| 真实进度 | `.workbuddy/tmp/playtest600/cap108/final_state.json`（10 现实小时 · 600× 实机试玩存档） |
| 极限补料 | 30 片野地 · 8 支采集队 · **199 种物品全塞** · 60 份战报 · **166 位将领** · 大视口据点 |

它量三件事：① 主溢出；② **弹窗内可滚动容器数**（"一堆下拉条"的真身）；③ 尺寸。

## 二、整改（对齐老板三句话）

### ① 「设置合理的界面大小」→ xxl 档充分吃版面

```
xxl：1020×840  →  1200×850      （画布 1440×900；左右各留 120、上下各留 25）
```
坐在这一档的是"内容确实多"的面板（市场/客栈/见闻/君主/门派/出征/自动出征/全境营造/战报详情…），
加宽 18% 面积后，原本靠滚动条苟着的段多数能一屏站直。

### ② 「避免使用下拉条」→ 撤掉全部"写死的中间高度"

这些 `max-height` 是"小窗配小滚动区"的罪魁——弹窗内容区明明有 800+，容器却只给 252/360/414/558：

| 选择器 | 原值 | 现 |
|---|---|---|
| `.panel-body`（openPanel 家族） | 558px | **none** |
| `.exp-body`（出征出兵表） | 360 / 520 / 252px | **none** |
| `.modal-scroll`（快购/派驻） | 414 / 440px | **none** |
| 战报详情回合纪要 | `.bt-log` 168px 内滚 | 新类 `.rp-log`（无中间高度）+ 分页 |
| 出征表/辎重表行高 | `.tbl td` 8px 内边距（把 `.exp-tbl` 的 4px 覆盖了） | `.modal .exp-tbl td` = 3px |

### ③ 「条目过多的分页」→ 弹窗内翻页（复用 v20 的 `ui.modalPage` 机制）

| 弹窗 | 分页 | 说明 |
|---|---|---|
| 野地一览 | **13 行/页** | 30 片 → 3 页 |
| 采集点 | **4 队/页** | 8 队 → 2 页 |
| 装备 · 将领选择器 | **12 位/页 · 4 列**（新 `.gen-chips.wide`） | 166 位 → 14 页；旧是 83 行高墙 |
| 装备 · 背包 | **8 件/页**（`ui.EQUIP_PER`，4 列 2 行满排） | |
| 战报详情 · 回合纪要 | **5 行/页** | |
| 宝物背包 · 选择器 | 12 位/页 · 4 列 | 视图内联分页条 |

### ④ 版面平衡（数据多时两列不失衡）

- **本境调运**：辎重表从右列移入左列（旧：右列 876px 顶穿、左列 478px 空着 → 两列 max 731 ✓）；
- **"可用道具"** 从主将段移入右列（199 物品时体力丹 pills 换行撑高左列 +42px）。

## 三、顺手挖出的真 bug

**装备面板的分页条点不到**：它用 `ui.pagerHTML('equip', …)` → 画到屏幕**底部条**，
而弹窗打开时底部条被 modal-mask（z-index 1000）盖住 —— 翻页按钮存在但点不着。
本版改走 `ui.modalPage`（弹窗内翻页，`mpage` 动作），视图模式仍走底部条（双模式）。

## 五、诚实缺口

1. 老板屏若 ≤1366×768：xxl 的 850 高会被 `max-height: calc(100vh-20px)` 兜底压到 ~748 —— 高的弹窗仍会出兜底滚动条。
   这是物理限制（窗口装不下），但**列表型内容已分页**，受影响的只剩"单页内容本身超 748"的极端场景。
2. `ui.genChips` 的 `per` 目前只有装备/宝物两处启用；其余（派遣/采集/城墙的本城将领列表）数量有限，未分页。
3. 战报详情在"超长战报（100+ 回合 + 全兵种损耗）"下未压测——纪要已分页，损耗表行数 = 兵种数（固定 ≤16）。
