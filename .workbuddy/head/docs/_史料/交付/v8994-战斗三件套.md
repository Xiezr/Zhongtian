## 一、三件套各自做了什么

### E1 围攻战（据点/县城 → 多波次、可撤退、按日结算）

| 项 | 口径 |
|---|---|
| 守备值 | `s.sieges['f:x,y'｜'c:城id'] = { hold: 0~100, waves, day }`（懒初始化；随档走） |
| 唯一出口 | `siegeScopeOf / siegeKeyOf / siegeStateOf / siegeHoldOf / siegeScaleAt / siegeScaleOf / siegeChipOf / siegeChipApply / siegeClear / siegeTextOf`（10 个，上层不许摸 `s.sieges`） |
| 破防 | `chipBase 16% × 战力比`，夹在 `[10%, 45%]`；**围困 ×1.5**、**主动撤退 ×0.5** |
| 破防归属 | **只有「占领」破防**；「掠夺」取财不动守备（两个心智模型不混） |
| 衰减 | 守备 → 守军/城防同步衰减：`0.35 + 0.65×hold`（守军）/ `0.30 + 0.70×hold`（城防） |
| 按日 | 每整日未攻 → 守备 **+8%**；恢复到 100% 即「围解」，档自动清掉 |
| 下城 | `守备归零 + 本战获胜` → 据点拔除 / 县城易主（下城即清围攻档） |
| 可撤退 | 战场「🏳️ 撤退」两段确认 → 残部归城、**本波破防按半计**、**不算战败**（不扣忠诚）、围攻进度保留 |
| 试点范围 | `['fort','county']` —— 郡/州/都仍是决战（总纲原话：县城试点） |

### E2 军师估算（区间 + 战法三选）

- `ui.expPowerOf()` 从「一键正解」改为**区间**：`lo/def/hi + err + ratioLo/ratioHi + intelLv`。
- 误差随侦察技巧收窄（实测表）：`Lv0 ±55% · Lv3 ±34% · Lv5 ±20% · Lv8+ ±10%`（封底 10%）。
- 面板文案：`⚔️ 军师估算 我方 X vs 守军 约 Y（误差 ±Z%）` + `区间：我 1 : a ~ 1 : b` + `情报 LvN（升侦察技巧可收窄）`；
  区间跨过平衡点时追加 `⚑ 此战凶险：胜则可入史册`（总纲的"零成本"项）。
- 二次确认闸改按**最坏情形**（`ratioLo < 0.5`）拦 —— 情报越差区间越宽，警告越容易触发（不确定性的代价）。
- **战法三选**（`DATA.OPS`，与计略同一通道：出发校验 → 抵达生效）：
  - 强攻：无修正；
  - 围困：行军 ×1.5、守军 −12%、破防 ×1.5（实测战报注脚「围困 · 守军疲敝 −12%」）；
  - 奇袭：须先选计略，本战**计略效果 ×1.5**（妖言 −15% → 实测 −23%；趁火打劫/金蝉脱壳同样吃倍率）。

### E3 战报回放（关键帧 + 播放 + 以少胜多）

- `report.replay = { field, rounds, frames[≤10], key[], retreat }`；帧 = 首 2 + 尾 2 + 首杀/破塔/折半/最烈。
- 战报详情新增**分回合回放**：▶ 播放 / ⏮⏭ 逐帧 / 拖动条 / **关键帧跳转**（初次接敌 · 攻破箭塔 · 敌军折半 · 最烈一回合 · 得胜）。
- 「回合纪要」「兵种损耗表」保留（回放给画面、纪要给全量）；老战报（无 replay）退回静态条带列表。
- `以少胜多` 徽记（🏅）：我方战力 < 守方×0.8 且获胜 → 列表与详情双标记。
- 收藏仍是 v89.89 的 ⭐（回放与收藏各管一段）。
- **增量实测 507 B/场**（验收线 <2KB ✓）。

## 二、实测证据（探针 `probe_v8994_battle.js`，77 项全过）

### ① 引擎实测：盈亏平衡点不在 1:1（这是本轮最重要的发现）

| 对局 | 盈亏平衡比 | 含义 |
|---|---|---|
| 长枪 vs 长枪 3000（**无城防**） | **0.18 : 1** | 本引擎**攻方优势极大**（0.4:1 已能赢） |
| 弓兵 vs 据点 Lv5（**有城防 + 兵种相克**） | **0.97 : 1** | 城防与配兵把差距补回来了 |

→ 所以「五五开」的正确刻度：**据点类 = ratio [0.75, 1.24]**（平衡比 ±25%，带内 ±10% 兵力即可翻转胜负，实测 `486→def / 594→atk`）。
→ 顺带解释了 v89.90「0.02:1 全灭」与 v8992「Lv8 据点打不过」并存：不是同一个刻度。

### ② 验收线：五五开带波数占比 ≥20%（实测 21%）

「五五开」不是"静态目标占比"（据点 1.96× 一级，任一军力下只有 1~2 个靶的首波比值落在带内 → 只有 9%），
而是**围攻逐波**里的占比：守备一破防就衰减，同一场围攻从"打不动"一路走到"再投一点就能赢"。

| 破防强度 chipBase | 值得围攻子集带内占比 | 全量占比 | 总波数（160 目标） |
|---|---|---|---|
| 45（初版） | 14% | 6% | 593 |
| 28 | 16% | 8% | 676 |
| **16（定稿）** | **21%** ✓ | 9% | 855 |
| 12 | 22% | 12% | 867 |

→ 定稿 `chipBase 16 / chipMin 10 / chipMax 45`：一场围攻 4~7 波，逐波扫过平衡点。
（"值得围攻子集" = 首波打不赢、但进度可留的仗 —— 34 座目标 / 332 波里 69 波在带内。）

### ③ 台阶连续性

据点 Lv1→10 相邻档倍差：`1.97 · 1.96 · 2.43 · 1.97 · 1.97 · 1.96 · 1.97 · 1.96 · 1.96`
（Lv3→4 略陡 = **轻骑解锁**；县城/据点Lv10 = 3.67×，是**档位边界**不是断层）。
→ 台阶"粗但连续"：配合围攻衰减，任何军力都能找到"磨得动"的下一档。

### ④ 三件套行为实测

- 围攻全流程：Lv1 据点（6000 弓兵）→ 第 1 波破防 45% → 第 2 波城垣破 → 下城、档清空（真实结算）。
- 撤退：Lv8 据点（12000 弓兵）→ 步进 r1/live（我余 7159 / 敌余 52298）→ 撤退 → 破防 5%（半计）、残部 7159 归城、挂起清空、**忠诚变动 0**。
- 战法：守军起始 4077 →（围困）3587 = **−12%** →（奇袭+妖言）3159 = **−23%**；行军 3454 → 5181 游戏秒 = **1.5×**。
- 回放：8 回合仗 → 采样 ≤10 帧、关键帧 `[first,lost,hot,final]`、增量 507 B。
