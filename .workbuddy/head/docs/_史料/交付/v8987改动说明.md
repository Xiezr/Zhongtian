## 一、需求 1 · 就地快购

**组件**（`ui.js`）：两种形态，购买全部走商城**同一出口 `GAME.doShopping`**（价格/校验/扣款/日志零分叉）。

| 形态 | 函数 | 场景 |
|---|---|---|
| 单物品（默认数量=缺口） | `ui.openQuickBuy(itemId, need, back)` | 打造材料、套装图纸、锦囊、种子 |
| 整类选购 | `ui.openQuickCat(cat)` | 加速宝物（多品类选购）、种子 |

**接入点（六处）**：
1. **铁匠铺卡片**：缺材料 → `🛒材料×N` 补货按钮；缺图纸 → `🛒图纸×1`（`ui.forgeRow`，只在真缺时渲染，不占常态高度）。
2. **募兵/器械提速面板**：无加速宝物 → `🛒 购买加速宝物`；已有宝物 → `🛒 购买更多`。
3. **布防计略**：`🛒 购锦囊` + 不足提示改"可就地购买"。
4. **种田秘境**：`🛒 购买种子`。
5. **商城**：`ui.SHOP_CATS` 新增 **`seed: '种子'`** 页签（**种子开售**——v78 的"不售"按最新拍板解除；来源标注保留）。
6. 动作分发：`qb-item / qb-cat / qb-buy / qb-cat-buy`（`main.js`）。

**出口增强**：`GAME.doShopping` 增加返回值 `{ ok, msg, bought }`（快购据此决定是否重开来源面板；旧调用方无视返回值，行为不变）。

## 二、需求 2 · 派兵统一走行军通道

**新方式**（`DATA.EXPEDITION.modes`，`panel:false` 不出现于出征方式下拉）：

| id | 名称 | 说明 |
|---|---|---|
| `transfer` | 🚚 调兵 | 跨城调兵（含新城调兵入口）：抵城入编，**主将随军入驻新城**（`gen.cityId` 变更） |
| `station` | 🛡️ 驻守 | 向已属我方野地增派驻军：抵达即驻（守地不衰减） |
| `gather` | ⛏ 采集 | 开赴己方野地：抵达后开始采集（满 1 小时方有收成） |

**改造落点**：
- `GAME.doTransferTroops(fromId, toId, army, genId)` —— 原"瞬间改兵账"改为 `march.dispatch({kind:'owncity'})`；
  抵达再验目标城校场（超容**整体折返**）；出发时校验兵量/校场（保留原口径）。
- `GAME.doWildGarrison(x, y, army, cityId, genId)` —— 改走 `dispatch(occupy semantics → 'station')`；
  驻军上限仍在出发校验（抵达 `wildGarrisonAdd` 的 overflow 兜底不变）。
- `GAME.dispatchGather(x, y, genId, army)`（新）—— 采集出发走 `dispatch`；
  `GAME.startGather(..., {arrived:true})` 为抵达落账路径（跳过重复扣兵）。
  **驻军开采（`from:'garrison'`）保持"就地开采"**（兵本就在野地，不进行一次行军）。
- **UI**：调兵/驻守面板新增"带队将领"选择（空闲将领过滤 = `genCityOf` + 非出征/守将/采集中）；
  采集面板沿用原将领选择；三者提交全部带 `genId`（**一律要选将**）。
- **抵达落账**（`expedition` 顶部分支，先于"侦查判定"）：`owncity` 入城 / `gather` 建采集记录。
- **召回**：三类行军均可 `march.recall`（兵归出发城、未抵达不入驻）。

**军务总览**：行军中自动可见（全境口径，含三类）；含出发城/主将/方式/兵力/进度/召回。

## 三、需求 3 · 战斗规则（每兵种每回合一个目标 + 反击不限次）

**引擎改造**（`tactic.js`）：
- 新增常量 `T.SPLASH_PCT = 0.30`。
- `fireOnce` 增加 `ctx.single` **单主目标分支**：
  - 主目标 = 指定目标（射程内优先）/ 否则最近的一支；
  - 主目标**吃满**本次全部伤害（自然钳制：最多打光它）；
  - 吃满后的**超出伤害**对**射程内其他每个敌方兵种各溅射 30%**（`ctx.splashTargets` 预筛"在射程内"）；
  - 命中明细：首条为主目标（无标记），后续溅射条带 `splash:true`。
- **箭塔火力与反击不传 `ctx.single`** → 行为不变（反击为单目标天然无溅射）。
- **反击不限次**：保持每次命中逐条触发（`res.hits.forEach(counterStrike)`），射程内即反击、按被打后余量计算。

**实测观测**（探针场景）：
- 7000 弓 vs 义兵 2 + 轻骑 60 → 首击主目标（轻骑 60）全灭 + 溅射义兵 2 全灭；`SPLASH_PCT=0` 时溅射条消失（翻转判据）。
- 义兵 20v20 拉锯 → 我方反击累计 3 次（第 1~3 回合各 1 次）——"不限次"的稳定观测窗。
- ⚠️ 设计观测：本作攻击/生命比高（齐射可秒杀），**有效反击窗口天然只有 1~3 次**；
  小基数（杀伤<1 人）与超快清场（首回合全灭）都不会产生反击记录，属既有语义（"没被打出伤害=无反击"）。

## 四、需求 4 · 战斗观战界面

**引擎会话化**（`tactic.js`，机械重构——`T.simulate` 行为逐字节不变，既有 2400+ 战斗断言全绿）：
- `T.begin(...)` → 战斗会话 env：`step()` 逐回合 / `runAll()` 跑完 / `finish()` 收尾 / `snap()` 快照 / `setCmd()` 下指令；
- **确定性引擎** → 会话可由「输入 + 逐回合指令历史」重放重建（读档恢复用）。

**游戏层**（`battle.js`）：
- `_needWatch`（观战闸门：`settings.battleWatch`，默认开）→ `_suspendExpedition`（挂起，`s.battles` 纯数据随存档）；
- `stepBattle`（每回合：指令落会话 → 快照入 `history` → step）/ `autoBattle`（一键跑完）/
  `finishBattle`（`_result` 重入 `expedition` 走**既有落账段**——伤兵/占领/战报零复制）/ `tick`（**真实秒**倒计时）/
  `restoreBattles`（读档按 history 重放恢复）/ `pendingCount`；
- 挂起期间将领保持"征战中"（`status='march'`，防被重复派遣）；落账后统一收尾为 `idle`。

**界面**（`ui.js` + CSS）：
- 全屏战场（`openBattlefield`）：距离轴（左我军/右敌军，**CSS transition 位移演出**）+ 双方单位卡（兵种图标/数量/位置）；
- 逐兵种指令：**前进 / 驻守 / 后退** + **目标**（任意/敌兵种/城防箭塔）；
- 顶部：**60 秒读秒**（`settings.battleSec`，真实秒，不走 timeScale）+ 回合数 + 间距；
- `✅ 完成回合`（提前结算）· `⏩ 自动战斗`（一键跑完）· `后台运行`（关闭 = **后台照常走**，每 60 秒自动结算一回合）；
- 每回合事件逐条字幕（前进/后退/攻击/反击/箭塔）+ 目标闪烁；动画期间倒计时暂停（`rec.anim`）；
- 军务总览新增 **⚔ 征战中** 段（进入战场入口）；战果面板（胜负/回合/双方损失 → 战报见公文，`ui.onBattleDone`）。

**接入**：`march.arrive` → `expedition` 抵达 → 观战开则挂起（`onMarchArrive` 直接打开战场）；关闭后军务可再进。

## 八、复验指引（试玩）

1. **快购**：铁匠铺点一张缺料的图纸/装备 → 卡片出现 `🛒…×N` → 点开直接买（黄金结算，与商城同价）。
2. **派兵**：城池间操作「派兵」→ 选将领出发 → 军务总览见行军 → 抵达后目标城兵力 +N（将领也在新城）。
3. **战斗**：拉一支与守军相当（约 60%）的队伍打野地 → 抵达弹**战场界面** → 给兵种设「驻守/前进 + 目标」→ 点「完成回合」看位移与打击字幕 → 「自动战斗」跑到战果。
4. **读秒**：不管它 60 秒 → 自动结算一回合；点「后台运行」去干别的 → 军务「⚔ 征战中」可再进。
5. **种子**：商城新增「种子」页签可购；种田秘境「🛒 购买种子」直达。
