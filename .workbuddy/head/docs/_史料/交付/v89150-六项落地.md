## ④ 诚实缺口 / 待老板定夺

1. **缩放的上下限**：现在 k 不设上下限（4K 屏 k=2.4 → 全站 ×2.4）。若觉得"大屏太大 / 小屏太小"，
   加 `Math.min(1.6, …)` / `Math.max(0.6, …)` 各一行即可。
2. **缩放后浏览器原生缩放（Ctrl+±）的叠加**：两者会相乘（浏览器缩放改的是 CSS px 大小）——
   这是标准行为；若出现"双缩放"观感，说明该加限幅（同第 1 条）。
3. **兵牌三档的具体数值**（28/32/36）是我按"步兵明显窄、骑兵居中、器械维持"的直读定的；
   要更明显的区分（如 24/30/38）改 CSS 三行即可。
4. **清单只在行军抵达时弹** —— 若玩家关闭清单又关闭战场，入口是「公文 · 战报页」
   （战斗仍在按 battleSec 自动推进）。要不要在顶栏加"待指挥 N"角标？（本轮未做）
5. **`r.replay`（关键帧数据）保留在档**：UI 板块退役但数据仍生成（测试/探针在读，≈800B/场 ·
   上限 60 场 → 最多 ~48KB）。若确定不再需要"逐回合复盘"，可整条退役（`replayFramesOf` + 3 条断言）。
