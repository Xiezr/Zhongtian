废土·余烬纪元 · 英雄（将领）肖像 prompt（v2 · 重做版）
========================================================
用途：出英雄半身像，供招募随机分配。风格：废土·余烬纪元。
配套：docs/出图prompt/ 其它批；后处理 .workbuddy/tools/asset/portrait_pool.py。

本版含**三条经验教训**（上一批踩的坑）→ 直接决定 prompt 怎么写。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一、目标分类（**按实际人物特征**，出图时就按这个控制）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
两个维度：**性别**（男 m / 女 f）× **头部型**（三选一）：

| 头部型 | 特征 | 出图要点 |
|---|---|---|
| **human 人形** | 露出人类脸（幸存者/军官） | 正常人脸，废土装束 |
| **beast 兽首** | 动物头（狼/狐/虎/熊/蜥/鸟…） | 拟人兽首，同款废土装 |
| **mecha 机甲重甲** | 脸被遮（全盔/面罩/金属脸/赛博） | 头盔或金属面，无人类五官 |

> ⚠ 上一批我把"机甲重甲"错标成"变异(mutant)"——实际绝大多数是**动力甲/全盔/赛博脸**，
> 不是生化变异。本版叫 **mecha**，出图时明确"face hidden by helmet/visor/metal"。

**性别判定**：人形看脸/体型；兽首看体型与装束；机甲看轮廓与配色（默认男，除非明显女性身形）。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
二、经验教训（上一批的坑 → 本版对策）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
| # | 坑（上批实况） | 对策（写进 prompt） |
|---|---|---|
| 1 | **左上角被写上角色名**（江河/铁弩…） | 硬负面：**ABSOLUTELY NO TEXT**（名称/标题/标签/编号/签名/logo/字母/汉字）；且**顶部不留空**（名字就写在空背景上） |
| 2 | **背景是渐变**（暗角/过渡）→ 没法抠 | 硬约束：**SOLID FLAT 纯色背景、无渐变无暗角无投影**（建议 `#f2f0ee`） |
| 3 | **2×2 图集有串格**（上一格的下巴/头发漏进来） | 要么**单张出**（最稳）；要么图集**格间留宽缝**、每格**内容内缩**、prompt 明令"不跨格不裁切" |
| 4 | 人物**贴边/顶边**，边缘像被切 | **人物填满画幅但四周留一线边**（头顶近上边、但别顶死）；胸下干净截断 |
| 5 | 性别/风格**混杂**，不好分类 | **每张 prompt 明写性别 + 头部型**（见下"分型模板"） |

> 核心一句：**上批的问题是"没把约束写死"** —— 文字、背景、构图、串格，全靠 AI 自觉，就翻车。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
三、分型 prompt（每条都带：纯色底 + 无文字 + 填幅 + 性别+头部型）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
**公共技术块（每条必带）**：
```
Half-body bust portrait, head to mid-chest, cleanly cut at the chest, figure fills the
frame (top of head near the top edge, small even margin all sides), slight three-quarter view.
Refined semi-realistic game art, NOT anime, NOT cartoon, NOT glossy 3D.
Warm muted desaturated wasteland palette (gunmetal / rust / brown / antique gold),
warm key light from the upper left.
SOLID FLAT light warm-grey background (#f2f0ee), NO gradient, NO vignette, NO scenery, NO shadow.
ABSOLUTELY NO TEXT: no name, no title, no label, no number, no caption, no watermark,
no signature, no logo, no letters, no Chinese characters. One person only, no border.
```

**① 人形（男/女）**：
```
<male/female> wasteland survivor/commander, human face clearly visible, weathered skin,
scars, worn military/scavenged clothing, goggles or mask resting on the head/neck.
+ 公共技术块
```

**② 兽首（男/女）**：
```
<male/female> anthropomorphic beast-headed wasteland warrior (species: <wolf/fox/tiger/
bear/lizard/bird>), animal head with expressive eyes, wearing the same worn scavenged
armor/clothing, gritty battle-worn look.
+ 公共技术块
```

**③ 机甲重甲（男/女）**：
```
<male/female>-build heavy wasteland power-armor trooper, FACE HIDDEN by a full helmet /
visor / metal mask (no human facial features), bulky welded scrap-armor plating,
hydraulic neck seals, cold desaturated metal.
+ 公共技术块
```

> **英文即用**；中文版同理，把三条硬约束（**纯色平底 / 绝对无文字 / 人物填幅**）原样保留。

**四格批量版**（省成本，但注意坑#3）：上面每条前加
```
2x2 grid of 4 DIFFERENT portraits, wide clean gutters between cells, each portrait
fully inside its own cell (no bleed, no cropping, no crossing cells), each cell a
separate character. Plain #f2f0ee including the gutters. No dividing lines. No text.
```
并逐格写清 `<角色n>: <性别> <头部型> <一句话>`。

四、出图后怎么用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 存 `assets/icons/英雄及头像/`
2. 跑建池：`python .workbuddy/tools/asset/portrait_pool.py`（或只裁切版）
3. 分类标签沿用 **性别(m/f) + 头部型(human/beast/mecha)** → 写 `tags.json`
4. 游戏侧：招募时按 性别+头部型 从池里随机分配（改 portraits.js / domain.js）

五、一句话总结
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
