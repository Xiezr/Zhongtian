二、经验教训（每条都踩过）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### ★ 最重要：简单的事别搞复杂
- **裁切就是"裁白边 + 放大"**。我一度做成"地面填充/软抠底/无缝混合/凸包"，绕了十几轮。
  → **用户给了具体简单指令，照做且最小化。**

### ★ Prompt 必须把约束"写死"
出图 prompt 的坑（上批全踩过）：
| 坑 | 对策 |
|---|---|
| 左上角被写角色名 | **ABSOLUTELY NO TEXT**（名称/标签/编号/字母/汉字） |
| 背景是渐变 → 没法抠 | **SOLID FLAT 纯色底**，无渐变无暗角 |
| 2×2 图集串格 | 单张出，或**宽缝 + 内容内缩 + 明令不跨格** |
| 人物贴边像被切 | **填满画幅但四周留一线边** |
| 性别/风格混杂 | **每条明写 性别 + 头部型** |
- 一句话：**没写死 = 全靠 AI 自觉 = 翻车。**

### ★ 素材要"地面材质"不是"物体"
- 地形贴图败在：旧素材是"土立方/一丛树/一座山"（**物体**），铺到菱形格上四角露白、像浮物。
- 正解：**俯视、均匀光、edge-to-edge 铺满整格的材质**。

### ★ 分类按"实际特征"，别照旧标签
- 上一批把"动力甲/全盔/赛博脸"错标成"变异(mutant)"——实为**机甲重甲(mecha)**。
- 正解：**性别(m/f) × 头部型(human 人形 / beast 兽首 / mecha 机甲重甲)**。

### ★ 别用"色块遮掩"去名字
- 用背景色涂/凸包/修补去左上角名字，**都留印或伤了头部**（名字压渐变、紧贴头发，无解）。
- 正解：**从源头出图时就不要名字**（prompt 写死），别事后修。

### ★ 换皮方法论（可复用）
- **同名原地覆盖**（不改文件名 → 零代码改动、`bitmaps.js` 逐字节不变）。
- **装前门禁**（不合格只浪费一次出图，不污染线上）。
- **快照可回滚**（每批独立，坏了只回滚该批）。
- 判据镜像 `smoke-test.js` 的像素断言（色散/尺寸/两两不同）。

### ★ 技术坑
- **改图集/贴图后浏览器缓存旧图** → 手动 bump `index.html` BUILD + `?v=`。
- **图集命名/象限要规范**：单张 vs 2×2 混用，且无统一后缀标记，导致反复误判。
- **改 `HH`/几何常量后**要同步所有派生（`diaBox` 高度写死 `cell/2` → 拉高后"横切一刀"）。
- **别在跑长后台任务时改同一目录**（后台覆盖了前台成果）。
