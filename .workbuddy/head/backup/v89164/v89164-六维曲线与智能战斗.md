## ① 六维曲线（数值设计 · 定稿）

**分段减半折线**：每 **150 点**一段，段内率逐段减半，总量收敛于"首段满值的 2 倍"：

```
段 0（0–150）    ：1.0%/点  →  满段 +150%          ← 与旧线性一字不差（老档体感不变）
段 1（150–300）  ：0.5%/点  →  累计 +225%
段 2（300–450）  ：0.25%/点 →  累计 +262.5%
段 3（450–600）  ：0.125%/点→  累计 +281.25%
…                              →  收敛 +300%（内政系）
智谋系同构（首段 0.5%/点）     →  收敛 +150%（研究/城防）
```

样本：**150→+150% · 200→+175% · 300→+225% · 500→+268.75% · 836→+293.31% · 极限 +300%**。
落地：`DATA.MAYOR_CURVE`（seg 150 · maxK 20）+ `GAME.curveBonusOf` **唯一出口**；
五项（产量/建造/税收/研究/城防）全走曲线；三处消费端的"二次截断"（min 1.5 / min 1.0）**退役**
（曲线自带边界 —— 老口径"封顶 +150%"被曲线替换，836 从 +150% 提到 +293%，但永远不会回到 ×9 量级）。

## ③ 智能战斗系统（通用战斗方案 · 逐回合）

### 方案（`DATA.SMART_PLAN`）

**静态目标表 + 逐回合姿态规则**（扫参标定 · 非拍脑袋）：

```
目标表（相克账）：
  长枪 → 轻骑（打骑 ×3 · 挨骑 ×5）      刀盾 → 弓（防射 ×3 顶箭冲 · 弓防最低）
  藤甲 → 长枪（防高扛枪阵）              弓/投石 → 弓（对射）     床弩 → 器械（×3）
  骑族（6 种）→ 弓（骑防远程 ×2~×4 · 冲散后排火力）
姿态规则（逐回合动态）：
  远程：进自身射程 → 转「防御」（受创减半 · 照常开火）
  骑/步近战：距敌前军 ≤ 250 → 转「防御」（结阵/缠斗）；拉开后自动转回「前进」
```

- **执行点** = `stepBattle`（推进唯一出口）→ 每回合 step 前改写指令 → 落 `rec.cmd` → 进 history
  （**重放 / 读档 / 沙盘校验逐回合一致**，与玩家手改指令同一条链）。
- **只托管我方攻方**（守城侧有城墙/固守体系，不掺和）。
- **开关**：出征 / 自动出征面板「战术」下拉首项「⚡ 智能战斗（通用方案）」，**默认开**；
  选任何其他项 = 关（回到手动战术）。战场顶栏有「⚡ 智能」指示（攻方才显示）。

## 诚实缺口

1. **双智能对撞会退化为"互相等先手"的对峙**（0:0 打满 30 回合）——当前 NPC 永远全前进，
   实战不受影响；**若将来让 NPC 也托管，需要配套破局规则**（探针里已有该用例兜底）。
2. **智能默认开**：玩家手改的指令会在下回合被托管覆盖（要自定义请在下拉里关智能）。
   若您希望**默认关（手动opt-in）**，改 `smartOnOf` 一处即可。
3. 器械打造时长未动；曲线与智能的数值如需再调，各有单一常量/表位置（文档已标）。
