# v89.213 —— 分页条改「整体居中」，不再分散至两边

> 老板原话：「底部导航栏有隐藏名称，指挥战斗菜单，；商场等多页码页面，页码集中在中部，
> 不要分散至两边，导致和其他菜单重叠住了」

**一句话**：v89.204 的三栏 grid 把分页按钮推向条两端——底栏里左栏按钮压进
「🏷 隐藏名称 / ⚔ 指挥战斗」**重叠 95px**（按钮被盖住、点「首页」实际点到「隐藏名称」）。
本轮把 `.pager` 改成**整体居中 flex**（分页控件作为一个整体排在中轴），并对称化底栏
padding，让内容轴回到屏幕正中。

---

## ① 病根（实机实测 · 改前基线）

| 量（画布坐标） | 改前数值 | 判读 |
|---|---|---|
| 分页条首按钮「« 首页」左缘 | 102 | 完全落进 `.bb-tools` 区域（10~197） |
| **首按钮左缘 vs bb-tools 右缘 = +95px** | 重叠 | bb-tools 绝对定位（画在上层）→ **分页按钮点不到** |
| 条体左缘 vs bb-tools 右缘 | +105px | 条本身也压过去（左侧从未留白） |
| 右侧（v89.204 留的 52px） | -24px | 右侧当时避开了缩略图 |
| 内容盒中轴 vs 屏幕中轴 | 760 vs 720 | 底栏 padding 左 92/右 12 不对称 → 居中内容右偏 40px |

## ② 改法（三段 · 只动 CSS）

| 段 | 改前 | 改后 |
|---|---|---|
| `.pager` 排布 | `display:grid; grid-template-columns:1fr auto 1fr`（前导/页码/后导推向两端） | **`display:flex; justify-content:center; flex-wrap:wrap; width:100%`**（整体居中） |
| `.pg-side.l/.r` 方向性 justify + `only-child` grid-column | 3 条规则 | **删除**（flex 下天然居中） |
| `.bottombar .pager` margin | `0 52px 0 0` | `0`（不再满行铺开，右留不再需要） |
| `.bottombar` padding | `0 var(--sp-mid) 0 92px`（不对称） | **`0 92px`**（对称化 → 内容轴回屏幕中轴） |

DOM 结构**不变**（l → 页码 → r 顺序保留）——翻页动作、断言选择器、e2e 全零改动面。

## ⑤ 诚实缺口

1. **页码文本本身在块内偏右约 36px**（底栏）：整体居中后，l 组（4~7 按钮）比 r 组（2 按钮）宽，
   「第 1/2 页」文本落在块内偏右位置。这是"整组控件居中"的自然结果——若您要
   "页码文本绝对居中、左右按钮严格对称"（右组补等宽占位），一句话可调。
2. **弹窗场景无重叠对象**，本轮同步改为整体居中只为"两个出口同款"；其像素对照
   （首列 366→516）为"两端收进中部"的证明，非缺陷修复。
3. 历史脚本 `shot_v89204_gates.js` 的两条"页码居中"判据已按新口径更新
   （内容块居中），它测的是 v89.204 的版面标准在新布局下的等价形态。
