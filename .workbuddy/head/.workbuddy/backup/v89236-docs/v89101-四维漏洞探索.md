## 0. 结论先行（六条）

1. **轻骑兵是事实，铁骑兵也是事实——但"同成本对撞轻骑完胜铁骑"**：1500 轻骑（615 万资源）5 回合全歼 683 铁骑（同价）；铁骑的价值在"低绝对战损"（攻 Lv4 据点损 47 vs 轻骑 94），不在性价比。**批量能力**：50 万金可立即成军 轻骑 609 / 铁骑 277 / 义兵 6410 / 长枪 2380 / 投石 85。
2. **"有粮有钱，再造兵岂非轻而易举"——实测成立**：金直接买训练时间（20% 资源价值），**57.4 万金买断 5.83 年**→700 轻骑立等入列；54 万金→300 铁骑。训练时间不再是人力的墙，只是黄金的价。
3. **城流 = 跨越式主发动机（本轮的核弹）**：筑城**无数量上限、无人口门槛、即时落成**，成本仅"粮木石铁金各 1 万" + 一块已占平原；**附近 61×61 格内可筑平原 1233 块**；实测连建 8 城→9 城，建造并行度 3→27 条。城市数 = 并行建造 × 人口上限 × 税收 × **爵位门票（第 N 档需 N 城）**，是唯一的乘法杠杆。
4. **金能买到的"不可逆"有明确天花板**：丹药（+50/维，100 万金；第 51 颗实测被拒）、内功绝学（10 重封顶，16 万金 +60/门）、资质链（种子 54 万金 + 秘境 48 游戏时/株）。**买不到的两样**：**节钺**（只认首占名城：县+1/郡+2/州+3/都+5）与**名城本身**（县城守军当量 **1.16 亿**，18.75 年不可及——磨城可到 0 但决战门槛 3584 万）。
5. **据点 = 无限日常引擎**：26 格内 **246 座**据点，**每日重生**（`fortRazedToday` 只挡当天）；实测单座奖励：掠夺掉落全表（材料/珠宝/种子/资源，见 §4）+ 磨城下城 **声望 +30/座**。声望→爵位、掉落→金/材料，天天可刷。
6. **行内实跑（新 span 模式，四轮校准）**：**9 城 / 27 条建造并行 / 0 错误**（对照 rushH 3 城）——城流在真跑里达成 3× 基线；但**军事更薄**（军 1028 vs 4198）暴露了下一个瓶颈：建造队列吞吐 + 人口涓流。四轮校准的完整暴露链见 §6。

## 3. 位维 · 爵位与节钺

- **爵位每档：城池 N + 声望 + 金 + 珠宝**（每档翻倍）：公士（城2·1000·2万·珍珠10珊瑚5）→ 上造（城3·2000·4万）→ 簪袅（城4·4000·6万）→ 不更（城5·8000·8万）→ 大夫（城6·1.6万·10万）→ ……
- **晋升实测**（沙盘 · 9 城）：`canPromote` 通过 → **公士 → 上造**连晋成功，永久特权入账。
- **节钺**（黄金买不到）：首占名城 县+1/郡+2/州+3/都+5；**爵位每 4 档 +1**。用途：名世→天授 1 枚；开府扩编（建造位 +1，每城至多 2 次）。
- **门槛联动**：城数（城流）→ 爵位 → 节钺/特权 → 更多城市容量 —— 这是一条**自我强化的不可逆环**。

## 4. 世维 · 城流 / 据点 / 名城

### 4.1 城流（跨越式主发动机）· 全部实测

| 项        | 实测                                                           |
| -------- | ------------------------------------------------------------ |
| 筑城条件     | 一块**已占的平原**（先派军 occupy）+ 粮木石铁金**各 1 万**；**无数量上限、无人口门槛、即时落成** |

| 连建实测（沙盘） | 8 城连建全成 → **9 城 · 建造并行 27 条**（每城 3 位）                        |
| 新城市属性    | 48 格 + 城外 12 格 + 3 建造位 + 民房上限 200 + 启动物资 6000×5 + 人口 100     |
| 复数意义     | 城数 ↑ = 建造并行 ×N · 人口上限 ×N · 税收 ×N · **爵位门票**（第 N 档需 N 城）      |

### 4.2 据点（无限日常引擎）

- 26 格内 **246 座**（Lv8~10 为主：85/66/72）；**每日重生**（razed 只挡当天）。
- **掠夺掉落采样**（Lv4 落雁关 · 3000 轻骑 · 4 回合险胜损 127）：  
  `粗葛+7 麻布+7 凡植种子+1 珊瑚+2 凡铁+7 松木+7 河石+5 兽筋+5` + 粮+2.0万 木+1.6万 石+1.1万 铁+8796 金+1.1万。
- **磨城**（占领至下城）：Lv2 据点 2 波下城 → **声望 +30**；同日不再出现（次日恢复）。
- 数学：任一点位 **7~10 波磨到守备 0**（破防保底 10~15%/波 + 围困 ×1.5）。

## 5. 跨越式复合路线图（把四个维度叠成一条时间线）

```
第 0~1 年  军链金提速：官府→军营(7)→马厩(3)→书院(6) 全链抢建（单次提速实测仅 ~900 金）
           + 金提速成军：57.4 万金 → 700 轻骑立等入列
第 1~3 年  占平原 → 即时筑城刷城（5 万/座）；城数爬爵位（城 2/3 → 公士/上造，永久特权）
第 3~10 年 据点日刷：掠夺（材料/珠宝/金）+ 磨城（声望 +30/座）→ 声望喂爵位
           + 内功绝学/丹药买穿（金→永久四维）
第 10 年+  城 5~9 座 → 建造并行 15~27 条 → 民房→人口→骑兵规模 → 扫荡 Lv6-7 据点
           → 冲县城/节钺（长线）
```

**不可逆清单**（做过就永久）：城市（容量）、爵位（特权）、资质（+18）、丹药（+200 四维）、内功（+240）、节钺（制度资产）、据点战果（声望/掉落日日复利）。

## 6. 行内实跑（新 span 模式 · 四轮校准 · 全部 0 错误）

在推演脑上新增 `span` 模式（城流跨越：筑城刷城 + 轻骑批量 + 军链抢建），同 seed（20260922）1× 全跑 18.75 游戏年：

| 轮次        | 暴露的瓶颈                                                                             | 修复                        |
| --------- | --------------------------------------------------------------------------------- | ------------------------- |
| span1     | 军链 16 年才开（junying Lv2→3 卡 3.2 游戏年）；无骑兵；城 6                                        | 军链金提速（阈值 4.5 万）           |
| span2     | 提速**从未触发**——排查发现队列字段是 `gridIndex`（非 idx）                                          | 修正字段 + 阈值 1.2 万 + 放开生产宝物线 |
| span3     | 提速生效但仍慢 9 年——**根因：官府总闸**（建筑等级 ≤ 官府等级）                                             | 全链抢建：官府→军营→马厩→书院 各轮全试     |
| **span4** | **9 城达成**（目标 maxCity）；骑兵自 y10.6 成军（402 次批次，被人口上限压成 ×1~×28）；**军力更薄（1028 vs 4198）** | 下一迭代：队列全提速 + 人口/训练配比（§7）  |

**span4 终局 vs rushH（同 seed 对照）**：

|      | rushH（军事流） | **span4（城流）**  |
| ---- | ---------- | -------------- |
| 城池   | 3          | **9**          |
| 建造并行 | 9 条        | **27 条**       |
| 军力   | 4198       | 1028           |
| 爵位   | 上造         | 上造             |
| 建筑和  | 401        | 335            |

**诚实结论**：城流的"容量语法"已在行内跑通（9 城/27 队列/0 错误），但**军事转化率**被两个老瓶颈拖住——① 建造队列吞吐（3 位/城 × 建造时长，军链升级排队数年）；② 人口涓流（每城 4~~9 人/游戏时，骑兵被压成小批次）。这与沙盘（§1~~4 全部机制可即时达成）的差距 = **自动脑的调度问题，不是游戏限制**。

## 7. 下一迭代探索队列（无限探索 · 未竟清单）

4. **扩展兵种条件破解**（青州/藤甲/突骑/虎豹/西凉/象兵的 city+tech 条件到底是什么）。
5. **辎重车物流**（load 5000）与**多城资源调运**（城流后资源分布碎片化）。
6. **据点日刷循环进脑**（掠夺→磨城→次日重刷的 246 座循环调度）。
7. **`span` 双跑对照**（轻骑流 vs 铁骑流两个 seed 的配对统计——单跑路径分叉噪声大）。
8. **爵位-节钺环**：城数→爵位→每 4 档节钺→开府位——把 22 档表推完。
