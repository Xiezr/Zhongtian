## 0（答：是封顶值，附三条调整路子）

城主的内政 → 产量 / 建造 / 税收都是 **`min(1.5, 内政×0.01)`** —— **封顶 +150%**，
**内政 150 点即顶格**（您 836 也只按 150 算）。上限是 v89.93 整改时定的
（当时守卫 nz 980 → 产量 ×10.8 的失控案例；六项收益统一封顶：产量/建造/研究 +150%、城防 +100%）。

想调整有三条路子（**等您拍板**，都是一处改动）：

| 路子 | 效果 | 代价 |
|---|---|---|
| ① 提高封顶（如 +300%） | 内政 300 点内继续线性受益 | 一处常量；数值 ×4 量级 |
| ② 取消封顶 | 836 → 产量/税收 ×9.36 | 回到 v89.93 前的失控量级，需重估 GOLD_GATE 等 |
| ③ 曲线（超 150 后 0.3%/点） | 成长感与可控兼顾 | 一个小公式改动 |

## 1 指挥战斗清单 =「两段一门」（落地）

底栏「⚔ 指挥战斗」清单从"只有待指挥战斗"扩为**两段一门**：

| 段 | 列 | 操作 |
|---|---|---|
| ⚔ 战斗待指挥 | 目标 / 战斗类型 / 是否观战 | 👁 观战（原样） |
| 🛫 行军中的军队（新） | 军队 / 主将 / 兵力 / 行军进度 | 🏳 召回（复用 `march-recall`） |

- **只读出口**：`ui.battleListOf`（战斗 live）+ `ui.marchListOf`（s.marches）——两段各自唯一；
- **召回宿主跟走**：清单里点召回后**原地重绘本清单**（`.war-list` 探测），
  改前硬编码 `openMarches()` 会把人弹到"行军队列"弹窗；
- **幽灵行防护**：弹窗已开着时两段全空也原地重绘（显示"当前没有…"空态），
  不留已召回的行、不误 toast；未开着且两段全空 → 只 toast「当前没有待指挥的战斗与行军中军队」；
- 两段都空时按钮不闪烁（闪烁判据仍是"有战斗待指挥"——行军不需指挥）；
- 抵达自动弹（`onMarchArrive`）与底栏按钮**共用本出口** —— 一份清单，两处入口。

**实机证据**（`v89163-war-list.png`）：1 场战斗 + 2 支行军 → 「⚔ 战斗待指挥（1）」
「🛫 行军中的军队（2）」两段齐全；点召回 → marches 2→1、弹窗**仍是清单**、M1 行消失无幽灵。

## 2 征兵时长压缩（落地）

`time` = **单兵训练时长（游戏秒）**——兵种卡悬停「单兵耗时」显示的就是它；
一批总时长 = time × 数量 ÷（科技/守将/专精等加速）。按**原排序**压缩并取整到 5 秒：

| | 改前（秒） | 改后（秒） | | 改前 | 改后 |
|---|---|---|---|---|---|
| 义兵 | 20 | **10** | 突骑兵 | 270 | **60** |
| 民夫 | 40 | **15** | 虎豹骑 | 385 | **70** |
| 斥候 | 90 | **20** | 轻骑兵 | 480 | **80** |
| 青州兵 | 115 | **25** | 辎重车 | 970 | **110** |
| 长枪兵 | 140 | **30** | 西凉铁骑 | 1160 | **125** |
| 藤甲兵 | 170 | **35** | 铁骑兵 | 1450 | **150** |
| 刀盾兵 | 210 | **40** | 南疆象兵 | 3500 | **300** |
| 弓箭手 | 340 | **60** | | | |

- **步兵（inf）全部 ≤ 60（1 分钟）· 骑兵（cav）全部 ≤ 300（5 分钟）** ✓
- 器械（床弩 2910 / 冲车 4370 / 投石车 5830，craft）不属"征兵"，**未动**；
- 换算：120× 下练 100 个弓箭手 = **50 现实秒**；100 铁骑 = **125 现实秒**（约 2 分）。

**实机证据**（`v89163-train-time.png`）：悬停弓箭手卡「人口 2 · **单兵耗时 1分**」；
义兵卡「**单兵耗时 10秒**」。

## 诚实缺口

1. **第 0 条是问答**，上限仍为 +150%（未动）；按您选择的一条路子改，一处即可。
2. "步兵 1 分钟 / 骑兵 5 分钟"按**单兵耗时（游戏秒）**口径执行——若您指的是别的刻度
   （如"一批 100 个的现实时间"），数值需再调（当前两口径恰好都 ≤ 限：100 弓 50 秒 / 100 铁骑 125 秒 @120×）。
3. 器械打造时长未动（"征兵"不含打造）——如也要压缩说一声。
4. 指挥战斗清单的行军段不分页（全军正常规模 <10 支）；若远征多线并发超过一屏再加折叠。
