## 一、A2 · 离线归来报告（分类弹窗）

**痛点**（100+ 轮实玩实录）：离线 10 小时归来只有 msgLog 滚动几十条；资源/建造/研究/月俸/事件全混在流水里。

**实现**（`state.js` + `ui.js`）：
- `GAME.offlineCatchup` **补算前后快照**（纯读取，不碰任何结算逻辑）→ 归集 `GAME._offlineReport`：
  - `res`：五项资源全城合计**净变**（含产出、俸禄、战利品、超限五折折算）
  - `done`：build/tech/train **队列完成数**（前后条数差）
  - `reports` + `reportsN`：新增战报标题（前 6 条 + 总数）
  - `wounded`：伤兵净变 · `marchMsg`：离线行军抵达消息
  - `secReal/applied/overflow/capDays`：时长与**推进上限说明**
- `ui.offlineReportHTML()` + `ui.openOfflineReport()`：分类弹窗（资源净变 / 在办完成 / 战报与事件 / 军务）。
- **触发**：`ui.enterLoaded`（主档与槽位读档共用入口）里 `off >= 60` 秒自动弹；原 toast 保留为轻提示。
- **不进存档**：会话级展示物（下次归来必有一份新的）。
- 探针实测：1800 秒补算 → 资源净变 +13609 粮、建造完工 1 项入账；240 小时超限 → `overflow=858960`、报告写明"五折折算"。

## 四、C3 · 门派晋升曲线校准（老板拍板：加来源 + 重估到 2-3 个月）

**痛点**：声望唯一来源 = 门派任务（杂役 480/日封顶）→ 长老（30 万 rep）= **625 天现实时间**，长线玩家永远够不着。

**实现**：
- **新来源 · 开疆拓土**（门派系统规则 §六"占城"一条落地）：占城一次性给门派声望，按城档分：
  `DATA.SECT_CONQUER_REP = { county: 1500, jun: 4000, zhou: 12000, capital: 30000 }`（挂在 `onConquer`，与君主声望各记各的）。
- **唯一出口** `GAME.sectRepGain(src, n)`：门派声望**唯一发放口**（门派系统规则 §六："全部走 sectRepGain"）——
  `doSectTask` 与 `onConquer` 同源；未入派自动拒；返回 `rankUp`（本次跨阶名）。
- **门槛重估** `DATA.SECT_RANKS`：`0/2000/12000/60000/300000` → **`0/1000/6000/25000/60000`**。
- **可达性实测**（探针）：
  | 路径 | 长老达成 |
  |---|---|
  | 纯杂役（480/日） | 125 天 |
  | 带 10 城占城（+20000） | **84 天** ✅ |
  | 活跃（20 城，+50500） | 20~45 天（占城渐进则自然拖长） |
- **UI 透明**：门派面板补一行「声望来源：门派任务（每日）· 开疆拓土（占城一次性入账）」。
- **回归**：`doSectTask` 改走出口后行为逐字节一致（12 / 开山祖师 ×1.5=18 / 跨阶文案），smoke 全绿。

> ⚠️ **影响提示**：长老从此前的"天文数字"变为 2-3 个月目标；中阶（外门/内门/真传）也相应提速（1000/6000/25000）。
> 若觉过快/过慢，回调旋钮：`DATA.SECT_RANKS[4].rep`（长老线）与 `DATA.SECT_CONQUER_REP`（占城权重）。

### 测试非确定源治理（本轮新发现 · 重要）

**现象**：终态门禁 smoke 出现 `2477/1`（1 处失败无头绪），12 连跑不复现；
随后定位期间**再次复现**并抓到实证（失败断言 = `v89.87（派兵）：采集走行军`）。

**根因一（主根因）**：`mapSeed = U.now() % 100000` 是**毫秒时间戳** ——
每次 run 的**地图布局 / 出生点 / 野地分布**都不同 → "在地图上找格子"类断言随布局**偶发假红**
（上述失败断言的核心逻辑正是在 `(7..11)²` 范围找一块干净格）。
**修法**：`newGame` 支持 **`mapSeed` 注入**（与 `portraitSeed` 同一先例；未注入时行为零变化），
smoke/e2e 全域钉黄金 seed **20260921** → 修复后 **12 连跑全绿**（修复前 ~1/3 复现率）。

**根因二（次根因）**：`STORY.rollWeather` 用 **Math.random** 重掷天气，触发点两处：
① `newGame`（建局即随机：实测 8 局 = snow/clear×3/rain×3/fog）；
② 游戏内每 1/4 游戏年（= 120 真实秒 @120×）自动换天气。
雨/雾/雪改战斗与产量口径（弓兵射程 −20% / 粮产 −15% / 行军 −20%）→ 天气敏感断言偶发假红。
**修法**：smoke/e2e 全域钉天气为「晴」（测试环境包装 `STORY.rollWeather`，产品零改动；
需要测天气效果的用例仍可直接赋值 `s.world.weather`）。

—— 两条合起来 = **"把随机源钉在测试入口"**：v89.88"逐条钉天气"的**根治版**。

## 九、复验指引（试玩）

3. **一键全领**：任务页「✅ 可领取奖励」块右侧 → 点「一键全领」。
4. **战报检索**：公文页战报区 → 点 `⚔️败` 筛选 → 点任意行 ☆ 收藏 → 切 `⭐收藏` 查看。
5. **故事集**：史册页底部「📖 故事集」→ 点任意已读篇目重读。
6. **人口三段条**：兵营招募页（步兵/骑兵页）底部工具条 → 看可征/上限/增势。
7. **门派晋升**：占一座城 → 看门派声望 +1500（县城）与日志「🎋 门派声望 +1500（开疆拓土）」。
