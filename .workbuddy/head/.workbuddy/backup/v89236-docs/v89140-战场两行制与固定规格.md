## 2. 关键设计论证

### 2.1 距离为什么是 ×1.25（而不是别的数）

老板问"最远射程乘以某个系数？合理设计"。取 1.25 的依据：
- **与旧口径同量级**：弓 1200 → 1499(旧 +299) vs 1500(×1.25)；投石 1600 → 1899 vs 2000。
  老玩家对"开战间距"的直觉不被推翻；
- **任意射程下成立**：+299 是绝对值（射程 200 时它占 60%，射程 2000 时只占 15%）；
  比例式在任何射程下都同比例缩放 → 不用再解释"为什么是 299"；
- **三下限不变**：`max(FIELD_MIN(1400), maxR×1.25, 速度和×2)` —— 近战仍吃 1400/速度项。

### 2.2 自动出征：从"总量顺位"到"逐兵种"

- 域侧 `autoMarchPickArmy(city, want, cfgArmy)`：**给了 cfgArmy 就逐兵种取**（`min(配置, 城内实有)`）；
  **没给就退回顺位口径**（老档与"未配置"时行为与改前一致，不会突然不出征）。
- `autoMarchWant` 同步：`want = Σ cfg.army`（有配置时），否则退回 `cfg.troops`。
- 键走 `army:<tid>`（`doSetAutoMarch`），界面不自己拼 cfg（保留唯一出口）。
- 实测：配置只带长枪 500 → 出兵只有长枪（其余 0）；老口径 300 → 顺位取 300 ✓

### 2.3 夜明珠"所有野地"的边界

- 放在 `gatherJewelPick` **最前**：命中珠宝后先掷 `jewelAnywhereP`，命中即改判为夜明珠；
- **平地仍无珠宝**（`jewelTable` 无该地形条目 → 直接 return null）—— 保住原版"平地不可采集"铁律；
- 数量仍按野地等级（`1+⌊lv×0.2⌋`），所以高级野地出得更多。

## 4. 诚实缺口

1. **宝物"整叠使用"能力丢失**：格子化后没有数量输入框，点击 = 使用 **1 个**（e2e 断言同步改为"用掉 1 个"）。
   若要整叠使用，建议在格子上加"长按/右键 → 数量小窗"（约 60 行）—— **等您一句话**。
2. **战场记录框是"弹性理想值"**：`flex: 1 1 250px` 在有富余时仍会撑到 425px（已比改前 493 矮）。
   若要硬钉 250px，需改 `flex: 0 0 250px`（代价：12 兵种极端载荷时可能又溢出）—— 现状是平衡点。
3. **`stepsToWall` 与 `FIELD_MARGIN` 常量并存**：新口径已不吃 MARGIN，但常量仍被攻城类断言引用（保留为历史口径）；
   彻底清理需一并改 4 条断言（无功能影响）。
4. **军务总览的"合计"列**：老板说"在城 XXX这行也去掉"，我按"顶部统计行"理解并删除；
   表格里保留了"合计"列（否则看不到总数）。若您指的是这一列，一句话即可去掉。
5. **已出征将领"派去第二处"**：同一将领**不能同时在两处**（数据会错乱：v89.136 的"驻将丢失"就是这类）。
   现在的行为 = 下拉里可见但置灰 + 注明"驻守野地/征战中"；名册可点开属性与装备（本就可操作）。
   若您要的是"召回后改派"，那是既有能力（召回 → 重新出征）。
