## ① 蕴养同款（照百炼专属界面重做）

**病根（一句话）**：v89.201 把百炼强化改成了"xxl 网格卡 + 点选 + 底部唯一键"的专属界面，
**蕴养（修炼装备强化）仍是 v88 的单列小窗**（lg + 每行一颗「蕴养 +N」键）——两套平行体系观感割裂。

**改法**：

| 面 | 改前 | 改后 |
|---|---|---|
| 布局 | 单列列表（lg 小窗 · .enh-row 家族） | **3 列网格卡片**（品阶图 + 名称·序号 + 品质 + 大号 +N/上限 + 下级成本） |
| 操作 | 每行一颗「蕴养 +N」键 | **点选（ling-pick）+ 底部唯一蕴养键**（与百炼/打造同款形态） |
| 筛选 | 无 | 全部 / 未满 / 圆满（chips 带计数） |
| 档位 | lg (860×600) | **xxl**（1200×850） |
| 分页 | 无 | 15/页（`ui.LING_PER_PAGE`） |
| 实时 | 静态 | live 每秒刷新（灵气精华随采集/游历即时变） |
| 滚动 | — | 操作后 `ui.reopenKeepScroll`（滚动位保留 · v89.201 机制） |
| key 出口 | — | **复用 `ui.enhKeyOf`**（uid ?? id · 两体系同一把尺，不另造） |
| 旧单列 | .enh-list/.enh-row/.enh-nm/.enh-tag/.enh-cost | **整族退役**（CSS 同步清 + 墓碑注释） |

**实测（实机 `shot_v89202_gates.js` ①）**：3 网格卡 · 3 筛选 · over=0；
真点卡片 → 底键「☯ 蕴养 +1」→ 真点 → 该件 **+0→+1**（选中保留）；

## ③ 「按建议进行」= 收藏「达到过即永久解锁」（清 v89.196 遗留）

**病根（改前实证）**：收藏条件的判定读**现值** —— 物品品种被消耗（5→1）时，
**已达成过的条件重新锁上**（探针实测 met=false）。

**改法**：
- 峰值记录 `s.collectPeak`（随档）· `GAME.collectPeakOf(type, cur)` **读即记录**；
- `GAME.collectPeakSweep(force)` 每 10 游戏秒扫掠（tickOnce 挂钩）—— 玩家不打开收藏页也照记；
- `collectCondValOf` 全部 16 类条件**统一走历史最高**；
- 文案口径同步：锁定行「最高 X / N」· 藏珍阁 help「解锁按历史最高判定」· 未解锁拒绝「（最高 X）」。

**实测（探针改前/改后对照）**：

```
改前：品种 5→1 回落 → met1=false（已达成条件重新锁上 —— 遗留缺陷实证）
改后：品种 5→1 回落 → met1=true（保持解锁）· valNow(口径值)=5 · rawNow(真实现值)=1
```
