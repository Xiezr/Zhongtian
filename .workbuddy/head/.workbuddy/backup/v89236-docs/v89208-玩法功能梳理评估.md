   与 **dropOnly 族 9 件**（商城不卖 · 走掉落），二者共用唯一过滤口 `ui.shopItems()`。
6. **数值阶梯：已复核为"设计如此"而非断点**——单城满级（官府 Lv12）可出义兵 31,200，
   最高档名城守军 224,220 → **需约 7.2 座满级城**。相邻档跨度 3.8× / 3.8× / 2.0×，
   **多城是设计意图，不是够不着的墙**。
7. **经济构成：被动收入主导**——税收占新手档 100%、后期档 91.6%（岁贡补 8.4%）。
8. **玩法空白只剩一处：势力外交**（现为"州郡野城"模型，无势力间关系/外交行为）。

## ② 数据动作面【新】

**口径声明**：全站**唯一 `data-action` 值 292 个**，按关键词归属到系统（启发式）。
关键词重叠会重复计数（如 `build-*` 同时落在城池建设与城外建筑），**看量级不看精确值**。
本口径取代两个试过但不成立的口径，沿革写在脚本头部：

- ~~"case 体引用出口名"~~ —— 认不出**视图型**系统（科技是城池面板的子视图，
  动作叫 `tech-research`，体里根本不出现 `techHTML`，会把科技算成 0 入口）；
- ~~"index.html 骨架直达"~~ —— 骨架里只有 23 个静态 `data-action`，
  界面按钮绝大多数由 `ui.js` 运行时生成。

| 动作面档位 | 系统 |
|---|---|
| 20+（大界面） | 出征战斗 35 · 资质晋升 20 |
| 10~19（中界面） | 城池建设 19 · 道具材料 17 · 装备锻造 16 · 存档 11 |
| 5~9 | 纪事剧本 9 · 城外建筑 9 · 征兵练兵 7 · 野地流寇 7 · 运输补给 6 |
| 1~4 | 前哨体系 5 · 门派 5 · 种田秘境 4 · 内功修炼 4 · 战报消息 4 · 宝具挂件 3 · 爵位晋升 3 · 宝物收藏 3 · 官府任免 2 · 将领招揽 2 · 声望 2 · 沙盘推演 2 · 科技研究 1 · 战斗回看 1 · 忠诚月俸 1 · 精力体力 1 |
| **0（被动/环境型）** | **人口民房 · 来犯防御 · 奇观 · 季节天气 · 离线补偿** |

**0 动作面 ≠ 缺口**：这 5 个系统由其他面板/事件驱动——人口民房靠 `build-*`（归属城池建设）、
来犯防御靠主循环的入侵事件、奇观与季节天气是环境态、离线补偿在归来时自动弹报告。
**真正值得记的是**：它们**没有自己的"进入点"**，新玩家不会主动"去玩"它们——
这是可发现性上的固有形态，不是 bug。

## ③ 关停 / 退役 / 墓碑清单【新】

代码注释里声明"退役 / 下架 / 下线 / 墓碑"的共 **67 条**。**性质要先分清**：

| 类型 | 数量 | 实况 |
|---|---|---|
| **真退役（墓碑制）** | 约 60 | 代码已清，只留一行"去向见 xxx"注释。例：战法三选整条退役（`DATA.OPS` 墓碑）、度支归集、全境营造总览、珠宝旧 15 种、相克表、驻守直补、采集行军通道 |
| **数据在 · 入口关（noShop）** | **29 件** | 商城下架档位（v89.104 起不售 / v89.197 再下架兵仙遗篇·千古兵圣）——**仅存量可用**，掉落/任务/炼制亦不给 |
| **数据在 · 商城不卖但可掉落（dropOnly）** | **9 件** | 与 noShop 语义不同：商城不上架，但走采集/战役掉落 |

**唯一过滤口**：`ui.shopItems()`（商城页与快购都读它）——这是本仓"口径只此一份"的又一例：

```js
return it.price > 0 && !it.noShop && !it.dropOnly && !!ui.SHOP_CATS[it.type];
```

**判读**：67 处退役说明**玩法口径迭代剧烈**（这游戏走到 v89.207 已换过多轮设计），
但**处置是干净的**——退役即清代码，不留死代码，也不会出现"两个真相源"。
**风险提示（非缺陷）**：`noShop` 存量道具对**老存档**仍然可用、对新玩家不可见，
这是**有意的不对称**（"承认绝版"），但会让新老玩家的道具池不一致。

## ⑤ 五条玩法闭环核对

### 经济闭环 ✅
```
产出：民房税收（popOf/CITY_YIELD）· 官府加成（STATE_SEAT_BONUS）· 采集（GATHER）
      · 种田秘境（FARM）· 战利缴获（LOOT_BASE/NPC_CITY_RES）
消耗：建造（BUILD_GOLD）· 征兵（TROOPS）· 提速（BOOST_CAP）· 月俸（GEN_SALARY）
      · 强化/宝具合成（ENHANCE/BAOJU_FUSE）· 科技（TECH）
存储：府库三资源 + 溢出机制（OVERFLOW）· 金门槛（GOLD_GATE）· 运输（TRANSPORT）
```

**经济构成实测**（`economy_audit.js`，v68 基线 · 未计科技加成）：

| 阶段 | 自动收入合计（/游戏时） | 税收占比 | 岁贡占比 |
|---|---|---|---|
| 新手（1 城 · 官府3 · 民房×2） | 99 | **100.0%** | 0% |
| 中期（3 城 · 官府8 · 民房×4） | 3,564 | **100.0%** | 0% |
| 后期（5 城含都/州/郡 · 官府12 · 民房×6） | 26,002 | **91.6%** | 8.4% |

**读法**：金币**几乎全部来自人口自然增长**（被动收入），主动收入（战利/寄售/岁贡）只在后期
补 8.4%。三环节均有唯一出口与界面，**闭环闭合**。

### 成长闭环 ✅
```
将领：战功经验（EXP_CURVE）→ 等级 → 资质档（GEN_RANKS/RANKUP_AWARD）
      → 装备（EQUIP/FORGE/ENHANCE/SETS）→ 宝具挂件（BAOJU/ATTACH）
      → 内功重修（NEIGONG）· 精力/体力双轨（ENERGY/STAMINA）
城池：建设等级（BUILDINGS）→ 科技（TECH）→ 主城特权（CITY_PERK）
势力：声望（REP_RULE）→ 爵位（RANK）→ 城池上限 + 门派（SECTS/SECT_TASKS）
```
多线（人/城/势）各自闭环且**互相供能**。

### 对抗闭环 ✅（v89.204 补上最后一环）
```
侦查（SCOUT_INTEL/intelTiersOf）→ 出征（EXPEDITION/STANCES）
→ 战斗（TACTIC/DUEL/CLASH/箭塔/城墙）→ 占领（SIEGE 民心制 · 野地/据点/名城统一）
→ 防守（INVASION 来犯预警）→ 失城（cityFallen · 主城保护）→ 反攻（NPC 城可再打回）
```
**已闭合**：可从占领一路走到丢失再夺回。本轮复核现行代码仍按该口径
（战斗胜方使守方 −20 民心，民心 0 + 城破即被占；主城不可被占）。

### 收集闭环 ✅
```
宝具体系：据点/名城缴获（BAOJU_DROP）→ 品质合成（2 低=中 · 2 中=高）
藏珍阁：18 系 73 件（COLLECT）· 成就型条件 + 金币激活 · 峰值记录（达到过即解锁）
奇观见闻录：隐藏点位（WONDER/WONDERS）· 见闻录收录（journal）
江湖遭遇：随机事件（ENCOUNTERS）· 全屏剧本演出
```

### 时间闭环 ✅
```
季节（SEASONS）→ 产出/战事修正 · 天气（WEATHERS）→ 逐日状态
离线补偿（LOOP_GAP）：息屏/离线自动结算 + 挂起战斗自动打完（battleAutoSec）
纪事（CHRONICLE_RULES）· 纪元（ERAS/CALENDAR）· 月俸周期（7 游戏日）
```
