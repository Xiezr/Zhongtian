## 二、改法（改前 / 改后）

### ① 受阻弹窗（需求 1）——**统一机制 + 全仓接入**

**机制（唯一出口组）**：
- `ui.openWhyAsk(el)`：统一弹窗（标题「⛔ 无法执行」+ 操作名 + 原因）；
- `ui.softenBlocked(root)`：渲染后统一跑——把 `button[disabled]` 与 `.disabled` 卡片转为
  「可点击 + 说明」（摘 `disabled`、挂 `data-why`；原因 = 显式 data-why > title > 兜底）；
- **main.js 委托**：`data-why` 元素**优先于一切**弹窗（按最近祖先找——灰卡可能没有 data-action）。
- 挂载点：`openModal`（两级重绘收口）+ `renderView` —— **未来新增按钮自动覆盖**。
- 白名单：分页"到头"（`data-no-why`）；输入框 / select 不软化。

**接入清单（21 处硬编码原因 + title 自动承接 + 灰卡）**：

| 场景 | 原因文案 |
|---|---|
| 出征提交（未选目标） | 尚未选择出征目标 —— 先在地图上点选，或从上方列表选择一个目标 |
| 治疗伤兵 | 伤兵营已空 —— 打完仗产生伤兵后才能治疗 |
| 释放俘虏 | 俘虏营为空，无俘可释 |
| 训练加速 / 商城 / 强化 / 购买 | 黄金不足：需 N 金 |
| 训练宝物"已用过" | 本队列本日已用过该加速（每队列限一次） |
| 打造 / 百炼 / 蕴养 | 先在下方点选… / 黄金不足… / 灵气精华不足… |
| 门派（入派/立派/任务×3） | 退派冷却中 / 驻地等级不足 / 次数已尽或资源不足 |
| 民心措施 | 本日已执行过该措施（每日一次） |
| 建筑升级 / 训练提交 / 研究 / 晋升 / 辎重 / 出征上限 | 已达最高等级 / 队列已满 / 正在研究他科技 / 条件未满足 / 存量为 0 |
| 城墙修建 / 客栈招募 / 道具＋ / 采集 / 占领 | （原 title 自动承接） |

**顺修两个真 bug**：
1. `train-locked` case 不可达（委托前置拦截）→ 灰卡改"无 data-action + data-why"，死 case 退役；
2. 软化器初版对"已带 data-why"的按钮**跳过摘 disabled** → 渲染代码补过 reason 的那批仍点不动（e2e 实测抓出，b7 修正"disabled 必摘"）。

### ③ 建筑人口占用（需求 3）——老板 9/16 口径

**口径换代**（一次性、全局）：

| | 改前（v89.126） | 改后（v89.189） |
|---|---|---|
| 公式 | 人口上限 × 12.5% × min(1, 级数/满配级数) | Σ 城内建筑（除官府/城墙）P_m(级)/**9** + Σ 城外资源 P_m(级)/**16** |
| P_m | — | 民房人口表同等级**单座**值（与人口上限同指数 → 任何规模占比稳定） |
| 官府/城墙 | 城墙计 | **都不占**（老板例外项） |
| 旧出口 | popLaborLevelsOf / popLaborFullOf | **退役**（不留第二算法） |
| 旋钮 | fullPct | **cityDiv / extDiv 两表值**（一个入口） |

**实测对照（probe_v89189d_labor）**：

| 场景 | 现状占比 | 新口径占比 | 可征余量 |
|---|---|---|---|
| 初始城（2 建筑 + 2 资源 Lv2） | 0.3% | **17%** | 496 |
| 中期城（5 建筑 + 8 资源 Lv6） | 2.1% | **35%** | 4,084 |
| 首城满配（2 民房 + 9 建筑 + 12 资源 Lv12） | 5.2% | **88%** | 1,950 |
| 首城满配（3 民房版） | 5.0% | **55%** | 1.1 万 |
| 都城满配（8 民房 + 11 建筑 + 96 资源 Lv24） | 17.5% | **90%** | 4.5 万 |
| 都城（12 民房全建筑） | 17.5% | **61%** | 27.0 万 |

**合适性结论**（老板问"按这么设计看看是否合适"）：
- "建筑占太少"已修复——**建筑规模有真实人口代价**（初始 0.3%→17%）；
- 满配张力出现但**有解**："1 民房 = 9 建筑"精确成立（定义恒等）；首城满配需 3 民房、都城全资源需 8 民房——**"全资源"与"多建筑"成取舍**（这正是人口经济的意义）；
- **老档提示**：现有存档的"建筑人口"会明显升高（如首城满配 5%→88%），征兵余量收窄——需多建民房或减建筑，属规则变更的预期冲击；
- 若嫌紧：改 `DATA.POP_LABOR.cityDiv/extDiv` 一处（如 12/20 松 25%）。

## 五、诚实缺口

1. **受阻弹窗的"全站穷尽"**：机制上"渲染后自动软化"覆盖 openModal/renderView 两条通道；个别**局部增量重绘**（不经这两个通道）理论上可能漏——本轮抽查的高频面板全部覆盖，长尾如遇漏网，软化的兜底文案为"当前条件不满足"（结构上仍会弹窗）；
2. **掠夺金的搬运**：金按"货币不靠辎重队搬"设计（直接入池）——若老板希望"金也要运力限制"，是三处的小改；
3. **人口口径的老档冲击**：未做迁移宽限（如旧档首日送"人口缓冲"）——需要可加；
4. **"96 块资源全开"的都城**需要 6-8 民房——若嫌此张力过大，调 cityDiv/extDiv 一处即可；
5. e2e 新增 1 条（受阻弹窗真点）；其余守护在 smoke §189 + 实机。
