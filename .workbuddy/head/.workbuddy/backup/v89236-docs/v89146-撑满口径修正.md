## 修正内容（v89.145 的理解偏了）

| 项 | v89.145（错的口径） | v89.146（对） |
|---|---|---|
| 规则 | `minmax(116px, 1fr)` + `align-content: stretch` —— **按现有行数平分、把行拉满** | `minmax(116px, calc((100% − 行距×3) / 4))` + `align-content: start` —— **一律按"4 行均分"的高度** |
| 4 行（满页） | 铺满 | 铺满（4×行高 + 3×行距 = 100%） |
| 3 / 2 / 1 件 | 现有行被拉高（1 件 = 684px 巨卡） | **行高不变**（与满页一致），**下方留空** |

```
.ui-page.shop-page .shop-rows.shop-fill {
  flex: 1 1 auto; min-height: 0; overflow-y: auto;
  scrollbar-gutter: stable; align-content: start;
  grid-auto-rows: minmax(116px, calc((100% - var(--sp-3) * 3) / 4)); }

公式含义：扣掉 4 行之间的 3 个行距（`--sp-3`）后四等分 ——
  · 4 行：4×行高 + 3×行距 = 100%（正好铺满）；
  · 不足 4 行：行高照旧（**不随件数变化**），剩余空间留空。
```
