# 换皮操作手册 · 傻瓜式（废土·余烬纪元 · 位图替换）

> 你只需要会**复制 / 粘贴 / 双击**。全部命令都可直接复制运行。
> 一切在项目目录 `E:\Deepseekdb` 下（命令行先 `cd /e/Deepseekdb`）。

---

## 一句话原理

游戏现在**文字是废土、贴图还是汉代**。我们要把 104 张贴图换成废土风。
换法：**出一张 2×2 的四格图 → 切成一格一格的图标 → 覆盖进游戏**。
每 4 个图标只出 1 张图，省成本。

---

## 你要做的只有 3 件事

### 第 1 步 · 拿提示词（复制）

```bash
python .workbuddy/tools/gen/wasteland_prompts.py --batch W-B1
```

屏幕上会打印一段段**可以直接复制的英文提示词**，每段前面写着**存成什么文件名**
（例如 `存成：assets/icons/raw/atlas_A_src.png`）。

> **先做试点**：`W-B1`（建筑 16）和 `W-B3`（兵种 18）是最难的两批，先跑通它们。
> 看全部批次：`python .workbuddy/tools/gen/wasteland_batch.py --list`

### 第 2 步 · 出图（粘贴）

把打印出来的整段提示词，**粘贴**到你的图像工具（WorkBuddy 图像处理 / 即梦 等），
生成一张 2×2 四格图，**按提示词顶上写的文件名**存进 `assets/icons/raw/`。

- **建筑批（W-B1）注意**：建筑走"**图生图**"。先跑一次
  `python .workbuddy/tools/asset/build_atlas_src.py`，
  它会在 `.workbuddy/tmp/atlas/` 生成 4 张白底源图集；把这 4 张源图**当作参考图**喂给图像工具，
  再贴提示词（提示词里已经写明"保持同样角度轮廓、只换材质"）。
- 四格图**必须是纯白背景**，四格均匀分开，不要有分割线（提示词里已含，照着出即可）。

### 第 3 步 · 一键入库（复制运行）

```bash
# 先体检（不会动游戏，安全）
python .workbuddy/tools/gen/wasteland_batch.py --batch W-B1 --check

# 体检 ✅ 就入库（自动切图 + 贴族旗 + 重生成登记表 + 校验）
python .workbuddy/tools/gen/wasteland_batch.py --batch W-B1 --apply
```

**完事。** `--apply` 会自动帮你做完后面所有事。

---

## 怎么知道成了没有

`--check` 会打印一张表，每张图一个 ✅ 或 ⛔：

```
  guanfu     0.41   0.93     11  ✅
  minfang    0.52   0.93      9  ✅
  ...
  逐张完整性：16/16 过
  ✅ 批级判据全过          ← 看到这个就能 --apply
```

- 看到 **`✅ 批级判据全过`** → 冲。
- 看到 **`⛔ 批级判据未过：图内色散均值 X < 15`** → 出的图**太单调（像单色剪影）**。
  重新出图，让画面里**多几种材质**（案例：锈铁顶 + 水泥墙 + 木架 + 一面彩旗）。
- 看到 **`⛔ 缺族旗 xxx`** → 这不怪你，是没贴旗；换个批重出或联系我。

> 看整体进度：`python .workbuddy/tools/gen/wasteland_batch.py --status`
> 看哪些图标还在用旧图：`node .workbuddy/tools/asset/verify_wasteland.js`

## 后悔了怎么办（回滚）

```bash
python .workbuddy/tools/asset/wasteland_rollback.py            # 先干跑看会改什么
python .workbuddy/tools/asset/wasteland_rollback.py --apply    # 真还原
```

全量还原到换皮开工前。也可以 `--batch W-B1` 只还原某一批。

```bash
# 进度

# 拿提示词（换批次号）
python .workbuddy/tools/gen/wasteland_prompts.py --batch W-B1
```
