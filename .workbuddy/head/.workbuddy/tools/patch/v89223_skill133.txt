## §133. 兵牌简称（ab）换代 + 「全仓旧词收尾」的三层边界（v89.223）

### 133.1 单字符字段改名的镜像扫描（形态维度）

单字符字段（`DATA.TROOPS[].ab`）比多字词难扫——**字面量扫描必须带"形态"维度**：
引号形态（`'枪'`）· 正则/HTML 形态（`>枪<`）· 拼接形态。本轮实证：全仓镜像恰好 2 处
（smoke §129③ 正文 + §129③/§151 正则），**但只扫引号形态会漏掉正则那一处**。
探针法 = "字符 × 语境"（bt-rnm / troopAb / 简称 / 兵牌）双维度扫描。
消费面清点法：`grep troopAbOf` + `grep '\.ab\b'` —— 本轮消费面 = 域出口 + ui 兵牌一处，
**纯显示派生（无存档 / 无打包）→ 换字零迁移**。

### 133.2 「换位链」的补丁执行顺序

成对/链式改名（腾出 A 给 B：民→搬 + 义→民；弩→重 + 弓→弩）时：
**先腾后入**（先把旧持有者搬走、再写新值），每步 `ab: 'X'` 断言 count==1
（18 个唯一值保证锚点干净；链式任一步顺序错都会 count=2 报警）。

### 133.3 版本号三连（每轮必改）

`GAME.VERSION`（main.js）→ **smoke §199④ 的写死正则**（`/GAME\.VERSION = 'v89\.NNN'/`）→
设置页「🧩 运行版本」行。改主版本号**必须同轮改 §199④**，否则门禁红。

### 133.4 「全仓旧词收尾」的三层边界（老板授权"类似需求免批准"后照此判断）

| 层 | 动作 |
|---|---|
| 产品 / 用例 / **活工具夹具** | **清扫**（本轮：产品 16 处 + 活工具 33 处） |
| 沿革注释（"原XX"）/ 概念词（枪阵 / 拒马 / 枪克骑）/ 货物义（辎重）/ 习语 / 装备层古典名 | **保留**（逐类有理由，写进档案） |
| 历史仪器（tools/patch 补丁脚本 · probe/show 探针截图） | **保留（映射源属性）**——MAP 表被替换会变自映射，毁掉可复跑与可追溯；"过一遍"时先分类、只动"活"的一层 |

### 133.5 新守卫 §223 形态（可抄）

① 逐字对表（`MAP = { id: '字' }` 全 18 项 + 出口 `troopAbOf` 双验证 + 两两唯一 + 旧字零残留 +
基数自证 18）；② **源码可执行形态**零残留（查 `ab: '枪'`，不查剥注释后的裸出现）；
③ 镜像同步（渲染源码 + 用例期望双查）；④ 产品侧收尾在册；⑤ 版本与档案在册（老板原文逐字）。
