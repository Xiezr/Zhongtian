## 二、P1 · 本迭代修（低成本高收益，多为文案/单点逻辑）

| # | 问题 | 建议修法 | 验收 |
|---|---|---|---|

| P-19 | 募兵上限静默归零（人口耗尽，无任何提示） | `maxTrainCount` 为 0 时面板显示原因："人口不足（建议建民房 / 等待人口增长）"；区分人口不足 vs 资源不足 | 上限 0 时有明确归因提示 |
| P-04 | 官府升级中时，依赖它的建筑显示"需官府 Lv2"（像永久锁） | 前置"升级中"时改显示"官府升级中（剩余 X），完成后可建" | 升级期间提示动态化 |
| P-05 | 募兵消耗人口（1 兵 = 1 人口）无任何界面说明 | 募兵面板加一行常驻小字："每名士兵占用 1 人口（当前可用 X）" | 说明可见 |
| P-16 | 野地数量达上限仅战后提示，出兵前无预警 | 出征面板：目标为"占领"且已达上限时，前置警告"野地已达上限（N），占领将转为就地取材" | 出兵前可见 |
| P-11 | Lv0 野地"就地驻守"文案与实际（驻军上限 0）落差 | 文案按等级动态：Lv0 显示"该等级无驻军位"；或给 Lv0 驻军上限 1 | 文案与行为一致 |
| P-02 | 每次会话固定 1 条 404（疑似 favicon） | 补 favicon 或路由忽略；确认非业务资源 | 控制台无固定 404 |

| P-26 | **新城建成即"裸城"（守备 0）无提示**，实测首波入侵即破城 | 新城落成弹窗提示"当前守备力 0，建议驻军/修墙"；带"从主城调兵"快捷入口（复用调兵出口） | 新城建成时风险可见、可一键补防 |
