## 一、B0 堵漏（削弱 / 统一）—— 5 项全部落地

### W1 · 生产宝物流：**同类取最强 + 到期真消费**（P0）

| | 改前 | 改后 |
|---|---|---|
| 叠加 | `s.buffs.prod[res] += eff` **无上限**（实测 110 个 = ×134） | `Math.max(旧, 新)` —— **同类只取最强**，重复使用仅刷新时长 |
| 到期 | `prodUntil` 写下后**全库无人读**（死字段）→ "24h"形同虚设 | `prodBuffMult()` 逐资源比对 `prodUntil`，**过期即剔除并回写清理** |
| 探测 | `buffActive('prod')` 恒真 | 走同一出口，与到期同步 |

- 落点：`js/systems.js`（useItem prod_buff 分支 + buffActive）· `js/state.js`（prodBuffMult）
- 兼容：旧档缺 `prodUntil` 记录的资源按"仍生效"处理，不静默砍掉老档 buff。
- **实测效果（同骨架 225 年重跑）**：

| 游戏年 | gold 粮/时 | 修复前 buff | **修复后 buff** | 倍数 |
|---|---|---|---|---|
| 10 | 1,360.6 万 | 6.75 亿 | **3,061.3 万** | 2.25× |
| 25 | 5,728.0 万 | 593.25 亿 | **2.56 亿** | 4.47× |
| 40 | 3.13 亿 | 18,858 亿 | **3.84 亿** | 1.23× |
| **225** | **5.95 亿** | **944,517 亿** | **6.83 亿** | **1.15×**（验收线 ≤30× ✅） |

> 花费侧同步回落：1.28 亿金（27,434 个犁）→ **1.2 万金（1 个犁 + 维持刷新）**。
> 省下的金流向别处：军力 3.0 万 → **6.9 万**、建筑等级和 264 → **498（三城近乎满级）**——这才是"金花在正处"的形态。

### W2 · 符类：**同属性取最强**（P0，与军事符同口径）

- 改前：每条符各自乘一次 → 治粟(+100%)×安民(+75%)×玄德(+50%)×文曲星(+25%) = **×6.5625**（实测守卫 nz 945→6,203）。
- 改后：同属性取最大加成、**一次施加**（不同属性仍可并行，如统率符 + 内政符）。
- 落点：`js/domain.js` genAttrs 符类段。实测 ×2.0（不再叠乘）；虎符 ×1.5 等单符行为不变。

### W3 / U3 · 守将内政 → 产量**封顶 +150%**（口径统一）

- 改前：产量是**全游戏唯一不封顶**的加成（守卫 nz 980 → ×10.8；宝物流推到 nz 6,203 → ×63）；
  而建造/征兵/研究早已 `Math.min(1.5, …)`、城防封 1.0。
- 改后：`guardBonus.prod = Math.min(1.5, nz×0.01)`、`build` 同源封顶 —— **五条链一个口径**。
- 落点：`js/domain.js` guardBonus。

### U4 · 物品来源文案（在售 == 文案一致）

- 五种种子 desc 由「来源：高级野地 / 名城缴获」改为「**来源：商城 / 采集归来 / 出征缴获**」
  （v89.87 已开售但文案停 v78 口径 → 玩家/推演都以为只能缴获）。
- 落点：`js/data.js` 种子表 + 表头注释。

### E8 · 建造队列 2 → 3 格（含测试断言同步）

- `GAME.buildSlots` 基础位 **2 → 3**（专精/爵位/名城/徭役令照旧叠加）。
- 同步改写 smoke 第 12 节（填满队列再验"满则不再排队"）与第 28 节（补两个新槽位断言）。
