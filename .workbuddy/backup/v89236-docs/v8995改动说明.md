## ① 稀缺资源「节钺」+ 物多价贱

### 1.1 节钺（不可再生 · 黄金买不到）

| 项 | 口径 |
|---|---|
| 定位 | **不解锁强度，只解锁资格** —— 发展限制器（老板原话：免得"玩家通过黄金无所不能"） |
| 获取 | 首次攻占名城（县 1 / 郡 2 / 州 3 / 都 5，**同一座城只算一次**）· 爵位每 4 档 +1（22 档共 5 枚） |
| 用途 | 名世→天授 **1 枚**；城池开府扩编（建造位 +1，每城至多 2 次） |
| 反例 | **商城不得售卖**（断言守）；灵草链的"全链 54 万金打穿资质"到此为止 |
| 命名 | 初版叫"虎符"→ 实测**撞名**（商城早有 `id:'hufu'` 的符类，+50% 带兵）→ 定名 **节钺**（持节开府/拜将） |

- 唯一出口：`jieyueOf / jieyueGrant / jieyueClaim（幂等）/ jieyueSpend / jieyueTextOf / jieyueExpandCity`。
- 与第 3 问的关系：**打仗是节钺的唯一大宗来源** —— 这就是给"不想蹲田的人"的替代内容。

### 1.2 物多价贱（市场）

- 规则：当日（现实日）从市场换出的黄金越多，汇率乘数越低：`mul = max(0.10, 1 − 当日已换金 / 20 万)`；隔日清零。
- 实测：450 年长跑累计只换出 **1.23 亿金**（3,973 笔）→ 汇率当天即锁 **底价 ×0.10**，"卖资源套现"彻底失去意义。
- 唯一出口：`mktSlipOf / mktFreeOf / mktMulNow / mktSlipRecord / mktSlipText`（卖价链 `marketSellPer` 只读它们）。

## ② 通商券：补上缺失的通道

**原状**：用券后只弹一句"市场折损降低 50%（30 分钟内）"，而它写的 `s.buffs.tradeCut` **全库没有任何读取点** —— 典型的死接线（老板一眼看穿）。

**现在**：通商券 = **免折抛售凭信**
- 30 分钟内，市场卖出**不打"物多价贱"的折**（按基准价结算）；
- 免折额度 **50 万金当量**，用尽即回折价；额度与时长都在 `DATA.MARKET_SLIP.free`；
- 读取点：`mktFreeOf / mktMulNow`（挂在卖价唯一出口上）→ 面板、日志、断言同一口径。

## ③ 「关闭城池市场」是否可行 —— 我的答案：**不关，改成"有摩擦的市场"**

| 方案 | 判断 |
|---|---|
| 关掉市场 | ❌ 不推荐。市场的真正用途不是"换金"，是**应急调剂**（缺木时救急）+ **新城的启动资金**。关掉会：① 让"坐拥粮山却缺铁"的玩家束手无策（体验断崖）；② 把新城建设的门槛变成"等" |
| **加摩擦（已做）** | ✅ 已做两件事：**物多价贱**（卖资源不再是无底洞）+ **通商券**（把"免折额度"变成有限的、可赚的、可买的资源）。结果：想靠卖资源滚雪球 → 撞墙；正常调剂 → 几乎无感 |
| 战斗玩家的替代内容 | ✅ 已给：**节钺只能靠打**（首占名城）→ 开疆 = 扩编 + 顶档资质。B3 还会补"天下大势"（NPC 互伐/援助/调停）与防御玩法（E13） |

一句话：**"关掉出口"和"给出口加价格"是两回事**。前者的代价由所有玩家承担，后者只惩罚"滥用者"。

## ④ 取消溅射（一击一目标）

- 删掉"主目标吃满后，溢出对射程内每支敌军各溅射 30%"（`T.SPLASH_PCT` 退役 = 0）；
- **溢出伤害作废**（打光目标即止）；城头火力同样**只打最靠前的一支**；
- 战报/条带/字幕同步（不再出现"溅射"字样）；断言换成"只有一支受损"的实证。
- 效果：一回合最多打掉**一支**部队 → 战斗从 1~3 回合拉长到多回合（见 ⑤）。

## ⑤ 速度受控（每 5 级 +1）与纵深（去掉"一步到面前"）

| 改动 | 改前 | 改后 |
|---|---|---|
| 等级成长 | 速度**每级 +1**（240 级 +239） | **每 5 级 +1**（240 级 +47） |
| 自由点投放 | 无上限（可把 1,900+ 点全砸速度） | **上限 = 10 + 等级/5**（装备/坐骑仍是独立来源） |
| 战场纵深 | `max(200, 最远射程+199)` → 纯近战 249 | `max(1400, 最远射程+299)` |
| 单回合推进 | 速度即步长（无上限） | **上限 = 纵深 × 35%**（谁也不能一回合贴脸） |
| 伤害总量 | 一击可杀 1,660（对面只有 600） | **统一乘 `DATA.BATTLE.damageScale = 0.34`** |

实测（探针）：均势对局 **13~21 回合**、接敌推迟到第 1~3 回合；轻骑仍比长枪先接敌（机动优势保留）；
速度 300 与 2000 的将领在实战中**不再有差别**（都被推进上限截平）——"速度决定论"到此结束。
断言的期望值全部**从常量/配置推导**（上一批写死数字踩过坑）。
