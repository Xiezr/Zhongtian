# 异人志 · 角色谱系（故事库「④ 志异线」角色库）

> **老板原话（2026-09-18）**：「发掘更多角色，包括练功，灵异，甚至鬼怪。再琢磨那么10种20种。」
> **用途**：故事库铺量的**角色库**——20 个名目，分四部：**甲·练功人（6）｜乙·术人（6）｜丙·志怪（5）｜丁·异物（3）**。
> **用法**：写卷时按此库取角色；每个名目给出「一句话 / 三种故事用法 / 器物 / 红线」。

---

## 〇 总则（轻志怪 · 三笔法 · 四红线）

**世界观锚点（志怪线不是新设定，是把既有设定写进人间）**
- 既有底子：野地有**贼寇妖兽**（讨伐·拔寨擒王「清剿贼寇妖兽，胜则灵材丰厚」）；灵地有**妖物奇遇**（灵蟾吐月·三足蟾对月吐纳，**可选择学它吐纳、也可退后静观**；孤峰观星·看懂几分天象）；灵物有**灵鲤 / 白鹿 / 灵蛇 / 灵驹**。
- 因此本线的"鬼怪"一律按此口径：**可遇、可观、可学、可避**——不落"打怪"戏码，更不落恐怖戏码。

**三笔法**
1. **半解**：怪事给七分解释、留三分。可由器物、风俗、误会、天时拆解大半，最后**一分不收口**。
2. **留白**：不写"显灵 / 斗法 / 收妖"，写**事后人们怎么说、怎么做**（规矩、风俗、器物、账本）。
3. **本地视角**：从乡人 / 兵卒 / 船家 / 书吏 / 匠人的眼中写；旁白不下结论，不替玩家"揭秘"。

**四红线**
- ① **不写神通斗法、不写长生飞升、不写符咒驱邪的"特效"**（沿用全局 ⛔「不给仙侠神通」）。
- ② **不恐怖**：不写尸变、不写虐杀、不写亵渎——志怪 ≠ 志恐；夜里的东西要"让人想再想一遍"，不是"让人睡不着"。
- ③ **鬼怪不落"实锤"**：不写"它赢了 / 它害了谁"；写人的**应对**（规矩怎么来的、器物怎么用的）。
- ④ **不夹带机制**：异物不给数值承诺；奖赏仍由 `reward` 字段承担（本线不发秘籍）。

## 甲部 · 练功人（6 名目）——「功夫在人身上」

### 1. 桩功老人
- **一句话**：站桩四十年的老人，每日卯时来、辰时走，不与人比武，只看人手。
- **三种用法**：① 新募少年打赌去推他，推不动——"站住别倒"四个字怎么教；② 县里要请他"教桩"入新课表，他只想教一句话；③ 他的手看惯了几代人的架式，谁身上有"练岔的根"他一眼看得出。
- **器物**：桩位土印、校场新课表、旧伤（他不说的）。
- **红线**：不写内力外放、不写一掌断树；"功夫"只写站、看、等。

### 2. 武痴
- **一句话**：逢人便要拆招的痴人——不赌钱、不记仇，输了笑、赢了也笑。
- **三种用法**：① 山道上拦人拆招，出手只一招，像某营的旧枪法；② 有人说他疯，有人说他在"等一个人"；③ 收他人入营，他只要一样：让他把"那一手"演完。
- **器物**：拆招木棍、山道、旧营枪谱残页。
- **红线**：不写成"扫地僧"式无敌；他只在"那一手"上痴。

### 3. 石锁班
- **一句话**：村里的力气班子，练石锁不为武，为春社"举石"上的一口气（体面）。
- **三种用法**：① 老班主摔坏腰，十六岁少年要顶班，石锁比人重一倍；② 将军路过要看"举石"，班子把给社日的劲提前使了；③ 一村人凑钱给班主买膏药，账记在门板上。
- **器物**：石锁、春社彩头、膏药、门板账。
- **红线**：不写成"天生神力"传奇；写的是练习与体面。

### 4. 夜练者
- **一句话**：官仓夜值的老卒，每夜练同一路刀——不是练刀，是"不想事"。
- **三种用法**：① 刀法是当年某营的"收队刀"，收队刀练给"没能收队的人"；② 同值的人想学，他教腔不教意；③ 仓里的鼠患、灯油账，都成了他夜练的"配角"。
- **器物**：灯、刀、旧营旗角、灯油账。
- **红线**：不复仇、不痛苦卖惨；他的十年只说一句"练着，心里就静"。

### 5. 练岔的人
- **一句话**：偷学邻家师傅吐纳、练岔了气的少年——胸口疼、夜里盗汗。
- **三种用法**：① 游方郎中说"这不是病，是快了"；② 师傅在外地，托人带回一句话："先停三个月"；③ 少年不肯停——快慢之争写在两个月的作息表上。
- **器物**：药方、少年抄的口诀残页、吐纳时辰表。
- **红线**：不写"走火入魔"发狂；写的是疼、汗、停与不停。

### 6. 教习旧卒
- **一句话**：退伍老兵在村里教娃娃"起手式"，头一课是"先学挨打"。
- **三种用法**：① 团练来收编他当教习，按新操典教，娃娃们学得快；② 老兵说新操典"少了挨打那一课"；③ 一个娃娃被家里领回去学手艺，老兵替他留了根棍。
- **器物**：起手木棍、操典册、村里娃娃。
- **红线**：不贬新操典、不神化老底子——两套都在理。

## 乙部 · 术人（6 名目）——「通灵的手艺」

### 7. 巫祝
- **一句话**：乡里问卜的老巫，她的"神"是只画在旧布上的一只眼睛；禁祀令下，她要改行看病。
- **三种用法**：① 乡人不肯——春耕、婚丧、找牛都还来找她；② 县丞要办"违禁"，她把卜布卷起来不卜了；③ 她真会些草药，只是"看病"比"问卜"更费手。
- **器物**：卜布、禁祀告示、药草。
- **红线**：不把巫祝写成骗子或圣者；她有手艺、有软处、有要吃饭的嘴。

### 8. 傩者
- **一句话**：傩戏班主，旧傩面裂了要重刻；他的规矩——刻面人不能照活人的脸刻。
- **三种用法**：① 郡里管事的偏说"照他的刻"；② 徒弟偷照了一个孩子的脸刻，班主连夜把面具燎了；③ 驱疫的傩戏要开演，老面具修还是不修。
- **器物**：傩面、刻刀、傩戏单、香。
- **红线**：不写傩面"有法力"；写的是规矩与面子。

### 9. 阴阳生
- **一句话**：看宅择日的中年先生，自家宅子却一直没修——他算自己"不宜动土"。
- **三种用法**：① 有人笑他迂，有人怕他说真话；② 县里修仓择日，他选的日子"犯工"，工匠们却信了；③ 他把自己家的漏屋写进历日册当笑话。
- **器物**：历日册、旧罗盘、漏屋。
- **红线**：不写"择日灵验"的实锤；写人心与习惯。

### 10. 纸扎匠
- **一句话**：扎纸马的老匠，纸马扎完要"喂火"（燎一下）才"像"——丧家信他，市上笑他。
- **三种用法**：① 这回是给一个"无人认领"的人扎纸马，匠人自己掏的钱；② 学徒问"没人看，扎这么细做甚"；③ 火燎过的那匹纸马，匠人自己盯着看了很久。
- **器物**：纸马、浆糊、火燎的规矩、丧单。
- **红线**：不写纸马"活了"；写的是手艺人给"无人认领者"的体面。

### 11. 守墓人
- **一句话**：义冢守墓的老兵，给每座无名坟栽一棵树，栽了二十年。
- **三种用法**：① 县里要平冢改田，树也要伐；他说"树不挪，人也不挪"；② 有人来寻亲，靠树认坟；③ 他自己将来葬哪，早写在义冢册最后一页。
- **器物**：树、锹、义冢册。
- **红线**：不写闹鬼；写的是"无名"的重量。

### 12. 望气人
- **一句话**：抬头看"地气"的老向导，说某处地气"冷"、不宜立屯——说不清道理。
- **三种用法**：① 工队不听，扎了营，开春营地塌了半边（无伤亡）；② 官府要查"妖言"，他不会辩，只会说"那里风不对"；③ 有人请他去看新校场选址，他只绕了三圈。
- **器物**：屯营地、塌痕、旧路标。
- **红线**：不给"玄学实锤"；半解——塌方可能是雪水、可能是别的。

## 丙部 · 志怪（5 名目）——「夜里的事」

### 13. 山魈 · 声（喊山）
- **一句话**：樵夫上山的规矩——砍柴前喊山，三声一停；号子不能断。
- **三种用法**：① 一个外乡人独自上山，号子停了半刻，找回来时人没事，只说"有人在树后应了我"；② 老樵夫把规矩传给孙子，说的是规矩，不说为什么；③ 山规要不要立成告示——写好还是不写好。
- **器物**：号子、柴担、树后。
- **红线**：不写山魈现身；那"应声的"永远在树后，不出场。

### 14. 水鬼 · 约（问水）
- **一句话**：下水前投米"问水"；捞人的人另有三条规矩（不捞夜里喊名的、不数人头、上岸前不回头）。
- **三种用法**：① 少年笑规矩，老捞人只说"规矩是给捞人的人定的"；② 收网收上来一件旧物，老捞人看了一眼就收进箱子；③ 有船家请老捞人去"镇水"，他只去投了一把米。
- **器物**：米、网、旧物、渡口。
- **红线**：不写水鬼拖人；"规矩"本身就是主角。

### 15. 狐 · 宅（狐宅）
- **一句话**：老宅东厢住着"一位住户"——不害人、连鸡也不吃；年年在窗台留一碗净水。
- **三种用法**：① 荒年村里揭不开锅，东厢窗台上多了一窝野兔；② 新主人要翻修东厢，老辈人劝"留着那扇门"；③ 那碗水是谁添的——村里人各有各的说法。
- **器物**：窗台水碗、野兔、老宅东厢。
- **红线**：狐从不出场；所有"证据"都可两解（人可为、狐可为）。

### 16. 伥 · 忌（应声）
- **一句话**：老猎户的禁忌——山中若有"人语"引你走岔，万不可应声。
- **三种用法**：① 徒弟不信，老猎户讲这条禁忌的来历——他师父的师父应过一次；② 山那边新开了炭窑，窑工夜里听见"有人喊名字"；③ 禁忌怎么写进猎户的行规，又怎么被新搬来的人笑话。
- **器物**：猎具、岔路、火绳、行规。
- **红线**：不写伥鬼索命；写的是"应过一次的人"后人怎么活。

### 17. 灯 · 障（灯障）
- **一句话**：烽台夜值记录里的旧话——"灯障"：灯下多出人影，是困出来的。别数，添灯油。
- **三种用法**：① 新来的烽卒真遇上了——灯下"多了一个人"；② 老卒教他：别数、添油、把记录写得平实；③ 那一页值夜簿被识字的人翻到，两人对着看了一夜。
- **器物**：烽灯、值夜簿、灯油。
- **红线**：不写火熄台失（不涉军情事故）；写的是值夜人的困与自持。

## 丁部 · 异物（3 名目）——「会说话的东西」

### 18. 石言
- **一句话**：河滩一块石头"长了字"，每年多一笔；识字的看过一次就不肯再看。
- **三种用法**：① 村老说它没说话，是"给话"；② 有人拓了纸要报官，拓到一半不拓了；③ 河水改道，石头要没入泥里——搬还是不搬。
- **器物**：刻字的石、拓纸、河滩。
- **红线**：石头上的字**永不写出来**（留白到底）。

### 19. 湖灯
- **一句话**：湖上放灯还愿的旧俗——灯到湖心不沉；撑船人不许追根问底。
- **三种用法**：① 新来的县吏要"查验"放灯，被船家劝在岸边看；② 一盏灯三年都顺水回来，放灯人第三年不放了；③ 湖灯夜与既有《临湖夜钓》的"灯"相互致意（可不点名）。
- **器物**：湖灯、船、还愿簿。
- **红线**：不揭秘（灯为什么不沉）；写风俗与人心。

### 20. 木客
- **一句话**：老林深处夜里"伐木声"不断，白日无痕——木客之名由此来。
- **三种用法**：① 木客与林工的"规矩"：不砍某种树；② 新林工多砍了那棵树，老工头连夜去"补栽"；③ 山外要买那批木料，林工报的册子上少写了几棵。
- **器物**：伐木册、斧、那棵"不砍的树"。
- **红线**：不写树精报复；写行规与敬畏。

## 附一 · 与既有内容的区隔（防撞表）

| 既有 | 已有篇章 | 本线怎么避开 |
|---|---|---|
| 巫 / 祭祀 | 《问气》（巫医问瘴）·《铜鼓》（祭泽主） | 本线《问卜》写**巫祝本人与禁令**，不写瘴、不写祭仪本身 |
| 妖物 | 灵地事件《灵蟾吐月》《孤峰观星》（游戏内） | 本线一律**不写妖物出场**；写"传说与人的应对" |
| 水 | 《临湖夜钓》《渡船》《问水》短语 | 《问水》名目写**捞人规矩**（人物篇），与《渡船》题材不同 |
| 树 | 《树息》《轮伐》《无字碑》 | 《木客》写**夜里伐木声**（声闻篇），不写守夜人（树息已写） |
