全部对齐到现行术语（**区 / 重镇 / 聚落 / 旧都** + 架空城名），共 **92 处**（跨 9 个文件）。

| 类 | 例（改前 → 改后） |
|---|---|
| 紧凑档位 | `（县12/郡16/州20/都24）` → `（聚落12/重镇16/首府20/旧都24）` |

| 行政区划 | `行政区划「州 · 郡 · 县」` → `「区 · 镇 · 聚落」`；判据链 `县=聚落 / 郡=本区最近重镇 / 州=写死 state` → `聚落档/镇档/区档` |

| 地图注 | `台基（都/州）` → `（旧都/首府）`；`州域` → `区域`；`州心` → `区心` |
| 测试标题 | `「重镇」档出现「州」下拉` → `「区」下拉`；`选定郡后只标注该郡聚落` → `选定镇后…` |
