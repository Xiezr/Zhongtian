## 结论先行

1. **规模 5.2 万行 / 1765 函数 / 注释率 19.5%**——规模适中偏大，注释密度健康（每个函数平均带"为什么"）。
2. **分层纪律良好**：剥注释后，下层误引上层仅 **9 处真代码**，其中 6 处是同一功能（失城处置）的防御式通知，无违规级问题。
3. **迭代热度集中在 4 个文件**（ui / domain / battle / data）——版本注释 token 2264 个、涉及 108 个版本，属高频小步迭代的典型形态。
4. **最大单点是 `GAME.action` 主分发器（1228 行 switch）与 ui.js 单文件 1.7 万行**——
   这是"无构建单体项目"的有意取舍，但已到临界，记入观察。
5. **质量闸门全绿且有兜底**：audit 六项全 0（死函数/孤儿/重复/零引用/未定义/恒真）· smoke 3547 · e2e 1239。
6. 无外部依赖、无构建、无 npm——**加载即运行**（file:// 直开），是项目最大"反脆弱性"资产。
