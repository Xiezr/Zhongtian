## 一、前哨可放手（清账 v89.193 遗留①）

**病根**：前哨自 v89.193 起有「每城上限 5 处」硬闸 —— 打满后新据点只能"从其他城池出征"，
`claimFort` 的超限文案早已预告"可先放手一处"，但**放手功能从未实现（空承诺）**。

**改法**（唯一出口 `GAME.abandonFort(x, y)`）：

| 面 | 改前 | 改后 |
|---|---|---|
| 出入口 | 无 | 前哨面板「危险操作」区 + 总览行内「放手」→ 确认窗 → 红键**一击执行**（v89.156 口径："打开确认窗本身已是 2 次确认"） |
| 数据 | — | 删除 `s.forts` 记录 —— 护持 / 商税 / 名额**随记录走**（各消费点读同一组出口，自动失效） |
| 格子地形 | 占据时 `terrain='city'` 写死 | 恢复占据前原值（`rec.terrain0`；**老档兜底 'plain'**）—— `claimFort` 起记录 |
| 据点重生 | — | **`fortsTaken` 保留**：该处据点已拔除、不会再出现（防「打→占→放→再打」刷战利品/声望） |

**实测**（探针 `probe_v89195b_fort.js`，原始输出）：


## 三、为将领资质补全属性（主解读：资质→攻防链修复）

> **解读说明**（如与老板本意不符，一句话可改）：我理解为「资质对**属性的影响链**要补全」。
> 探针全量体检（`probe_v89195a`）发现三处缺口，逐一修复。

### 3.1 攻防成长被取整抹平（真 bug · 长期潜伏）

`applyLevelGrowth` 旧写法 `Math.round(g.attack + step*0.4)` —— 每级都把小数回吞：

| 资质 | 设计成长（0.4×grow） | 实测 Lv100 攻防（改前） | 真身 |
|---|---|---|---|
| 凡品 | 0.4/级 | **10（从头到尾不涨）** | `round(10+0.4)=10` 每级归零 |
| 良材 | 0.8/级 | 109（≈ +1/级） | 0.8 → 1 |
| 英杰 | 1.2/级 | **109（与良材一字不差）** | 1.2 → 1 |
| 名世 | 2.0/级 | 208 | 无损 |
| 天授 | 3.2/级 | 307 | 3.2 → 3 |

**修法**：**小数累积器**（`atkAcc/defAcc`：整点入账、余数留池）—— 修后 Lv100 = 49/89/128/208/326，
**200 级均值与设计值差 0**（探针 ⑤）。

### 3.2 升档从不补攻防（v89.179c 口径缺口）

v89.179c 的"补全该资质的固定属性"只覆盖**四维**——"凡品练上来"的将升档后
攻防停在旧档水平（Lv60 凡品升到名世：攻防 10，而直接招募的名世标准 212+）。
**修法**：升档时补齐到「**全程按新资质成长**」的标准线 `10+(Lv−1)×0.4×新成长`，**只补不削**，
并在晋升 toast 显式列出（"攻防补足至「英杰」Lv60 标准（攻 +24 · 防 +24）"）。

实测升档链（凡品 Lv60 起步）：`10 → 57（良材）→ 81（英杰）→ 128（名世）→ 199（天授）`；
对照"全程天授 Lv60"逐级重演值 198 —— **差 -1**（对齐）。

### 3.3 守将攻防遗漏（v89.185 出口缺口）+ 老档补发

- `guardFillOf`（守将成型唯一出口）只补四维与体力，**攻防漏**：野地/据点守将恒 base 10（+1% 全军）。
  本轮补全，并配**独立折损旋钮** `DATA.GUARD_FOLD.atkDim = 0.25`（探针标定）：
  **名城守将不补**（保持 v89.73 起既有平衡）。

  | 对照（据点 Lv10 · 名世守将） | A 现状 | B 折 0.5 | **C 定稿 · 折 0.25** |

  | 我方 1.4×守军 | 我胜 | **守胜（越界）** | **我胜（边界保持）** |
  | 我方 1.5×守军 | 我胜 | 我胜 | 我胜 |
  | 守将全军攻击增量 | +0 | +16.3% | +7.7% |

  野地 Lv10 我损比：1.20（A）→ 1.49（C）—— "资质相称"可见、不破墙（1.4× 可胜边界与既有口径一致）。

- **老档补发**：`rankOf` 两条路径按已过等级补发攻防（与 v74 freePts 同法）——
  排除守将（`npcGuard`/`wild`：其攻防由 guardFillOf 按折损档定值，若补会把折损**顶穿**：
  实测 47 → 158，本轮已修 + 探针防回归）。

## 五、诚实缺口 / 需老板定夺

1. **「为将领资质补全属性」的解读**：本轮按"资质→攻防链修复"落地（四维补全 v89.179c 已有）。
   若您指的是别的口径（面板上资质属性展示 / 招募生成时补足 / 灵草使用体验），一句话可改。
2. **守将攻防折损 `atkDim=0.25`** 是探针标定值（保住 1.4× 可胜边界）；要更强（0.5）/关闭（0）改一处表值。
3. **放手后不可重新占据**（`fortsTaken` 保留，防"打→占→放→再打"刷战利品）。
   若要"放手后可重新设哨"，需加"再占据不给战利品/声望"的护栏——说一声。
4. **老档攻防补发**是"补齐到全程当前资质标准线"（高等级老将变强）——若想收紧改 `rankOf` 判据。
5. **速度 / 体力不参与资质**（设计如此：速度全档一致；体力上限已随 grow 自动变化）——未动。
6. 守将攻防使"有将的野地/据点"我损上升（野地 Lv10 ×1.49）——"野外有将更有感"的既有方向
   （v89.185 老板 2）延续；若嫌狠，降 `atkDim` 即可。
