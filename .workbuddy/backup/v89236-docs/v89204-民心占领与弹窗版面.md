## ① 病根（一句话）

老板两条需求：
1. **民心占领**：「据点、城池占领以民心为基础，战斗成功，败方失去20点民心，民心为0时可以被占领
   （如为我方，除主城不可被占领外，别的城池将会被敌方占领）」——
   现状是"守备值"体系：**不论胜负都破防**（战败也推进 · 按战力比 16×比 夹 [10,45] · 撤退半计），
   且`DATA.INVASION.loseCity:false` 写着"⛔ 体验红线：输了不丢城"（玩家城永远不会失）；
2. **弹窗版面**：「任何多页内容弹窗，其页码固定显示位置为居中，其他菜单按钮位置合理排布。
   比如强化界面的资源要求请以悬停显示，而不是直接占用位置。打造界面不要"套装效果一览"。等等」——
   现状是分页条页码信息吊在最右（按钮串末）、强化卡面常驻"下级成本"行、打造界面挂着
   「套装效果一览」按钮 + 独立小窗。

## ② 改法（改前 / 改后）

### 需求 1：民心占领机制

| 面 | 改前 | 改后 |
|---|---|---|
| 单场推进 | 不论胜负都破防；量 = `16×战力比` 夹 [10,45]；撤退 ×0.5 | **仅"本战获胜"推进；固定 −20**（`DATA.SIEGE.heartsLoss`） |
| 占领条件 | 守备归零 + 本战获胜 | **民心归零 + 本战获胜**（语义等同 · 口径换名） |
| 围攻范围 | `['fort','county']`（郡/州/都=决战制一波定胜负） | **全部城池**（`fort/county/jun/zhou/capital`）——名城同样多波磨 |
| 恢复 | 每整日守备恢复 8% | 每整日**民心**恢复 8%（`repairPerDay` 不动） |
| 玩家城 | 永不失（`loseCity:false` 红线） | **敌方破城得手 → 战争创伤 +20**（城级民心 = 全境民心 − 创伤）；**民心 ≤0 + 城破 → 失城**（主城除外） |
| 失城处置 | （不存在） | `GAME.cityFallen`：照 CITY_SCOPED 清理（将领/队列归收容城；在途行军/在外采集**改属**不丢）；城内驻军随城失陷；城变回地图 NPC 城（**可再打回**） |
| 主城 | （不存在） | **双闸保护**：明设主城 / 缺省首城 / 最后一座城 —— 均不可失 |

### 需求 2：多页弹窗版面

| 底栏分页 | 内容宽居中 | 满行三栏（右留 52px 给缩略图，实测间隙 14px 不相交） |

## ⑤ 诚实缺口

1. **失城的 repDrop（声望罚）未加** —— 老板没说，保持最小设计；若需要一处表值可加。
2. **战争创伤只按城平摊"全境基准"**（全境税率/安抚共享）——"某城被单独打残"的模型下，
   该城民心按城扣（战争创伤按城记），但"基准"仍是全境值；若要做"每城独立税率"是另一个大改。
3. **NPC 城的民心初始 100、无"城主安抚"通道**（只有恢复 8/日）——玩家打城的节奏预期 5 波；
   若嫌慢，`heartsLoss` 一处可调。
4. **`shot_v89117.js`（历史截图脚本）仍引用 `forge-setinfo` 按钮** —— 一次性历史工具、不进门禁；
   重跑会"找不到按钮"（无害 · 未改）。
5. 失城的"敌方接管城"**档位按县城（自建城）/原档位（攻占城）**—— 换主后再打回来，城档位
   可能变化（游戏内自洽，文档声明）。
