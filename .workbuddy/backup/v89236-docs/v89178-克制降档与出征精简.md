## 一、病根：「766 弓杀 35 骑」的对账

**完整链条（全部实测）**：

| 环节 | 数值 | 说明 |
|---|---|---|
| 766 弓一轮齐射（无将 · 满伤） | **21 骑** | 引擎真跑（探针 · 雨天口径） |
| 带将（+65% 攻）≈ | **35 骑** | ← **老板所见**（对账成立） |
| 同样齐射 · **若无克制系数** | 50 骑 | 对照组（临时清表） |
| 被「轻骑抗箭 ×4」压到 | **0.43x** | 即每 2 次伤害只落地不到 1 次 |
| 改后（×2） | **0.68~0.69x** | **+58%**（35 → ≈56） |

**机理**：克制不是"加减法"而是乘在**防御**上，再经攻防对冲 `cf = 2A/(A+D)` 折算。
×4 防御把"轻骑挨箭"的实际伤害砍到 **0.43 倍**；×5（冲车抗弓）砍到 **0.25 倍** ——
这就是"外的系数给到 3 倍、体感很差"的量化来源。

## 三、探针发现：战斗数字受**天气**影响（机制取证）

排查"同场景两次跑出 11 / 21"时定位到真因：
**雨天 → 弓兵射程 −20%**（`DATA.WEATHERS.rain.archerRange = -0.2`，战斗引擎两条链都读它）→
改变"接敌/开火时机"→ 首轮齐射的**射程衰减**档位不同：

- **晴**（er 1200）：推进到射程边缘（gap=1200）即开火 → 半程外 **0.5 衰减** → 首杀 **11**；
- **雨**（er 960）：本轮推进到 1175 未进射程 → 下轮敌入 300 处开火 → **满伤** → 首杀 **21**。

**这不是随机、不是 bug，是天气设定**（雨天弓射程 −20%）的直接表现。
**探针纪律**：战斗对账必须固定 `world.weather`（详见技能 §90）。

## 六、诚实缺口

1. 降档标定以**双方无将、晴天**为基准；带将与雨天为整体缩放（比值不变）；
2. **表里仍有两个 ×3**：床弩打器械（专项）与枪拒马（"枪克骑"生命线）。若仍嫌高，
   `DATA.COUNTER_ATK/COUNTER_DEF` 一处表值可再降——**但需重标定枪 vs 骑与攻城平衡**；
3. 枪 vs 骑**同数量（骑 2 倍人口）从"胜"变"败"**（敌损 63%）：降档的预期结果，非缺陷；
4. 未动兵种基础数值（hp/atk/def）——"兵种特性本身体现在数值上"的诉求落在"去掉过强的外在系数"。
