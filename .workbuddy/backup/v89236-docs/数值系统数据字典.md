### 9.3 属性对内政的加成公式（产量六项加成来源）

| 加成项 | 公式 | 示例 |
|---|---|---|
| 科技加成 | 基础产量 × 书院科技生效等级 × 10% | 基础粮63000、种植9级 → 63000×9×10% = **56700** |
| 将领加成（统率未超上限时） | 基础产量 × 城守统率 × (1+统率科技×10%) × 城守内政 × 10 ÷ 人口上限 | 城守39级统率39内政107、统率科技7级、人口72100、基础63000 → **61987** |
| 将领加成（统率超上限时） | 基础产量 × 内政 ÷ 100（粮食再减1） | — |
| 宝物加成 | 基础产量 × 25%（使用后24小时有效，连续使用延长；高级宝物7天） | 神农锄/鲁班斧/开山锤/玄铁炉 |
| 野地加成 | 基础产量 × 所占野地资源加成百分比之和 | 10级湖粮+35%、10级木场木+23% |
| 军队加成 | =军队耗粮/小时（**恒为0或负值**；野地驻军耗粮×2） | 100弓箭驻野地：100×9×2 = **-1800**粮/时 |

> 将领分界判据：城守统率×(1+统率科技×10%) 与 人口上限/1000 比大小，选公式。城守等级×1000与人口上限的关系决定内政加成的分支。空闲将领无任何加成——必须任命为城守才生效。

### 9.4 属性对战斗的加成公式

| 公式 | 表达式 | 示例 |
|---|---|---|
| 统帅攻击加成 | 将领统帅 × 100 × 单兵攻击 × 勇武/100 × 该兵种数量 ÷ 总军队数量 | 4级将（统率5勇武90）带500弓+200刀+300枪：弓兵总攻击 = 500×120 + 4×100×120×90/100×500/1000 = **65400** |
| 兵种总攻击 | 兵种数量 × 单兵攻击 + 统帅攻击加成 | 见上行 |
| 生命加成 | 城守内政每5点 → 军队生命+1% | 内政100 = 生命+20% |

> 高统率的本质：统率×100=加成覆盖兵力上限，超出部分的士兵吃不到将领勇武/智谋加成。所以带兵将优先级：**统率 > 勇武 > 智谋 ≈ 内政**；攻城将堆勇武（先手+远程优势），守城将堆智谋+内政。

## 十、出征系统（出兵流程·校场规则·战术设置）

### 10.1 出征的前提条件

| 条件 | 具体要求 |
|---|---|
| 校场 | 必须建造校场；N级校场 = 同时可出征 N 支队伍（侦察/派遣/运输/掠夺/占领/采集均占用出征名额） |
| 每队带兵上限 | N级校场每支出征队伍人口上限 = N × 10000（15级校场一次可出征15万兵）；使用道具可额外+25% |
| 将领与士兵 | 每队至少 1 名将领 + 至少 1 个兵（斥候可单独执行侦察，不带将） |
| 宣战（打玩家） | 攻击玩家城需先宣战，等待 8 小时；联盟宣战无等待 |
| 粮食 | 出征部队耗粮 = 在城耗粮 ×2（行军+在外驻扎翻倍），粮尽则军队哗变进逃兵营 |

### 10.2 出征的两种入口

| 入口 | 操作路径 | 适用场景 |
|---|---|---|
| 大地图点选 | 大地图 → 点击目标野地/城池 → 弹窗选「掠夺 / 占领 / 侦察」→ 选将带兵 | 指定明确目标（推荐） |
| 校场出征面板 | 校场 → 出征 → 输入目标坐标 → 选将 → 配兵 | 已知坐标快速出兵 |
| 助手自动出征 | 校场助手功能：选目标类型（野地/城池/名城）+ 出征方式（掠夺/占领）+ 目标等级 + 直径范围，自动寻的目标连续出征（每次有冷却时间） | 挂机刷野 |

### 10.3 五种出征类型

| 类型 | 用途 | 要点 |
|---|---|---|
| 侦察 | 查野地/城池兵力城防 | 仅需斥候，可无将领；侦察等级不足会被反侦察挡住 |
| 运输 | 城池间运送资源 | 用辎重车（负重5000）效率最高 |
| 派遣 | 部队调动到自己的其他城 | 不消耗战斗 |
| 掠夺 | 攻击目标抢资源，不掉对方民心 | 打县城/玩家城的第一步：先掠夺清光守军 |
| 占领 | 夺取野地/城池所有权 | 打城需连续占领耗尽民心（民怨100后每6分钟降1点） |

### 10.4 出征战术设置（核心技巧）

| 设置项 | 推荐配置 | 原理 |
|---|---|---|
| 弓箭手 | **全部后退** | 开战距离约1500，野兵每回合只前进200~300；设定后退弓兵不前进，敌兵接近前已被射杀大半。不设置则第二回合被近战冲脸 |
| 刀盾兵（炮灰） | 后退 | 全军后退时，逼近的野兵优先攻击刀盾（血高防厚）而非弓兵，保住脆弱的弓 |
| 斥候 | 反复冲锋 | 专破城防「拒马」（1万斥候可撞掉县城拒马） |
| 冲车 | 距城墙3格暂停 | 等刀盾耗光滚木礌石后再前进破墙，避免过早损毁 |
| 设置路径 | 校场 → 出征 → 出征战术 → 野地战/攻城战 分开预设 | 预设后无需手动指挥，出兵即自动执行 |

> 远程兵攻击超出有效射程的目标伤害减半——弓兵会自动优先打击射程内单位，所以马贼（速度快第一回合即入射程）反而最先被集火消灭。

**实例（打县城标准队）**：8万弓 + 3万刀盾 + 1万斥候 + 6000冲车


### 11.4 链D 出征链（校场约束 → 耗粮 → 战果回收）

```
可同时出征队数 = 校场N级｜每队人口上限 = N×10000（军旗×1.25）
负重约束：运输/掠夺量 ≤ 部队总负重（辎重车5000/兵 为最高）
掠夺：不降民心、按仓库存放比例抢｜占领：民怨100后每6分钟-1民心，连续占领至民心0
```

> 出征前置校验链：将领空闲 → 校场队列空位 → 每队人口≤上限 → 负重够运 → 城内粮够(出征耗粮×2) → 出兵。任何一环不满足即无法出征。打玩家需宣战8小时（联盟宣战免等）。

### 11.6 链F 黄金链（人口 → 民心 → 税率）

```
每小时黄金 = 人口上限 × 民心 ÷ 100 × 税率
俸禄/黄金消耗 = Σ(将领等级×20) + 市场交易等｜黄金容量 = 官府等级对应（10级5500万）
```

**实例**：人口上限72100 × 民心100 × 税率50% = **36,050金/h（86.5万/天）**。税率每超50%一档，民心每小时-10×(税-50)/50——税100%时每小时-10民心。安抚百姓：+5民心/次，耗粮=人口上限，15分钟冷却。
