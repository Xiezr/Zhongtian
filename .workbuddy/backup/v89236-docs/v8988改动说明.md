## 一、需求 1~3 · 野外城池（据点）改造

### 1）等级：上限 10 + 构造性配额分布

- `DATA.FORT`：`levelMax` 8 → **10**；新增 `levelDist: { high: [8,9,10], highPct: 0.30, lowPct: 0.10 }`。
- **分布口径**（老板："8、9、10 级城分别占 30%，其他低级城均分 10%"）：
  全图候选据点按**当日哈希**排序 → 按名额切段：前 30% → Lv8 · 次 30% → Lv9 · 再 30% → Lv10 · 末 10% → 1~7 均分。
- **为什么是构造性配额**（v89.72 教训）：掷点占比不成立（161 样本 σ≈3.9%，肉眼可见）。
  本轮 2 万级样本用配额法，**实测精确**：Lv8/9/10 = 30.00%/30.00%/30.00%，1~7 级各 296~297 座（差 ≤1）。
- **位置固定 + 等级逐日重掷**：位置由 `hash(x,y,seed)` 定，与"日"无关（v89.88 起恒为"位置固定"，与 UI 文案一致）；
  等级按 `(seed, 现实日)` 缓存 —— **同日任意次查询完全一致**（渲染/面板/出征/战斗同一份表），逐日重掷（实测次日 ~73% 据点换级）。
- **两个新出口**：`GAME.map._fortLevelTable(day)`（当日等级表）与 `GAME.map._fortLevelAt(day, x, y)`（单格查询，测试/恢复用）。
- **性能**：候选格按 seed 缓存（全图 25 万格扫一次，实测 16ms）；当日配额重算 10ms（14 万次查询摊薄后 ≈ 0）。
  `_fortHash` 内联（与旧 `U.rng(h)()` **逐位等价**，smoke 有 361 点比对断言防漂移）。

### 2）守军 ×10 且恒超同级野地

- `garrisonBase: 50 → 500`（兵种构成不变：义兵 35% / 长枪 25% / 刀盾 20% / 弓 20% + 4 级起轻骑 10%）。
- **逐级对拍野地上限**（实测）：Lv1 500>76 · Lv5 7,954>1,480 · Lv8 58,967>11,470 · Lv10 224,220>57,500 —— **每一级都成立**（smoke 有逐级守卫）。

### 3）建筑满配 + 资源满配

- **建筑**：野外城池建筑 = **自身的城等级满配**（走既有 `GAME.fortPlanOf → cityPlanOf`，与未占据名城同一出口）：
  Lv8/9/10 → 全城建筑 Lv8/9/10、城墙 Lv8/9/10、人口上限 97,200/121,500/148,500、城防 42/46/50（`10 + 等级×4`）。
- **资源（战利品）满配**：`genLoot` 的据点等级因子由线性 `(1+lv×0.12)` 改为**满配曲线 `1.35^(lv-1)`**：
  Lv1 不变（1.0）→ Lv10 = **14.9 倍**（旧口径只有 2.2 倍，"高级据点拿不出城的样子"）。
  上限口径不破：Lv10 的 7.45 仍低于都城档 mult=8（smoke 有"档位次序"守卫）。
- **顺带修一处口径不一致**：侦查「掠夺可得」原先读 `wildResMul.raid`（1.2），而实际结算走 `cityResMul.raid`（0.5）——
  **虚报 2.4 倍**。已对齐，smoke 有行为级断言（同一随机种子下与 `genLoot(t, 0.5)` 逐值相等）。

## 二、需求 4 · 大地图悬浮（坐标 + 等级）

- **做法**：复用既有浮层系统（`ui.tipShow/tipHide` + `.tip-layer`，与 data-tip 提示同一层渲染），
  拾取复用**点击同一条路**（`GAME.map.pick`）；`document` 级 `mousemove` 委托（与重绘无关）。
- **按格节流**：同一格内移动 **0 次重绘**（浮层稳稳停住），换格恰好 1 次（e2e 真实 DOM 实测 `同格×0 · 换格×1`）。
- **四类地块内容**（等级一律走唯一出口）：
  | 地块 | 浮层 |
  |---|---|
  | 己方城池 | `🏯 名（己方）` · 城等级 LvN（`cityLvOf`）· 距主城 N 格 |
  | 名城 | `🏯 州·郡名` · 城等级 LvN（`cityLvOf`）· 档位名 · 点击可出征 |
  | 野外城池 | `🏕 县·名` · 野外城池 LvN（每日变化）· 点击可出征 |
  | 野地/空地 | 地形名 · 野地 LvN（`wildLevelNow`）· 点击可出征 |
  末行恒为 `📍 坐标 (x, y) · 距主城 N 格`。
- **内容出口**：`ui.mapTipFor(hit)`（纯函数，smoke 直接对拍唯一出口；e2e 走真实 mousemove）。

## 三、需求 5 · 界面打磨（审计先行，只补真缺口）

> 审计结论：本项目历经 88 版打磨，令牌体系（字号/间距/圆角/语义色/四套主题）已成熟 —— **不动体系，只补缺口**。

| 缺口（审计发现） | 修复 |
|---|---|
| **浮层对比度不达标**：`.tip-layer` 正文读 `--text-dim`，浅色主题（素绢/青竹）下是深色 → 压在深色浮层上 ≈3.6:1（低于 WCAG AA 4.5:1） | 浮层文字**钉死为高对比暖色**（`#e8ce88` / `#cdc8ba` / `<b>` 提亮）——浮层是全主题共用的"深色卡"，文字跟卡片走 |
| **焦点不可见**：全站仅 2 处自定义焦点样式，键盘走查"看不出焦点在哪" | 全站统一 `:focus-visible` 金色焦点环（鼠标点击不出现） |
| **动效降级不全**：`prefers-reduced-motion` 只覆盖公文徽标闪烁 | 追加全局降级块（全部过渡/动画归零） |
| **地图无光标提示**：整块可点却用默认箭头 | `#mapCanvas { cursor: pointer }` |
| 弹窗无入场反馈（瞬开） | 遮罩淡入 130ms + 面板 7px 上浮 150ms（只动 opacity/transform） |
| 页签图标淡入硬切 | `.nav-ico` 透明度过渡 150ms |

图标盘点：导航 13 个线描 SVG 图标**全部在册**（无缺图、无占位）；新增素材一律走既有 `ICONS/BITMAPS` 管线。

## 四、需求 6 · 全面审查（结构 + 设计 + 自审）

**② 设计审计（设计技能 §11 规程）**：见 §三（4 个真缺口 + 2 个微反馈全部修复）；形状/色板/层级三项一致性锁复核通过。

**③ 自审修复**（本轮新代码的复核发现）：
- `data.js` 据点头部注释仍写"等级 1~8"（stale）→ 更新为 1~10 + 配额口径；
- `_fortCandidates / _fortLevelTable` 补"地图未生成"防御（返回空表，不抛异常）；
- `fortAt` 语义收口：**当日等级表 = 据点存在的唯一事实**（不再二次读 live `hasFort`），
  副作用是"据点位置在整局内固定"（与 UI 文案"位置固定"一致，去掉"占城后邻格冒新据点"的旧怪癖）。

**④ 测试侧假红治理**（三处既有脆弱点，顺手修复）：
- **§87 战斗断言天气敏感**：战斗引擎读天气（雨：弓兵射程 −20%、行军 −20%），该断言在雨天**假红**（本轮实测复现）。
  修法：战斗类断言**钉定天气为「晴」**（与项目既有惯例一致）。
- **§⑦ 据点两处断言"自证式"**：等级随天变化断言原按旧公式现算哈希（改了口径后它测的是"不存在的公式"）；
  守军断言只到 Lv8。均已改为读**真实出口**并覆盖 1~10。
- **e2e §90 战场流转断言随战局摆动**：探针实测**杀伤量随将领强度暴涨**（tong/yw 3000 的强将一回合清场、
  Lv1 弱将同兵力打 4~5 回合），而 e2e 主局老将早已练高 → 点完「完成回合」战场被战果面板替换。
  修法：本段改用**新建 Lv1 弱将** + **Lv2~4 野地**（小规模多兵种）的对称兵力，另钉天气。
- **界面规约联动**：浮层新配色按项目规约**令牌化**（`--tip-ink*`），硬编码色计数守卫继续成立。

## 七、复验指引（试玩）

1. **据点强度**：点开任一据点 → 守军应为同级野地的数倍；看等级（多为 Lv8~10，偶尔低档）。
2. **等级分布**：地图上连看十几个据点 → 应为 8/9/10 为主、偶尔 1~7（次日再看一遍，等级会换、位置不变）。
3. **满配**：据点弹窗"城内建筑"应为「皆 LvN」（N = 据点等级，Lv10 据点全 Lv10、城防 50）。
4. **资源满配**：侦查据点看「掠夺可得」→ 数字应随等级明显放大（Lv10 ≈ Lv1 的 15 倍）；实际掠夺同量级。
5. **悬浮**：鼠标扫地图 → 每格浮出一张小卡（名称 + 等级 + 坐标 + 距主城），移出地图即收起。
6. **界面**：Tab 键走查能看到金色焦点环；弹窗打开有轻微上浮；把系统设为"减少动态效果"后动效全部静止。
