## 二、战场距离（🔴 玩家实测 + 🟢 官方交叉验证）

### 2.1 公式

```
战场距离 = 双方【最远射程】 + 199        ← 玩家实测（多源一致）
战场距离 = 最大射程 + 200                ← 🟢 4399 官方「战争系统」
```

两个数字差 1，应为边界取整口径不同。**用 +199 或 +200 都可以，但必须统一。**

例证（🔴 实测）：
- **野战/掠夺**：无远程兵、无城防时 战场距离 = **270**
  —— 这条本身就是公式的自洽验证：全场最远射程只剩铁骑的 **70**（近战最大射程），
  `70 + 200 = 270` ✓。也就是说**近战射程也参与"最远射程"的比较**，不是只看远程。
- 满抛射（10 级）时：弓 **1999**、床弩 **2299**、投石 **2599** → 逐项 = 射程 ×1.5 + 199
  （1200×1.5=1800 +199 = 1999 ✓　1400×1.5=2100+199=2299 ✓　1600×1.5=2400+199=2599 ✓）
- 十抛射十城墙（3079）= 投石 1600×1.8=2880 + 199 ✓
- 抛射 3 级：**1580**（弓 1200×1.15=1380 + 199 ≈ 1579 ✓）；抛射 6 级：**约 1700**（1200×1.3=1560+199=1759，源文写"1700 左右"）

### 2.2 三种场地的起算点

| 场地 | 起算方式 |
|---|---|
| 野战 / 掠夺 | 双方各在两端，距离 = 最远射程 + 199 |
| **攻城** | 守方兵种在**位置 0**、**城墙在位置 100**；城防射程**从 100 起算**（这就是"箭塔射程 2500，我在 2600 还被打到"的原因） |
| 跨服「决战天下 v2.0」 | **双方射程最远兵种 + 800**（投石 1600 → 2400） |

### 2.3 为什么战场距离是核心机制

🔴 实测结论："**抛射科技影响的不是只有弓的射程，对战场的距离也有影响**"。
即：射程科技同时抬高"开战间距"，这让**远程方获得先手**（先动先射），
也解释了老玩家反复强调的"弓的第 1 回合先发打击是关键"。
→ **战场距离不是背景参数，它是先手权的一部分。**

## 四、出手次数与反击

🟢 官方「战争系统」原文三条（这段是本次检索**最重要的收获**）：

> 1. 每一回合，按照速度决定行动次序。速度快的军队先行动。速度相同时，防守方先行动。
> 2. **如果双方都在射程内，则攻击方的每次进攻都将遭到防御方的反击。其反击人数按照被攻击后的数量计算。**
> 3. **每回合每个兵种攻击一个目标。**如果射程内有指定目标则攻击指定目标，如果没有则任意攻击一个。

推论：
- **出手次数 = 每兵种每回合 1 次**（不是"速度高就出手多次"）。
  速度只决定**先后**，不决定**次数**。
- **反击**是"额外一次"伤害，且**反击方用的是"被打之后剩余的兵力"**
  —— 所以战报里反击伤害会随回合递减（🔴 战报实证：同一支部队第 2 回合反击 10,710,272，
  第 3 回合只剩 1,231,194）。
- 反击的触发条件：**双方都在射程内**（远程隔空打时不会被反击）。

🔴 战报实录（回合 1~5 摘录，可作行为基准）：

```
【回合1】[攻]轻骑兵前进1500
        [守]轻骑兵前进500,攻击2771215,[攻]轻骑兵230-230=0
        [攻]铁骑兵前进900
        [守]铁骑兵防御 / 长枪兵前进600 / 刀盾兵前进550
        [守]弓箭兵前进500,攻击3535683,[攻]铁骑兵24878-2357=22521
【回合2】[守]轻骑兵后退500
        [攻]铁骑兵前进500,攻击17023246,[守]长枪兵500-500=0
        [守]铁骑兵前进600,攻击6678200,[攻]铁骑兵22521-4452=18069
        [攻]铁骑兵反击10710272,[守]铁骑兵23890-7140=16750     ← 被打者立即反击
```
可读出：**每兵种每回合只动一次**（前进 N 步或后退 N 步或防御），动完若射程内则攻击；
步数 ≈ 该兵种的满科技速度（轻骑 1500、铁骑 900、枪 600、刀盾 550、弓 500）。

### 5.1 射程怎么涨（🔴 实测表格，10 级抛射 + 10 级城墙）

| 兵种 | 基础射程 | 科技加成 | 城墙加成 | 实际射程 |
|---|---|---|---|---|
| 弓兵 | 1200 | +50% | +30% | **2160** |
| 床弩 | 1400 | +50% | +30% | **2520** |
| 投石 | 1600 | +50% | +30% | **2880** |
| 箭塔 | 1250 | +50% | +30% | **2250**（+100 墙位移 = 2350） |
| 陷阱 | 2000 | 0 | 0 | 2000（+100 = 2100） |
| 拒马 / 滚木 / 擂石 | 800 / 500 / 250 | 0 | 0 | 各 +100 |

**结论公式**：
```
进攻方远程射程 = 基础射程 × (1 + 抛射技巧 5%/级)
守城方远程射程 = 基础射程 × (1 + 抛射技巧 5%/级) × (1 + 城墙 3%/级)
城防固定件射程 = 基础射程 + 100（墙位移）
```
交叉验证：另一篇 43u 攻略写"GJ 版本破城防满抛射射程 **1800**"（=1200×1.5，进攻方无城墙加成）、
"CN 版本 **2100**"（=1400×1.5）→ 与上式吻合 ✅

### 5.2 距离带来的伤害衰减（**原版有、我们没有**）

| 距离区间 | 伤害 |
|---|---|
| 射程的 **1/2 以内** | **全伤害** |
| 射程的 **1/2 以外、射程以内** | **半伤害** |
| **贴身**（被近战贴住） | 🔴 两说：**1/4**（game2 论坛实测帖）／**1/10**（乐都科技攻略）。两源冲突，未定 |

🔴 计算帖的原话："远程在半程外及贴身，分别是**杀兵数**变为 1/2 及 1/4 ——
而**并不是兵攻变成 1/2 及 1/4**"。
→ 差别在于"减半作用在伤害上"还是"作用在攻击力上"，会**影响相克因子与科技的叠乘顺序**。
另有说法把远程基础攻击**先除以 2** 再计算，全伤害射程时再 **×2** 还原（数值上等价于"半程外半伤害"）。

### 5.3 城防的"双倍攻击区"（🔴 单源，待验证）

> 箭塔：2350，攻击区【0, 2350】，**双倍攻击区【0, 2250/2 + 100 = 1225】**

即箭塔在**近半个射程内打双倍**（另一半 +100 是墙位移）。若属实，
则"贴脸拆箭塔"和"远处对射"的收益差一倍，直接影响攻城战术。

## 八、伤害公式（🔴 玩家推导，两版，结构一致）

```
统御率 = 满统兵数 / 出征兵数（上限 100%）

攻方兵攻 = 兵种基础攻击 × (1 + 0.5% × 战斗科技 + 0.1% × 武将攻击 × 攻方统御率)
守方兵防 = 兵种基础防御 × (1 + 0.5% × 防守科技 + 0.1% × 武将防御 × 守方统御率)

每兵伤害 = 攻方兵攻² / (攻方兵攻 + 守方兵防)
杀兵数   = 兵士数 × 每兵伤害 / 守方生命
守方生命 = 兵种基础生命 × (1 + 5% × 补给科技 + 1% × (武将内政 / 5) × 守方统御率)

远程专用：兵攻先 ÷2 代入，全伤害射程时结果 ×2（等价于"半程外半伤害"）
```

要点：
- **核心是 `攻²/(攻+防)`**，不是 `攻 − 防`。所以"堆攻击"在攻击力远超对方防御时收益递减式放大。
- **统御率同时作用于攻与防** → 超统带兵"杀伤略增、抗击力急速下降"（🔴 原帖结论）。
- 相克因子的挂载点要看版本：挂在"兵攻"上还是"兵防"上，结果不同（见第七节）。

## 九、阵位与指挥指令

🟢 2024 年新战术指挥系统（官方论坛攻略）：

- 每个兵种两个变量：**动作**（前进 / 防御 / 后退）+ **目标**（敌方某一兵种）。
- **默认动作决定初始站位**：前进 = **100**（第一排）、防御 = **50**（第二排）、后退 = **0**（第三排）。
- 攻城时**城墙在位置 100**，所以"前排在城墙前"。
- 若指定目标在射程内 → 优先打指定目标；否则打射程内任意目标。
- **防御**动作 = 本回合不攻击、受到的伤害**减半**（新版手动战斗里还多了"保护"指令）。
- 出征前可在**校场 → 出征 → 出征战术**里设默认动作；防守方在校场 → 防守战术里设。

🔴 老版（页游）：每回合有指挥时间，玩家给每个兵种下"前进/防御/撤退"，
**下一回合该兵种按命令行事**（命令有一回合延迟）。
