## ⓪ 澄清：元宝 / 240（老板上轮的两个疑问）

**游戏没有"元宝"货币**（玩家可见只有 金 / 粮 / 木 / 石 / 铁）——"元宝"是 v1 遗留词，只残留在我上轮的
交付说明与几处**代码注释**里；商城显示的一直是"金"。本轮已把 4 处注释口径统一为
「**内部价（商城实售 = price × 100 金）**」，并在数据表里补了换算示例。

**独山玉（240）的 240** = 数据表**内部定价单位**：商城实售 = 240 × 100 = **24000 金**。
同口径换算：蚌珠 2 → 200 金 · 夜明珠 150 → 15000 金。以后给老板的说明一律用"金"口径。

## ② 系统页 = 军情 / 任务 / 系统 三源合一 + 小标签（老板 2）

- **军情**：战报页下半段的「军情」流水**整条挪入**系统页（`ui.warFlowOf` 退役）；
  战报页现在**只列战报**（报告列表 + 胜/败/收藏筛选 + 分页）。
- **任务**：可领取摘要（"任务 · 可领取 N 项"）+ 任务类消息都在系统页；
  摘要只在「全部 / 任务」标签下置顶显示。
- **小标签**（参考战报的 全部/胜/败 样式）：`全部 · 军情 · 任务 · 改元 · 天时 · 建造 · 采集收获 · 系统`
  —— **只列"有消息的"**（与宝物页分类同口径）。
- **字体颜色不同**：小标签与消息行都按主题上色。颜色是**数据表的属性**
  （`DATA.MSG_SUBS[].color` / `DATA.MSG_TAG_COLOR`）—— chips 与行内 style 都从表读，改色只改表。

**架构（三级分类 · 可扩展）**：
```
kind（大类 = 页签归属：war / scout / sys；beacon、task 保留值域不出页签）
  └─ sub（主题 = 系统页小标签：era / weather / build / gather）
发射点：GAME.log(msg, kind, sub)   （GAME.log.gather(msg) 等命名空间同上）
读取：  GAME.msgSubOf(rec)（唯一出口：有 sub 按 sub，否则按 kind）
池子：  GAME.msgFeedOf()（唯一出口：军情+任务+系统三源合一、时间倒序）
```
已打标的发射点：天时（story.js）· 改元（story.js）· 建造 ×3（state.js 两处 + domain.js 自动升级）·
采集 ×5（domain.js：开始 / 不足 1 小时 / 收获 / 自动收获 / 停采）。加主题 = 表加一行 + 发射点补第三参数。
