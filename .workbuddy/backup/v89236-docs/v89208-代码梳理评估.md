## ⑤ 玩家可控文本转义面【新】

**为什么查**：玩家能改的字只有 3 个来源——开局君主名（`#create-name`）、
改城名（`#rename-city-input`）、改君主名（`#rename-lord-input`）。这些字会进 `innerHTML`，
不过转义就是"自定义名字能改坏版面"的风险位。

| 项 | 数量 |
|---|---|
| `U.escape` 全仓用量 | **398** |
| 含玩家可控 `.name` 的 HTML 行 · **已转义** | 11 |
| 含玩家可控 `.name` 的 HTML 行 · 探针报未转义 | 8 → **逐条核实全假阳性** |

8 处命中逐条结论：

| 位置 | 实况 | 判定 |
|---|---|---|
| domain.js:2006 / 2008 / 2159 / 4785 / 5759 / 7634（6 处） | 都是 `return { ok:false, msg: city.name + … }` —— **错误文案**，最终经 `ui.toast → ui.notify → U.escape` 落 DOM | ✅ 安全（转义在出口，不在拼串处） |
| ui.js:7364 | `{ name: c.name, rank: … }` —— **数据对象**，非 HTML | ✅ 非转义面 |
| ui.js:16795 | `'<div class="farm-crop">' + c.name` —— 此处 `c` 是**作物种子**（`DATA.FARM`），非城池 | ✅ 非玩家可控 |

**结论：0 处真缺口**。转义纪律的实际形态是"
**出口统一转义**（toast/notify 层）而非"拼串处逐点转义"——这是更省心的形态，
但**代价是拼串处看不出来**，所以本探针的假阳性率天然高。尺子已保留（能发现"新开一条
不走 notify 的 HTML 出口"这类真缺口），但**读的时候必须先看是不是 msg 文案**。
