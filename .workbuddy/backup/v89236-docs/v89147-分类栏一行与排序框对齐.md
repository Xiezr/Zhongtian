# v89.147 分类栏一行 + 排序框对齐（装备页 4 主类 / 宝物页左起 / 两页排序框同位置）

> 老板原文（逐字）：
> 1.背包，装备界面，上边分类栏保持在一行，位于界面左侧，状态，品质，散件，全部这4个作为主类，依次往右排列
> 2.宝物界面也是，分类从从界面左侧开始，目前是居中。
> 3.设置文字间距，使得装备和宝物界面的排序框在同一位置，使界面一致性更好

---

## ① 装备页分类栏：一行 4 主类（左侧起）

| 项 | 改前 | 改后 |
|---|---|---|
| 布局 | **两排居中**（row1 类别：全部/套装/散件；row2：`状态`+`品质` 两组） | **一行 4 组、左起** |
| 主类 | — | `状态`（全部/未穿戴/已穿戴）→ `品质`（全部/Q1…）→ `散件`（全部/套装/散件 + 套名细化）→ **`全部`**（重置） |
| 第 4 主类「全部」 | 无 | **一键把三个维度还原**（`setBagEqFilter('reset')` 新分支）；激活态 = 当前即全默认 |
| 容器 | `.chips.chips-xs` + 内联 `justify-content:center` | `.chips.chips-xs.bag-filterrow`（块级占满 + 左起 + 不换行） |

## ② 宝物页分类条：左起

原因：`.chips` 是 `inline-flex`（**内容宽 = 自身宽**）→ "居中"其实是父级把整个 inline 盒子居中。
改挂同款 `.bag-filterrow`（`display:flex; width:100%; justify-content:flex-start`）后从界面左侧起排。

## ③ 两页排序框：同一位置

两页分类行**用同一个类**：`.chips.bag-filterrow { min-height: 32px; flex-wrap: nowrap; }` ——
行高恒定 → 其后的 `.bag-sortbar`（排序框）落在同一 y。
`nowrap` 是前提：装备页在「套装」下追加套名 chips 时**横向滚动**、行高不因此长高。

## 关于第 4 主类「全部」的说明

按您的原话把 4 个词（状态 / 品质 / 散件 / 全部）做成一行 4 个主类：
前三个是**筛选维度**（各带"全部"选项），第 4 个「全部」是**一键还原**（点了之后三个维度都回到"全部"，
也就是重新显示全部装备）。若您想要的"全部"是别的作用（例如单纯显示数量），说一声即可改。
