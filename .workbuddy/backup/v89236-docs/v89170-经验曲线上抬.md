# v89.170 · 经验曲线上抬（前期抬高 · 全程低于线性 · 道具不再一步登天）

> 老板原文：等级诡异在前期所需经验太低了，曲线应该上抬一点，比直接线性低，
> 但低到目前的承担有点离谱了，玩家只要花 24 万金买兵仙遗篇，直升一百多级，
> 这样军队战斗和将领升级的体验感受不到

## ① 病根（一句话）

两段式曲线（v89.82）把"体验份量"全压进了最后 40 级：**Lv100 的累计只占全曲线 0.59%**，
于是「兵仙遗篇」（商城 24 万金 = 曲线总量的 10%）从 Lv1 一路飞升到 **Lv177**
—— 军队战斗与将领升级的体验被一份道具整个跳过。

## ② 改法（单段幂律）

```
need(lv) = 100万 × (lv / 240)^1.25        ← DATA.EXP_CURVE.alpha = 1.25
```

| # | 项 | 改前（v89.82~v89.169） | 改后（v89.170） |
|---|---|---|---|
| 形状 | 两段式：Lv1~30 二次起步 + Lv31~240 每级 ×1.037 | **单段幂律**（全程平滑、无接缝） |
| 锚点 | need(240) = 100 万 | **不变**（拍板锚点） |
| 起步 | Lv1 需 41 | **1,059**（×25.8） |
| Lv100 | 6,215 | **334,762**（×53.9） |
| 与线性的关系 | 深趴在线下（Lv100 处约 1.5%） | **低于线性但贴合**（Lv100 处 80.7% / 最高 99.9%） |
| 折角 | Lv30→31 每级增幅 +29→+18（v89.168 暴露） | **消失**（单段幂律天然平滑） |
| 兵仙遗篇（24 万金） | Lv1 → **177** | Lv1 → **86** |
| 千古兵圣（40 万金） | Lv1 → 196 | Lv1 → 118 |
| 前 100 级累计占比 | 0.59% | **14.04%** |

**数值设计说明**：
- **为什么是 1.25 次幂**：幂律指数 α=1 即"穿过原点的直线"；α>1 = 凸曲线（在弦下方）。
  α=1.25 是"上抬到接近线性、但仍保留前轻后重"的位置——换算成直觉：
  **累计占比 = (lv/240)^2.25**，Lv100 占 14%、Lv150 占 35%、Lv200 占 66%。
- **为什么不能再高（比如 α=1.5+）**：α 越大，10% 总量覆盖的等级越高（越回到"道具一步登天"），
  且低段会陡到"Lv1→2 就要翻倍多"；α 太小（<1）则曲线凹到线性以上，违反"比直接线性低"。
  α=1.25 是同时满足两个约束的甜点。
- **调平衡旋钮**：`DATA.EXP_CURVE.alpha`（形状）与 `needTop`（锚点）—— 只改这两处。

## ⑤ 诚实缺口

1. **高等级升级变慢是预期副作用**（见 ③ 表）：县城级战斗从"Lv177 前全程 0.8 级/场"变成
   "覆盖到 ~Lv38"；高等级要靠更大的仗（州城级到 Lv126 仍 0.8 级/场）、练功或道具。
   若体感过慢：调 `DATA.EXP_RULE.perResource`（战斗经验换算）或 `alpha` —— 都是单点旋钮。
2. **侦察（固定 30）/采集（20+收获/500）的相对价值变小**（旧 Lv1 时侦察 = 0.73 级，
   现在 0.03 级）—— 二者本就是"零风险小额/副产物"，暂列为观察项。
3. **老档经验池**：新 need 全程 ≥ 旧 need（唯 Lv240 相等）→ `migrateExpScale` 的截断
   只少不多，不会白送等级；但老将的"距升级进度条"会看起来"倒退"（分母变大了）。
