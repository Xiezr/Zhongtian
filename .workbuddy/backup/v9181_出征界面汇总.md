# 出征界面汇总（v91.76 · 固定界面版）

> 结论先行：**全站只有一套出征界面**（`ui.openExpModal`），所有"派兵/用兵"入口都走它。
> **固定一个完整界面**：主档恒在，不适用项**置灰并说明**，不再按形态隐藏。
> **到达性限制由目标决定，出发性限制由派出城决定，通用内容恒在。**

## 二、固定主档（每个形态都有且只有一份）

1. **标题**：当前目标全称。
2. **一行形态摘要**：`ui.expShapeSummary`。
3. **目标行（单行）**：当前目标全称（左）+「其他目标」按钮（右，弹窗分类选择）。v91.77 起**不再重复渲染第二行目标**——「其他目标」并入首行右侧。
4. **相称建议** / **限制性信息**（到达性限制：领地上限、野地上限、据点每日掠夺）。
5. **派出城**：缺省当前城，可选**本星球全部己方城**（单城为静态名）。
6. **主将**：只列**派出城**的英雄（本城全部 + 置灰注明），另有「不派将」。
7. **出征方式**：恒列 7 种，不适用置灰并写原因（`ui.expModeAvailOf` 唯一出口）。
8. **探索层级 / 探索行动**（仅奇观目标出现）。
9. **方案 / 出征战术 / 计略**：恒在；非接战方式整块置灰。方案按派出城练兵场上限裁剪。
10. **可用道具**：恒在（作用于当前主将）。
11. **派遣兵力**：右列独占，14 兵种全列，每行「上限 / 清空」。
12. **预估**：恒在，内容按方式切换。
13. **辎重 · 资源调配**：仅「运输」展开，列 = 资源 / 现有 / **上限（不超过运力的最高数量）** / 起运 / 全 / 实收。
14. **确认**：文案随方式（探索/占领/派驻/派遣/起运）+ 推演 / 战备快购（仅战斗）/ 取消。

## 三、7 种出征方式

| 方式 | 目标 | 说明 | 无需英雄 |
|---|---|---|---|
| 侦查 | 野地/据点/名城 | 不接战，探守军+少量物资 | 否 |
| 掠夺 | 野地/据点/名城 | 不占城，财货最丰 | 否 |
| 占领 | 野地/据点/名城 | 野地就驻、据点收为前哨、名城易主 | 否 |
| 派遣 | 己方城市 | 英雄归属变化 + 两城兵种减增 | **是** |
| 运输 | 己方城市 | 用英雄/兵种负重调资源；送达后**原路返回**（耗时同去程） | **是** |
| 派驻 | 己方野地 | 藏兵；无将驻军**不可采集** | **是**（后果在摘要说明） |
| 探索 | 奇观 | 统一奇观入口；「探索层级」>0 = 挑战该层守卫，否则按探索行动采集 | 视行动 |

## 四、到达性 vs 出发性限制

- **到达性（由目标决定）**：方式候选项、领地上限、野地上限、据点每日掠夺、奇观层级未解锁、目标是否为己方。
- **出发性（由派出城决定）**：主将列表、方案、战术、计略、辎重、兵力与上限（练兵场 / 驻军上限 / 不限）。
- **通用**：出征战术、计略、道具、预估。
- 判定唯一出口：`ui.expModeAvailOf(modeId)`（界面置灰）与 `GAME.battle.prepare`（执行端）同源。

## 五、v91.77 本次改动

1. 出征面板**目标行去重**：原「目标（仅名称）」与「目标 + 其他目标按钮」两行合并为**单行**——名称在左、「其他目标」按钮在右（`.exp-one` 占满剩余宽度把按钮顶到右侧）。删掉重复的下方目标行。
2. 「其他目标」弹窗（仅本星球）改版：**左侧 1/4 分类导航**（己方城市 / 己方野地 / 周围 30 格野地 / 周围 30 格据点 / 名城 / 奇观），**右侧展示**选中分类的目标；只列非空分类，点击切换。名城仍按「区 → 城」分级。

## 五、v91.76 本次改动

1. 方式拆分：`transfer` 拆为 **派遣 `dispatch` / 运输 `transport`**（旧 `transfer` 保留为内部别名）；奇观统一为 **`explore`** + 探索层级。
2. 无将放行：派遣/运输/派驻可不带英雄（运输只按运力校验）。
3. 运输返程：`roundTrip` 标记；送达卸货后自动原路返回（耗时同去程）。
4. 固定界面：方案/战术/计略/预估恒渲染，非接战方式整块置灰。
5. 目标：「当前目标 + 其他目标」弹窗（本星球、按类型、名城按区分级）。
6. 派出城/主将/方案/预估/限制性信息统一按 `ui.expFromCity()` 读。
7. 辎重：新增「上限」列与输入封顶；只在运输展开；放在两列之后避免撑爆列高。
8. 顺修：方式粘滞（上次运输→这次点野地）、军务出征页把 (x,y) 当 ci 的候选 bug。
