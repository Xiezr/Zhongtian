## 二、老板 2：自动征兵（构思界面 + 设置：触发/停止/目标兵种/可用栏位判别）

### 界面（自动化 → 🛡️ 自动征兵；募兵面板队列页有快捷入口）

- **规则四行**：触发条件 / 停止条件 / 执行范围 / **可用栏位** —— 逐字回答老板点名的四件套；
- **目标兵种表**：15 个非器械兵种 ×（**触发线**（低于即补）/ **目标**（补到）/ 全境现状）；
- **资源保底**：黄金 ≥ N · 粮草（各城）≥ N（0 = 不保底）；
- **各城栏位与缺口**：逐城实时 —— 军营 N 座 · 空位 `X/Y` · 待补缺口（判别走同一把尺）；
- **触发记录**：最近 8 单（城 / 兵种 / 数量），与「自动治疗」同款。

### 口径（全境统一规则、**逐城独立执行**）

| 项 | 口径 |
|---|---|
| 触发 | 某城某兵种（**驻军 + 在训 + 排队**）低于「触发线」→ 补单（触发线 0 = 低于目标就补） |
| 停止 | 达到「目标」即停 · 金/粮低于保底即停（**暂停不关开关**）· 军营队列满则等待（消化后自动继续） |
| 可用栏位 | 只往**有空位**的军营放单 —— 空位 = Σ军营（队列位 − 已占），`trainSlotsLeft` 唯一出口（与募兵面板同一把尺） |
| 兵种范围 | 非器械 15 种；器械（床弩/冲车/投石车）走工匠作坊队列，不在此列 |
| 节流 | 每 **10 现实秒**最多检查一轮（主循环挂钩 `tickOnce`；关闭时零开销） |

### 引擎（唯一出口组 · domain.js）

`GAME.autoTrainCfg`（配置存取与补全）· `GAME.autoTrainSet`（数值落库）·
`GAME.autoTrainPlanOf(city)`（**逐城判别**：军营空位 + 各兵种缺口）· `GAME.autoTrainTick`（执行）。
配套：`canTrain(troopId, city?)` 与 `trainLimitOf(troopId, city?)` 加**可选城参数**（逐城判别用；
不传 = 当前城，旧调用零改动）——自动征兵给别的城补兵时，门槛与资源上限按**目标城**算。

### 探针实测（probe_v89190a · 真调）

```
plan：军营 1 空位 1/1 缺口 [{troopId:changqiang, …, max:500, need:500}]
tick#1 done=1 acted=[{城:新城池, 兵:长枪兵, 数:500}]        ← 触发补单
tick#2 done=0 msg=待命 —— 各城已达标                       ← 在训计入 → 达标即停
tick#3 done=0 msg=暂停：黄金低于保底                        ← 资源保底
tick#6 done=0 msg=暂停：新城池 队列已满                     ← 队列满 → 等待消化
canTrain(changqiang, 无营城) = {ok:false, "需军营 Lv2　需书院 Lv2"}   ← 城参数真按目标城
```

## 五、诚实缺口（待老板定夺 / 下轮候补）

1. **自动征兵目标为全境统一**（各城同规则、逐城执行）——「不同城不同目标」是把 targets 挂到 city 的小改，未做；
2. **器械不参与**（床弩/冲车/投石车走作坊队列）——如需自动造械，要另开作坊判别分支；
3. 补单**只填空位**，不排「等待位」（队列满即等消化，不再叠单）——若想"排到 3 位满"，改一处循环上限；
4. 据点情报：**前哨格本身**（我的前哨=城市视觉格）未加情报按钮（点击走据点面板，口径不同）；
5. 老档安置为一次性「补足」，无逐日衰减/动画（如需仪式感可加）。
