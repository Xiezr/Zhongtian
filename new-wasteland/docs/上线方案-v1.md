# 上线方案 · v1.0

> 目标：把 `new-wasteland` 从"能玩的原型"推到"能发给别人玩的线上版本"。
> 推进方式：分五阶段，每阶段**实现 → 实测 → 评估 → 再进下一阶段**，卡住才停。

---

## 零、先说结论性的两个判断

**判断一：不接旧战斗引擎。**
实测：`js/bundle.js` 能在空白页载入，`GAME.tactic.simulate` 也能跑（30k vs 20k → 2 回合结束）。
但它的 UI 启动会碰 `classList of null`，且 iframe 隔离在 `file://` 下会被浏览器拦。
**代价大于收益。** 改成"编成角色制"——让 17 个兵种在远征里承担不同职能。

**判断二：编成必须有取舍，不能是"战力加法"。**
旧项目里编成死在东风手上，是因为所有兵种只竞争"每回合伤害"一根轴。
这一版给每类兵一个**不同的轴**：火力 / 装甲 / 侦察 / 运输。
四个轴各自解决不同问题，带谁就放弃谁 —— 这才是编成。

## 二、P1 · 编成系统（详细）

### 四个职能轴

| 轴 | 作用 | 谁给 | 代价 |
|---|---|---|---|
| **火力** | 提高击杀速度（打得更快 = 挨打更少） | 东风、自走炮、轨道炮、轰炸机、直升机 | 吃人口、脆 |
| **装甲** | 降低每次伤亡 | 主战、泰坦、盾卫、电磁盾卫 | 吃人口、慢 |
| **侦察** | 降低遭遇率 / 提前发现（危险 -1 档） | 侦察车、伏击车 | 不打架 |
| **运输** | 提高补给上限（走得更远） | 运输平台、板车 | 不打架 |

### 队伍编成

- 队伍容量 = 8 格（每单位按人口占格：步行机 1、主战 4、泰坦 5）
- 招募时给默认编成（4 主战 + 4 步行机）
- 聚落/物资站可补充特定兵种
- **编成决定这一队能干什么**：能打、能扛、能探、能走远——四选二

### 结算改造

```
火力 F = Σ(数量 × 攻) / 参考值
装甲 A = Σ(数量 × 血) / 参考值
侦察 S = Σ(数量 × 侦察权重)
运输 T = Σ(数量 × 载重)
危险 d = tileDanger - S（最低 1）
击杀比 = F / d
伤亡比 = d / (A + 1)
补给上限 = 6 + T
```

### 验收

1. 同一格子，四种偏科编成（火力/装甲/侦察/运输）产生**不同结果**，差值 ≥10 点战损或 ≥2 格补给；
2. 没有一种编成在所有场景最优（防守型打不过据点、火力型走不远）；
3. 旧测试全绿。

## 三、P2 · 斗将（详细）

**触发**：攻打据点 / 重镇 / 旧都时，对方守将叫阵。可拒绝（全军士气 −15%）。

**规则**：
- 5 回合，每回合双方各出一招：突刺 / 格挡 / 佯攻 / 蓄力
- 克制：突刺破格挡、格挡防蓄力、佯攻骗突刺、蓄力打佯攻
- 看不到对手这回合出什么，但能看到他前三回合的习惯
- 将领性格决定招式池（猛将没有格挡、智将有佯攻加成）
- 赢：全军攻防 +15%，守军士气崩（危险 −1）；输：主将受伤，本场危险 +1

**验收**：一场 30 秒；同样的将，换一套出招顺序胜率变化 ≥30 个百分点。

---

## 四、P3 · 势力外交（详细）

三家各有一次主动找你：

| 势力 | 要什么 | 给什么 | 拒绝的后果 |
|---|---|---|---|
| 铁锈会 | 水厂图纸 | 零件（修泵）、帮你打一次 | 他们开始往你这边扩张 |
| 灰烬教团 | 你烧掉自动控制柜 | 人（+6 人口）、粮 | 他们不再跟你交易 |
| 商队联盟 | 过路费（粮） | 情报（地图上随机 3 格点亮） | 物价上涨 |

选边之后，另外两家会变敌对。这是"世界有意图"的第一步。

**验收**：三家事件都能触发；选边后地图颜色/扩张方向有可见变化。

## 五、P4 · 打磨

- 第一次打开：自动选中队伍 + 一句"点金色的格子"提示
- 队伍编成界面（现在只能看不能改）
- 失败感：队伍全灭后给一页"这一队没了"，不是静默消失
- 移动端：1080 最小宽度在手机上会横向滚动，改成自适应

---

## 六、P5 · 上线

- 部署到可公开访问的链接
- 验收：外部设备能打开、能存档、手机竖屏能玩、加载 <5 秒

---

## 七、不做的

- 接旧战斗引擎（理由见零）
- 塔防 / 卡牌构筑 / 收缩圈（属于第二部玩法，不在这次上线范围）
- 多人 / 服务端（这一版是单机存档）

**门禁**：jsdom 流程测试 **70 项全绿**；无头 Edge 实截 **12 张**，无页面错误（除 favicon 404）。

**与方案的两处偏差（都是实测后改的）**：
1. 不接旧战斗引擎：`bundle.js` 能载入、`GAME.tactic.simulate` 能跑，但它的 UI 启动会碰 DOM，
   且 iframe 隔离在 `file://` 下被浏览器拦。代价大于收益，改成「编成角色制」。
2. 编制上限从固定 8 改成 **12 + 每年 2**：固定 8 时旧都对任何编成都是死局，
   而且默认 8 步行机正好占满、无法换装。
