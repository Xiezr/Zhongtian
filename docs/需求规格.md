1. **点击奇遇**（v89.29）：点建筑 / 城外建筑 / 地块 / 城池掷骰（35% 首遇 · 12% 重读 · 60 秒冷却），命中随机抽一篇完整故事叠层开卷；
2. **动作触发**（v89.31）：14 个动作键（战事 4 / 营造 3 / 民生 4 / 成长 3）结算后偶遇，池子按「相关建筑 + 题材标签」解析；
3. **世事并入**（v89.39）：40 篇世事（misc）不设独立 UI，按 `miscTags` 并入各动作池（晋升→《策勋》· 胜仗→《凯旋》· 迁址→《迁治》…）。

**工装**：`manifest.json` 台账（pending 队首 = 断点续传接口）· `check.py`（12 判据）· `check_file.py`
（`.part` 单文件校验，并行零冲突）· `story/README.md`（§七 题材四线写作规范）。

**版本节点**：v89.6.3~6.4（立项+样张）→ v89.8（结构 v2）→ v89.9/10（铺量启动+自动续批）→ v89.14（提速）
