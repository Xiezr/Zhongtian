## ① 斗将结果：顶部固定一行

**病根**：斗将播报行只渲染在回合战况（`#bt-log`）**最底**（时间最早处）—— 玩家要滚到底才看得到，
而且它会随 64 行裁剪被 `BT_LOG_MAX` 吃掉。

**改法**（文案唯一出口，两处同源）：

| 位置 | 改前 | 改后 |
|---|---|---|
| 文案 | 内联在 `btDuelHTML` | **`ui.btDuelLine(rec)`** 唯一出口（顶部行与战况行都读它） |
| 战场顶部 | 无 | **`ui.btDuelBarHTML(rec)`** → `.bt-duelbar` 整块排在 `.bt-top`（读秒/三键）**之前** |
| 回合战况 | 那一行（保留） | 不变（战前事件的历史记录，不丢） |

未触发 / 无会话 → 顶部**不占位**（返回空串）。

## ② 「上限 / 清空」挪进每个兵种行

**病根**：两枚键挂在「派遣兵力 · 兵种数量」**标题旁**（全局一键：按兵种表序把额度分下去）——
老板要的是"对单独兵种数量进行操作"。

**改法**：

| 项 | 改前 | 改后 |
|---|---|---|
| 按钮位置 | 标题栏 `[上限][清空]`（全局） | **每个兵种行** `[上限][清空]`（18 个兵种 × 2 键） |
| 表头第 4 列 | 「上限」（单键「全」） | **「操作」**（两个键） |
| 列宽 | 42 / 22 / 21 / **15** % | 40 / 19 / 19 / **22** % |
| 「上限」口径 | 全局按行序分配（吃剩余额度） | **该行** = `min(该兵种拥有, 总额度 − 其他行已填)`（唯一出口 `ui.expTroopMaxOf`；不限 → 拥有数） |
| 「清空」 | 全局清零 | **只清该行** |
| 分配顺序 | （曾建议"强兵优先"） | **玩家点哪行算哪行**（老板明确否掉强兵优先） |
| 动作 | `exp-fill-all` / `exp-clear-all`（全局）+ `exp-max`（=拥有） | `exp-max` 语义升级 + **新增 `exp-zero`**；前两枚**整条退役**（case 一并删） |
| 悬停 | 全局算法说明 | `ui.expTroopTipOf`（该行拥有 + 额度口径 + 额度来源） |
| 额度占满 | 静默填 0 | **toast 说明**："本次总额度已被其他兵种占满 —— 先清空其他行，再点「上限」" |

## ③ 「编制 · 出战能力」→「军队校场扩容」独立页签

## ④ 出征目标下拉：固定位置与长度 · 默认空 · live 刷新

**病根（五处叠加）**：① label 宽度随文字变（下拉起点不齐）；② 下拉无长度约束（随内容忽长忽短）；
③ 右侧挂「共 174 · 列最近 24」备注；④ `actPickOf` **兜底自动选第一个目标**（不是"默认空"）；
⑤ 选完不刷新（下方"进入军事行动"要等下次重绘）。

**改法**：

| 项 | 改前 | 改后 |
|---|---|---|
| 行结构 | `.exp-sel`（label `min-width:28px`） | **`.exp-sel.act-row`**：label **定宽 108px**（以「我方城池」行为基准） |
| 下拉长度 | `flex:1`（随栏宽） | **`width: 20em` 定长**（20 个中文）+ `flex:0 0 auto` |
| 首项 | 第一个目标（默认选中） | **空 option**（默认显示为空） |
| 备注 | 「共 N · 列最近 N」 | **删除**（目标只在下拉里出现） |
| 默认选中 | `actPickOf` 兜底选第一个有货组第一项 | **删兜底**：没选过就返回 null；目标失效自动清空 |
| 选定后 | 不刷新 | **`exp-act-pick` → `GAME.refreshView()`**（live 刷新：当前目标行 + 按钮状态立即可见） |
| 按钮可用性 | 有任何目标即可点 | **只有真选了目标才可点**（未选 = 置灰） |
| 换行选择 | 两行各显各的选中 | **旧行自动回到空**（`_actPick` 只有一份）；该行选回空 = 取消选择 |

## 诚实缺口（3 条，都不影响现在用）

1. **「上限」的额度是"共享"的**：逐行点上限时，先点的行会吃掉总额度（第二行可能为 0，已加 toast 说明）。
   若您更想要"每行独立 `min(拥有, 额度)`（不互相扣、超额出兵时由既有校验拦）"——改 `ui.expTroopMaxOf`
   一处出口即可，可随时切。
2. **空首项文本为空串**（视觉留白，符合"默认显示为空"）：若想加占位文字（如"（请选择目标）"），
   改渲染一行。
3. **下拉定长 20em**：在更窄的窗口（视图区 < 900px）会挤压右侧说明；当前视图页最窄 1280px 无问题。
