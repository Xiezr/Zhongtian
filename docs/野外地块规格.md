# 野外地块规格

> 野地 = 地图上非城池的 7 类地形地块。本表是**唯一权威规格**，数据取自代码（出处逐行标注）。
> 涉及：几何 / 地形表 / 生成权重 / 等级 / 采集 / 据点 / 贴图渲染。

---

## 一、地块几何（等距菱形）

| 项 | 值 | 出处 |
|---|---|---|
| 地图规模 | **500 × 500 格** | `data.js` `DATA.MAP_W/MAP_H = 500` |
| 每格屏幕形状 | **菱形**：宽 = `cell`、高 = `2/3 · cell`（`HH = cell/3`） | `map.js` v50 |
| 格距 `cell` | 默认 **44px**（自适应约 44~128） | `map.js` `opts.cell` |
| 视口 | **12 × 8 格**（横向菱形排布） | `map.js` `spanX/spanY` |
| 格坐标 → 屏幕 | `x = ox + (gx−gy)·HW`，`y = oy + (gx+gy)·HH` | `map.js` `gxy()` |
| 半宽/半高 | `HW = cell/2`，`HH = cell/3` | `map.js` |
| 顶面内缩缝 `IN` | 世界采样 **0**（无缝）/ 旧模式 5px | `map.js` v90.2 |

## 二、7 种野外地块（`data.js` `DATA.TERRAIN`）

| id | 名 | 底色 | 移动力 | 可建城 | 产量加成/级 | 可采资源 | 备注 |
|---|---|---|---|---|---|---|---|
| `plain` | **平原** | `#b8c08a` | 1.0 | ✅ | 净水 +3% | — | 唯一可建新城；平地不采集 |
| `caoyuan` | **草原** | `#a9c08a` | 1.0 | — | 净水 +3% | 净水 | |
| `zhaoze` | **沼泽** | `#8a9d6b` | 1.4 | — | 净水 +5% | 净水 | |
| `lake` | **湖泊** | `#5f86a3` | 1.6 | — | 净水 +8% | 净水 | 净水产量最高 |
| `forest` | **森林** | `#4e7a3c` | 1.4 | — | 生物质 +5% | 生物质 | |
| `desert` | **荒漠** | `#cbb277` | 1.8 | — | 电能 +5% | 电能 | 移动力最高 |
| `hill` | **山地** | `#9c8871` | 1.6 | — | 废钢 +5% | 废钢 | |
| `city` | 城池 | — | 1.0 | — | — | — | 非野地（单列） |

> `add` 键：净水=`grain` · 生物质=`wood` · 电能=`stone` · 废钢=`iron`。
> 产量加成 = `add[res] × 等级`（`GAME.wildAddOf`）。
> **移动力**：越大越费行军（1.0 最快）。

**地形名称显示**（`map.js` `TERRAIN_NAME`）：平地 · 草原 · 沼泽 · 湖泊 · 森林 · 荒漠 · 山地。
> 注：`plain` 代码里叫"平原"、地图标签用"平地"。

## 三、生成权重（`DATA.TERRAIN_WEIGHTS`）

按噪声场（fBm，主波长 21）分位切分，各类型占比：

| 平原 | 草原 | 沼泽 | 湖泊 | 森林 | 荒漠 | 山地 |
|---|---|---|---|---|---|---|
| 18% | 14% | 12% | 10% | 18% | 12% | 16% |

> 出生点周围 5×5 强制 `plain`（`map.js`）。主波长 21 → 团块均值约 139 格（约 1/2）。

## 四、野地等级

| 项 | 值 | 出处 |
|---|---|---|
| 等级范围 | **1 ~ 10**（`wildLevelBase`：0~10，出生点等另算） | `map.js` |
| 日变化 | **每日 +1 级**（模 11 循环） | `map.js` `wildLevel` |
| 已占野地 | 每现实日 **−1 级**（衰减） | `map.js` |
| 地形加成 | `add[res] × 等级` | `GAME.wildAddOf` |
| 守军 | `DATA.WILD_DEFENSE` 逐级表（Lv1≈76 … Lv10≈57,500） | `data.js` |
| 例外 | 约 4% 边陲遗迹（8~10 级）· 约 4% 腹地弱地（0~2 级） | `map.js` |

## 五、采集（`DATA.GATHER`）

| 项 | 值 |
|---|---|
| 收成 | 采集力 × 时长 ×（1 + `levelBonus`×等级） |
| 采集力 | Σ(某兵种数量 × 该兵种采集效率)；`basePerHour = 2`（板车基准） |
| 等级加成 | `levelBonus = 0.35`（每级 +35%） |
| 采集力上限 | `powerCap = 30000` |
| 时长 | `minHours = 1`（不足为 0）· `maxHours = 24`（封顶） |
| 同时采集队 | `maxActive = 3` |
| 体力消耗 | `stamina = 6`／次 |
| 可采地形 | 草原/沼泽/湖泊→净水 · 森林→生物质 · 荒漠→电能 · 山地→废钢；**平原不采集** |

## 六、野外据点（`DATA.FORT`）

| 项 | 值 |
|---|---|
| 密度 | 1/12（约每 12 格 1 个） |
| 等级 | 1 ~ 10 |
| 等级分布 | 权重表：Lv1:3% · 2:4% · 3:5% · 4:8%（合计20%）· 5:10% · 6:12% · 7:13% · 8:14% · 9:15% · 10:16%（**5 级以上占 80%**） |
| 安全半径 | `safeRadius = 3`（出生点与名城周围不生成） |
| 守军基准 | `garrisonBase = 500`，`garrisonGrowth = 1.95`（每级 ≥ 同级野地上限） |

## 七、地块贴图规格（渲染）

| 项 | 值 | 出处 |
|---|---|---|
| 贴图尺寸 | **256 × 256 PNG** | `map.js` `ART_MAX = 256` |
| 落位 | `assets/icons/ui/ai_terrain_<id>.png` | `map.js` `loadArt` |
| 采样方式 | **世界坐标采样**（平铺整图，每格取一小块） | `map.js` v90.2 |
| 采样尺度 `Wt` | **5 格/贴图**（越大越成片） | `map.js` |
| 投影 | 等距：斜切 45° + 纵向压扁 1/3 | `map.js` |
| 裁切 | 菱形路径 `clip`（外扩 0.5px 消缝） | `map.js` |
| 边界线 | 仅**地形交界**处画（同地形内部不描） | `map.js` `edgeOf` |
| 出图要求 | 正俯视 · 均匀光 · 无缝 · 铺满整格 · 少人造物 | `docs/废土地形生成规格.md` |

> 换贴图零改代码：文件同名覆盖 → 重载即生效（`index.html` 的 `map.js?v=` 若改代码需 +1）。
