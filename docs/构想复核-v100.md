漏一处就是"模块存在但没生效"—— 本项目已经因此吃过好几次（六层世界那批、兵源那批）。

**改后：5 处**

| # | 文件 | 改什么 | 性质 |
|---|---|---|---|
| 1–4 | 四份静态清单 | 各加一行 | **纯登记**，不承载逻辑（构建脚本要读文件顺序，没法运行时推导） |
| 5 | `main.js` | import 一行 | 同上 |
| — | ~~main.js case~~ | **不用了** | 模块在 `GAME.reg.add({ actions })` 里声明 |
| — | ~~state.js tick~~ | **不用了** | 模块在 `GAME.reg.add({ tick })` 里声明 |
| — | ~~ui.js 面板块~~ | **不用了** | 模块在 `GAME.reg.add({ panel })` 里声明 |

### 注册表长什么样

```js
// 模块文件末尾，一次声明三件事
GAME.reg.add({
  id: 'muster',
  order: 10,                                   // 在世界账本里的位置（小在前）
  tick: function (force) { MU.tick(force); },   // 月度结算（自动 try/catch，抛错不拖累别人）
  panel: function (ctx) {                       // 世界账本的一块（ctx: sec/U/cities/c0/toast/refresh）
    var sec = ctx.sec;
    if (!GAME.muster) return '';
    return sec('🚶 人从哪来', GAME.muster.lineOf(), '...');
  },
  actions: {                                     // 按钮动作（main.js 的 switch 不再加 case）
    'muster-accept': function (el, ctx) { ctx.toast(GAME.muster.accept().msg); ctx.refresh(); }
  }
});
```

**已经迁进来的 4 个**：兵源（panel+actions+tick）、兵员等级（panel+actions）、
惰性（panel+actions+tick）、世界形态（panel+actions+tick）。

`ui.js` 从 19436 → 19353 行（少了 83 行），并且那四块**只有一份**（在各自模块里）——
`smoke §322④` 专门钉住"ui.js 里不许留第二份"，防复制粘贴式屎山。

### 为什么不一锅端

老的十来个模块（faction / wonderwar / deck / tower …）的面板块还在 `ui.js` 里。
**一次全迁 = 一次大改 = 一次大炸**，本轮只迁新模块。
以后要迁，照着上面那 4 个的样板做，一次一个，每迁一个跑一次门禁。

### 顺带修好的一件事

`audit.js` 原来只认 `main.js` 的 `case`，迁走动作后会报一堆"点了没反应"的假红。
现在它也会扫各模块 `GAME.reg.add` 里的 actions 键 —— **改了机制，检查工具要跟着改**，
否则门禁会替新机制撒谎。
