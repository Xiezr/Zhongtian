## ① 模拟口径：五段链（逐项真跑，不许平凡解）

每一件物品 / 每一项功能，都按同一把尺子走完五段，每段都要"真状态变化"才算通：

| 段 | 判据（怎么算"通"） | 不许的平凡解 |
|---|---|---|
| 获得 | 在售 → **真走商城出口购买**（真扣金）；非售 → 直发并查"渠道是否接线" | "有价格就算有来源"（不跑购买） |
| 持有 | `s.items[id] >= 1` 真入背包 | 只看返回值不看背包 |
| 使用 | 走**真实消费出口**（useItem / 打造 / 蛰养 / 计略…），带齐前置场景 | "调用没抛异常就算过" |
| 效果 | **断言状态真的变了**（buff 写入 / 属性变化 / 队列缩短 / 忠诚+5…） | "返回 ok 就算过" |
| 清账 | 数量递减、归零消失 | 不看清账 |

工具：`.workbuddy/tools/play/lifecycle_v89121.js`（`--part=A1..B1|ALL` 可分段复跑）。

## ③ 抓出并修复的三个真 bug

### bug 1 · 游历「沼泽寻宝」给了不存在的物品

- 病根：`LING_ACT.zhaoze_scene` 奖励写 `{ t: '得古朴木盒', item: 'chest' }` ——
  而 `chest` 是**槽位名，不是物品 id**（`DATA.ITEMS` 里没有 id='chest'）。
  发放走 `gift()`：找不到名字就显示原始 id → 玩家背包多出一个"chest"，
  点使用报「未知宝物」。
- 修法：`item: 'chest'` → `item: 'chest_tong'`（青铜宝箱，与"古朴木盒"文案匹配）。
- 防回归：smoke §102① —— **全仓扫 `item: 'X'` 引用，必须都在 DATA.ITEMS**（扫描 10 处）。

### bug 2 · `DATA.ITEM_BY_ID` 是一张**过期的表**

- 病根：表在 `data.js` 中段建（那一刻只有早期 ~70 件），而本文件**后段**又 push 了
  100+ 件新物品（通商券/灵草/新档位/四门绝学…）。后果：读 `ITEM_BY_ID[id]` 的地方
  （state.js 存档摘要）对新物品**一律回退显示原始 id**（`tongshang_quan` 而非「通商券」）。
- 修法：在全部扩充完成之后（文件末尾）**重建一次**表。
- 防回归：smoke §102③ —— 键数必须等于 ITEMS 条数（199 / 199）。

### bug 3 · 移民令"半上架"（有价却永远买不到）

- 病根：v89.104 新增移民令（`pop_fill`，价格 120 元宝、**无 noShop 标记**=想卖），
  但类型没进商城页签表 `ui.SHOP_CATS`。而「在售 == 有页签」是本项目的唯一判据
  （v89.51 写死）→ 商城与快购都渲染不出来 → **有定价、零渠道**（全仓零引用）。
- 规格依据：设计文档明写"定价 120 金（增民令 30 的 4 倍）"——不卖则定价无意义。
- 修法：`pop_fill: '民生'`（与增民令同页签）。上架后**真买实证**：-1.2 万金、背包 +1、使用生效。
- 防回归：smoke §102④ —— **"半上架"守卫**：有价 + 非下架 → 必须有页签（不想卖就写 `price:0` 或 `noShop`）。

> 三个 bug 的共同形状：**静默失效**（不报错、测试全绿，只有玩家在某个角落里碰得到）。
> 这正是"全生命周期模拟"这类**端到端真跑**才抓得到的东西。

## ⑦ 诚实缺口

1. **"功能"侧本轮以系统循环 + 既有 12 链复核为主**（36 环节全通），
   44 个面板的**布局层**由既有 `audit_v89105_modals.js`（真浏览器）负责，本轮未重复覆盖；
   "每个面板内每个按钮的副作用"没有逐像素级跑（那属于交互测试，量级不同），
   若老板要"功能也逐项到每个按钮"，可另开一轮（用真浏览器逐按钮点）。
2. **渠道判定的"已知渠道表"是人工梳理的**（8 条产出路径），
   若未来新增产出路径，需要同步更新判定表（smoke §102② 的基线机制会把"减少"视为通过、
   "新增缺口"视为失败——方向正确，但"渠道表本身过时"不会报警）。
3. **模拟跑在 Node 桩 DOM 下**：能验"逻辑通不通"，不能验"点得到点不到"
   （后者由 e2e 与实机截图负责）。
4. 上一轮（v89.120）遗留待定夺项（自动进推演提示 / 回合窗口行数 / 后台运行文字键）仍未定。
