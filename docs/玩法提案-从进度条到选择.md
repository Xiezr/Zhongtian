# 玩法提案：从「进度条」到「选择」

> 起因：老板指出「玩家只能机械造兵，最优只有东风+，因为兵源无限」。
> 并追问：**我们怎么确认，之前认为万无一失的设定，实际上正在摧毁游戏？**

本文件分两部分：**记录**（两轮讨论产生的玩法建议）和**追问**（根因、乐趣在哪、怎么改）。

---

# 第一部分 · 记录：两轮产生的玩法建议

## A. 探索（老板提「迷雾可否二次开发」）

| # | 方向 | 机制 | 成本 |
|---|---|---|---|
| A1 | 领土连通 | 只有与主城连成一片的亮格才算领地；断链的部队掉补给 | 中 |
| A2 | 半信息痕迹 | 未点亮区能看到烟柱、脚印、无线电杂音，知道「有东西」但不知是什么 | 小 |
| A3 | 迷雾长回来 | 点亮过的格过 N 天重新变暗（辐射回涌 / 敌方反侦察） | 小 |
| A4 | 遗物埋点 | 特定格埋遗物/图纸，先点亮 + 满足条件才能挖 | 小 |
| A5 | 危险梯度 | 迷雾边缘最危险，越往中心越安全 | 小 |
| A6 | 侦察点数 | 点亮要花侦察点，由建筑/将领产出 → 探索变成可经营的资源线 | 小 |
| A7 | 点亮即暴露 | 你点亮一格，附近的东西也会注意到你 | 小 |
| A8 | 迷雾里的势力 | 势力藏在迷雾里移动，点亮才现身 | 中 |
| A9 | 遗迹剧情点 | 点亮特定区域触发故事（废弃实验室/旧时代纪念碑/幸存者营地） | 小 |
| A10 | 迷雾即情报差 | 你看不到对手的兵，对手也看不到你的 → 实时对战的基础 | 中 |

附带：每颗星球独立迷雾（天然二周目）· 难民潮（点亮发现幸存者）。

## B. 世界（势力 / 内政 / 生存）

| # | 方向 | 核心机制 | 实现方式 |
|---|---|---|---|
| B1 | 势力 | 4 个军阀（侵略/守成/狂热/贸易），有领地、兵力、对玩家态度 | 一张表 + 每游戏日一次**粗模拟**（战力比+骰子，不跑战斗引擎，只播报+地图染色）；只有打到玩家城才真跑 battle |
| B2 | 势力的四种用法 | 打（抢地）/ 贡（换和平）/ 盟（共同敌人）/ 挑（让 A 打 B，收渔利） | 关系值 + 事件弹窗 |
| B3 | 内政治理 | 占城后要管民忠、税收、驻军；民忠低会叛乱 | 每城一组数字 + 日结 |
| B4 | 生存压力 | 城市有粮食/温度/民心三条线，冬天或辐射季来临时做抉择 | 周期事件 + 三条资源线 |
| B5 | 历法 = 赛季 | 11 个年号各带独特规则（大迁徙年移速+50%、寒潮年粮产-50%、军阀年势力互战率×3） | 只换规则表，**几乎零成本** |

## C. 战斗（斗将 / 战场目标 / 建筑）

| # | 方向 | 核心机制 |
|---|---|---|
| C1 | 斗将 | 已有 stub（战前斗将，胜者+10%属性）但是自动比大小。要做成玩法需三件：①可选非强制（拒绝掉士气）②招式心理战（突刺/格挡/佯攻/蓄力，看不到对手出什么）③将领性格决定招式池。一场 5 回合×3 秒=30 秒 |
| C2 | 战场目标多样化 | 不只是「全灭」：坚守 N 回合 / 护送车队 / 斩首敌将 / 撤退保命 |
| C3 | 建筑 = 战场工事 | 城墙、炮塔在守城战里真实存在（现在建筑只产资源） |
| C4 | 异步 PvP | 你设防守阵型，别人来打，你回来看战报；不需要同时在线 |

## D. 用现有组件（不用新做系统）

| 组件 | 现在 | 可以变成 |
|---|---|---|
| 历法（11 年号） | 时代推进给加成 | **现成的赛季系统**：每年号一套规则 |
| 奇观 | 建了拿加成 | **全图唯一的世界争夺点** |
| 羁绊 | 组合加成 | **将领关系网**：一起出战有加成，也可能意见不合不听指挥 |
| 装备套装 | 凑齐给属性 | 凑齐给**一个技能**（天罚套 19 件 → 解锁「轨道轰炸」指令） |
| 建筑 | 只产资源 | **战场工事** |

## E. 外部可迁移

| 玩法 | 出处 | 迁移 | 解决什么 |
|---|---|---|---|
| Roguelike 远征 | 暗黑地牢 / 杀戮尖塔 | 派 3 将进地下遗迹，每层随机事件，**死了永久损失** | 现在**没有任何永久损失**，所以没有紧张感 |
| 塔防守城 | 王国保卫战 | 守城时布置炮塔、障碍 | 让建筑在战斗中有用 |
| 卡牌构筑 | 杀戮尖塔 | 战前选 5 张指令牌组成牌组 | 把 417 装备/246 道具变成「构筑」而非堆属性 |
| 生存三命 | 冰汽时代 | 粮/温/民心三条线 | 让经营有紧张感 |
| 大逃杀收缩圈 | PUBG | 辐射云收缩，被迫向中心迁移 | 给扩张一个**时间压力** |
| 异步 PvP | 部落冲突 | 防守阵型 + 战报 | 挂机期间也有事发生 |

## F. 废土内核（机制承载题材）

| 废土内核 | 机制 | 玩家感受 |
|---|---|---|
| **稀缺** | 一座废墟拆解只能选一样：钢铁，或粮食 | 拿到一样＝失去另一样 |
| **牺牲** | 幸存者营地：招募（长期产出，但要养）或抢（一次性，坏名声传开，别的营地会跑） | 我在决定自己是什么人 |
| **代价** | 旧世界技术强，但积累污染，污染高会变异/民心崩 | 强是要付账的 |

## G. 一个颠覆性建议

**把「科技树」换成「废墟挖掘」**：科技不是点出来的，是挖出来的。
→ 探索=成长（迷雾与科技树合并成一个系统），每座废墟是一个选择，废土感自动成立。

# 第二部分 · 追问：为什么平平无奇

## 一、被摧毁的假设：兵源无限

**实测数字**

```
POP_CFG.fillHours = 2          → 人口 2 小时补满
全表无「伤兵」概念              → 没有 wound / hurt 任何字段
无任何永久损失出口              → 没有 LOSS_PERM / GRAVE / DEAD
东风 8,050 资源/人口 vs 步行机 970  → 贵 8.3 倍，但资源也是持续产出的
```

**推论**

> **一场仗的全部代价 = 2 小时等待。**

于是：
- 玩家没有任何理由「小心」；
- 最优策略永远是「带满、带最强」；
- 兵种选择退化为「战力 ÷ 人口」的单值比较，东风登顶；
- 输了重打，赢了继续，不存在「这一步走错了」。

**兵源无限不是数值问题，是「损失不可逆」这个前提被抹掉了。**
没有不可逆，就没有重量；没有重量，选择就退化成试错。

## 二、七条「安全设定」

这些设定每一条都出于好意，合起来把游戏变得没有感觉。

| # | 设定 | 设计者为什么这么定 | 实际后果 |
|---|---|---|---|
| 1 | 兵源 2h 补满 | 怕玩家卡死、怕流失 | 损失无代价 → 不需要小心 |
| 2 | 资源持续产出 | 怕玩家等太久 | 建造成本无意义 → 只需要等 |
| 3 | 科技/建筑最终能全点满 | 怕玩家选错后悔 | **选择变顺序** → 取舍是假的 |
| 4 | 将领不会死 | 怕投资打水漂 | 培养无风险 → 无情感重量 |
| 5 | 全图可见 | 怕玩家找不到目标 | 情报免费 → 侦察无需求 |
| 6 | 战斗必须全灭 | 怕出现僵局 | 无撤退/僵持 → 无中间态 |
| 7 | 城不会被真正夺走 | 怕玩家失去进度 | 无失去 → 无归属 |

**共同点：每一条都在避免「玩家难受」。七条加起来，把紧张感全部消除了。**

> **安全过头，就没有游戏了。**

## 三、灵魂层：乐趣 = 不可逆 × 可预判

```
完全可逆                 → 试错游戏，无重量（玩家只需要耐心）
完全不可预判             → 赌博，无技巧（玩家只需要运气）
不可逆 + 可预判          → 真决策（玩家需要判断）
```

验证：

| 游戏 | 不可逆在哪 | 可预判在哪 | 结果 |
|---|---|---|---|
| 围棋 | 落子无悔 | 能算 | 深 |
| 暗黑地牢 | 角色会死 | 能评估风险 | 紧张 |
| 文明 | 科技选了这个就没那个 | 有科技树预览 | 每局不同 |
| **本游戏** | **无** | 有（数值全公开） | **无重量** |

**所以问题不是「玩法不够多」，是「玩家的决定都能撤销」。**

加十个玩法，如果每个都能重来，就还是十个进度条。

## 四、一把尺子：放弃测试

> 描述一个玩法时，能不能说出「**玩家为了这个放弃了什么**」？
> 说不出 → 这是数值包装，不是玩法。说得出来 → 真玩法。

| 系统 | 玩家放弃了什么 | 判定 |
|---|---|---|
| 造兵 | 什么也没放弃（2h 补满） | ❌ 不是玩法 |
| 升级建筑 | 时间（而时间不稀缺） | ⚠️ 弱 |
| 打野地 | 兵（会补回来） | ❌ 不是玩法 |
| 选将领 | 其他将领（有限） | ✅ 真玩法，但差距太小 |
| 选装备 | 其他装备（有限） | ✅ 真玩法 |
| 点科技 | 其他科技（但最终能全点满） | ⚠️ 假选择 |
| **迷雾** | 另一条路的地图 | ✅ 真玩法 |
| **废墟挖掘** | 另一座废墟的科技 | ✅ 真玩法 |
| **营地：招募 vs 抢** | 另一种名声 | ✅ 真玩法 |
| **斗将** | 拒绝的士气 | ✅ 真玩法 |

## 五、广度：十类玩法，空了七个

| 玩法类型 | 现状 | 深度 |
|---|---|---|
| 建设经营 | ✅ 有（但只是队列） | L1 |
| 养成（将领/装备） | ✅ 有（但只是堆属性） | L2 |
| 战斗 | ✅ 有（但只奖励伤害） | L2 |
| **探索** | ❌ 无（全图开放） | — |
| **外交** | ❌ 无 | — |
| **内政治理** | ❌ 无 | — |
| **生存危机** | ❌ 无 | — |
| **构筑（组合）** | ⚠️ 半个（套装只给属性） | L1 |
| **竞技 PvP** | ❌ 无 | — |
| **叙事选择** | ❌ 无（叙事层 v89.218 已删） | — |

## 六、深度：三层阶梯，游戏停在 L1-L2

每个玩法都可以有三层深度：

- **L1 有没有**：能操作
- **L2 有没有取舍**：不同做法结果不同
- **L3 有没有不可逆**：选错了不能重来

| 玩法 | L1 | L2 | L3 |
|---|---|---|---|
| 建设 | ✅ | ⚠️ 顺序差异小 | ❌ |
| 养成 | ✅ | ✅ 装备有取舍 | ❌ 都能拿满 |
| 战斗 | ✅ | ⚠️ 只有编成 | ❌ 输了重打 |
| 构筑 | ⚠️ | ❌ | ❌ |
| 探索 / 外交 / 内政 / 生存 / PvP / 叙事 | ❌ | ❌ | ❌ |

> **结论：乐趣在 L3，而现在的游戏全部停在 L1，最多 L2。**
> 这比「兵种不平衡」深层得多——不平衡只是 L2 没做好，L3 是根本没有。

## 七、改造顺序（修正之前的建议）

**之前我建议「先做迷雾」，这是错的。**

理由：兵源无限时，迷雾只是「更多资源点」，玩家照样带满东风扫过去，还是不疼。

正确顺序：

| 步骤 | 做什么 | 为什么必须在这个位置 |
|---|---|---|
| **1** | **修「不可逆」**：伤兵/阵亡分离、老兵等级 | 这是地基。损失不疼，后面加什么都是刷资源 |
| **2** | **人口与探索绑定**：新人口来自幸存者营地 | 一次解决两件事：兵源变稀缺 + 探索有回报 |
| **3** | 迷雾（探索的载体） | 有了 1、2，迷雾才是「资源有限的未知」，不是「免费资源点」 |
| **4** | 势力（世界的意图） | 有了稀缺，才有「趁虚而入」的时机 |
| **5** | 斗将（实时入口） | 有了不可逆（败将重伤），斗将才有赌注 |

## 八、修正一：不调死亡剂量（死亡不是惩罚）

> 老板原话：「**死多少不是问题，问题是死亡换来什么，是收获？是开拓体验？这才是你应该考虑的，不要被数值困住**」

这段话把上一节的写法否掉了。上一节我写「会疼但不毁灭」，本质还是在**调死亡剂量**——那是数值思维。

换框架：

| 错的框架 | 对的框架 |
| --- | --- |
| 死亡是惩罚，要控制剂量 | 死亡要能换到东西，而不是扣分 |
| 目标：让玩家「不敢乱打」 | 目标：让玩家「愿意为一个理由付代价」 |
| 调参数（死 10% 还是 30%） | 设计情境（什么样的死是悲壮、什么样的死是冤枉） |
| 玩家回避损失 | 玩家主动承担损失 |

## 八·补、修正二：**但也不要给死亡标价**

> 老板原话：「**不必过于强调死亡换来什么，这将调整玩家的道德感**」

这一句把上面那张表也按住了。如果每条死亡都配一句「所以他换来了 X」，
玩家会开始**计算人命值不值**——那不是悲壮，那是把人当耗材。
道德感一旦被调成账本，后面的所有叙事都救不回来。

所以最终做法是：

| 不做 | 做 |
|---|---|
| 不给死亡算收益 | 只记名字、地点、最后一句 |
| 不显示「用 5 个人换了这张地图」 | 地图该亮就亮，不解释代价 |
| 不给阵亡补偿或惩罚 | 没有任何数值反馈 |
| 不写「他死得值」 | 写他最后说了什么 |

一句话：**记事，不记账。**

下面的「八种交易」保留为**设计时的思考工具**（判断哪些东西只能用命换），
但**不进入玩家界面**——玩家看到的只有纪念碑。

### 八.1 死亡能买到什么（八种交易）

| # | 情境 | 死亡换来 | 玩家感受 |
|---|---|---|---|
| 1 | 探索迷雾 | **地图与情报**（命点亮的地，别人点不亮） | 「我知道那边有什么了」 |
| 2 | 侦察敌情 | **对方编成与守将**（打输一仗 = 拿到一份敌情） | 「下次有准备了」 |
| 3 | 断后撤退 | **时间**（主力活下来） | 「他们没白死」 |
| 4 | 填沟攻坚 | **突破口**（第一批人打开缺口） | 「城是我们的了」 |
| 5 | 护航/护送 | **车队安全** | 「东西送到了」 |
| 6 | 挡兽潮/辐射潮 | **城市存续** | 「城里的孩子活着」 |
| 7 | 惨烈战斗 | **名声**（其他势力忌惮你，或同情你） | 「他们知道我们不好惹」 |
| 8 | 血战幸存 | **老兵与传承**（幸存者变精锐，阵亡者留下遗物） | 「这支队伍是从灰岭活下来的」 |

**关键判断：这八种里，只有第 1、2、3、6 是「不可替代」的** —— 用资源买不到，只能用命换。
其余四种可以被资源部分替代，所以价值低。

### 八.2 最值钱的一种：**用命换地图**（这才是「开拓体验」）

这是老板说的「开拓体验」的具体形态，也是迷雾的正确做法：

> **迷雾不是靠「侦察点数」点亮的，是靠人命点亮的。**

机制一句话：

```
你派一支拓荒队走进黑区 → 他们每小时推进 → 遇事件，可能全灭
  ├─ 活着回来：带回资源/幸存者/坐标
  └─ 没回来：地图仍然点亮了一格，并留下最后一条记录
              「第 3 小队在灰岭失联。最后信号：有巨大的东西在动。」
              那块地从此有名字。
```

三件事因此成立：

1. **探索有真实代价**：不是花点数，是死人；
2. **代价换来不可替代的东西**：那块地只有你的队伍走过，别人要再走一遍还得再死一次；
3. **玩家会记住**：不是「解锁了第 12 区」，是「第七小队死在那里」。

这才是「开拓」——**不是解锁地图，是我们付出了什么才走到那里。**

### 八.3 再深一层：废土的灵魂是「文明断了，我们是接着活的人」

在废土语境里，死亡最崇高的交换不是资源，是：

> **用这一代人，换下一代人能活。**

| 派出去找什么 | 他们可能死 | 但换来 |
|---|---|---|
| 种子库 | 是 | 城市明年有粮 |
| 旧时代图纸 | 是 | 城里有电了 |
| 挡住变异兽潮 | 是 | 城里的孩子活着 |
| 医疗档案 | 是 | 下次瘟疫不死那么多人 |

**这给了「死亡」一个不属于数值的意义**：它不是在扣你的兵，是在决定「人类还剩下什么」。

### 八.4 这改变了主线的答案

同一件事（死了 3000 兵），两种主线下的玩家感受完全不同：

| 主线 | 死亡的定位 | 玩家会想 |
|---|---|---|
| **变强** | 损失（要减少） | 「我又死了 3000 兵，烦」 |
| **重建** | 投资（要算回报） | 「第七小队全灭了，但他们带回的种子让城里熬过了冬天」 |

**所以「死亡」这个设计点，本身就是「变强 vs 重建」这个岔口的试金石。**
如果死亡只是损失，那这游戏只能走「变强」；如果死亡是投资，那「重建」才成立。

### 八.5 落地手段（服务上面的交易，不是为了让玩家疼）

| 手段 | 服务哪笔交易 |
|---|---|
| 伤兵 / 阵亡分离 | 让「死」有分辨率：不是全灭，是一部分人永远回不来了 |
| 阵亡者留名 / 纪念碑 | 交易 1、7、8：让死亡留下痕迹，玩家记得住 |
| 老兵等级（阵亡不可恢复） | 交易 8：让「活下来的人」有价值 |
| 人口靠拓荒队带回 | 交易 1、6：让「人」本身成为探索的产出 |
| 将领重伤 / 退役 | 交易 3、6：让将领的「派出」有分量 |

## 九、还没想清楚的问题

1. **难度曲线要不要跟着改**：兵源变稀缺后，前期会明显更难，「前期舒适」的标定要重做。
2. **存档过渡**：已有存档的玩家，突然发现兵会永久死，可能反感。要不要给一个「旧档保护期」。
3. **会不会劝退纯挂机玩家**：如果玩家就是想要「无脑收菜」，这套会不会把他赶走。可能需要一个「低强度模式」。
4. **八种交易里，哪些真的不可替代**：目前判断是「地图/情报/时间/城市存续」四种只能用命换。但要用实际设计验证——如果一个交易能被资源替代，它就退化成数值。
5. **「用命换地图」会不会太残酷**：拓荒队全灭但地图点亮，这个交换对玩家是「悲壮」还是「被坑」？取决于信息给得够不够——「他们死前看到了什么」比「死了 30 人」重要得多。
