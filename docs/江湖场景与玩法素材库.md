| 偷窃 / 下毒 / 潜行 / 暗杀 | 与本作"轻松明亮"基调不符，且有合规风险 |
| 织造 72 道工序 / 文物修复临摹 | 工序型玩法太重，与"小游戏 ≤5 分钟"原则冲突 |
| 养生系统（子午觉/晨练打卡） | 现代养生概念，世界观违和 |
| 蹴鞠（完整版） | 需实时操作新交互层；如做仅建议"极简判定版"，随 V3+ 再说 |
| 促织（斗虫） | 与斗鸡重合，二选一即可（选斗鸡：史料更早、受众无门槛） |

### 4.4 三国在地化处理说明（仙侠元素 → 三国江湖）

本作世界观是**汉末三国 + 灵气设定**（灵气装备体系已立），场面玩法统一按"轻仙侠、重江湖、贴三国"处理：

1. **优先选汉末三国可考的雅戏风物**：投壶/射艺/蹴鞠/五禽戏/斗鸡/六博围棋/煮酒/石经/屯田/观星——全部有史料支撑，既好玩又能当"文化彩蛋"卖；
2. **仙侠向内容就地包装**：灵田→屯田制、洞府→隐士居所、妖丹→异兽内丹（野地妖兽本来就存在）；
3. **说书/典故彩蛋**：听书讲"前朝故事"（战国/楚汉），为未来"三国演义本传剧情"留接口。
