## 一、病根（一句话）

七条里有两条是**真 bug**、五条是设计变更：

| # | 需求 | 病根 / 现状 |
|---|---|---|
| ① | 战斗可获得声望 | **从未有过**：声望只有"释放俘虏 / 占城 / 门派任务"三个来源，打仗（无论歼敌多少）**一点声望都不给** |
| ② | 动作设置每回合可重设 | **真 bug**：`ui.btSetCmd` 改完用 `rec.snapLast`（**上一回合结束时**的快照）重绘棋盘 → 下拉立刻跳回旧值（实机实测：会话已 `retreat`、DOM 回 `advance`）→ 玩家以为"改了不生效" |
| ③ | 兵种一字简称 | 名称位是 3~4 字全名（约 60px），把两个下拉挤到 42px / 57px（行宽仅 105px） |
| ④ | 默认前进 + 同兵种 | 玩家侧目标默认 `''`（= 任意/最近），且选项写"目标：XXX"（占字数、读着累） |
| ⑤ | 战场区拉到回合记录上方 | `.bt-field { height: 330px }` 定高 + 兵牌 `top = idx×42`：**3 队时战场条只有 203px**，底边离回合记录留 **140px** 空白 |
| ⑥ | 删「左侧设动作/目标」备注 | 顶栏右列常显一行说明（动作/目标就在两侧下拉里，属冗余） |
| ⑦ | 间距读数统一 | 顶栏只写「间距 30」——不知道 30 是什么尺度、战场多深；其余各处（回放帧/事件行/图例）文案也各写各的 |

## 五、诚实缺口

1. **⑦ 的读法**：「统一设置为最近距离/全局战场距离」我读作**两个数都要报**
   （最近距离 = 当前两军最近距离；全局 = 战场纵深）—— 若老板只想留一个数，
   改 `ui.gapReadOf` 一处即可（顶栏/沙盘/实时刷新同源）。
2. **④「同兵种」在对面无该兵种时**：下拉仍显示「同兵种」，引擎按"最近的敌队"打
   （不是 bug，但**显示与实际**在这一点上是"意向 vs 兜底"的关系）——
   若希望改成"对面没有就显示任意"，改 `ui.btSideHTML` 一处。
3. **① 声望的量级**是标定的（对照：释放 1000 俘虏 = +20、占城 10~40、年号目标 2 万）——
   若觉得偏多/偏少，只改 `DATA.REP_RULE.perPower`（唯一旋钮）。
4. **⑤ dense 档阈值 8 队**是估计值（9 队间距 36px 仍不重叠、12 队才需要缩），
   极端 18 兵种未实测（需真凑齐 18 种兵的存档）。
5. **② 每回合重设**依赖"播放动画期间不重绘"——若玩家在动画中改下拉，
   值会记入 `rec.cmd` 但棋盘视觉要等本回合播完才同步（已记入交付说明）。
