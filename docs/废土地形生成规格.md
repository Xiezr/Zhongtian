# 废土地形贴图 · 地块规格与生成规格

> 目的：给 **7 种野外地块**重出**铺满整格、好看、一眼可辨**的俯视地形贴图
> （`ai_terrain_<id>.png`，256×256）。
>
> **为什么必须重出**：现有 7 张是"**物体**"不是"**地面**"——`plain` 是个土立方（带白底）、
> `forest` 是草地上一丛松树、`hill` 是一座孤立山峰。铺到菱形格上：四角露白、像浮物、
> 相邻格接不上。这是**源素材形态**的问题，调色救不了。

---

## 一、地块规格（从代码取，出图前必读）

| 项 | 值 | 出处 |
|---|---|---|
| 源图 | **256×256 PNG · 正方形** | `map.js` `ART_MAX = 256` |
| 格子在屏上 | 等距**菱形**：宽 = cell、高 = cell/2（cell 44~128） | `map.js` render |
| 贴图用法 | 整张源图 **cover 铺进菱形外接矩形**，再按菱形 **clip** | `blitArtRect` + 渲染段「② 地形贴图」 |
| 采样范围 | **整张源图（100%）** | `map.js` v89.226 |
| 光影 | 渲染统一加地面明暗 → 贴图本身须**均匀光** | 三铁律 |

**由此推出的三条硬约束（每条 prompt 都要带）：**

1. **铺满整格** —— 贴图必须 **edge-to-edge 不透明、无透明边、无居中孤物**。
   否则菱形四角露出空洞/白底。**这是本轮的头号目标。**
2. **菱形裁角** —— 正方形的**四个角会被裁掉**（菱形内切）。把最可辨的细节放在**中心**，
   四角允许弱化；保证中心那圈读得出"树是树、草是草、沙是沙"。
3. **俯视 + 均匀光** —— `top-down / no directional shadow / no single light source /
   no perspective / no 3D cube`。否则相邻格光影打架、拼起来乱。

> 严格无缝（seamless）是**加分项不是必需**：每格是独立贴图，跨格不连续肉眼看不出来。
> 但要求一下能减少"同地形连片"时的重复感。

## 二、共用风格块（每条 prompt 都带）

```
STYLE: refined semi-realistic game art for a post-apocalyptic wasteland strategy
game — painterly and matte, warm desaturated wasteland palette (ochre / olive /
rust / grey-brown), crisp high-detail, readable at small icon scale, shape contrast
strong but color contrast muted.

VIEW: strict top-down orthographic (camera looking straight down), evenly lit flat
ambient light — NO directional shadow, NO single light source, NO perspective,
NO 3D height, NO isometric cube/block.

FILL: an edge-to-edge full-bleed opaque ground texture filling the ENTIRE square
frame, no transparent background, no centered object, no isolated prop, no border,
no frame, no vignette, no white background, no text, no watermark, no people,
no animals. NOT anime, NOT cartoon, NOT glossy 3D render.
```

**负向词**（工具吃负面时附上）：
`no object, no isolated prop, no centered silhouette, no isometric cube, no white/transparent background, no border, no vignette, no directional shadow, no text`

## 三、逐地形 prompt（7 条 · 各自可单独出图）

每条 = **§二 共用块** + 下表**地形行**。

| 地块 id | 显示名 | 地形行（接在共用块后，英文） |
|---|---|---|
| `plain` | 平原 | `Cracked dry earth ground, tan/ochre. A fine network of dry mud cracks across the whole frame with a few small pebbles scattered evenly. Nothing centered.` |
| `caoyuan` | 草原 | `Dry withered grassland, pale yellow-green. TIGHTLY PACKED tufts of dead grass covering the whole frame edge to edge over dry soil, even density, no focal point.` |
| `zhaoze` | 沼泽 | `Murky swamp. Stagnant dark yellow-green water with rotten reeds and slimy mud patches spread across the entire frame, no focal point.` |
| `lake` | 湖泊 | `Stagnant dark lake water, murky grey-teal. Faint surface ripples and a few floating algae / duckweed patches spread evenly across the whole frame.` |
| `forest` | 森林 | `Dense dead forest canopy seen from DIRECTLY ABOVE. TIGHTLY PACKED round clumps of dark-green and dead-brown treetops COVERING THE WHOLE FRAME edge to edge, only tiny gaps of soil between clumps. Do NOT draw a single clump or any tree trunk/height.` |
| `desert` | 荒漠 | `Wind-rippled desert sand, sandy yellow. Soft parallel dune ripple lines across the whole frame with a few scattered small stones.` |
| `hill` | 山地 | `Rocky highland seen from DIRECTLY ABOVE. TIGHTLY PACKED grey rock slabs and boulders COVERING THE WHOLE FRAME edge to edge with dry soil in the cracks. Do NOT draw a single peak or any 3D height.` |

> **forest / hill 是本轮重点**：必须"填满整格"（密铺树冠 / 密铺岩板），
> **不是**一丛树、一座峰。旧素材就败在这。

**参数**：`1024×1024` → 切/缩到 **256×256**、`quality: high`、**背景不设 transparent**（要实心铺满）。

## 五、出图后怎么装

1. 图存 `assets/icons/raw/terrain_sheet.png`（或单张 `terrain_<id>.png`）
2. 切分/缩放到 **256×256**，命名 `ai_terrain_<id>.png`（映射见 §三表）
3. 落位 `assets/icons/ui/`（代码读 `assets/icons/ui/ai_<key>.png`）
4. 校验：`node smoke-test.js`（7 张 256×256、两两不同）
5. 实机看地图：`python .workbuddy/tools/gen/wasteland_batch.py` 或直接起游戏

> 切分脚本复用现有管线（`.workbuddy/tools/gen/atlas_split.js`）；格子有偏移告诉我来调。

## 六、验收判据（铺满 + 好看，硬标准）

| 项 | 合格 | 说明 |
|---|---|---|
| **四角不留白** | 菱形四角无透明/白色 | 铺满的**第一判据** |
| **无居中孤物** | 画面无单一焦点物体 | 淘汰"立方/树丛/山峰"旧形态 |
| 中心可辨 | 中心 60% 区域读得出地形 | "树是树、草是草、沙是沙" |
| 尺寸 | 256×256 · 不透明 | 与管线一致 |
| 相邻格 | 同地形连片不露接缝 | 均匀光的自然结果 |

## 七、这一步为什么绕不过去

前几轮尝试（旧道具方块校正 / 无缝混合 / 调色）**都治不了"不是地面"**：
- 道具方块 → 独立物件，铺不成地面
- 调色 → 只变色，"物体感"还在
- **只有"重新画成填满整格的俯视材质"能解决** —— 就是本文档。
