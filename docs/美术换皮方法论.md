# 美术换皮方法论（位图层 · 可复用）

> 适用：把**一批现成位图**整体换成另一种风格（本项目：汉代三国 → 废土·余烬纪元）。
> 本文是**可复用的操作方法论**，不是某一轮的记录。任何游戏的美术换皮照此执行。
> 首次落地见 `docs/AI图标生成清单-废土版.md`（规格）+ `.workbuddy/tools/`（工具）。

---

## 〇、三条铁律（先记住）

1. **同名原地覆盖**——换的是 `assets/xxx/ai_<id>.png` 的**字节，不是文件名**。
   代码零改动；做一次快照即可全量回滚。
2. **切分入库前必过门禁**——不合格只浪费一次出图，绝不污染线上素材。
3. **凡"自动判 X% 有问题"，先怀疑尺子**——本项目已两次出现"工具 bug 被当产品 bug"
   （case 切片误报 77%、色散公式漏权重项）。**先对已知合格样本标定尺子，再判产品。**

---

## 一、总流程（四步）

```
① 出图集（2×2 四格）  →  ② 切分 + 抠底  →  ③ 装前门禁  →  ④ 入库
   外部工具/AI            自动管线            自动判据         同名覆盖
```

每 4 个图标出 1 张图集（降本 75%）。图集元素顺序 = 左上/右上/左下/右下。

---

## 二、必带的技术规格（出图 prompt 固定项）

**每条 prompt 都必须带**（否则出图规格漂移，后期返工）：
```
isolated on a plain solid pure white background (#ffffff), no text, no watermark,
no frame, no border, no ground shadow, centered composition, slight three-quarter
isometric view, warm light from upper left, soft ambient occlusion,
highly detailed material textures, crisp clean edges
```
- **背景必须纯白**：`background:"transparent"` 参数**不生效**（实测透底率 0）；
  一律出白底，再靠抠底去白。
- **主体不得占满**：占宽/占高到 100% = 没留边 = 抠底会把主体切掉。

---

## 三、两个阶段的不同做法

| | **文生图 t2i** | **图生图 i2i** |
|---|---|---|
| 用于 | 全新物件（兵种/材料/道具） | **保持轮廓**的整体（建筑） |
| 输入 | 只有 prompt | 现有图标拼的**白底源图集** + prompt |
| prompt 要点 | 描述目标物体 | 「同角度同轮廓，**只换材质**」 |
| 好处 | 自由 | 保住引擎已调的机位/比例，不改构图 |

**i2i 拼源**：把现有 4 张图标拼成 2×2 白底图集当作参考图（本项目 `build_atlas_src.py`）。

---

## 四、抠底的两种做法（**别用全局阈值**）

| 做法 | 用于 | 原因 |
|---|---|---|
| **连通域洪水填充** | 有浅色内部结构（建筑白墙、灰钢） | 只抠"与边缘连通"的白底，**不伤内部浅色** |
| 四角采样距离 | 简单独立物件（兵种/道具） | 背景单一，够用 |

⚠ **全局距离阈值会把主体内部的浅色一起抠成洞**——本项目历史上因此把白墙/石基打穿。

---

## 五、实测踩到的 4 个坑与修法（**最有价值的一节**）

> 全部来自废土建筑批（16 张）实测，**不是理论**。

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| ① | 图标**单色、染色难看** | 一张图只有一个色相（**图内色散仅 7°**），染任何色都像色块 | prompt 强制**≥4 种不同材质**；门禁卡**色散均值 ≥15°** |
| ② | 边缘**毛、有漂浮小点** | AI 图集背景**有噪点**，抠底后残留 2~5px 独立小点（每张 20~93 个） | **去散点**：只保留面积 ≥ 阈值的连通域；**且必须在缩放后的最终画布上再清一遍**（缩放会把弱 alpha 又切成小点） |
| ③ | 边缘**半透明浑浊** | 抠底羽化带过宽 | alpha **硬化**（半透明 → 全不透明），保留 1~2px 抗锯齿 |
| ④ | 底部**参差地台** | AI **多画了一圈地面底座**（沙袋/水泥），非抠底问题 | 要么 prompt 明令"no ground/base/platform"，要么接受（多数建筑游戏本就带地台）；**先确认旧图有没有**再决定 |

**②③ 的判据（可量化）**：
- 连通块数：主体 1 块 + 少量真实分离件（旗杆等）；**漂浮碎点应为 0**。
- 弱 alpha（1~128）占比：越低越利落。

---

## 六、门禁判据（装前自动跑）

| 判据 | 阈值 | 作用 |
|---|---|---|
| 图内色散**均值** | ≥15° | 防单色剪影（坑①） |
| 每张图含**指定标记色** | ΔE00 ≤12 | 防"应挂的标识没画"（建筑族旗） |
| 每族均色离背景地色 | ΔE00 ≥12 | 防"糊在地里" |
| 输出尺寸 | 精确 | 引擎按固定尺寸采样 |
| alpha 覆盖 | ≥10%（空图护栏） | 防空白/切错格 |
| 连通块 | 主体 1 + 真实件 | 防散点（坑②） |

**门禁不过 = 整批拒入库**；只在"确实想强推"时 `--force`（并记录）。

## 七、可复用工具（本项目已封装）

| 工具 | 作用 |
|---|---|
| `gen/wasteland_prompts.py` | 按批打印**可直接复制**的图集 prompt |
| `gen/atlas_split.js` | 通用：2×2 → 4 图（四角采样抠底 + 居中还画布） |
| `gen/wasteland_batch.py` | **批驱动 + 装前门禁**：切分→体检→（过才）入库；建筑含洪水填充抠底 + 去散点 + 贴标记 |
| `asset/verify_wasteland.js` | 穷举业务 id 的取层（位图/矢量）+ 登记表 vs 磁盘 |
| `asset/wasteland_rollback.py` | 全量/分批回滚 |
| 批次清单 `asset/wasteland_batches.json` | 唯一真相源（分组/前缀/门禁阈值） |

## 八、推广到新项目/新批次（照抄清单）

1. **快照**现有位图 → `backup/<批次>/`（回滚杆）。
2. 写**批次清单**（id → 图集分组 → 输出前缀 → 门禁阈值）。
3. 写**生成规格**（统一风格块 + 逐资产形制 + 技术固定项）。
4. 出**图集**（t2i 或 i2i）→ 丢 `raw/`。
5. 跑**批驱动** `--check` → 看门禁 → `--apply`。
6. 跑**校验**（取层 + 三件套护栏）。
7. 老板目检 → 通过则铺下一批。

**每批只动一批**：某批不合格，只回滚该批，不影响已入库的。

---

## 九、一句话总结

> **换皮 = 出图集 + 抠干净 + 门槛挡住 + 同名覆盖 + 可回滚。**
> 最贵的是"出图"，最省的是"装前门禁"——**门禁挡下的每一批，都省掉一次线上回滚**。
