# AI 图标生成清单与 prompt 模板

> 用途：**全量图标的生成规格书**。批量重出图时照此执行，保证 100+ 张风格一致。
> 配套：`docs/图标素材注册表.md`（素材落位台账）、`docs/图标适配流程.md`（接入流程）。

---

## 一、统一风格基线（每条 prompt 都必须带）

**品质锚点**（写进 prompt 才有游戏级质感）：
```
Refined realistic game art, in the style of Rise of Kingdoms / Three Kingdoms strategy games
```

**汉代形制词库**（按元素取用，不要用笼统的 "ancient Chinese"）：
| 类别 | 必须点明的形制 |
|---|---|
| 屋顶 | 庑殿顶 / 歇山顶 / 悬山顶 / 硬山顶、灰陶瓦垄、**翘起的檐角** |
| 木构 | **朱漆木柱**、**斗拱**（dougong bracket sets）、抬梁式、木格窗棂 |
| 墙体 | 夯土墙（rammed earth）、青砖、木骨泥墙 |
| 台基 | 夯土台基、石阶踏道、栏干 |
| 甲胄 | **札甲**（lamellar armor，漆皮甲片 + 绑绳）、护肩、兜鍪 |
| 兵器 | 环首刀（ring-pommel sword）、卜字戟、矛、弩、云梯 |
| 器物 | 漆器、青铜器、竹简、陶罐、麻布、朱红/黑漆 |

**固定技术项**（每条都带，避免出图规格漂移）：
```
isolated on a plain solid pure white background (#ffffff), no text, no watermark,
no frame, no border, no ground shadow, centered composition, slight three-quarter
isometric view, warm golden light from upper left, soft ambient occlusion,
highly detailed material textures, crisp clean edges suitable for a small UI icon
```

**统一负面项**：`no people face, no logo, no signature`

## 二、生成参数

| 项 | 值 | 说明 |
|---|---|---|
| size | `1024x1024` | 方图，缩放后用于 64~128px 图标 |
| quality | `high` | 必须，medium 细节不足 |
| background | 不设或 `opaque` | **`transparent` 实测不生效**（透底率 0），统一出白底再抠 |
| 输出目录 | `assets/icons/raw/` | AI 原图 |
| 抠底输出 | `assets/icons/ui/` | 命名 `ai_<id>.png` |

**抠底流程**（`.workbuddy/tools/asset/matte.js`）：
四角采样取背景色 → 距离阈值 `T=42` → 羽化 `SOFT=26` → alpha 归零。
复检：透底率应 > 50%，且「主体占宽/占高」**不应为 100%**（= 没抠干净）。

## 十一、接入方式（位图与矢量的区别）

- 位图用 `<img src="assets/icons/ui/ai_<id>.png">`，**不内联 SVG**
- **地块不再显示承台背景**（老板 v35 要求）：`ui.isoCell` 里建筑/野地只输出 `<img>`，
  去掉 `plate()` 承台圆盘与光晕层
- 抠底后的 PNG 直接以轮廓形式落在格子上（对应"直接以图标轮廓"）
- 保留 `gicons.js` 矢量层作为**未命中回退**，逐组替换
