# 可玩性改进计划与迭代复核（v114–v116 · 2026-10-23）

> 起因：老板问「这个游戏目前为止好玩吗，对于人类来说。你找找标准，好好评估一下。」
> 评估结论：**这是"设计师的游戏"，还不是"玩家的游戏"** ——
> 机制齐（57 模块 / 4082 条断言），缺"第一分钟做什么、第一小时做什么"的编排。
> 本文件是评估后的改进执行记录。

---

## 一、评估用的四个标准

| 标准 | 出处 | 判什么 |
|---|---|---|
| 游戏 = 一系列有趣的决定 | Sid Meier | 每 30 秒有没有带取舍的决定 |
| 30 秒核心循环 | 宫本茂 | 不看文档能不能立刻"做→反馈→再做" |
| MDA 八类美学 | Hunicke/LeBlanc/Zubek 2004 | 该给哪几种快感、实际给了几种 |
| 心流 + 学习曲线 | Csikszentmihalyi / Koster | 挑战与技能是否匹配 |

判分（改前）：

| 维度 | 分 | 依据 |
|---|---|---|
| Sensation | 2/10 | 几乎无音效，界面纯功能性 |
| Fantasy | 7/10 | 设定扎实（四家立场 / 村社 / 棚户） |
| Narrative | 2/10 | 主动砍掉了，空出来的位置没人填 |
| Challenge | 7/10 | 数值有深度 |
| Discovery | 5/10 | 有迷雾但没有线索 |
| Expression | 3/10 | 编成有取舍，可选项少 |
| Submission | 6/10 | 有用离线产线 |

## 二、五个改进项与执行状态

### ✅ 1. 前传第一屏：50 个控件 → 三个动作（v114）

**证据（改前真实 DOM 文本）**：12 个 tab + 行省/市/区三级下拉 + 7 种地形筛选 +
坐标输入 + 9 个地图按钮，而玩家该做的事（去打点什么）**一次都没出现**。

**改法**：前传期盖一层全屏，藏起 `#topnav` / `#view-container` / `#bottom-bar`，
只留天数、一句人话、等级进度条、三个动作、一行"最近发生了什么"。

**改后**：
```
第 1 天
你们 200 个人，还没有城。
天还没冷。得找点能打的，先把人练出来。
君主 Lv1 / 20   ▬▬▬░░░░░░░░░░
[清剿 1 格外] [试炼 · 附近没有] [采集 · 附近没有]
```

**改完才看见的三个问题**：底栏没藏干净 / 主按钮不能是"附近没有" /
smoke（node）没有 `document` 会让 `syncScreen` 静默抛错并污染后续用例。

### ✅ 2. 空状态兜底（v115）

七个分类六个空，原来写"0"、点进去「— 无 —」。现在空项写「—」+ 45% 透明 +
有内容的排前面；每个分类配一句"去哪儿搞"。四方势力全未探明时，引导只写一次，
不再抄四遍。

### ✅ 3. 创建界面如实描述（v116）

原来标题写「创建城市」，交付的是**没有城**的前传。改成「给这支队伍起个名」+
一行「你还一座城都没有 —— 先把人带出去，活到能立城那天」。

### ◐ 4. 顶部 tab 分级（判断：暂不结构改动）

12 个 tab **已经分好 5 组**（`.nav-sep` 分隔符），问题不在分组，在**数量**。
真正的解法是把「空间站/游商/背包/收藏/公文/自动/设置」合并成 3 个
（物品 / 系统 / 建造），但那要动视图与几十条选择器断言 —— **属于产品决策，需要老板拍板**。
先不做"把次要 tab 调暗"这种半吊子方案：暗掉的 tab 容易被误读成"没解锁"。

### ◐ 5. 视觉硬伤（判断：部分修正，部分待单独一轮）

- **「这是好事，也是好事」病句** → 复核 DOM 文本，实际是「**既**是坏事，也是好事」。
  **是我看低分辨率截图看错了**，不存在这个 bug。
- **「四 方 夏 力」字距** → CSS 只有 `letter-spacing: 1px`（对中文正常）。
  **同样是截图看错的**。
- **探明区是一团蓝色**（不像地表）：真问题，但要动 map3d 的地形着色，风险中高，未改。
- **城名「老家 新城市」重叠**：真问题，3D 标签定位，未改。
- **打开世界账本时截图超时 60s**：未定位（可能是渲染动画，也可能真卡）。

> **教训（写给自己）**：从低分辨率截图下的判断，有两成是错的。
> 凡是"看到的问题"，先取一次 DOM 文本核实，再下结论。

## 三、迭代复核：改完之后

同一个标准重评：

| 维度 | 改前 | 改后 | 变化原因 |
|---|---|---|---|
| **Sensation** | 2 | 2 | 没动视听 |
| **Fantasy** | 7 | 7 | 没动设定 |
| **Narrative** | 2 | **3** | 前传那句"天还没冷。得找点能打的"给了处境 |
| **Challenge** | 7 | 7 | 没动数值 |
| **Discovery** | 5 | 5 | 迷雾依旧没线索 |
| **Expression** | 3 | 3 | 没动编成 |
| **Submission** | 6 | 6 | — |
| **（新增）第一分钟可玩性** | **2/10** | **7/10** | 50 个控件 → 3 个动作，且动作直指主循环 |

**结论：入口从"劝退"变成"能进去"。但天花板没变** —— 玩家进去之后，
Sensation（视听）、Discovery（探索线索）、Expression（编成深度）还是原样。

**下一步该动的不是界面，是这三件事**：
1. **Discovery**：迷雾要有"那边可能有东西"的线索（半信息痕迹已有实现，但玩家看不见）
2. **Sensation**：至少给"打中/被打中/占下"三种反馈（音效或屏震），这是 MDA 最低的一层
3. **Expression**：编成选择太少（8 张牌 / 5 个将位），撑不起"我是怎么打的"这个自我叙事
