## 〇、本轮即时修复（老板第 2 条点名项）

### 「资源界面 · 野地 · 进入按钮」——**已修，病根是 CSS 特异性**

老板说得对：v89.128 声称"按钮缩小"但**从未生效**。实机量测：改前 **46×30px**（资源区"＋"按钮只有 16×16）。

- **病根**：v89.128 写的 `.wild-go { padding: 0 var(--sp-2); … }` 特异性 **0-1-0**，
  被前文 `.btn.sm { padding: var(--sp-1) var(--sp-4); … }` 的 **0-2-0** 压过 ——
  padding 根本没应用（只有 line-height 生效），高度仍是 30px。
- **修法**：`.btn.sm.wild-go`（0-3-0）+ `height: 20px` + 字号 `--fs-cap` + 阴影 3px→1px。
- **实测**：**46×30 → 36×20** ✓（对齐资源区 plus-btn 视觉体系）。`shots/v89130-wildrow-{before,after}.png`。
