## 〇、总览：两条交付线

| # | 交付 | 一句话 | 定位 |
|---|------|--------|------|
| ① | **灵气装备系统** | 与军中装备（煞气）并存的第二套装备，一键切换、整套生效 | 修炼培养的"装备线" |
| ② | **江湖游历系统** | 野地场景之上的修炼活动层，将领带兵游历江湖 | 修炼培养的"玩法线" |

**两条线的闭环**：

```
野地游历（打怪 / 采集 / 拜访…）
   ↓ 产出：灵材（灵气精华）+ 灵气装备成品（低概率）
灵气装备（穿戴 = 配置，不是养成负担）
   ↓ 消耗：灵气精华
蕴养（+1…+10）→ 总蕴养等级 → 共鸣境界（全属性飞跃）
   ↓ 灵力增长
敢去更险的野地 → 更高阶产出 …
```

**为什么将领游历不违背"将领轻量化"原则**（功法文档 0.1 节）：
游历产出的是**装备**（配置对象），不是将领等级/经验（养成负担）。将领依然只有"谁上场、穿什么、带什么兵"三类决策；"培养"体现在装备的积累与蕴养上——玩家管装备不管人。灵材、蕴养、共鸣全部作用于**装备**，将领本身零养成线。

## 一、双轨装备：总览与切换机制

### 1.1 两套装备的定位分工

| 维度 | 军中装备（煞气）——现有 | 修炼装备（灵气）——新增 |
|------|------------------------|------------------------|
| 世界观 | 军匠锻造，煞气淬体，制式装备 | 天地灵物，灵气养神，江湖行头 |
| 主战场 | 攻城 / 守城 / 出征野战 | 野地游历 / 修炼 / 采集 |
| 战斗加成 | **100%**（基准） | **≈75%**（速度/爆发略优，续航逊） |
| 独有数值 | 体力 / 统率 / 防御（军阵三宝） | **灵力**（游历战力）+ 修炼词条 |
| 强化方式 | 百炼强化（金币+铁+石） | **蕴养**（灵气精华，独立材料） |
| 组合加成 | 套装：同名套按**件数** 3/5/7/11 档 | **灵脉**（同套装）+ **共鸣**（总蕴养档） |
| 产出来源 | 打造 / 缴获 / 商城 | 游历（打怪/采集/拜访/修炼） |
| 经济循环 | 金币 + 铁/石/革/玉/锦 | 灵气精华（独立，不与军装经济互通） |

**设计声明（独立性）**：两套系统**互不关联**——灵气装备不吃军装材料、不吃金币强化、不参与军装套装计数；军装强度不受灵气体系影响。唯一共享的是：同一名将领、同一套 UI 骨架、同一个属性汇总出口。

### 1.2 为什么是"整套切换"而不是"混穿"

| 方案 | 问题 |
|------|------|
| ❌ 两套同时生效 | 数值双叠加爆表；两套强化/组合机制互相纠缠；最优解永远是"两套都拉满"，双轨失去意义 |
| ❌ 两套混穿（煞气武器+灵气道袍） | 组合空间 2^12 爆炸；玩家理解成本极高；平衡无法收敛 |
| ✅ **整套切换**（本设计） | 数值永远单套、可算可控；世界观自洽（出征换军装、游历换便装）；操作一键、零学习成本 |

**切换语义（关键）**：切换 = **改变当前生效的整套**，不是"只换显示"。
- 加成生效：当前套的 `genEquipBonus` 结果进入六维/体力/战斗
- 显示同步：人偶图 12 格、装备提供行、套装/共鸣面板全部换成当前套
- 存档字段：`g.equipOn = 'sha' | 'ling'`，缺省 `'sha'`（老存档零迁移，默认军装）

### 1.3 切换按钮（位置与表现）

位置：将领面板「装备栏（n/12）」标题行**右侧**。

```
装备栏（8/12）   [ ⚔ 军中 ] [ ☯ 修炼 ]   ⓘ
┌──────────────┐  装备提供
│   人偶图+12格  │  统 +120 …
└──────────────┘  套装 / 共鸣面板
                  [一键最优装备] [全部卸下]
```

- 双态 tab 按钮（复用现行页签样式），点一下即切，**零成本、零冷却、可无限来回**
- 新手引导文案（悬停 ⓘ）：「军中装备用于攻城野战；修炼装备用于野地游历与修炼。二者独立养成，点击切换当前生效的一套。」

### 1.4 切换后——全链同步更新表（开发必读）

| # | 位置 | 切换后的行为 | 技术口径 |
|---|------|--------------|----------|
| 1 | tab 高亮 | ⚔/☯ 高亮互换 | `g.equipOn` |
| 2 | 人偶图 12 格 | 换成该套的 12 部位（含槽名、图标、品质色、+N 强化标） | `dollSlot` 按 `equipOn` 读 `g.equip` / `g.lingEquip` |
| 3 | 格子悬停 | 显示该套装备描述与套装信息 | `equipDesc` / 灵脉信息 |
| 4 | 「装备提供」行 | 六维增量按该套**重算** | `genEquipBonus(g)` 唯一出口分流 |
| 5 | 套装/共鸣面板 | 军装 → 套装进度；灵气 → 灵脉进度 + 共鸣境界 | `setProgressOf` / `resonanceOf` |
| 6 | 六维总览 / 体力上限 | 自动跟随（无需单独刷新） | `genAttrs` / `staMax` 已消费唯一出口 |
| 7 | 战斗 / 游历判定 | 出征按军装集、游历按灵气集（均取当前生效套） | `atkValOf` / `defValOf` / 游历判定读同一出口 |
| 8 | 快速按钮 | 「一键最优装备」「全部卸下」作用于**当前套** | 评分/卸下按 `equipOn` 过滤 |

> 工程要点：**同步零特判**。因为六维、体力、战斗、显示全部消费 `genEquipBonus(g)` 这一个出口（本项目的既有架构），切换只需在该出口内按 `g.equipOn` 选表——下游七处自动同步，不存在"改七处忘一处"的风险。这是本设计选择复用现有架构、而不是新搭一套属性链的核心原因。

### 1.5 防呆提示（易理解性）

- **出征面板**：若将领当前生效为灵气套，标题旁显示小标「☯ 修炼装备（军中加成 −25%）」+ 一键切换按钮
- **野地游历面板**：若当前生效为军装（灵气套），显示小标「⚔ 军中装备（游历战力按灵力算）」+ 一键切换
- **首次切换**：弹一次轻提示（仅一次）：「两套装备各自独立。切换后属性、加成、战斗、游历判定立即按新套装生效。」→ 图鉴「见闻」收录，也可在帮助里再查

## 二、灵气装备体系（详细设计）

### 2.1 装备类型与部位（12 部位对照）

与军装**同一套 12 部位**（界面与交互一致的根基），术语全面江湖化：

| 槽位 id | 军中装备 | **修炼装备** | 灵性主题 |
|---------|----------|--------------|----------|
| head | 头盔 | **道冠** | 神识清明（修炼） |
| neck | 坠饰 | **璎珞** | 护心养元 |
| shoulder | 肩铠 | **云肩** | 抗压卸力 |
| chest | 战铠 | **道袍** | 护体灵光 |
| back | 披风 | **灵帔** | 御风而行 |
| waist | 腰甲 | **灵带** | 聚气凝神 |
| arm | 臂甲 | **护腕** | 运劲精准 |
| feet | 战靴 | **云履** | 踏云涉险 |
| ring | 戒指 | **灵戒** | 纳物藏珍 |
| pendant | 佩饰 | **玉佩** | 通灵养气 |
| weapon | 武器 | **灵剑** | 锋锐破敌 |
| mount | 坐骑 | **灵骑** | 御兽同行 |

### 2.2 品阶 / 境界划分（6 阶对齐 6 品质色）

沿用现有 6 品质色系（灰白蓝紫橙红）——视觉系统零新增，玩家对品质色的直觉直接迁移：

| 阶 | 品名 | 色 | 对应境界（世界观） | 单件灵力基准 | 单件六维系数 |
|----|------|----|--------------------|--------------|--------------|
| 1 | 灵胚 | 灰 | 炼气 | 10 | 军装 ×0.75 |
| 2 | 灵器 | 白 | 筑基 | 25 | 军装 ×0.75 |
| 3 | 法器 | 蓝 | 金丹 | 60 | 军装 ×0.75 |
| 4 | 宝器 | 紫 | 元婴 | 130 | 军装 ×0.75 |
| 5 | 灵宝 | 橙 | 化神 | 280 | 军装 ×0.75 |
| 6 | 道器 | 红 | 渡劫 | 600 | 军装 ×0.75 |

> 命名"灵胚→道器"取器物成道之序；括号境界仅用于世界观文案与事件池（如"这件宝器曾是一位元婴修士的本命剑"），**不构成任何等级门槛**（不卡点铁律）。

### 2.3 核心属性与灵气数值

**新数值：灵力（ling）** —— 灵气装备的主数值。

- 结算口径：`灵力 = Σ(单件灵力 × 蕴养系数) × (1 + 共鸣加成)`
- 用途 1（主）：**游历判定**。所有对抗性江湖活动（讨伐/切磋/试炼）的胜负判定 = 双方灵力 + 将领六维修正 + 随机。灵力即"修炼界战力"。
- 用途 2（辅）：体现修炼厚度。文书里可展示"XXX 灵力"作为将领的江湖名片。
- **灵力不进六维、不进战斗公式**（独立体系声明）——战斗时灵气套的贡献 = 它的六维（75% 基准）+ 词条里明确标注的少量战斗词条。这条边界是两套系统"互不关联"的技术保证。

**六维**：灵气装备同样给统率/勇武/智谋/内政/体力/速度（战力 75% 基准），保证切到灵气套也能打仗（不强迫玩家"必须切回"，只是不划算），且切换有真实的数值观感。

**修炼词条（灵气侧特有，% 加成）**：见 2.4。

### 2.4 各部位词条效果（每种部位 3 个词条槽，示例即完整设计方向）

词条设计原则：**词条只做"打开玩法/加效率"，不做"碾压数值"**（对齐功法文档能力化原则）。

| 部位 | 主属性 | 词条 1（阶位基础） | 词条 2（中阶解锁） | 词条 3（高阶解锁） |
|------|--------|--------------------|--------------------|--------------------|
| 道冠 | ling | 修炼所获 +6% | 拜访奇遇率 +8% | 悟道时刻概率 +3% |
| 璎珞 | ling | 体力上限 +40 | 负伤减免 +10% | 游历全产 +5% |
| 云肩 | ling | 六维 def +40 | 试炼失败损失 −20% | 对抗负伤 −15% |
| 道袍 | ling | 六维 def +50 | 灵气精华获取 +10% | 游历消耗 −8% |
| 灵帔 | ling | 速度 +3 | 游历耗时 −10% | 奇遇双触发 +5% |
| 灵带 | ling | 灵气精华获取 +8% | 蕴养消耗 −5% | 共鸣增幅 +5% |
| 护腕 | ling | 六维 atk +30 | 讨伐战力 +6% | 切磋心得 ×2 概率 +10% |
| 云履 | ling | 速度 +3 | 采集双收 +8% | 秘境层数 +1（V3） |
| 灵戒 | ling | 采集双收 +6% | 稀有掉落率 +8% | 悬赏奖励 +10% |
| 玉佩 | ling | 灵力 +5% | 切磋心得 +20% | 斗法先手 +1（V3） |
| 灵剑 | ling | 六维 atk +40 | 讨伐战力 +8% | 讨伐首击必中 |
| 灵骑 | ling | 速度 +4 | 游历耗时 −12% | 护镖必达（V3） |

> 词条数值为示意（待实测）；实现上每件装备 1-3 条词条沿"阶位"逐条解锁（1 阶 1 条、3 阶 2 条、5 阶 3 条），保证低阶装备也有用、高阶装备词条齐。

### 2.5 蕴养（强化 / 升级方式）

**蕴养** = 灵气装备的强化，与军装"百炼强化"形式对齐、材料独立：

| 项 | 军中（百炼强化） | 修炼（蕴养） |
|----|------------------|--------------|
| 等级 | +0 → +10 | +0 → +10（同） |
| 单级增幅 | 装备全属性 +8% | 灵力与六维 +8%（同） |
| 材料 | 金币 + 铁/石 | **灵气精华**（游历产出，独立材料） |
| 失败率 | 无 | **无**（不失败、不降级、不碎裂——铁律） |

**成本曲线（示意，待实测）**：第 n 级消耗 = `10 + n×10` 精华（+1 级 20 → +10 级 110，累计 650）。
产出对照：单次游历产精华 ~25-45（拆到各活动），日均 3-4 次游历 ≈ 100-150 精华。
节奏定位：一件 0→+5 ≈ 1.5 天（快速见效）；0→+10 ≈ 5-6 天（长线目标）；不催不卡，随时可停。

**入口**：将领面板装备格 → 装备详情 → 「蕴养」按钮（与军装"强化"同位置同交互，仅材料与文案不同）。

### 2.6 灵脉（套装）与共鸣加成

灵气侧的组合加成分两层：**灵脉**（对齐军装的件数机制）+ **共鸣**（灵气独有，蕴养深度机制）。

**① 灵脉加成（套装同构）**：
同名灵脉套按**件数** 3 / 5 / 7 / 11 档逐档加成、效果累计（与军装规则完全同构，玩家零学习成本）。

| 灵脉套 | 阶位 | 主题 | 3 件 | 5 件 | 7 件 | 11 件 |
|--------|------|------|------|------|------|-------|
| 青冥 | 1-2 | 入门均衡 | 灵力 +8% | 精华获取 +10% | 六维 +60 | 灵骑同源：速度 +8 |
| 赤霄 | 3-4 | 攻伐游历 | 讨伐战力 +10% | 灵力 +12% | 六维 +120 | 讨伐必得材料 +1 |
| 玄元 | 4-5 | 修炼共情 | 修炼所获 +15% | 共鸣增幅 +8% | 灵力 +18% | 悟道时刻 ×2 |

**② 共鸣加成（灵气独有）**：
按**全 12 部位总蕴养等级**（0 → 120）分档触发——养得越深、共鸣越强。这是灵气体系把"蕴养"从单体强化升华为**全局目标**的机制：

| 档 | 总蕴养 | 境界名 | 效果 |
|----|--------|--------|------|
| 1 | 12 | 初鸣 | 灵力 +5% |
| 2 | 36 | 和鸣 | 灵力 +12%，全词条 ×1.1 |
| 3 | 60 | 共鸣 | 灵力 +20%，全词条 ×1.2 |
| 4 | 84 | 长鸣 | 灵力 +30%，全词条 ×1.3 |
| 5 | 108 | 天鸣 | 灵力 +42%，全词条 ×1.45，人物特效微光 |
| MAX | 120 | 大圆满 | 灵力 +50%，称号「天人合一」（收集向） |

> 与军装套装的差异辨识：军装"凑件数"、灵气"养深度"。凑件是收集快感，养深度是修炼叙事——两个循环的心理动机不同，共同构成双轨的差异化乐趣。

### 2.7 灵气 vs 煞气：差异总表（独立性声明）

| 对比项 | 军中（煞气） | 修炼（灵气） | 是否互通 |
|--------|--------------|--------------|----------|
| 部位 / 槽位 | 12 | 12（同构不同名） | UI 共享，数据独立 |
| 数据字段 | `g.equip` | `g.lingEquip` | ❌ 完全独立 |
| 强化材料 | 金币+铁+石 | 灵气精华 | ❌ |
| 强化出口 | `ENHANCE`（+8%/级） | `LING_TEMPER`（+8%/级） | ❌ 同形式独立表 |
| 组合机制 | 套装（件数档） | 灵脉（件数档）+ 共鸣（蕴养档） | ❌ |
| 主数值 | 体力/统率/防御 | 灵力 | ❌ |
| 战斗加成 | 100% | 75%（+少数战斗词条） | 二选一，**不叠加** |
| 产出来源 | 打造/缴获/商城 | 游历 | ❌ 经济不通 |
| 生效方式 | `equipOn==='sha'` | `equipOn==='ling'` | 互斥 |

**一句话**：两条供应链、两套组合机制、两种主数值；共享一名将领、一张人偶图、一个属性出口。

## 三、江湖游历系统（修炼培养 · 野地联动）

### 3.1 框架：野地场景之上的"修炼层"

**现状复用**：v87 已有六地形专属场景（绿林探访/垂钓/寻宝/地宫探险/狩猎/牧马），落点 `ui.wildSceneHTML`，每处每日一次、消耗精力+体力、种子化可复现。

**新增**：野地弹窗内、场景区之下，增加「**江湖**」分区——同一处野地的**修炼活动菜单**（可做多件事，各自独立锁）。场景区与江湖区的关系：

| 分区 | 定位 | 产出 | 锁定 |
|------|------|------|------|

### 3.3 MVP 六活动详设

**A1 讨伐**（对抗）
- 流程：选目标（本地贼寇/妖兽，按地形出不同名号）→ 灵力对比判定 → 胜：精华+灵材，败：负伤归（也有一条"小插曲"收获，见"不惩罚"）
- 判定：`我方战力 = 灵力 × (1 + 讨伐词条) + 六维修正`；`目标战力 = 地形基数 × Lv`
- 风险分级不设门槛：高难度目标随时可打，但低于推荐灵力时负伤概率上升（软引导）
- 产出：精华 30-50；灵材按阶 0-2 件；5% 低概率掉落灵胚/灵器成品
- 消耗：精力 15 / 体力 6

**A2 切磋**（对抗 · 温和）
- 流程：与游侠/骑手/刀客对练，三合判定（前两合看灵力、第三合看词条）
- 特色：**必得心得**（精华 15-25 保底）——输了也有收获（"与高手过招，获益良多"）
- 产出：心得精华 + 10% 词条材料「武学心得」（用于灵脉词条洗练，V2 开）
- 消耗：精力 10 / 体力 4

**A3 试炼**（对抗 · 多层）
- 流程：古阵/石阶/祭坛，1-3 层，逐层加码；每层通过后可选择"见好就收"或"再进一层"
- 判定：每层灵力对比，败则止步（不入下一层，已过层奖励保留）——**中途退出无损**
- 产出：层数递增，最高层出宝器级灵材/成品
- 消耗：精力 18 / 体力 7

**B1 采集**（趣味）
- 流程：在山林水泽采灵草/灵矿/灵砂，抽取 1-3 份
- 词条联动：双收（灵戒/云履词条）可额外多抽一份
- 产出：阶位灵材（1-5 阶按地形成色）
- 消耗：精力 8 / 体力 3

**B2 修炼**（趣味 · 稳定）
- 流程：择灵气浓郁处（森林古树/湖泊水畔）打坐聚气
- 特色：**稳定产出**（精华 35-55，无失败）——灵气装备养成的保底来源
- 小概率"悟道时刻"（+1 次全额产出 + 图鉴卡）
- 消耗：精力 12 / 体力 5

**B3 拜访**（趣味 · 事件）
- 流程：拜访隐士/药农/渔隐/牧人——抽事件卡（2-4 句轻松小故事 + 2-3 选项，全选项皆奖励，对齐功法文档 2.2 三原则）
- 产出：事件礼物（精华/灵材/低概率装备）+ 名士谱进度（收集）
- 特色：**每个 NPC 三次拜访后成为"熟客"**（赠礼升级 + 专属小故事）——收集驱动的轻社交感
- 消耗：精力 8 / 体力 2

### 3.5 "少量收获"原则（数值克制）

1. **产出只进灵气体系**：精华/灵材只用于灵气装备（蕴养/合成），不产金币/铁/石，不冲击主经济
2. **单次产出克制**：一次游历 ≈ 精华 25-50 + 灵材 0-2 件；日均（3-4 次）≈ 精华 100-160
3. **装备成品低概率**：单次 3-5%，以低阶（灵胚/灵器）为主——加速"起步"，不替代"积累"
4. **不出军装、不出名将、不出资源**——两个体系的经济零交叉

## 四、平衡思路

### 4.1 三条平衡红线

1. **单套生效，永不叠加**：`equipOn` 二选一 → 任何时刻将领的装备强度 = 单套上限，全程可算可控
2. **战斗基准 75%**：灵气套打架永远逊于同档军装（速度/爆发略优但体力/防御/统率吃亏）→ "打仗用军装"不被动摇；同时 75% 不低——切错套不至于被吊打，只是不划算（不惩罚原则）
3. **游历看灵力，战斗看六维**：两条数值线各自独立结算、互不转化 → 没有"灵气套堆到极致顺便吊打战斗"的漏洞

### 4.2 双轨的经济闭环

```
军装线：金币/铁石 ──打造──► 军装 ──强化──► 攻城野战 ──缴获/图纸──┐
   ▲                                                              │
   └──────────────────────（主战力循环，本设计不触碰）────────────┘

灵气线：精力/体力 ──游历──► 精华/灵材 ──蕴养/合成──► 灵气装 ──灵力──► 更高阶游历 ──┐
   ▲                                                                              │
   └──────────────────────（独立循环，材料与货币零交叉）──────────────────────────┘
```

**为什么鼓励双养**：军装保证主战力（攻城掠地）、灵气装解锁游历深度（装备/材料/图鉴）；两线材料不互通 → 不存在"二选一"的资源冲突，只有"都想做"的自然驱动。

### 4.3 关键换算对照（同阶段强度示意）

| 项目 | 军装（4 阶神兵 +10） | 灵气装（4 阶宝器 +10） |
|------|---------------------|------------------------|
| 武器 atk | 960 × 1.8 = **1728** | 720 × 1.8 = **1296**（75%） |
| 全身六维 | 基准 100% | ≈75% |
| 主数值 | 体力 ≈ 7800+ | **灵力 ≈ 2800**（12 件 × 130 × 1.8） |
| 组合加成 | 倚天 11 件满档 | 灵脉 11 件 + 共鸣（可达 +45%） |
| 战斗口碑 | 攻城主力 | 野战可打、攻城吃亏 |
| 游历口碑 | 无灵力，游历效率低 | 游历主力 |

> 数值为示意（待实测调优）。调优锚点：让"两套都值得养"在体验上成立——军装玩家想开游历要养灵气，灵气玩家想打架要养军装。
