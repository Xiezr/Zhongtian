### 三项判断（整改后）

- **完整 ✅** —— 七类产物各有唯一位置、都有护栏；入口齐全（本文件 + 设计规范 + 工具索引 + MEMORY）。

  **改规范的人现在只需读 8KB**，不必翻 4000 行历史。史料归位后可整目录打包或忽略。
- **集中 ✅（本轮达成）** —— 规则从"散在 4 份主文件 + 6 技能"收敛为**四层明确分工、每层一个入口**；

## 六、一页速查

```
改完代码必须跑（缺一不可）：
  node audit.js
  node smoke-test.js                                         # 现 1880 通过 / 0 失败
  NODE_PATH='…\node\workspace\node_modules' node e2e-test.js  # 现 661 / 0

生成器（路径已带子目录）：
  node .workbuddy/tools/gen/gen_bitmaps.js         # 扫 assets/icons/ui/ → js/bitmaps.js
  python .workbuddy/tools/gen/gen_tools_index.py   # 重生成工具索引

同步到 GitHub（**收尾唯一入口**，默认干跑；门禁不过就不提交）：
  python .workbuddy/tools/git/sync.py                      # 干跑：先看将提交什么
  python .workbuddy/tools/git/sync.py --apply              # 真做：门禁 → 提交 → 推送
  python .workbuddy/tools/git/sync.py --apply --tag v68    # 顺带打版本标签
  python .workbuddy/tools/git/sync.py --push-only          # 不提交，只推已有提交

两个钩子（安装：python .workbuddy/tools/git/install_hooks.py）：
  pre-commit   提交前跑门禁（改 js/ 或 index.html 才跑全量三件套，约 47 秒；否则只跑 audit）
               跳过一次：SKIP_GATE=1 git commit …   强制全量：GATE_FULL=1 git commit …
  post-commit  提交后自动推送（后台、绝不阻断 commit；日志 .workbuddy/tmp/autopush.log）
               关闭：GIT_NO_AUTOPUSH=1

动手前先问三句：
  ① 这东西有没有唯一出口？（MEMORY §一.8 清单）→ 有就改出口，别改引用处
  ② 我改的是规范还是史料？（`设计规范.md` 才是规范）
  ③ 改完能不能翻转？（破坏测试注入一次，确认断言会红）
```
