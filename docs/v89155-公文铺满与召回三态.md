### 排序标号的口径（老板第 4 条）

```
标号 = 功能族 × 1000 + 族内档位（0~999）
  族 = 效果维度：eff 的键（military: atk/def/wound/cap；attr: tong_mult/…；prod_buff 看 res 字段）
     · 单键族 = 基族×10；**复合效果（多键）= 基族×10+1**（攻守符{atk,def} 不劈开纯攻击四鼓）
  档位 = 效果值×1000；无效果（珠宝/图纸/加速/经验…）用 price 当档位
物品写 ord（数字）→ 直接覆盖（手动微调口）
```
**实测（商城真渲染）**：`四鼓(atk .10/.15/.25/.35) → 复合件(攻守符→全军令→万全策→天时令) → 盾四件 → 转伤 → 上限`；
粮食系三件（神农锄0.25→神农灵锄0.5→后稷神犁1）相邻升序。

## ⑤ 诚实缺口

1. **`ui.DOC_HEAD_H=127 / DOC_TASK_H=104 / DOC_LINE_H`** 是实机量测常量 —— 改公文版式
   （标题/页签/chips/行高）后要**重新量测更新**（改动点集中在 `ui.docPerOf` 一段，注释已写明）。
   视口高是动态读的（改窗口自适应），只有"头/摘要/行高"是常量。
2. **召回 2 秒超时的回落依赖 setTimeout**：页面切到后台（标签隐藏）时浏览器会节流计时器 ——
   超时可能延后触发（按钮多黄一会儿），不影响正确性（第二次点击仍按状态执行）。
3. **排序标号只作用于三处列表**（商城/背包宝物/快购）；背包"材料/图纸"页沿用原有
   series/tier/价格排序（本来就成组），未强行并入。
4. **下拉框/其它列表**未纳入标号体系（本轮范围外）。
