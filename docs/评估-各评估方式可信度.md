# 评估 · 游戏内各「评估方式」可信度（独立评测）

> 触发：老板「独立评测当前游戏中多个游戏的评估方式确认，或者从业界现有的比较好的一些游戏对照来确认一下」。
> 方法：不看公式写得对不对，只用**真实战斗结果**当尺子，逐个评估"它说的"和"实际发生的"差多少。
> 探针：`tools/eval-audit.js`（可复跑 · 输出 `tools/eval-audit.log`）。

## 二、三条最有价值的发现

### 1. 战力能"排序"，不能"算倍数"，在"数量堆战力"时会错判

25 场里错判 2 场，**都在前期打 Lv9**：
- 我方 8,000 兵战力 1,894 万，守军 18,000 兵战力 3,584 万（战力比 **0.53**，系统说"你打不过"）
- 实际：**赢**，战损 87%

原因：`power` 是 `Σ 单兵战力 ×(1 + 加成×覆盖率)` 的**线性加权和**，把"人数"当线性；
而回合制战场是**接触面受限**的（一击一目标 + 阵位 + 射程），多出来的兵打不出来。
→ **加权和天然高估人海、低估精锐。** 这与业界"战力值≠实战"的老问题同源。

### 2. 装备评分的"分"和"战力贡献"不是一个量纲

6 个非武器槽：换上评分高 4,800 分的件，战损变化 **0.1 个百分点**（掷骰噪声级）。
武器槽才有真实意义（−9.7 点）。
原因：`equipScore = 3×四维 + atk + def + 0.2×sta + 4×spd` 按**属性点数**计价，
而战斗只看 `atkPct/defPct`（武力/谋略 + 装备攻防值）—— 四维里的指挥/治理在评分里占 3 分权重，
在战斗里却只经"覆盖/减伤/体力"间接生效。
→ 评分**排序**可用，但把它当"价值"读会误判；玩家会为 5,000 分换 0.1% 战损。

### 3. 选靶评分：守方落地但方向反，攻方根本没有落点

- **攻方**：9 个目标逐一强制指定，战损全部 44.0%。因为 `preferId` 只在"目标在射程内"才生效，
  攻方在推进中射程内通常只有最近那一支 → 评分被距离吃掉。
- **守方**：真的生效（差异 13.4 个百分点）。但 AI 评分（击杀 3.0 / 伤害 2.0 / 威胁 1.2 / 挡路 0.8）
  首选「主战机甲」—— 最强的目标，啃它导致守方输出效率下降，**我方战损反而从 53.6% 降到 40.2%**。
  → 权重奖励"击杀价值"，但没惩罚"击杀成本"；对高防目标应当降权。

## 三、业界对照（这些游戏怎么解决同一个问题）

| 做法 | 代表 | 对我们的启示 |
|---|---|---|
| **预测 = 结算，同一套公式** | 文明6 战斗预测（显示预计伤害/剩余血）、XCOM（直接给命中率） | 我们的 `power` 是**第二套加权公式**，不含射程/先手/阵位/城防 → 要么改成同源期望，要么在面板上明写"不含什么" |
| **估算必须标注"估算"** | 全面战争 auto-resolve（简化模型，明确不是精确值） | 战力面板的"实力对比"应降级为"粗略对比"，不给出"你强 3 倍"的暗示 |
| **战力值只做门槛，不做预测** | 率土之滨 / 三国志战略版：战力是养成进度与出征门槛，社区公认≠实战 | 我们自动探索用战力当"建议兵力"门槛 —— **这个用法是业内标准用法，保留** |
| **公式公开、可第三方复算** | EVE 的 EHP/DPS、流放之路的 Path of Building（外置模拟器）、WoW 的 simcraft | 我们的权重（hp/atk/def/spd）没有对玩家公开，也没有说明"哪些因素不在内"，玩家无法自证 |
| **AI 的优先级必须落到行为且可回归** | 全战 / 星际的 target priority 直接改单位行为 | 我们的 `scoreTarget` 在攻方侧落不了地 → 要么让它在射程外也影响"接近谁"，要么删掉省维护 |

## 四、建议（按优先级，均未实施）

1. **P0 选靶权重改"效率"口径**：把"击杀收益"换成"打掉它 / 我少挨多少"的比值，
   或直接对"高 def 目标"降权。现状是 NPC 主动帮我方减损 13.4 个百分点。
2. **P1 守住动作过强**：全体守住把战损从 53.6% 压到 4.4%（同一场、同一编成）。
   建议减伤 50%→25~30%，或"守住"只在有射程优势时生效 —— 否则"全体守住"是无脑解，
   而 `smartStanceOf` 的战术评估也会被这条规则带偏。
3. **P2 战力面板加限定语**：写明"不含射程 / 先手 / 阵位 / 城防"，并把倍数读法去掉
   （改为"实力接近 / 明显优势"三档）。
4. **P3 装备评分改用"战斗增量"**：按该件带来的 `atkPct/defPct` 增量打分（同槽比大小仍然成立，
   且尺度与实战一致）。
