# 可移植玩法：星露谷那类游戏能给废土什么

> 老板 2026-10-23：
> 「分析如星露谷之类游戏，有没有可移植玩法。废土是一个大世界，
>   不应该只有建造，战斗，发掘。也不用赋予太沉重的意义。」

---

## 一、先拆星露谷：它到底在卖什么

不是"种地"，是**三层嵌套的窗口**。

| 层 | 时长 | 机制 | 玩家在做什么决定 |
|---|---|---|---|
| 日 | 现实 15~20 分钟 | 6:00–2:00 + 精力条 | 今天只够做两件事，做哪两件 |
| 季 | 28 天 | 作物有种植窗口，错过等一年 | 提前囤、提前种、提前卖 |
| 年 | 4 季 | 冬天室外不长东西 | 被迫换一套玩法（钓鱼/挖矿/社交） |

三层里最关键的是**中观那层（季）**：它让"现在做"和"以后做"产生差价。
没有它，日循环就只是重复劳动；有了它，玩家会主动规划。

第二关键的是**冬季**：强制多样性。它解决开放世界最经典的问题 ——
玩家找到一个舒服的循环，然后一直重复。

---

## 二、废土这边：机制本来就有，缺的是「信号」

对着星露谷这三层看，"灰岗"其实一件都不缺：

| 星露谷 | 废土已有 | 差在哪 |
|---|---|---|
| 日 = 精力预算 | `energy` / `stam`，荒野行动消耗 | 有了，但只约束"打不打" |
| 季 = 种植窗口 | `DATA.CALENDAR` 四季 · `climate` 温度正弦 · `years` 年景 | **有，但只影响产量，不影响价格** |
| 冬 = 强制换玩法 | 寒潮（`DATA.COLD`）冻死城外的人 | **有，但只是惩罚，不是机会** |
| 加工链（果→酒） | **完全没有** | — |
| 集市 / 节日 | 游商（买卖固定价） | 有商店，没有**行情** |
| NPC 好感 | 村社 `mood`、`renown` | 有，但只影响产量 |

一句话：**废土不缺机制，缺的是让机制之间产生"差价"的那根线。**

所以这一轮不是加新系统，是给既有资源加一个**价格**。

## 三、这一轮做了什么（v117）

### 3.1 集市与行情（`js/market.js`）

```
每月三次"赶集"（每次约 4 秒现实时间）→ 全价收购
其余时间 → 收购价压低 18%
```

价格 = 基准 ×（6 月慢波 + 2.7 月快波）×（寒潮 / 年景乘子）× 小幅抖动。

全部是**确定性函数**（给定月份就算得出来），所以玩家可以预判，不是老虎机。

实测（12 个月，粮价）：**0.70 ~ 1.75**，最高最低差 1.5 倍。
冷月均价 1.57 / 暖月均价 0.96 —— 寒潮月粮贵 63%。

这就把既有系统串起来了：

```
寒潮（climate）→ 粮贵 → 该在寒潮前囤粮
丰年（years）  → 粮贱 → 别急着卖
战年（years）  → 废钢与粮都涨
```

### 3.2 作坊（同一模块）

```
800 粮  →（20 游戏小时）→ 60 压缩干粮 → 集市卖 1560 旧币
                                    （原料按市价约 976）
```

成品进 `items`（不占仓容），所以能攒着等高价。寒潮月成品再涨 35%。

这是星露谷"果酱桶"的最小版本：**原料 → 时间 → 成品 → 差价**。
一条完整的价值链，加了三个决定：什么时候开炉、做哪一种、什么时候卖。

### 3.3 顶栏分级（顺手，老板授权「你来确定」）

12 个页签 → **6 个常驻 + 「更多」**。

常驻的是每天都要点的：城市 / 城外 / 地图 / 英雄 / 军务 / 行政。
其余折进「更多 ▾」，切到折叠页签时自动展开。

**没有删 DOM 节点**，只改 CSS 可见性 —— 四百多条断言靠
`querySelector('[data-view=shop]')` 找页签，删了等于一次性废掉一批守卫。

## 四、还能移植的（按"离现状最近"排）

| # | 玩法 | 星露谷原型 | 废土怎么做 | 成本 |
|---|---|---|---|---|
| 1 | **猎场** | 钓鱼（小游戏） | 辐射区/沼地有"今日鱼汛"，一天只出几趟；打到的不是资源是**食材**，食材能做菜（短时 buff） | 中 |
| 2 | **节日** | 春 13 彩蛋节 / 秋 16 展览会 | 每年 2 次"换季大集"：价格全线上浮 + 一次稀有货；玩家提前知道日期 | 低 |
| 3 | **商路** | 无（星露谷没有） | 集市要"路通"：寒潮/战乱封路则集市取消 —— 让地图上的地形真正影响经济 | 中 |
| 4 | **常客** | NPC 好感 | 某个商队头目每月来一次，买得多了给你留稀有货（好感 = 折扣 + 独家） | 中 |
| 5 | **图鉴** | 博物馆捐赠 | 已有 `DATA.COLLECT`（六套藏品），缺的是"集齐一套给什么" | 低 |

**明确不做的**（写了理由，防以后自己手痒）：

- **不写"遗志/使命"**。老板两次说过：不要沉重意义。
  集市就是生意，作坊就是干活。加一句"这是为了后人"都是错的。
- **不做期货 / 借贷 / K 线**。那是另一个游戏，会把"什么时候卖"变成"盯盘"。
- **不加仓租 / 腐坏**。囤积不受惩罚 —— 惩罚囤积等于强迫玩家每月清仓，
  那正好消灭了"等好价"这件事。
- **不做限时抢购**。一月在 120× 下只有 40 秒现实时间，
  "必须掐秒"的窗口玩家根本反应不过来。窗口只决定**价格档位**。

## 五、这一轮之后，分数动了哪一格

上一轮评估（`docs/可玩性改进-v114.md`）里，Expression（自我表达）是 3/10，
理由写的正是"可选项太少"。

这一轮加了三个新决定：
1. 现在卖还是等赶集？
2. 原料直接卖，还是压成成品？
3. 什么时候开炉（一次只有一炉）？

**Expression 3 → 5。** 不是因为它变深了，是因为第一次有"不同的赚钱方式"。

Discovery 仍然是 5（集市不解决"迷雾里有什么"），Sensation 仍然是 2（没有音效）。
