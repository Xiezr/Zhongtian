# 地块生成与地形匹配规则（v155）

> 老板：「根据地形划分各地块类型，且地形颜色渲染又要跟地形类型尽量一致……总结一套地块生成和匹配规则，
> 以与地形核心搭配」。

**一句话：一个格子的样子 = 它的类型。** 颜色、判定、掉落、场景，全部读同一个类型。

> v155 起，类型不再由"几个阈值硬套"，而是走一条**有序流水线**（因子 → 分带 → 分区 → 平滑）。
> 规则本体在 `sphere.js` 的 `SP.buildTerrainTypes` 与 `SP.TERRAIN_RULES`。

---

## 一、格网（几何）

| 项 | 规则 | 代码 |
|---|---|---|
| 形状 | icosphere 对偶 = 六边形（12 个五边形在正二十面体顶点处） | `sphere.js icoSpheres` |
| 细分 | `SUB = 6` → **40962 格**（`10×4^6+2`） | `sphere.js:~30` |
| 为什么不再是 10242 | v152 误把格子放大了一倍；v153 退回 40962。再细一档 sub=7 = 163842 格，实测构建 5.9s / +360MB，浏览器扛不住 | `需求档案.md v153` |
| 地块高度 | **跟随地形**：`R + max(0, 高程)×HSC + PLATEAU`，`PLATEAU = 0.05` —— 六边形是"地表上的纹路"，不是"盖在球上的板" | `sphere.js terrainR` |
| 线框 | 同一条边两侧共享**同一个顶点高度**（`SP._rimHMap` 按坐标取整缓存）→ 不重影；只靠材质 `polygonOffset` 往镜头拉一点 | `sphere.js` / `map3d.js buildTiles` |
| 唯一有边的东西 | **只有地块线框**。省/市/区边界 = 给同一批地块边上色（`paintRegionEdges`），**不另画线** | `map3d.js` |

## 二、流水线（v155 · 因子表 → 有序推导）

| # | 因子 → 影响 | 怎么算 |
|---|---|---|
| ① | **海拔** → 温度直减、垂直植被带、切割强度 | 已有的 contField + mountainField + 细节噪声 |
| ② | **距海岸** → 大陆性、水汽输送 | 从所有海格做**一次多源 BFS**（越远离海越干） |
| ③ | **坡度** → 陡坡侵蚀强、积不住土 | 与邻居的最大高差（按全星归一） |
| ④ | **纬度** → 热量带、主导外力（冰/水/风） | `heat = (1-lat²) - alt×0.55`；风带按纬度取正弦 |
| ⑤ | **距水源 / 湿度** → 近水沉积湿润、远水风蚀 | `wet = fbm×0.8 + 风带×0.2 - 离海×0.55 - 海拔×0.10` |
| ⑥ | **岩石/植被** | 并入"坡度 + 湿度"的反馈（陡=裸岩，湿=成林），不单列 |
| ⑦ | **人类活动** | 属于**玩家**，不在地形生成里 |

**关键一步：④⑤ 的原始值全部转成"分位数 0~1"**（`rank01`）—— 于是"多少山地/多少平地"
由地类表说了算，不再取决于噪声恰好落在哪一段（旧版就是这样让森林/沼泽占满全星）。

## 三、地类表（`SP.TERRAIN_RULES`，按顺序短路）

```js
if (海平面以下)                                     lake
else if (alt > 0.86)                                hill      // 雪线以上裸岩
else if (alt > 0.70 && slope > 0.62)                hill      // 陡坡：积不住土
else if (离海 <= 1 && wet > 0.55)                   zhaoze    // 近水低地：沉积+滞水
else if (alt < 0.16 && wet > 0.62)                  zhaoze    // 低洼湿地
else if (heat > 0.50 && wet < 0.42)                 desert    // 热+干（内陆/背风）
else if (alt < 0.42 && slope < 0.58 && wet < 0.74)  plain     // 低平冲积：能立城
else if (wet > 0.56)                                forest    // 湿润成林
else if (heat < 0.28)                               forest    // 高寒针叶林
else                                                caoyuan   // 草原
```

随后做 **2 轮邻域投票**：同类邻居 < 2 的格子并进邻居里的主流类型（平地优先级调高，避免被整片吃掉）。
这一步就是"相同地形连续性"——**先分区、再平滑**，而不是先平滑再判。

实测（3 个 seed）：湖 49~53% · 森林 13~17% · 山地 9~11% · 沼泽 7~8% · 草原 6~8% · 平地 4~5% · 荒漠 4~10%。
构建耗时 1.0~2.7 秒（含全部分位数排序与两轮平滑）。

## 四、颜色（与类型一一对应，绝不串色）

| 类型 | 基色 RGB | 观感 | 额外规则 |
|---|---|---|---|
| 湖泊 lake | —（海面独立着色） | 旧方案 `#4a7fa0` + 顶点位移波浪 | 见第七节 |
| 沼泽 zhaoze | 86,104,70 | 浑浊青褐绿 | — |
| 平地 plain | 188,176,132 | 浅土黄（能立城的"空地"） | — |
| 草原 caoyuan | 162,180,98 | 黄绿 | — |
| 森林 forest | 48,112,58 | 饱和深绿 | **永远不会是黄的** |
| 荒漠 desert | 216,186,120 | 沙黄 | — |
| 山地 hill | 156,144,126 | 暖灰岩 | 很高处掺雪 |

- 同类内部只叠**明暗**（低频成片 + 高频颗粒），**不改色相** → 同类型成片、交界处自然断开。
- **渲染器关掉 sRGB 输出转换 + 关掉 ACES**：顶点色是按肉眼 sRGB 写的，再编码一次会整体发白
  （这就是"整颗球发白、地形色被冲淡"的根因，v154 修）。

## 五、由类型派生的一切（同源，不再各算一遍）

| 用途 | 读什么 |
|---|---|
| 能否立城 | `DATA.TERRAIN[type].buildable`（只有 plain 为真） |
| 野地掉落 | `DATA.WILD_MATERIAL[type]` |
| 荒野行动（采集/清剿/试炼…） | `DATA.LING_ACT[*].spots` 里含该 type |
| 2D 地图地形色 | `map.js H_FLAT[type]` |
| 3D 场景选哪一间 | `scene3d.pickFor(act, terrain)` |

> 加新地形 = ① 在 `cellType` 里给判定 ② 在 `TERRAIN_RGB` / `H_FLAT` 给基色
> ③ 在 `DATA.TERRAIN` / `WILD_MATERIAL` 给语义。**不要在别处再写第三套阈值。**

## 六、海面（v155 · 参考工程做法）

参考：`C:/Users/18811/WorkBuddy/2026-10-27-20-10-37/water-sphere.html`。
- **颜色回到旧方案**（`0x4a7fa0`），只改**波浪形态**；
- 顶点沿法线位移：5 个方向的正弦叠加（波数 **0.19~1.95**，按格距定 —— 一格 ≈ 5 世界单位，
  波数太大就是"整屏一个浪"，太小就是"看不到浪"）；
- 法线用**有限差分**（`n = cross(P_T - P, P_B - P)`）算，片元只做 diffuse + 很淡的 fresnel；
- 海面**只覆盖水格**（不再是一整颗球）→ 海岸线精确、不会盖陆地；
- 着色器编译失败自动退回纯色球。

## 七、奇观（与地形贴合）

- 底座平面 ⟂ 该格法线（= 底座躺平）；底座**压进地面 8%**。
- 尺度按**模型自身包围盒**缩到"格宽 ×1.6 × 2/3"，星环/太空/地表三种模式统一 ×2/3。

## 九、改规则的入口（只此三处）

1. **比例/分区**：`SP.TERRAIN_RULES`（地类表）与 `buildTerrainTypes` 里的阈值；
2. **颜色**：`map3d.TERRAIN_RGB`；
3. **语义**（能否立城 / 掉落 / 可做的行动）：`DATA.TERRAIN` / `WILD_MATERIAL` / `LING_ACT[*].spots`。
