## 二、技术实现（关键）

- **渲染**：`js/map3d.js` · Three.js（`vendor/three.min.js` 本地）
  - 地形：**cube-sphere**（6 面细分投影球面）+ 球面原生 3D 噪声（`sphElev`：大陆/山脉/细节/高频）→ 无接缝、无极性收敛。
  - 地块：**六边球**（icosphere 对偶 · 共边共享 → 严丝嵌合）· 固定 `TILE_SUB=6` → **40962 块**。
  - 相机：轨道（左键拖拽转向 · 滚轮缩放 · 点击拾取）。
- **行政**：球面 k-means 逐级嵌套（省→市在其省内分→区在其市内分）+ 连通修复 + 域扭曲平滑边界。1 旧都 / 12 省 / 48 市 / 144 区。
- **球系坐标**：`GAME.map.lonlatOf/coordText/dirOf`（单一出口）。**界面显示经纬，存档/逻辑仍 (x,y)**。
- **对接游戏**：地块属性索引（野地/据点/名城/行政城/己方城）→ 点击分发到 `openCityPanel/openAttackModal/openFortModal/openLandModal`。

## 三、经验教训（踩坑 · 下次别再犯）

1. **改 `js/*.js` 必须 bump `index.html` 的 `?v=` + BUILD** —— 否则浏览器用旧缓存脚本，改动"不生效"（本轮漏了两次，老板以为没做）。
2. **`GAME.map.heightAt` 必须定义在模块顶层** —— 放 `render` 局部作用域里，3D 渲图时 2D render 不跑 → 取高度拿 undefined → 全平。
3. **离屏图案填充**：`setTransform` 带世界原点平移时 `fillRect(0,0,F,F)` 会被推到画布外（"看着画了其实没画"）—— 要反算偏移。
4. **cube-sphere 各面三角形绕向不一致** → 光照半边黑半边亮；**显式设法线 = 向外的位置方向**。
5. **边界"锯齿/乱" 的根因**：给每个区用**不同噪声场**会逐格乱跳；正解 = **域扭曲**（一个平滑噪声扭曲位置后再就近）。
6. **边界"两套判定"必分叉**：渲染按全图就近重判 → 市会跨省。正解 = **层级成员数组**（市在省内分）+ 边界用成员数组（限父区）。
7. **无头的片"散块/飞地"**：k-means 有碎片 → 需**连通性修复**（孤岛并入相邻大区）。
8. **拿"子集"当"全域"**：球只放了**陆地的**行政区 → 海格归属 -1 → **边界/涂色要跳过 -1**（否则海上也画线）。
9. **地形类型 ≠ 球面地形**：弹窗回查 500×500 旧地图 → 与球面不符（海中央显示"山地"）；点击时要**带地块类型进弹窗**。
10. **柱子会"毛刺"**：voxel 柱立在地表 → 突兀；改**地块涂色**更稳。
11. **改断言不删**：规则变更（衰减地板 1→0、坐标文本改球系、据点减半…）→ 旧断言按新口径重写（本轮改了约 12 条）。
12. **pre-commit 钩子跑 gate 需 `PYTHONIOENCODING=utf-8`** —— 否则 gbk 控制台打印 emoji 崩、谎报提交失败。
