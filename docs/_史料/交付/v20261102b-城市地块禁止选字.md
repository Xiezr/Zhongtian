# 城市 / 城外 / 建筑地块：文字不可选

> 老板 2026-11-02：「城市和城外统计，建筑界面的地块，文字应为不可选，
> 就是不能左键长按拖动然后会选中文字或组件」

---

## 一、改了什么（只加了一段 CSS，零 JS 改动）

`index.html` 里 `.ui-page.city-pure { padding: 0; }` 之后新增一条分组规则：

```css
.city-pure,
.city-pure .city-iso,
.iso-tile,
.iso-tile .tile-face,
.bldg-foot,
.bldg-bottom,
.bldg-acts,
#city-attrs,
#res-bar,
#garrison-bar,
.side-block-garrison {
  -webkit-user-select: none;
  -moz-user-select: none;
  -ms-user-select: none;
  user-select: none;
}
```

### 为什么是这几个选择器

| 区域 | 选择器 | 说明 |
|---|---|---|
| 城内棋盘 | `.city-pure` / `.city-iso` | `cityHTML()` 返回 `.ui-page.city-pure` |
| 城外棋盘 | 同上 | **城外用的是同一个容器类**，一条规则覆盖两块 |
| 地块本体 | `.iso-tile` / `.tile-face` | 每格的文字与图标由 `isoCell()` 生成 |
| 建筑弹窗 | `.bldg-foot` / `.bldg-bottom` / `.bldg-acts` | 建筑详情的吸底操作区与底部按钮 |
| 左侧三块统计 | `#city-attrs` / `#res-bar` / `#garrison-bar` | 城市属性 / 资源 / 驻军；每秒重绘，选区会跟着闪 |

---

## 二、为什么**不**写成全局 `* { user-select: none }`

一行全局重置确实最省事，但会把**日志 / 战报 / 编号 / 坐标**一起锁死 ——
而那几样正是排查问题的命根子（复制一段战报出来对时间线是日常操作）。

所以规则只在上述"点了就是操作"的区块生效，其余照旧可选。
这条边界由门禁 §592⑤ 专门守着（见下）。

### 门禁（§592，5 条）

| 断言 | 守什么 |
|---|---|
| ① `.city-pure` | 城内 + 城外棋盘 |
| ② `.iso-tile` | 地块本体 |
| ③ `.bldg-bottom/.bldg-foot/.bldg-acts` | 建筑弹窗操作区 |
| ④ `#city-attrs / #res-bar / #garrison-bar` | 左侧三块统计 |
| ⑤ **反平凡解：不许有全局禁选** | 日志/战报必须仍能复制 |

**⑤ 做过破坏测试**：临时把 `* { … }` 加上 `user-select: none` →

```
❌ §592⑤ 反平凡解：没有全局禁选  [发现全局规则：*]
```

恢复后转绿。所以它不是装饰。

## 四、写断言时踩的一个坑

⑤ 第一版假红：报「发现全局规则：`/* =====`」。

原因：我用 `([^{}]+)\{([^{}]*)\}` 直接切 CSS 规则块，
而本项目的注释很长、**注释里还有 `{}` 的代码片段** ——
注释尾巴和下一条规则被拼成了一个假选择器。

修法：**先剥注释再切规则**；判全局改成"选择器列表逐个精确比对"而不是 `indexOf('*')`
（`*` 会在奇怪的地方出现）。

---

## 五、怎么撤销

删掉 `index.html` 里那段分组规则即可（无 JS 依赖、无构建产物影响）。

---

## 六、诚实缺口

- 只保证 `.city-*` / `.bldg-*` / 侧栏三块**之外的区域照旧可选**；
  但**没有**逐个检查其他弹窗（如集市、宝物、出征面板）是否也有"拖动选中"的困扰。
  如果老板发现别处也有，把类名告诉我，加进同一条规则即可 —— 门禁 ①~④ 的写法是现成的。
- 未验证 Firefox / Safari（本机只有 Chromium）。规则里带了 `-moz-` / `-ms-` 前缀兜底。
