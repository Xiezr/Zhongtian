# v158.58 · A/D 改飞行器方向，不再带动相机朝向

## 一、老板原话

> AD 不再改变相机朝向，而是改变飞行器方向

## 二、旧行为：为什么"方向改了，画面却像世界在转"

两个原因叠在一起：

1. **A/D 的语义是"横滚 + 一点协调转弯"**：`FLY_BANK_TURN = 0.75 rad/s`，转 90° 要 2 秒，横滚是主视觉、转向像附属品。
2. **相机朝向是从飞行器位置反算的**：`cam.position = shipPos − head × 26`。head 一转，相机立刻绕到新的机尾位置 → 视线跟着转 → 玩家看到的是"世界在转"。

顺带查出方向符号是反的：`_rollDir = a ? -1 : 1` 配 `applyAxisAngle(radial, …)`，按 A 实际是**右转**（Rodrigues：绕 +径向正角才向左）。

## 三、改法

| 项 | 旧 | 新 |
|---|---|---|
| A/D 语义 | 横滚 + 协调转弯 0.75 rad/s | **纯偏航改飞行器方向** `1.5 rad/s`（86°/s，转 90° 约 1 秒），**A 左 D 右** |
| 相机位置 | 沿 `−head`，立刻到机尾 | 沿 `fly.camTail`（滞后尾向） |
| 尾向更新 | 无（= −head） | 一阶跟随 `4.0 /s`（τ≈0.25s），恒投影在切平面 |
| 横滚 | 主视觉 | 降为**姿态**（左转左倾），不参与方向 |
| 鼠标指示 | A/D 时仍生效 | A/D 一按就清 `aim`（接管方向） |

### 一个必须踩过的坑

跟随必须是**一阶（时间常数）**，不能用"限速"。

首版写 `FLY_CAM_TURN = 2.2 rad/s` 限速，而偏航率只有 1.5 —— 相机永远追得上，实测滞后 **0.0°**，等于没做。改成 4.0/s 一阶后：急转稳态落后 ≈ 1.5/4.0 ≈ **21°**（看得见），松手 1.5s（6 个时间常数）收敛到 0.3% 以内。

## 四、"转向看得见"体现在哪

战舰**位置恒定居中**（机位吊在滞后尾向正后方，视线仍闭式反解到 screenY=0.66），转向体现在**机头相对相机视向偏出**：

| 状态 | 机头相对相机偏出 | 战舰屏幕水平位置 |
|---|---|---|
| 直飞 | 1.3° | ndcX −0.000 |
| 按住 A 0.45s | **17.4°** | ndcX 0.000 |
| 松手 1.6s | 1.3° | ndcX −0.000 |

截图 `v15858-B-turning.png` 里三角锥机头明显偏向一侧、横滚 47°。

## 六、断言处置

- §623① `FLY_BANK_TURN = 0.75` → `FLY_YAW_RATE / FLY_CAM_TURN` 在册 + **反向禁止 `FLY_BANK_TURN` 复活**。
