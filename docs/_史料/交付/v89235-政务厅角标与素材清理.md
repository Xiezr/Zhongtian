### ② 城外资源建筑等级 ≤ 政务厅等级（病根：域侧天然可超）

**改前实测**（探针）：政务厅 Lv2 时，净化厂 **成功升到 Lv3**（缺口实锤）。

**根因两处**：
1. `upgradeExt` 调 `buildCapOf(city)` **不传 bid** → 官府闸（`bid && …）`短路不触发 → 城外上限恒为"档位+加成"（12），与政务厅/科技/配对各闸全脱钩；
2. `buildCapCoreOf` / `buildPrereqOf` 的官府闸**只认 `DATA.BUILDINGS`**（v68 当年口径："城外建筑不受此闸"）。

**修复三处同尺**（内核 + 界面同一把尺，§v89.159 惯例）：

| 层 | 落点 | 改动 |
|---|---|---|
| 上限 | `buildCapCoreOf` | 官府闸两表并查：`DATA.BUILDINGS[bid] \|\| DATA.EXT_BUILDINGS[bid]` |
| 前置提示 | `buildPrereqOf` | 同上两表并查（拒绝时给「需政务厅 LvN」的 why） |
| 执行 | `upgradeExt` | ① 加 `buildPrereqOf` 检查；② `buildCapOf(city, e.type, e)` 传 bid（本座） |
| 界面 | `openExtModal` | 升级可用性 = `buildCapOf(c, e.type, e) && upPre.ok`；卡闸时按钮位显示 `ui.prereqText`（"**需政务厅 Lv2**"），不再误报"已达最高等级" |

**口径说明**：与城内同款三条保留——政务厅自身不受此闸 · "没有政务厅的城"不受此闸（govLv>0 才生效）· 建造成 Lv1 不受影响（1 ≤ 任何已有政务厅等级，语义自然成立）。
