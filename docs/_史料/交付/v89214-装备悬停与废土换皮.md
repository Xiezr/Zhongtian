## 一、装备悬停（需求 1）

### 1.1 病根

| # | 现状 | 问题 |
|---|---|---|
| ① | `eqLabel` = `名 + '+N' + '·甲/·乙'` | 名称行被序号污染（同名 2+ 件时每处都拖着 甲/乙/丙） |
| ② | 属性挤在一行：`统+94 勇+56 智+56 政+103 速+14 体+1080 攻+5198` | 玩家要在长串里找自己关心的那一项；强化增量与原始值**混在一起**，看不出哪部分是强化加的 |

### 1.2 设计（"更成熟的办法区分同名装备"）

> **同名件靠「强化等级 + 属性数值」两条天然差异区分**——这就是"更成熟的办法"：
> · 同级同名的两件在**数值上完全等价**（可互换），玩家不需要区分；
> · 需要精确定位的场合，序号以 **`同名第 N / M 件`** 出现在**详情面板**（不进名称行）；
> · 内部编号保留（件号 `u` + `eqSerialNo` 数字口径 / `eqSerial` 甲乙口径）。

| 层 | 改前 | 改后 |
|---|---|---|
| 显示名 `eqLabel` | `倚天长剑 +10·甲` | `倚天长剑 +10` |
| 内部编号 | `eqSerial`（甲乙丙…） | `eqSerial`（保留）+ **`eqSerialNo`（数字，详情用）** |
| 悬停属性 | 单行长串（`.tip-a`） | **逐行**（`.eqv-line`：属性名 / 现值 / 增量三段） |
| 颜色 | 全部同色 | 现值 **白**（`#ffffff`）· 百炼增量 **金**（`#f0c14b`）· 蕴养增量 **青**（`#7fd6e0`） |
| 来源说明 | 无 | 浮层底注：`+ 百炼 +10 级 · 每级 8%（新增值 = 原始值 × 80%）` |

行序（攻防置顶 → 六维连续成块 → 灵力）：`攻击 防御 统率 勇武 智谋 内政 速度 体力 灵力`。

### 1.3 唯一出口（数值与配色都只此一份）

```
GAME.EQUIP_STAT_DEFS      属性定义表（键 / 全名 / 短名 · 行序）
GAME.equipStatRowsOf(x)   ★ 唯一数据出口：[{ k, label, short, base, val, add, src }]
      base = 表值 · val = 现值（含强化/蕴养）· add = val − base · src = 'enh'(百炼) | 'ling'(蕴养) | ''
GAME.equipDescOf(x)       一行文本（由 rows 派生 —— 旧调用方零改动）
ui.equipStatsHTML(x)      分行浮层 HTML（bag 格 / 将领槽位 / 详情面板三处共用）
ui.equipEnhNoteHTML(x)    来源底注
```
乘数仍读既有唯一出口 `eqEnhMulOf` / `eqLingMulOf`（v89.211 立）——**改乘链只改那两个函数**。

### 2.3 三条设计决策（都写进映射表，便于回看）

1. **地名不动**（洛阳 / 许昌 / 赤壁…）：废土题材的标准处理 —— 幸存者沿用**旧世界地名**，
   与"大崩坏后重建"的设定自洽；地图形制（中国地理轮廓）属**视觉层**，随视觉批次统一处理。
2. **资质五档不动**（凡品 / 良材 / 英杰 / 名世 / 天授）：题材中性，且与**装备品质词**
   （凡品/良品/珍品/神品）同名撞车 —— 盲改会连带打穿装备品质链。
3. **数字口径零变化**：本轮只碰显示名与文案；**id / 数值 / 出口 / 存档结构一字未动**（老档免迁移）。
