# v157.63 · 2D 地图视野边界去杂色（要边界感，不要视野内增加渲染）

## 老板原话（截图反馈）
> 有视野的范围渲染出杂色了，要的是边界感，而不是在视野内增加渲染。

截图特征：蓝（水）绿（陆）交界处是一条**抖动/柔化过渡带**——蓝纹理在交界半透，底下透出土壤/邻格色，读成"蓝绿噪点互渗"的杂色；地形本身没有干净边界线。

## 根因
`js/map.js` 2D 地图地形纹理层，不同地形交界用 `rectMask` 做 **`fade = cell/3`（约 1/3 边长）的羽化遮罩**：
- `rectMask`（map.js:1345）把这个羽化实现成半透明渐变 alpha；
- 调用点 map.js:1795（世界采样模式下，不同地形邻格的边按 `cell/3` 带宽羽化）；
- 同时 map.js:1839 在世界采样模式**刻意关掉了 `edgeOf` 边界描边**（旧注 v90.5 怕"X 格纹"）。

于是交界处：没有干净边界线 + 有一圈柔化噪声 = 老板看到的"杂色 / 没有边界感"。

## 改法（v157.63，map.js）
1. **`rectMask` 羽化带宽收窄**：`fade = cell/3` → `Math.round(cell / 14)`（约 2px 干净切边）。
   - 同地形边仍 opaque（无缝连片不变）；
   - 不同地形之间从"柔化噪声填充"变"清晰边界"。
2. **世界采样模式重新启用 `edgeOf` 边界描边**（map.js:1838 区）：
   - `edgeOf` 只在**地形类型不同处**才画（北/西高光 + 南 AO 均按邻格地形差判定），不会每格画线 → 不会重现整片 X 格纹；
   - 给地形交界一道干净边界线，与上面收掉的羽化噪声配套：交界从"柔化杂色"变"清晰边界"。
