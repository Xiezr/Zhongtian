# v157.76 · 视野范围只做标识，不改地形颜色

**老板原话（2026-11-16 11:01）**

> 有视野的范围还是保留那个高亮吧。因为我看这个视野范围这个亮度调整，呃，我建议只做这个标识性的调整。不要影响到原来的渲染颜色。

一句话拆成两条硬要求：
1. **视野范围要有标识**（保留"看得见哪"这件事）；
2. **标识不许动地形颜色**（不要压暗、不要提亮）。

---

## 一、取证：为什么"亮度调整"会改地形色

| # | 事实 | 证据 |
|---|---|---|
| ① | 未探明区的"暗"是**顶点色乘系数**，不是遮罩 | `paintGlobeFog()`：`kCur = (vv >= 1) ? 1 : 0.34`，逐顶点 `arr[o] = base[o] * kCur`（99,846 顶点） |
| ② | 因此「未探明」看到的是**被压暗过的地形色**，不是原色 | 同一份地形在圈内圈外差 3 倍亮度 —— 正是老板说的"影响了原来的渲染颜色" |
| ③ | 地形色与视野在数据层完全无关 | 地形色来自 `DATA.TERRAIN` → `map3d` 派生 `TERRAIN_RGB`（v157.71 收口）；探明度来自 `GAME.fog.get(ci)`（0/1/2） |
| ④ | **地块线框整层是隐形的** | `M.TILE_LINES = false`（老板 v157.56「线条太杂，不要边线」）→ `_shellMat.opacity = 0`。把边界色染在线框上 = 画在隐形图层（本轮第一版就踩了这个坑：实机图一片干净，什么也没有） |
| ⑤ | 线宽改不了 | WebGL `linewidth` 在绝大多数平台被忽略（永远 1px）。1px 亮线在 900 米高处只剩亚像素，还被地形深度切成零星几点（`.workbuddy/tmp/v15776-red-600.png` 为证） |

**结论**：老板要的"只做标识"，在 3D 里唯一可行的落法是 **画一圈几何**，
而不是继续在**颜色**上做文章。

## 二、改法

### 2.1 退役顶点色压暗（`js/map3d.js`）

| 项 | 处置 |
|---|---|
| `paintGlobeFog()`（约 70 行，包含贪心邻接查找 + 两态系数） | **整条删除**，留墓碑（来历 / 老板原话 / 要恢复怎么恢复） |
| `M._globeColBase`（99,846×3 的原始色副本，供乘回原色） | 随之删除 —— 顶点色不再被改写，副本没有消费者（省 ~1.2MB） |
| `buildFog()` | 只调 `paintLineFog()` + `buildFogBoundary()`；注释写明"顶点色不再参与迷雾" |
| 结果 | **globe 顶点色自 `buildGlobe` 之后不再被任何代码改写**，已探明 / 未探明看到的是同一份原色 |

### 2.2 新增探明边界带（独立图层）

`buildFogBoundary()`：

- **只统计「一侧已探明 / 一侧未探明」的边**（`ensureEdgeOther()` 预计算"每段边的另一侧格"，`Int32Array`，由 `paintRegionEdges` 同一趟循环顺手填，零额外开销）。
- 每段边生成 **4 顶点 / 2 三角形**的细带（三角带，不是线）：
  - 径向 `n` = 边中点方向；方向 `d = B−A`；侧向 `s = n × d` 归一化 × 半宽 `HW = 1.7`
  - 沿径向抬 `LIFT = 4.0` —— 地形顶点起伏最大 40，只抬 0.05 会被地形吃掉大半
  - `polygonOffset` 对 `GL_LINES` **无效**（只作用于三角面），这也是必须用带不用线的原因之一
- 颜色 `#35ffe8` 亮青：地形主色是绿 / 黄 / 蓝 / 灰岩 / 雪白，纯白在荒漠与雪地上几乎看不见（实测）。
- 独立于 `TILE_LINES`：**只画边界这一圈**（新局百来段、铺开后几千段），
  不重开 24.5 万段全网格 —— 那正是老板嫌的"杂"。
- 地表模式（`M._surf`）隐藏：站在地上时它是"地图语言"，同 v157 让城色块 / 插旗退场的理由。
- 缓冲与索引按需增长复用，避免每次迷雾推进都新建 GPU buffer；显式设 `boundingSphere`
  （预留缓冲未用部分是 0，不设会让 three 报 NaN 刷控制台）。

### 2.3 明确没动

- `DATA.TERRAIN` 七色（v157.75 的降饱和成果）、`map3d` 的顶点色派生、`map.js` 的 `TERRAIN_TINT`
- `paintLineFog()` 的已探明冷蓝 / 未探明隐形（tiles 关着，但 `TILE_LINES` 打开时仍有效）
- v157.68「视野内部零额外渲染」、v157.63「要边界感不要在视野内增加渲染」
- 大气云壳 `M._sky`、区划边界（省市区）图层

## 四、代价（写明白，不是遗漏）

**未探明区现在也看得到真实地形色**（只是没有边界带、没有地块线）。
以前"暗一片"的未知感没有了 —— 这是「不许动地形颜色」的必然结果，不是实现退化。
老板若之后想要"未知感"，正确做法是**加遮罩层**（面）而不是**压暗色**（色），
两者是不同口径，需单独拍板。
