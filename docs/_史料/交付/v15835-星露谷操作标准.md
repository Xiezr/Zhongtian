# v158.35 · 「操作上达到星露谷的标准了吗」——没达到，差在范式

## 一句话结论

**改前没达到，而且是操作范式级别的差，不是手感微调能救的。**
改前是坦克式（W/S 前后油门、A/D 原地转向），实测**单按 D 一秒：位移 0 米、人原地转 172°**。
本轮按星露谷口径重写输入层，五项硬指标全部达标（探针 `p_stardew_ops.js` **9/0**）。

|---|---|---|---|

## 改了什么（都在 `js/map3d.js`）

1. **输入层**：`_mx/_my` 取 WASD → 合成方向 → **除以模长** → 位移沿输入方向。
   朝向还在插值时人也已经往对的方向走 —— 这是"跟手"的来源。
2. **朝向自动对齐**：`atan2(dot(wd,east), -dot(wd,south))` + 指数插值
   `M.YAW_TAU = 0.06`（≈3.6 帧）。坦克式的 `_yawSpd` 整段退役。
3. **移动基准 = 屏幕前方**：`_surfAvatarCam` 每帧写 `M._surfFwdW = -水平(dirCam)`。
   相机绕到哪，W 的世界方向就跟着转 —— 这才是"按 W 往画面上方走"。
4. **八方向同速**：`M.BACK_RATE`（后退 62%）退役。
5. **加减速调快一倍**：`WALK_ACCEL 18→34`（0.13 秒到全速）、`WALK_BRAKE 26→44`（0.10 秒停）。
   0.25 秒到全速在手感上就是"按下去等一下才动"。

## 顺带修掉一个时间炸弹

`① 端到端：小股部队只搬得走载重内的部分` 本轮假红：
`no-mid-wild;r1-no-haul:掠夺失败：平原 Lv8`。

根因：`GAME.map.wildLevel()` 里 `day = Math.floor(Date.now()/86400000)` 参与日盐 ——
**换一天跑，同一格的野地等级就变**。扫不到 Lv1~2 就兜底 Lv6，打输。

修法：给靶位写一条 `level:1` 的己方野地记录（`wildLevelNow` 优先读记录值），
"能赢"这个前提就确定了。**判据一个字没改**，`st94.wilds` 在 finally 里还原。
