# v158.61 · 更精细的地面贴图（消除"走在空中"）

> 老板原话：「生成更精细的地面贴图，现在感觉走在空中」

## 一、取证：脚下为什么像"空的"

| 项 | 旧值 | 判读 |
|---|---|---|
| 地块平台 `surfPlate` 的 uv | **没有 uv 属性** | 材质无法挂纹理 → 近景纯色平涂 |
| 地形层 `surfTerrain` 纹理 | 512² + repeat 28（92m 方阵）= **3.3 米一格** | 近看只剩糊块 |
| 阴影系统 | `renderer.shadowMap=false`、castShadow / receiveShadow **各 0 个** | 人物没有落地投影 → 悬空 |

### 顺带查出的真 bug（"走在空中"的主因）

`_tickFlight` 的"走路态"早退条件只有 `M._surf || M.FOLLOW`：

```
下机 flyExit → phase='dock'、active=false、surfaceMode(true)
下一帧 _tickFlight 先跑 → 不满足早退 → 又把 active 置回 true
→ placeCamera 里 _onShip 恒真 → _surfNow 恒 false → 地表层永远建不起来
```

玩家因此一直站在**球面图集**上（纯色地块）。修法：早退条件补 `fly.phase === 'dock'`。

## 二、改法

1. **`makeGroundTex()`**：1024²，四层互质格噪声（4/9/23/48）+ 域扭曲 + u 方向 1.9 倍各向异性拉伸（草/土丝状感）+ 单像素细粒；输出 0.50~1.0 灰度**乘子**（不改地形配色）；`anisotropy` 在渲染器就绪后补到硬件上限。
2. **平台补世界尺度 uv**：每个顶点（含侧壁）用锚点切基把球面方向投成弧长（米），再除以 `GROUND_TEX_CELL`（3.2m）—— 跨格连续、与地形层同一把尺，接缝为零。
3. **材质挂 map**：平台与地形都用同一张图（地形 repeat 按米：92/3.2 = 28.75）。
4. **接触阴影**：场景级单例 + **billboard 面向相机 + 纵向压扁 0.45**。贴地圆盘在 3.4° 仰角下会压成一条线（实测 opacity 0.75 仍看不见），billboard 才能在任何角度都给出"接地团块"。

## 三、踩过的坑

| 坑 | 现象 | 正解 |
|---|---|---|
| 贴地圆盘 + `depthTest:false` | 地形台面 polygonOffset(-2/-4) 把圆盘整片吃掉 | billboard + 反向 polygonOffset，保留深度测试 |
| 阴影挂在地表层 root | `destroySurf` dispose 材质 → 双实例，赋值 0.6 却读到 0.85 | 挂场景级、只建一次 |
| 对比太弱（0.70+n·0.30） | 三层平均把方差压到 ±0.18，只有 5% 明暗差 | 拉对比 `(n-0.5)·1.85+0.5` + 0.50~1.0 |

## 五、诚实缺口

- 阴影是**假接触阴影**（billboard 团块），不是真光照投影：没有方向性、不随地形起伏变形。真投影要开 `shadowMap` + 全场景 castShadow（几十万顶点每帧一次阴影 pass），本轮不做。
- 纹理是**灰度乘子**，只改明暗不改色相 —— 近看是"同一片地的草/土颗粒"，不是"草地/裸土/碎石分区"。分区需要多张 biome 图 + 片元混合，属下一步。
- headless 环境 `getMaxAnisotropy()` 返回 1（SwiftShader），斜视略糊；真机 GPU 会补到 8。
- 地形层与平台的分界（43m 环）在特定角度仍能看到纹理密度差，未做接缝混合。
