## 2. 顺手抓到的真 bug：城墙时间"哨兵 0"被外推污染

出时间表时发现：**城墙 `levelCost` 的时间列全是 0** —— 这是**哨兵**（"本表不指定"，由城墙升级出口兜底 `cost.time || 60`）。

但 `extRows` 的数据外推（把所有等级表一次性外推到 45 级）把 0 变成了数字：

```
旧外推 time 列（第 11/12/13 项）: 1 2 4      ← max(1, 0×1.85) = 1，越滚越大
新数据（修复后）              : 0 0 0 …    ← 0 保持 0
```

- **症状**：城墙 Lv10 之后的"标称时间"变成 1~2 游戏秒（应为 60）—— 表与调试读数全错。
- **诚实影响说明**：因"最短 5 现实秒"地板（`buildMinTime = 5×倍率` = 600 游戏秒 @120×），
  **修复前/后的入队时间相同（都是 600）** —— 玩家侧无感。修复的是**标称值与时间表读数**；
  且地板一旦调整，假时间立刻暴露。
- **修复**：`extRows` 外推段"**0 保持 0**"（一行判定 + 注释说明哨兵语义）。
- **守卫**：smoke §104① 逐级扫到 45（任何一级变正数即红）。
