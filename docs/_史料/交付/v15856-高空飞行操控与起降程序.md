# v158.56 · 高空飞行：滚轮禁高度 / 相机与机体分离 / 战舰落屏下 2/5 / 鼠标指示航向 / 上下加减速 / 起降程序

## 一、老板原话

> 在高空，不再由滚轮调整高度，飞行器和相机分离。相机总是在飞行器的尾端或者人物的背部。飞行器应该在屏幕的下 2/5 我要在正中间。鼠标指示飞行的方向。Ws 和上下为加减速。设置飞行器的起飞降落程序

## 二、六条怎么落地

| # | 诉求 | 实现 |
|---|---|---|
| ① | 滚轮不再调高度 | wheel 回调飞行态直接 `return`；`_tickFlight` 删掉消费 `_zoomTarget` 的整段 |

## 三、关键推导（不是试参数）

### 战舰为什么能精确落在 0.66

设相机已定在尾端，`Δ = shipPos − camPos`（相机→战舰）。把视线方向从 `Δ̂` 绕 `right = cross(Δ, camUp)` 抬高 θ：

- 屏幕上物体的纵向归一化位置 `ny = tanθ / tan(fov/2)`；
- 反解 `θ = atan(ny · tan(fov/2))`，`ny = (0.66−0.5)×2 = 0.32`；
- `fov=55°` → `θ ≈ 11.75°`；
- 因为 `right ⊥ Δ`，`Δ` 在 `right` 上分量恒 0 → **水平自动居中**，不需要另调。

探针实测：`screenY = 0.660`、`ndcX = 0.000`。

### 为什么滚轮要彻底断

旧实现里滚轮写 `_zoomTarget`、`_tickFlight` 再消费它改半径 —— 等于高度有两个入口（滚轮 + 飞行方向）。老板要"高度只由飞行决定"，所以入口必须唯一：滚轮 return，tick 不再读 `_zoomTarget`。

### 为什么起飞能被打断（首轮真 bug）

地表模式由 `placeCamera` 按半径派生（<55m 进、<62m 出）。起飞点离地只有 8.5m，**程序第一帧就被判回地表**，战舰收起、`phase` 直接 `dock`、`Δalt=0`（探针⑥首轮实测）。

修法：`placeCamera` 里加 `_progFlight` 豁免，起飞/降落期间禁用自动地表切换，落地那一刻由 `_tickProgram` 显式 `surfaceMode(true)` 交班 —— 进出地表只剩程序一个出口。

## 六、诚实缺口

1. **巡航看不到星球**：机头水平前飞 + 视线为把战舰压到下方 2/5 抬高约 11.8°，球在视野下缘之外（170m 高度时）。方位靠 HUD 罗盘。若要在画面里看到球，需要压低 `FLY_SCREEN_Y` 或让相机额外俯视 —— 会与"战舰在下 2/5"冲突，需老板定。
2. **起飞瞬间的近景地块**：起飞点离地 8.5m，相机在近地高度会看到放大的地块六边形（图 B 左侧）。属地表层近距离观感，本轮未动。
3. **起飞阶段横滚读数 ~56°**：`up` 必须 ⊥ `head`，而 `head` 与径向成 35°，正交化后必然偏离径向 —— 数学结果，不是姿态错误（视觉上战舰正立）。
