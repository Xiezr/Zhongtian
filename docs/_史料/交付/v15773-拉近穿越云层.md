# v157.73 · 拉近距离时穿越云层的感觉

## 一、需求（老板逐字）

> 「如何做到拉近距离时穿越云层的感觉」

## 二、诊断：为什么原来完全没有穿越感

不是「云不够白」，是三个硬原因：

| # | 问题 | 证据 |
|---|---|---|
| ① | **云在穿越前就被淡光了** | 旧公式 `uFade = (camO.dist − R*1.15) / (R*0.55)`：离地 45 米开始淡，而云壳在 `R + ATM_H(55)` —— 相机还没碰到云，云先没了 |
| ② | **球壳穿过时必然透明** | `edge = smoothstep(0, 0.45, rim)` 是 v156.34 为修「自转时大气边界闪烁」定下的「轮廓处淡出」；相机贴在壳面上时看哪儿都是边缘 → alpha 归零 |
| ③ | **只有一层壳、没有厚度**，也没有任何「在云里」的遮挡 | 穿过去只是画面少一层半透明，不会有「糊一下」 |

## 三、关键取舍：这条路不能走 3D

第一版按常规思路做了「云壳加浓 + `scene.background` 压白」，实机 `agl=55` 的截图是**一片放大的土黄地表纹理，一点云都没有**。原因：

**轨道相机始终朝球心俯视，3D 几何铺满整屏** —— `scene.background` 一个像素都露不出来；球壳又正好在相机所在高度（②），也看不见。

所以「糊一屏」只能走 **2D 合成层**（`target2d`）。它不受视角影响，成本只是几次 Canvas 填充，而且天然盖住地图元素 —— 穿云时本来就该看不见地图。

（第一版的 `scene.background.lerp(云白)` 已删除，只留注释记录「实测无效」，避免后人再走一遍。）

## 四、实现

### 4.1 把「淡出」和「在云里」拆成两件正交的事

```js
var _hC = atmH();                 // 云层高度（默认 55）
var _agl = camO.dist - R;         // 离地高度（球心口径，与滚轮缩放同一把尺）
// ① uFade：只管「别糊地面」—— 离地 ≥30m 全显示，30→5m 收到 0
var _fade = clamp01((_agl - _hC * 0.09) / (_hC * 0.46));
// ② uIn：只管「在云里」—— 以 |agl − hC| / (0.35×hC) 的钟形，跨层 ±19m 内 1→0
var _k = (_agl - _hC) / _hC;
var _in = Math.max(0, 1 - Math.abs(_k) / 0.35);
```

两者正交：400m 看全貌（fade 1 / in 0）、55m 穿层（fade 1 / in 1）、贴地 2m（fade 0 / in 0）。

### 4.2 2D 云雾（穿越感的主体）

- 固定种子生成 512² 云纹：**26 团**柔和冷白斑（`rgba(238,243,250)`），
  3×3 复制保证平铺无缝。
- 每帧两次 `fillRect` 平铺：**原尺寸慢漂移 + 0.62 倍反向漂移** ——
  单层在 1280 宽上会露出重复节奏，叠一层不同尺度就看不出来。
- 总透明度 `min(0.80, _in * 0.82)`，只在 `_in > 0.012` 时画（约 1 秒的穿层窗口）。

### 4.3 云壳与云片

- 云壳新增 `uIn` uniform：`alpha *= (1 + uIn * 1.35)`（clamp 1.0）——
  让「云墙扑过来」更实；穿层那刻壳本身仍透明（②），所以它不是主力。
- 新增 44 片 `Sprite` 云片，铺在 `R + ATM_H ± 0.6×ATM_H`，黄金角均匀撒点、5 档高度错开、
  压扁成层状；不透明度 `_fade × _in × 0.62`，**总览时完全收掉**
  （否则会在球面上糊一层薄雾，把 v157.71 刚修好的地形色又压灰）。

## 六、诚实缺口

1. **没有真正的体积云**。这是「屏幕空间云雾 + 一层壳」，不是 raymarch 体积渲染；
   侧视斜穿时能看到云片是平的。要真体积，得引入后处理管线（项目只有 `three.min.js`，无 addon），
   成本与风险都不成比例。
2. **贴地（<25m）没有云**：云在头顶 50 米，俯视看不到；前传贴地平视时理论上应能看到地平线上的云带，
   本轮未做（`uFade` 在 30m 以下收到 0 是刻意省性能）。
3. **穿层窗口约 34 米高**（agl 55±19），滚轮常规速度下约 4~7 格，能看清但不拖沓；
   若觉得太快/太慢，调 `_in` 的 `0.35` 分母即可（越大窗口越宽）。
4. 云雾是纯 2D 叠加，**会盖住地图标签与图标**——这是刻意的（云里本来就看不见），
   但穿层瞬间若正在点地块，点击仍会落到地图上（只影响观感，不影响操作）。
