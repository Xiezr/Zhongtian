## 二、执行方向（开工前锁定）

- **几何只算一次**：`scene3d._npcPlan(plan, seed, opts)` 只新增可选 `count` 覆盖人数，默认 4~10 与 §354 老断言逐字不动；
  P4 传 `count=12`，复用同一套 free 格筛选、三航点、同一颗 rng —— 不造第二套路网。
- **位置不入档**：NPC 身份/锚点由 `plan + ci + seed` 派生，运行位置只活在职 `N.list`；不写 `GAME.state`，
  `SAVE_VERSION=3` 不变；不为了路人调 `makeGeneral` 污染 `state.generals`。
- **不碰前四阶段的位置与相机**：不写 `_avatar`、不写 `camO`、不写 `D.pos`、不占第四套玩家按键；
  网格挂 P2 同一个 root、材质并入 `D._mats` 渐显，退出由 `D.exit → N.reset` 清干净。
- **判定出口唯一**：伤害/血量/胜负只由 `GAME.duel.play()` 复算，NPC 侧不写任何公式。

1. **航点有放回抽样 → 四段锚点平凡解**：首轮实测最小锚点间距 **0.075m**（`_npcPlan` 三个航点抽到同一格），

2. **smoke DOM 桩缺 `removeAttribute`**：`N.spawn → N.reset → renderNpcHint(null)` 在桩环境抛错，
   `§589ao` 假红。按「观测层不许炸玩法」给 `renderNpcHint` 加判空调用；不改测试桩、不改判据。
3. **smoke 作用域**：P0~P3 的 `mpC158/mnC158/dC1582/vC1583` 都关在上一组 IIFE 里，新断言组必须重新读源码，
   直接借名会 `ReferenceError`。
4. **探针敌对摆放**：敌对最初放在侧面（90°）被 60° 前向锥正确拒绝，测试假红；改为挪到正前方，不是放宽锥角。
