## 二、落点（骨架，不是补丁）

| 层 | 出口 | 语义 |
|---|---|---|
| 状态机 | `GAME.district.enter/exit/tick` | `active` 只有两处写（进入 true / 退出 false）；运行时态，不入档 |
| 位姿 | `M.playerPose()` 快照 → `M.setPlayerPose(snap)` 还原 | `district.js` **不直接写 `state._avatar`** |
| 标架 | `D.frameOf(ci)` → `M.avatarBasis(ci.dir)` | 逐位一致（实测 up/east/south 差 0）；跨极点不反向 |
| 布局 | `D.planOf(city)` → `S.cityPlan(city)` | 建筑、巷道、碰撞盒同一本账，不另算 |
| 渲染 | `districtRoot` 挂 `map3d._scene()` | 同一个 scene，不新建 Scene；每帧按 `D.t` 渐显/渐隐 |
| 相机 | `GAME.district.camera()` | 在 `placeCamera()`+P0 跟随之后覆盖，**只写 `cam`**，不碰 `camO` |
| 输入 | `data-action="district-enter/exit"` + `KeyQ` | 街区 W/A/S/D 走 `D.keys`，P0 走 `GAME._keys`，两级不串线 |
| 回退 | `M.DISTRICT=false` | 街区不建、相机不覆盖、位姿不动；旧 3D 入口照常 |

**SAVE_VERSION 保持 3**：街区位置是派生/运行时态，不入档；未改用户数据格式。

## 三、踩过的坑

1. **`G` 别名不存在**：`main.js` 里其他模块习惯写 `var G = GAME`，但本文件没有；
   Q 分支写成 `G.district` 直接 `ReferenceError`，表现为"按 Q 没反应 + 页面异常"。
   探针 G3 抓到 `G is not defined`，改为 `GAME.district` 后 21/21。教训：
   **跨模块复制代码前先确认该文件的局部别名**。
2. **两级按键状态必须隔离**：街区态若继续写 `GAME._keys`，P0 的 `stepAvatar` 会同时推球面位姿，
   退出后"位置不变"守不住。WASD 在街区态改走 `D.keys`，keyup/blur 各自清各自。
3. **提示条不能复用**：P1 的 `#interact-hint` 是 `pointer-events:none` 且按 sig 重写
   `innerHTML`，按钮会被吃掉；街区另建 `#district-hud`，但仍挂 `ui.layerRoot()` 唯一挂载点。
4. **断言要跟实现一起改**：把 `G` 改成 `GAME` 后，§589aj 仍按旧字符串找锚点，假红一条。
