## 二、执行方向（开工前确认并验证成立）

- **载具跑在街区层，不是球面格**：建筑只在 P2 街区里；`nearestInteractable` 用球面格锚，
  载具用街区局部米坐标，是两套坐标，另起 `V.nearestMount()` 而不改 P1 分类。
- **位置锚复用而非自建**：`V.step` 写 `D.pos/D.yaw`，`D.camera` 同帧读到 → 相机自动跟随，
  不改 `placeCamera` / `camO` / `M._avatar`；退出仍走 `D.snapshot → setPlayerPose` 唯一出口。
- **按键三级隔离**：`GAME._keys`（P0 球面）/ `D.keys`（P2 街区）/ `V.keys`（P3 载具）；
  载具态写第三套，避免同时推动球面位姿导致「退出位置不变」失守。
- **碰撞同源**：`plan.solids` 只读，碰撞盒与 scene3d 同一本账；用载具半径 0.65（人物 0.3）。
