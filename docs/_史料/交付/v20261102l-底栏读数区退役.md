# 地图底栏：读数区也删了（点选 — / 中心坐标）

> 老板 2026-11-02：「去掉地图上这些无用：点选 — / 球系坐标 / 经度 / °E / 纬度 / °N / 前往」

---

## 一、先分清两轮

| 轮次 | 删的 | 结果 |
|---|---|---|
| v156.35 | 球系坐标标签 + 经度框 + °E + 纬度框 + °N + 前往按钮（**输入组**） | 底栏 579 → 428px 之前先降到 579 |
| **v156.37（本轮）** | `点选 —` + `中心 244°E 17°N`（**读数区**） | 底栏 579 → **428px** |

老板这次把「点选 —」加进列表，说明要的是**连读数一起不要**。
上一轮只删了输入，读数还在（`中心 244°E 17°N` 里就有 `°E` / `°N`）。

## 二、这轮删了什么

### 界面

```diff
- <span class="map-info" id="map-info">中心 244°E 17°N</span>
- <span class="map-info mk-pick" id="map-pick-info">点选 —</span>
  <span class="mk-sep"></span>
  [回主城] [回本城] [🌌 星系] [🚩 前哨] [🧱 建造] [灰烬城]
```

### 代码（连带，不留"点不到"的出口）

| 出口 | 原来干什么 | 现在 |
|---|---|---|
| `ui.mapInfoText` | 视野中心格 → `中心 244°E 17°N` | 删 |
| `ui.mapPickText` | 点选格 → `点选 我城 …`（还带"荒野事 ×N"后缀） | 删 |
| `ui.syncMapInfo` | 平移/跳转/点选后刷这两行 | 删 |
| `ui.mapPick` | 存最后一次点选结果（唯一读者是 mapPickText） | 删 |
| canvas click 里的三行 | `mapPick = r; syncMapInfo()` | 删（点选本身仍有效，只是不再写底栏） |

## 四、测试口径（smoke 6 处 + e2e 5 处）

| 位置 | 原判据 | 改成 |
|---|---|---|
| smoke §v90.67 | `mapInfoText().indexOf('中心 ') === 0` | 四个出口全 `undefined` |
| smoke ×2 | 用 `ui.mapPick` 造点选态验"荒野事 ×N" | 被测对象没了 → 整条删 |
| smoke ×2 | 查 `mapPickText` 里的 `jianghuWildMounted` guard / 接线 | 去掉那一句判据 |
| e2e ×2 | `#map-info` 存在 / 内容等于 `mapInfoText()` | 反转成"节点不存在" |
| e2e ×2 | 点选后 `#map-pick-info` 含"灵机" | 整条删（行为不存在） |

**踩了一个坑**：第一次跑 gate，e2e 只到 579 条就中断 ——
还有一处 `document.querySelector('#map-info').textContent` 漏改（第 3611 行），`null.textContent` 直接抛。
**grep 只搜了 `mapInfoText`/`mapPickText` 这类函数名，没搜 DOM id。**

> 教训：删一个 UI 元素要搜**两类**引用 —— 生成它的函数名，和它的 `#id` / `.class`。
> 只搜一类，另一类会在跑完 8 分钟后才告诉你。

## 五、顺带发现（未处理，记下来）

e2e 里这条：

```js
check('点击地图格子有响应', true, document.querySelector('#modal-root').innerHTML.length > 0 ? '弹出面板' : '选中格子');
```

**cond 写死成 `true`** —— 永远不会红，永远在"通过"。
也就是说"点地图会弹面板"这件事**从来没有真断言**。属于"恒真断言"，audit 只查了"check 第二参传函数引用"这一种形态，没覆盖"字面量 true"。

本轮不扩大范围，只记录。要修的话应该改成读 `GAME.map.pick()` 的返回值 + `#modal-root` 是否真有内容。
