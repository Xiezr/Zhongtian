# v157.64 插件箱（可插拔数值插件 · 无限人口）

**日期**：2026-11-15
**需求原话**：「给一个可插拔的插件，不影响原代码，实现功能是无限人口。创建一个插件箱，用于存放这种数值调整的插件，放到菜单上『自动』菜单的左边」

## 需求拆解

| 要素 | 落地 |
|---|---|
| 可插拔、不影响原代码 | 插件箱本体 `js/plugins.js` **全部运行时接入**，零改动任何既有 js 源码 |
| 无限人口 | 内置插件 `infinite-pop`：运行时替换 `GAME.maxPopOf`，关闭即恢复 |
| 插件箱（数值调整容器） | `GAME.plugins` 注册表 + 插件箱整页视图（列表/开关/警示） |
| 菜单位置 | 顶栏「自动」左边，`data-view="plugins"`，图标为手绘插头 |

## 架构（三条铁律）

1. **不改任何既有 js 源码**。接入全走运行时：
   - **视图**：包装 `GAME.ui.renderView` —— `'plugins'` 视图由本文件渲染，
     其余视图原样放行（`return _origRenderView(v)`；syncTheme/底栏/syncPhase/_tip 汇合点照常跑）；
   - **图标**：往 `GAME.icons.navSet` 补 `'plugin'` 键（页签里是既有占位 `<i data-nav>` 机制）；
   - **动作**：`GAME.reg.add` 注册 `plugin-toggle`（main.js:2110 的注册表兜底分发**早已存在**，零改动）。
2. **数值插件 = 运行时换函数**：`_on` 保存原函数再替换，`_off` 原样恢复。
   删除 `js/plugins.js` + 摘掉 index.html 页签 = 完全回到原样（可插拔的字面义）。
3. **开关状态存 localStorage**（key `dsdb.plugins.v1`，不写入存档）：
   玩家本机的玩法层调整，不污染游戏数据、不随存档传染到别的浏览器。

## 无限人口的技术依据

`domain.js` 的幸存者上限**唯一基准**是 `GAME.maxPopOf`（居所+专精+孢囊，v89.185「唯一出口」架构），
`effPopCapOf`（民心折算）/ `popGrowthOf`（增速基数）/ 迁入封顶全部从它派生 ——
换掉这一个函数，整条消费链同步生效，正是唯一出口架构给运行时插件留的缝。

- 开启：上限视为 **999,999**（居所与民心不再约束人口；增速随上限放大，按固定补满时长爬升约 2 小时到顶）；
- 关闭：恢复原函数；已涨上去的人口**不回收**（与 v89.185「只封增长、不削存量」同规）。

## 加新插件的方式

`js/plugins.js` 底部一段 `PLUG.register({ id, name, desc, _on, _off })` 即可 ——
插件箱 UI、localStorage 持久化、`plugin-toggle` 动作分发自动跟上，不需要再动任何别的文件。

## 守卫（smoke §586f，6 条）

1. 登记面：顶栏有「插件」页签且在「自动」左边；
2. 登记面：plugins 模块进 uiSplit（bundle-ui · 排 main 之前）；

6. 视图面：`renderView('plugins')` 渲染插件箱（含开关按钮与 infinite-pop 条目）。

## 踩坑记录

- 桩环境（无 `document`）下包装函数首版直接 `document.querySelector` 会炸 —— 修复为
  `typeof document !== 'undefined'` 守卫（node 桩测试抓出，浏览器/smoke 桩本来有 document）。
- gen_index --check 会抓源码变更后的 hash 漂移：改完 plugins.js 必须**最后**重跑一次生成器再提交。
