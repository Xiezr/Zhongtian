# v157.55 · 戴森球残片奇观窗口震颤修复（overflow:hidden 裁溢出，视窗尺寸恒定）

> 老板：「戴森球残片超出窗口之外 → 窗口界面大小调整 → 造成震颤。人的视窗大小不应该随意变动，
> 内容可以在虚拟空间里超出。」
>
> 界面指认：网页界面（星球 3D 大地图），奇观转动到网页边缘时出现。

---

## 一、改动前 vs 改动后

| 指标 | 改动前 | 改动后 |
|---|---|---|
| `.map-wrap` 溢出处理 | 默认 `visible`（溢出漏到外层） | `overflow:hidden`（溢出裁在地图框内） |
| 奇观（戴森残片）转至网页边缘 | 箭头/模型溢出入 `#view-container` → 触发滚动条 → 画布每帧缩放跳变 | 溢出被裁在 `.map-wrap` 内 → 无滚动条 → 视窗尺寸恒定 |
| 视窗尺寸 | 随滚动条出现/消失跳变（用户感知的「震颤」） | 零变动 |
| 内容超出虚拟空间 | 反向改变视窗（错误方向） | 被裁，不影响视窗（符合老板铁律） |

---

## 二、根因链（完整取证）

1. **整体缩放引擎健全**：`fitAppSize()` 只算等比缩放比 `--app-k = min(w/1440,h/900)`（限幅 [0.6,1.6]），
   画布恒为 1440×900，`#app-scale` 用 `transform:scale(k)` 整体缩放，**不重排、不改 `--app-w/h`**；
   3D 渲染器容器 `scene-layer`（scene3d.js:1184 / bundle-ui.js:9786）自带 `overflow:hidden`，
   不反撑视窗。→ 排除「缩放引擎导致 resize」。
2. **画布尺寸唯一可变源 = 滚动条**：`#view-container` 带 `.view-box` 类（`overflow-y/x:auto;
   scrollbar-gutter:stable`）。奇观弹窗 `ui.openWonder` 用 `size:'md'` 固定 px，非震颤源；
   星系总览 `galaxyCanvas` 走 `box.clientWidth` 固定。→ 唯一能改变地图画布尺寸的，是
   `#view-container` 因内容溢出而被撑出的滚动条（吃 ~15px）。
3. **`.map-wrap` 缺 `overflow` 声明（默认 visible）**：`#wonder-arrow`（`ui-space.js:syncWonderArrow`
   按奇观屏幕坐标定位，出屏/背面夹到距边 `pad=40`，`transform: translate(-50%,-50%) rotate(..) scale(2.4)`）
   2.4 倍缩放向界外溢出约 37px；3D 奇观模型（planetRing 外径 2.5R、wonderStep 太空轨行 R×1.6）
   同理溢出。二者经 `visible` 漏进 `#view-container` → 滚动条出现 → `.map-wrap(100%)` 缩小 →
   `renderMapCanvas`(bundle-ui.js:27479) 每帧读 `.map-wrap.clientWidth` 改 `#mapCanvas`
   → 画布每帧重算、箭头位置重算、溢出仍在 → 滚动条常驻。奇观转回中央 → 溢出消失 → 滚动条消失
   → 画布跳回。**奇观扫过边缘时画布尺寸随滚动条出现/消失跳变 = 震颤。**

**唯一修复**：`.map-wrap { ... overflow: hidden; }` —— 把溢出裁在地图框内，
切断整条反馈链。内容仍可超出（被裁），视窗尺寸恒定，完全符合老板「视窗不随意变动」铁律。

## 四、诚实缺口

1. **`overflow:hidden` 会裁掉箭头溢出界外的 ~37px 尾部**：箭头是「指向奇观」的指针，
   主体（距边 40px 起的 77px 半宽）仍完整可见，仅最外侧 37px 被地图框裁掉；
   视觉上指针仍在、仍指向奇观，且这正是老板要的「内容超出被裁、视窗不动」。
   若未来要求箭头尾部也完整露出，应改 `syncWonderArrow` 的 `pad`（距边留白），
   而非动 `overflow` —— 那会重新引入溢出漏出风险。
2. **改动是纯 CSS 单行**：逻辑回归风险极低；但 JS 侧 `syncWonderArrow` / `renderMapCanvas`
   未作任何改动，行为完全保持。
3. **「是否还有可感震颤」是主观项**：须老板 **Ctrl+F5** 后实机转动戴森球残片至边缘观察判定，
   AI 不代拍板。
