# v158.59 · 连续空间：着陆后仍是飞行器，下机后才是人

## 一、老板原话

> 设计飞行程序，地面不要切换成人。做一个飞行器着陆，然后出来之后才是人。我要画面不跳变，还是 60-40 这一段。我要从设计上出发，不允许有高空和地面之分，这是一个连续的空间，有一个连续的运动过程。

## 二、跳变的真身：一个二元开关

旧链路：

```
高度 < 55m  →  placeCamera 派生 _surfNow = true  →  _applySurf(true)
            →  建地表层 / 隐藏飞行器 / 现出人 / 相机跳到地表机位
```

`_surf` 是个布尔。55m 处发生的是**模式切换**，不是连续运动——60-40 段之所以"跳"，根子在这里。

新设计：

```
飞行全程：fly.active → _surf 恒 false（永不按高度派生）
降到地面：landing 程序 → phase='landed'（飞行器停在原地，人未出现）
按空格：  M.flyExit() → 落玩家位姿 + surfaceMode(true) → 人才出现
```

| 项 | 旧 | 新 |
|---|---|---|
| 进地表触发 | 按半径自动（<55m） | **只有下机** `M.flyExit()` |
| 落地后 | 人瞬间出现、飞行器消失 | `landed`，飞行器停在地上、无人 |
| 60-40 段 | 55m 处切换 | 全程飞行态，零切换 |
| 地表 alpha | 预览硬顶 0.45 | 连续加深到 1（65m→0.45、48m→1） |

## 三、实测：60→40 段确实连续

探针在飞行器俯冲穿过该区间时逐帧采样（rAF）：

| 指标 | 实测 |
|---|---|
| 该段采样数 | 73 |
| `_surf` 出现 true | **从未**（0 次） |
| 相机单帧位移 | 最大 **1.55m**（峰值/中位 3.1，无尖峰） |
| 地表 alpha | **0.22 → 0.98 单调上升** |
| 高度 | 59.3 → 40.2 |

## 四、完整链路

| 阶段 | 状态 | 画面 |
|---|---|---|
| 巡航 | `phase=cruise` | 飞行器在屏下 2/5，地表层按高度渐显 |
| 降落 | `phase=landing` | 压机头、按高度/常下沉率下降，相机跟随 |
| 停稳 | `phase=landed` | **飞行器平放在地面**、人未出现、HUD「已着陆 · 空格下机」 |
| 下机 | `flyExit()` | 人出现在落点、第三人称背后、飞行器收起 |
| 再起飞 | `phase=takeoff` | 回到连续空间（`_surf` 回 false） |

## 五、顺带修掉的四个真缺陷（实机图逐张抓出）

| 缺陷 | 现象 | 修法 |
|---|---|---|
| 停放姿态 | 飞行器**竖直插在土里**（landing 把机头压到 −73°，落地沿用该姿态） | `flyLand` 记 `landHead`，落地摆平（机头水平、up 归径向） |
| 下机相机 | 仍沿 −73° 俯冲视线，**人不在画面里** | `flyExit` 按 `landHead` 主动给 `_surfDir/_surfRight` |
| 人物没落位 | 地表态小人还停在进入飞行前的位置（可能在几百米外） | `flyExit` 走 P0 唯一出口 `M.setPlayerPose({dir,h,yaw})` |
| HUD 不刷新 | 着陆瞬间速度归 0、方位不变 → 去重签名不变，永远显示"巡航" | 签名加 `phase` |

下机相机两个默认值也不适合"刚下机"，一并调了：地表距离 16m→5.5m（否则人只有十几像素）、俯角 57°→24°（否则低头看脚）。

## 七、断言处置

- 新增 §623⑨：锁「飞行态永不派生地表切换」、`landed` 停稳态、`flyExit` 唯一入口 + `setPlayerPose`、预览 alpha 连续公式、HUD 文案、探针四条下限。
- 旧探针 v15857 / v15856 的"落地等 `dock`"判据按新规则改为等 `landed`（规则变更，不是放宽）。

## 八、诚实缺口

1. **地表层仍是预览层复用**：下机后地面细节沿用飞行时的预览构建，不是"地表态专属"的完整层。当前 agl≤48 已显示全部景物，肉眼一致；要严格区分需在地表态单独 rebuild 一次。
2. **下机没有连续运镜**：目前是"落位 + 切第三人称"，没有"开门→走下→相机跟过去"的动画。
3. **上机仍是人瞬间消失 + 起飞**，没有对称的登机动画。
