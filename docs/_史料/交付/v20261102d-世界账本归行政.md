# 世界账本：顶栏退役，入口归到「行政」，有事件时闪

> 老板 2026-11-02：「把世界账本去掉，放行政里边就行，我看到已经有了，那就里边图标闪烁」

---

## 一、改了什么

| 位置 | 改动 |
|---|---|
| 顶栏 `#nav-ev` | **整条移除**（HTML 节点、`.topnav .nav-ev` 样式、`syncBadges` 里那段都清掉） |
| 行政页按钮 | 有事件时 `.btn.ev-on` 呼吸 + 文案「⚡ 事件名」；平时「🌍 世界的账本」 |
| 动画 | `ev-breathe` **原样保留**，挂载点从 `.topnav .nav-ev.ev-on` 换成 `.btn.ev-on`（同一套视觉语言） |

顶栏右侧从此只剩两件工具：**图例 / 天时**。

### 两处都要写，因为触发时机不同

```js
// ① js/ui-view.js（渲染时）
var evNow = (GAME.events && GAME.events.current) ? GAME.events.current() : null;
var evLive = !!(evNow && evNow.def);
'<button class="btn' + (evLive ? ' ev-on' : '') + '" …>' + evLabel + '</button>'

// ② js/ui-modal.js 的 syncBadges（停留时）
var evEl = document.querySelector('#view-container [data-action="open-world"]');
if (evEl) { evEl.classList.toggle('ev-on', !!evOn); evEl.innerHTML = …; }
```

为什么不能只写一处：**行政页不随 tick 重绘**。
`main.js` 只对 `city / ext / map / generals / marches` 触发 `renderView`，
玩家停在行政页时来了事件，渲染那条路不会被走到 —— 必须由 `syncBadges` 补那一刀。
反过来，只靠 `syncBadges` 也不行：切进行政页那一刻是先渲染、后跑 badge 的，会闪一下才亮。

## 三、断言怎么改的（翻红不删不宽）

§335⑤ 原来钉的是：

```js
check('§335⑤ 世界账本**常驻顶栏**（#nav-ev 入口常显，不再是事件才弹）', …)
  return html.indexOf('id="nav-ev"') >= 0 && … html.indexOf('🌍 世界账本') >= 0;
```

老板改主意了，这条必须改。按项目规矩**不是删掉，而是换成新口径**，并且三条一起验：

| 判据 | 守什么 |
|---|---|
| `html.indexOf('id="nav-ev"') < 0` | 顶栏**真的删了**（留着就是没改） |
| `ui-view.js` 里有 `data-action="open-world"` | 入口**还在**（删入口等于砍功能） |
| `.btn.ev-on` 样式 + `evLive` + `' ev-on'` | 有事件**会闪** |

第三条是**反平凡解**：只删不加的人能过前两条，但会让"有事件看得见"这个能力静默消失 ——
那正是老板要的"图标闪烁"，不能丢。

## 六、改断言时发现：钉这件事的其实有 **两条**（5 个判据）

第一次改完只处理了 §335⑤，全量立刻冒出 3 条新红：

```
❌ §338① 顶栏有世界账本位（nav-ev），常驻可见…
❌ §338② 它点一下就是「开账本」…
❌ §338③ 有事件时加 .ev-on 呼吸 + 写明事件名…
```

**同一件事被两组断言各钉了一遍**（§335 那次 v2026-10-31 的改造 + §338 又单独写了一遍）。
所以我用 `grep nav-ev` 只搜到一处，漏了另一处 ——
真正可靠的做法不是搜"变量名"，而是**跑一次全量，让红的自己报出来**。

§338 的三条按同样原则改成新口径：

| 断言 | 新判据 |
|---|---|
| ① 入口在行政页 | 顶栏**无** `id="nav-ev"` + `ui-view.js` 有 `data-action="open-world"` + 默认文案在 |
| ② 点一下即开 | 按钮有 `data-action` **且** `main.js` 有 `case 'open-world'`（只查按钮会漏"死按钮"） |
| ③ 有事件会闪 | `ui-view.js` 的 `evLive` + `ui-modal.js` 的 `#view-container [data-action=…]` + `.btn.ev-on` 样式 |
| ④ 不是新页签 | 保持原样（一直绿） |

③ 特意写成"**两处都要有**"：删掉任何一处，就有一半场景失效（切进去不亮 / 停留时不亮）。

顺带把两段的标题也改了 —— 还写着"世界账本常驻顶栏"的标题，下次看报告会误导人。
