## 一、底衬二档调亮（`.55 → .80 + brightness(1.15)`）

| 档 | opacity | filter | 区域均值 | 明亮像素占比 | 人形带均值 |

- **同一会话内三方逐值一致**（live 真文件 = 注入档 = 复位重拍，74.1 ×3）—— 测量法自证；
- 跨会话有 ~±4 的全局渲染浮动（实测 .55 档两会话 54.8 vs 58.5）—— 所有对照以**同会话**为准；
- 历史基线（跨会话留档）：改前（.32 + 剪影）= 47.0 / 1.6%；v89.238 交付 = 54.8 / 20.6%。

### 1.2 定档理由

- 「不够亮」发生在 v89.238 的 +7.8 之后 → 本轮增量须**明显大于**它：E 档同会话 **+15.6（58.5→74.1）· 人形带 +15.9（61.6→77.5）** ≈ 2×；
- `brightness()` 属「提亮」**非**「染色」：与 v39~v45 血账不冲突（该血账禁的是 hue/saturate/sepia/grayscale 类染色滤镜，断言里**继续全禁**）；备忘 §14.2 原文也是「只做 brightness 提亮」口径；
- 槽位是 z-index 3 独立层、下缘 mask 渐隐未动 → 同会话实测**底部渐隐区几乎不动（40.4→40.9）**，亮区集中在上半人形区（ASCII 结构对照已验）。
