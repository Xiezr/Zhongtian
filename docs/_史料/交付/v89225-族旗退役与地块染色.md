# v89.225 · 族旗退役 → 城内地块按「族」染色

> 老板原话：「**建筑前边的带颜色棋子是什么，能否用地块颜色区分，不然好突兀。
> 同类型建筑地块颜色相同，比如酒馆和招募站，训练营和练兵场等**」

---

## 一、"带颜色棋子"是什么（调查结论）

**它是 v89.107 立的「族旗」** —— 给七个建筑"族"各配一面燕尾小旗，程序化画在
每张建筑图标的**右下角外侧**（深木旗杆 + 横挑 + 三角燕尾布，旗面 ≈102×59px/512）。

完整取证链（三个独立证据）：

| # | 证据 | 数据 |
|---|---|---|
| ① | 16 张建筑图标**全部**在旗位（x 0.62~0.87 / y 0.58~0.78）检出与族旗色一致的色块 | 距旗色 ≤21（色相 160°/210°/40°/0° 分别命中文教青/军事靛/官署金/工商朱） |
| ② | 旗的绘制几何逐字节吻合（`flag_bldg_icons.py` / `wasteland_batch.py` 的 `draw_flag`：杆顶 (432,307)、旗面 x330-432 / y313-372） | 旗色 bbox 实测 **(330,313)-(432,371)** · 4806px |
| ③ | 历史来源：v89.107 为治"颜色不对劲"改"小面积高饱和色标"，旗由**两款管线**产出（美术会话的 `wasteland_batch.py` 亦含"逐张含族旗"门禁） | data.js 原 `DATA.SERIES[].flag` 七色 = 生产唯一来源 |

**为什么突兀**：旗色是高饱和纯色（s 0.27~0.60），悬在偏暗的地面上非常跳；
且它只编码"族"（7 类），与老板要的"同类型建筑同色"的观感诉求（酒馆+招募站=招募、
训练营+练兵场=军事训练）并不完全对应。

## 二、改法总览

| 层 | 改前 | 改后 |
|---|---|---|
| 素材（16 张图标） | 右下角画族旗（4806px/张） | **旗全部清除**（重切不画旗） |
| 族色载体 | 图标上的小旗（小面积高饱和） | **建筑地块底色**（大面积、低饱和"染色"） |
| 数据 | `DATA.SERIES[].flag`（七族旗色） | `DATA.SERIES[].plot`（八族地块色 · 默认主题 HSL） |
| 族划分 | 7 族（live 含酒馆、edu 含招募站） | **8 族**：新增 `recruit`（招募）——酒馆+招募站迁入 |
| 样式 | `ser-*` 只是语义标记（不驱动颜色） | `ser-*` **重新驱动颜色**：`.iso-tile.built.ser-x .tile-face` × 8 条 |
| 主题 | — | 4 主题各一版（`--ser-*`：默认/silk/bamboo/night） |
| 死变量清退 | `--ground-gov` `--ground-sel`（零消费） + `.iso-tile.gov` 死规则 | 全删 |

## 四、去旗工程（素材层）——"重切不画旗"+ 双重防线

1. **管线退役**：`gen/wasteland_batch.py` 删除 `draw_flag` 调用与函数本体（墓碑注释），
   gate ③ 由"逐张**含**族旗"**反转**为"逐张**无**族旗"（墓碑色表 `HIST_FLAG_RGB` +
   旗位区域计数，阈值 `guards.buildingNoFlagMaxPx = 1500`）。
2. **16 张图标重切**：`--batch W-B1 --check → --apply`（从 raw 图集重切，**不画旗**；
   install 自动把旧图另存 `backup/pre_wasteland/`）。
3. **切分确定性验证**（硬证据）：stage(无旗) vs UI(旧带旗) 全量像素比对 ——
   **总差异 5992px/张，全部落在旗的几何范围内（扩大区外差异 = 0）**，
   证明"重切 = 同材质 − 旗"，没有引入任何材质变化。
4. **旗零残留验证**：16 张旗位区域对 7 个历史旗色逐一扫描，**最大命中 ≤448px**
   （有旗时 ≈4806px，判别力 ~10×；gate 阈值 1500 居中）。
5. `asset/flag_bldg_icons.py` 加**墓碑 + 运行即退出**（防误跑把旗画回来）。

## 六、诚实缺口

1. **训练营/练兵场与围墙/瞭望塔同为 mil 族**（同色）——老板点名的"两对"成立；
   若要把"训练设施"与"防御设施"再分家，加一行族即可（一句话可改）。
2. **另三主题的色值未做逐值断言**（smoke 只对默认主题做 HSL→RGB 逐字节校验，
   其余三主题做"存在性 + 8×4 齐备"校验）——设计矩阵已全量实测达标，见上表。
3. **美术会话的 raw 源图集**不受本次影响；若将来重跑**建筑批次**，管线已不画旗 ✓；
   若跑**兵种/材料等批次**，它们本来就不画旗（与本次无关）。
4. 旧存档零影响（地块色是纯渲染层，无状态字段）。
