# v157.88 · 修「水面穿模，似乎有个球体在下面」

> 老板原话：「水面穿模，似乎有个球体在下面」

这句话描述的现象是真的，但**不是模型穿模** —— 是海面着色器里两处会"漏出别的东西"的写法。
先取证、再改、再验，两步都留了反向证据。

---

## 一、取证（先把"球"找出来）

三路定位，都不靠猜：

1. **隔离层**：把海面单独关掉（`seaMesh.visible=false`）→ 白斑随之消失，浮物还在。
   → 白斑**长在水面上**，不是水下有个模型。
2. **列球体**：把场景里所有 `SphereGeometry / CircleGeometry / Sprite` 全列出来（世界坐标 + 半径）：
   只有天空穹顶（r=4200）、人的头（r=0.115）、胸口核心（r=0.045）、脚下圆片（r=0.36）。
   → 场景里**没有任何"水下的球"**。
3. **摆角度**：低角度 / 俯视 / 贴近水面各拍一张：
   白斑是**边缘圆滑的大块**（3~5 米），跟着浪尖出现，俯视时最明显。

结论：白斑来自水的片元着色器。

## 二、真因两条（都在我自己写的水面里）

### ① 白沫是"阈值化噪声"→ 生成大圆斑

```glsl
// 旧（错）
float foam = smoothstep(0.78, 1.0, crest) * 0.42;
foam += smoothstep(0.74, 0.97, vnoise(p * 0.42 + ...)) * 0.10 * crest;
```

`smoothstep` 卡阈值 + 值噪声 = **一堆边缘圆滑的斑块**。噪声尺度 0.42（≈2.4 米一个特征）画在浪面上，
近景看就是"水下浮着一颗白球、透过水面显出来"。

**改法**：泡沫必须是**细碎纹理 × 浪尖**，两个门槛相乘：

```glsl
float foamC = smoothstep(0.90, 1.0, crest);        // 只在最高浪尖
float fn = vnoise(p * 2.4 + vec2(uTime*0.45, -uTime*0.35));  // 高频细纹
float foam = foamC * smoothstep(0.55, 0.85, fn) * 0.9;       // 斑点，不是圆块
```

### ② 海面是单面材质 → 镜头被浪盖住时整片海"消失"

`ShaderMaterial` 默认 `FrontSide`。低俯角贴着浪看时，一排浪头会把镜头盖到水面之下 ——
此时海面从背面**整块不渲染**，画面直接露出天空穹顶的内壁（一个巨大的球面）。
这就是"水面破了个洞、下面有个球"的第二种成因。

**改法**：`side: THREE.DoubleSide` + 相机离水面余量 `0.85 → 1.5` 米（浪尖振幅 1.65，0.85 挡不住）。

## 七、诚实说明

1. 这两种成因都能独立造成"看到球/洞"：只修泡沫的话，贴着浪看还会露出穹顶；只修单面的话，白斑还在。
   所以两条一起改、一起守。
2. 水**仍然是单层不透明网格**：没有折射、没有水下体积。真要"涉进水里"，得再写一层水下渲染（下一轮的量）。
3. 白沫现在偏克制（只在最高浪尖出零星斑点）。要更"碎浪"的效果，把 `smoothstep(0.90,1.0,crest)` 的下界降到 0.85。
