# v89.145 撑满与冻结滚动（商城不足 4 行也撑满 / 去「最多」/ 冻结头部只滚物品区）

> 老板原文（逐字）：
> 1.商城某分类不足 4 行时仍会下方留白（内容本来不够）—— 要不要"无论如何都撑满"？——撑满。购买数量那里不要"最多"这个功能，因为总不能那点金币全买了同一件商品，日子还过不过了
> 2.可以滚动，但不要整页面滚动，设置冻结部分，比如上边的材料等分类和排序功能所在行不应该动，而只是底下细分的宝物可以

## ① 商城：不足 4 行也撑满 + 购买数量去「最多」

| 项 | 改前（v89.143） | 改后（v89.145） |
|---|---|---|
| 物品区拉伸 | 只有**满页**（16 件 = 4 行）才挂 `shop-fill` —— 3 行/2 行/1 件的分类下方一片留白 | **恒定挂** `shop-fill`：任何分类都把物品区铺满可视区（行高按行数平分） |
| 旧条件 | `var fullRows143 = slice.length >= per;` | **整条删除**（判据里有"`fullRows143` 不得再出现"的反向断言） |
| 列表「最多」键 | 商城购买行也有（按金币能买的上限一键填满） | **去掉**（`ui.qtyInput(..., noMax=true)`）；−/＋ 与直接键入都在，`data-cap` 越界钳制仍守 |
| 其他弹窗「最多」 | 同上 | **照用**（募兵/加点/用道具…不受影响 —— 反向断言防"过度删除"） |

**实测（最少分类「talis」1 件）**：单卡被拉高到 **684px**（定高口径 116px）；物品区占页高 **87%**；
元素截图 337×684 三段齐（名称带 3.5% / 图标带 3.8% / 操作行带 10.1%）。

## ② 冻结头部、只滚物品区（背包 / 商城同规）

```
改前：整个 #view-container 一起滚 —— 标题、分类条、排序条都跟着跑（老板："不要整页面滚动"）
改后：
  背包 = .ui-page.bag-page（满高 flex 列）
         ├─ 标题 / 页签（装备·宝物）/ 分类条 / 排序条   ← flex:0 0 auto（冻结）
         └─ .bag-body { flex:1; min-height:0; overflow-y:auto }  ← 只有它滚
  商城 = .ui-page.shop-page（v89.143 已是满高 flex 列）
         ├─ 标题 / 分类条                              ← 不动
         └─ .shop-rows.shop-fill { overflow-y:auto }    ← 只有它滚（窗口矮时）
```

## 诚实缺口（2 条）

1. **单件分类的卡片会被拉得很高**（实测 1 件 = 684px 高；名称在顶、操作行在底、中间留白）——
   这是"无论如何都撑满"的直接后果。若您觉得单件时太夸张，可给"1~2 件"设一个高度上限
   （改 `.shop-rows.shop-fill` 一处）——但那样又会留下一部分空白，取舍由您定。
2. 冻结只在**背包 / 商城**两页做了（老板点名的"材料等分类和排序功能所在行"）。
   其他整页（如铁匠铺、军务）如果也有"顶部筛选 + 长列表"，可按同一套 `.XX-page` 模板扩 —
   目前没做，等您的清单。
