## 一、拆械特性（需求 1）

### 病根

v89.179 克制全撤后，"冲车同人口无解"失去旧答案（原靠"床弩克器械 ×3"对位）——
实测（`probe_v89180c` 基线）：同人口 4000，**床弩 1333 vs 冲车 800 → 弩全灭、冲车损 14.6%**；
对投石车同样被碾压（弩全灭、投石损 21.4%）。

### 改法（**单向、单兵种、不构成矩阵** —— 与"克制系统"的本质区别）

| 层 | 落点 |
|---|---|
| 数据 | 器械标签 `mech: true`（冲车 / 投石车 / 辎重车 / 床弩 —— 与原方向表同集合）；床弩 `vsMech: 3`；desc → 「强力远程，拆械破车，攻城必带」 |
| 引擎 | **唯一消费点 `tactic.fireOnce`**：`mechMulOf(目标id)` × 到最终伤害（`eff`）上 —— 主动攻击与反击共用本函数，一处即全覆盖；`battle.smartPickTarget` 同尺（智能评分知道"床弩该打器械"） |
| 界面 | 战场悬停 + 募兵卡悬停各一行「拆械 对器械伤害 ×3」（有 `vsMech` 才显示）；其余兵种零变化 |

### 倍率标定（`probe_v89180c` · 同人口 4000 · 单变量扫描）

| 倍率 | 打冲车（敌损） | 打投石车（敌损） | 打长枪（对照） |
|---|---|---|---|
| ×1.25 | 19.1% | 28.4% | 我损 50.0%（恒定） |
| ×1.5 | 22.8% | 35.4% | 同理 |
| ×2 | 30.9% | 53.0% | 同理 |
| ×2.5 | 39.5% | 83.5% | 同理 |
| **×3（定稿）** | **48.3%** | **100%（弩胜 · 险胜损 70%）** | 同理 |

**定稿 ×3**：与历史"弩器械专项"一致；口径 = **床弩对器械从"被碾压"变"能抗衡"**
（打投石能胜、打冲车能拆掉近一半）；**非器械对位零影响**（长枪对照行所有倍率下恒定）。

## 二、智能风筝（需求 3/4）—— "距离是弓兵的生命线"

### 病根

智能战斗（v89.164 起）的远程规则 = "进射程 → 站桩（防御）"——
**只会"前出对射"，不会用距离**。老板看到的"弓兵跟长枪兵对对碰"就是这条规则的结果。

### 改法（智能战斗 v3 · 只加"会退"，不动别的）

```
echelon（默认阵型）远程单位：
  gap > 有效射程                       → advance（前出接敌，照旧）
  gap ≤ 有效射程：
    ├─ 【风筝四条件】全部满足 → retreat（后撤一步 · 引擎支持退到 −D · 后退回合照常开火）
    │    ① 团队条件：我方存活远程的最小速度 > 敌最前单位速度（跑不动就别退）
    │    ② 威胁线：gap ≤ 敌射程 + 敌速度 × kiteLead(1)（"它下回合能不能打到我"）
    │    ③ 窗口：敌射程 < 我（"我打得到 / 它够不着"才值得拉开）
    │    ④ 可退且退后仍能开火（退出去打不着 → 原地站桩，受创减半）
    └─ 否则 → hold（站桩输出，照旧）
```

- **团队条件**是实测逼出来的：混编里"突骑跑、弓留"反而全灭（S3：45% 损 → 100% 损）——
  最慢的那支远程决定整条远程线是否风筝（一致行动 > 各自为战）。
- **向后兼容**：`smartStanceOf` 加第 5 参；**无 ctx（旧调用/旧断言）= v89.164 逐字行为**。
- **可见**：调整自动进回合记录（「突骑兵 防御→后退」）与顶栏「⚡ 智能 · 调整 N」。

### 实测（`probe_v89180d` · 真实 smartApply 管线 · 关/开单变量对照）

| 场景 | 关（v89.164） | 开（风筝） | 变化 |
|---|---|---|---|
| S1 突骑2000 vs 长枪4000 | 我胜 · 我损 **39.9%** · 20 回合 | 我胜 · 我损 **1.3%** · 12 回合 | **保兵 +38.6 个点** |
| S4 突骑2000 vs 长枪3000+弓500 | 我胜 · 我损 20.3% | 我胜 · 我损 **0.7%** | +19.6 点 |
| S2 弓2000 vs 长枪4000 | 我败（100%） | 我败（100%） | 零差异（**弓跑不动**，团队条件不触发） |
| S3 突骑1000+弓1000 vs 长枪4000 | 我胜 45.0% | 我胜 45.0% | 零差异（同上） |
| S5 弓对射 / §176 四场景（mirror/cavHeavy/bowHeavy/infHeavy） | — | — | **全部零差异（不劣化）** |

**实机**（真浏览器 · Lv4 野地 626 守军）：打 9 回合，智能调整 8 条中 **5 条是"后退"**
（「突骑兵 防御→后退」「突骑兵 后退→防御」节律可见）。

  "快半拍的强击队"。数值**未动**（本条为口径修正；若老板要求"虎豹同人口胜轻骑"，
  改法 = 提 hp 或 def，一处表值，等一句话）。

## 五、诚实缺口

- **床弩 vs 冲车同人口仍负**（拆械后冲车损 48.3%）：冲车是 pop5 血牛（hp 36000），
  1v1 要"床弩胜"需 ×5 以上（与"系数别猛"相悖）；定稿口径 = 拆械让床弩**有效拆械**
  （打投石能胜 / 打冲车拆半），实战靠"前排 + 床弩"体系。
- **风筝是团队触发**：混编里有慢速远程（弓 250 / 床弩 120 / 投石 100）时不触发
  （S3 实测"部分退、部分留"反而更差）——纯机动远程（突骑）才吃风筝红利。
- **弓跑不过任何步兵**（250 < 长枪 300）——数值层面维持"阵地远程"定位；
  若要让弓也能风筝需提速到 310+（牵动速度体系，未动，等拍板）。
- 拆械只对**器械兵种**（冲车/投石/辎重/床弩），不涉及"床弩拆箭塔"（工事另有 tough 口径）。
