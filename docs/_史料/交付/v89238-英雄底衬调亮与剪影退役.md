## 五、诚实缺口

1. **抠图为不透明方图**：素材池现役 91 张（`assets/portraits/pool/`）**全部无 alpha 通道**，
   底衬以"方形图片 + 下缘渐隐"呈现、**非人形抠底**观感；若要"人形裁切"效果，需素材侧补透明通道（另批）。
   （本批已做的兜底 = 画框 `overflow: hidden` 圆角裁形，方角不会露到框外。）
2. **亮度 0.55 为经验值**：0.26 = 历史实测"可见像素仅 9%"的下限 → `.55`（+72%）。
   观感最终由老板拍板 —— 若还要更亮/更暗，改 `index.html` 一处（`.doll-portrait img` 的 `opacity`）即可，
   smoke 断言同步一处。
3. 剪影退役后，"哪一格贴哪儿"的感知由 **DOLL_POS 落点布局**独立承担（槽位自身有部位名），
   不依赖剪影轮廓 —— 若老板觉得槽位"悬空"，备选是给槽位加一条淡连线（未做，等明示）。
