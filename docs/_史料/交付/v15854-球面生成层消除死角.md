# v158.54 · 从球面生成层消除死角 / 轴线 / 闪变

## 一、需求原文

> 星球闪变，始终没有解决为什么星球有死角，有该死的轴线。那轴线只做标识用。从生成层面消失死角。

背景：「死角」在前四轮（v157.78 / .80 / .81）修的都是**相机旋转层**（拖不过极点、yaw/pitch 奇点、双真值）。老板这次明确点名「从生成层面」「轴线只做标识用」——是要换一层：从球体几何与法线的**生成本身**消除，而不是继续修相机输入。

## 二、取证（不猜参数，先量化）

两个真浏览器探针：

| 层 | 观测量 | 结果 | 判读 |
|---|---|---|---|
| 顶点法线 | 六面共享棱焊接后最大夹角 | 0.02° | 顶点层早连续 |
| 顶点颜色 | 图集模式下 col 全 (1,1,1) | 差 0 | 假象，不是接缝证据 |
| **图集法线（片元真读）** | 共享棱 60 采样点 | **平均 68.65/765、最大 358/765** | **真凶** |
| 图集颜色 | 同上 | 平均 5.67、最大 86 | 次要 |
| 轴线 axisRoot | CylinderGeometry(1.15,1.15,780) | Mesh/DoubleSide/depthWrite=false/无 raycast | 本就只做标识 |

根因链：cube-sphere 六面各自用 **面参数 `fn(u,v)` 的切向 + 面内 `hArr` 差分**烘法线。共享棱两侧切基不同、边缘还单边差分。顶点法线虽已焊接，但 `RELIEF_TEX` 下片元读的是图集——所以改相机永远消不掉那条"像轴线"的直线，这就是老板说"始终没解决"的原因。

## 三、改法（生成层）

法线改为**球面原生 3D 梯度**：同一方向 d 在任意面、任意纹素得到同一法线，与 cube 面参数无关。

- `sphBasis(d)`：切基只依赖 d，`|y|>0.9` 换参考轴兜底（与 `SP.tangentOf` 同口径，避免新极点）。
- `elevAt(d,t,s)`：法线专用低频高度（`fbm3` 2~3 阶：大陆骨架 + 褶皱脊）。高频颗粒归 `uDetailTex`；全量 8 octaves 差分既放大高频闪变、又把烘焙拖到 5.45s。
- 中心差分 `g=(e(+s)-e(-s))/(2s)`：前向差分实测接缝反涨（30/135），对称是零缝必要条件；`e0` 同口径取 `elevAt(d,t,0)`（混用完整 sphElev 会在海洋处冒出巨大常数梯度）。
- 曲率遮蔽复用同一次 4 邻域采样。颜色图集仍用完整 sphElev，配色一字未动。
- 轴线保持纯标识：Mesh + DoubleSide + depthWrite=false + 无 raycast，不参与几何、拾取、判定。

## 六、诚实缺口

- 修的是**光照接缝**（球面上那条看似轴线/死角的明暗线）。贯穿球心的青色圆柱是正位标识，按老板口径保留，未删。
- 「闪变」的其余来源（大气壳边缘 smoothstep、线框层、海面波浪逐像素衰减）未动——消元实测这些层的动态像素占比与本修复无关；若仍见闪变，请指出具体位置再取证。
- 低频法线使极端近距的地形浮雕比旧版略平滑，高频细节由既有 `uDetailTex` 承担。
