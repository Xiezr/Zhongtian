# v158.52 · 高空惯性战舰飞行（老板五条）

> 老板原话：「高空的相机移动不对， 一是高度固定，不合理，二是把QE加减速改为←→加减速，↑，↓改变海拔高度。3是方向问题，前进不是前进，后退不是后退。4是转向中没有体现速度，物体本身在太空中速度应该恒定，除非受到别的力，现在完全没有体现转向中的运动轨迹，让人感觉反倒是在转星球本身。5，赋予相机一个形体，简单的三角锥战舰吧，把运动体现出来」

## 核心模型变更

| | v158.51（旧） | v158.52（新） |
|---|---|---|
| 位置 | 锁球面：`camO.dir` + `camO.dist` | 自由 3D：`fly.pos/head/vel` |
| 推进 | 视线切平面投影（看哪飞哪） | 沿速度矢量 `pos += vel·v·dt` |
| 加减速 | Q/E | `←/→`（右加速、左减速可倒飞） |
| 高度 | 滚轮/滑块，飞行中固定 | `↑/↓` 直接改半径（24 m/s）+ 滚轮共存 |
| 松键 | `FLY_DECAY` 指数衰减 | 速度恒定（牛顿第一定律） |
| 转向 | `lookYaw` 转头，位置瞬移切向 | 机头先转、速度矢量有限角率追随 → 弧线 |
| 相机 | 轨道"看球心" | 第三人称战舰机位（后 24m / 上 9m / 看前 60m） |
| 形体 | 无（纯相机） | 三角锥战舰 + 引擎球 + 尾迹 |

## 改动明细

### ① 高度可变 + 滚轮共存
- 飞行状态从单标量 `v` 升级为全状态 `{v,pos,head,vel,active,climb,trail,trailAt}`。
- `↑/↓` 调 `FLY_CLIMB=24 m/s` 直接改球心距离；每帧由 `fly.pos` 反算写回 `camO.dist/dir/yaw/pitch`（**§243①p 第 5 处合法 asin 写点 `_ndF.y`**）作为地表交班/探针唯一接口。
- **真 bug**：旧版每帧无条件 `_zoomTarget = camO.dist - R`，把滚轮写入的目标覆盖 → 飞行态滚轮完全失效、永远降不回地表（探针⑨抓出）。修法：tick 先消费 `_zoomTarget`（差 >1cm 才动）再叠加 `↑/↓`，最后统一写回。

### ② 键位重排
- `→` 加速 / `←` 减速倒飞（48 m/s²，上限 120/−72）；QE 整条退役。
- `↑/↓` 升降；W/S 机头俯仰、A/D 机头转向。
- 高空键通道 `GAME._flyKeys` 独立。**关键点**：`AV_KEY_ALIAS` 会把方向键归一成 `KeyW/A/S/D`，所以 keyup 必须读原始 `e.code`（`_c0`）才清得到 `left/right/up/down`，否则键粘住。
- HUD 直印键位（不藏设置页）：「🚀 空天战舰 · N m/s · ←→ 加减速 · ↑↓ 升降 · W/S 俯仰 · A/D 转向」。

### ③ 前进 = 沿速度矢量
- 位置推进不再用「视线在切平面投影」，改为 `pos += vel·v·dt`；第三人称机位注视机头前方 —— 前进就是画面往前，不是把星球转过来（探针⑤：位移与 vel 余弦 1.0）。

### ④ 太空惯性 + 弧线轨迹
- 无 `←/→` 输入不做任何衰减（FLY_DECAY 退役）。
- 机头 `head` 由 A/D、W/S 转；速度矢量 `vel` 以有限角率追随：`vel.lerp(head, _vt·dt)`，`_vt = FLY_VEL_TURN × (0.25 + 0.75·|v|/vmax)`。
- **参数失衡真 bug**：初版 `FLY_VEL_TURN=0.65` 时有效追随仅 0.49 rad/s < 机头 1.1 → 侧滑角发散到 140°（机头与航向完全脱节，探针⑥抓出）。改 2.4（有效 1.8 > 1.1）→ 稳态侧滑角约 35°、松手 1.5s 归位 2.3°：有漂移感但不倒着飞。

### ⑤ 三角锥战舰 + 尾迹
- `ConeGeometry(1.2, 4, 3)`（锥尖朝 +Z）+ `SphereGeometry(0.5,8,6)` 引擎球 + `THREE.Line` 尾迹（120 点 / 80ms 采样）。
- 第三人称机位：后 24m、径向抬高 9m、看前方 60m、`cam.up` 恒径向（脚底永远朝星球）。
- **实机截图取证**：初版大锥（2.4,8 / 后 18m）占屏约 1/4、挡住大半视野 → 运行时实验对比后缩机 + 拉远，占屏约 1/12 且形体仍清晰可辨。
- 机头对齐用**正交基 `makeBasis`**（z=机头、y=径向），不用 `setFromUnitVectors((0,0,1),dir)` —— 后者是 §586s 明令退役的最短弧构造，即便只作用于战舰 mesh 也不许借同形态复活。

### 启动瞬态空指针
- `camO.dir` 初始为 `null`，旧 `_tickFlight` 首帧直接读 `camO.dir[0]` → `M._flErr1 = "Cannot read properties of null (reading '0')"`（探针①抓出）。修法：用 `yaw/pitch` 反推等价单位方向兜底，不依赖相机状态机先跑过一轮。

## 诚实缺口

- 高空平视时星球在脚下视野外（「脚底星球、头顶太空」姿态的自然结果），画面主体是黑背景 + 稀疏远景点；按 W 低头把机头朝星球即可看到地表。未为此改注视点方向 —— 那会破坏「前进=画面往前」。
- 尾迹是 1px `THREE.Line`，多数采样点在第三人称机位后方视锥外，画面上不明显；数据层 120 点持续累积、mesh 在册。要做「看得见的航迹」需改三角带（WebGL linewidth 恒 1px）。
