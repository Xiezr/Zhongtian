# v158.53 · 无人深空式飞行操控（星球方位指示）

> 老板原话：「角度转向始终有硬伤，可操纵性差，上不上上，下不是下。参考无人深空的操纵，。就完全没有一个坐标原点，没有一个可参考性。你我现在鼠标左键，右键，上下前后完全不知道自己在哪里，你懂吗？玩家完全不知道自己在哪里。也不能按照自己的意愿自由的想去哪就去。就是那种可操作性不行。」
>
> 方案追问：「我不懂别问我。」空间参照点名：「星球方位指示。」

## 一、先取证：不是参数，是范式错了

v158.52 做到「物理正确」（惯性、恒速、弧线），但玩家开不了。诊断探针 `.workbuddy/tmp/diag_v15853_controls.js` 实测：

| 动作 | 观测 | 结论 |
|---|---|---|
| 按 `↑` | 机头夹角 `0°`，海拔 `570→594.36` | 「↑」是电梯，不是抬头 |
| 右键拖 | `lookYaw 0→-1.5`、`lookPitch 0→0.75`，机头夹角 `0°` | 视线与航向解耦 = 看这边、飞那边 |
| 按 `A` 0.5s | 机头转 `32.3°`，速度只转 `11.5°`，侧滑 `20.8°` | 推了舵还往原方向飘 |
| `camUp` vs 径向 | 夹角 `0.1°` | 无 banking，转向缺姿态参照 |
| HUD | 只有速度和键位 | 没有任何空间参照 |

## 二、核心模型变更

| | v158.52（旧） | v158.53（新） |
|---|---|---|
| 视线与航向 | `lookYaw/lookPitch` 与 `fly.head` 两套，彼此无关 | 鼠标即机头，看哪飞哪 |
| 速度矢量 | `vel.lerp(head, _vt·dt)` 有限追随，侧滑 20.8° | `vel.copy(head)` 瞬时对齐，侧滑 0° |
| W/S | 机头俯仰 | 推进 / 刹车（与 ←→ 并行） |
| A/D | 水平转机头 | 横滚 + 协调转弯 + banking |
| `↑/↓` | 唯一的升降（"电梯"） | 辅助升降，抬头低头归鼠标 |
| 相机 up | 恒径向，转向无姿态反馈 | 机体 up，转向画面倾斜 |
| 双击右键 | `lookYaw/lookPitch` 归零 | 回正平飞（up 归径向，机头不变） |
| 空间参照 | 无 | HUD 常驻星球方位罗盘 |

## 三、改动明细

### ① 鼠标即机头
右键拖动不再写 `camO.lookYaw/lookPitch`，直接旋转 `fly.head`：左右绕径向 `_frad` 偏航，上下绕机体 right `_fright` 俯仰；`FLY_LOOK_K=0.0042` rad/px（拖 250px ≈ 60°）。机头 = 视线，飞行态不再有第二套角度。地表态右键仍走 `_rmbOrbit` 环视，两条通道隔离。

### ② 速度瞬时对齐（侧滑归零）
`vel.copy(head)` 取代有限追随；`FLY_VEL_TURN` 整条退役（墓碑留去向）。转向的弧度由机头自己在转产生 —— 轨迹仍是弧，但不再「推了舵还往原方向飘」。

### ③ W/S 推进刹车、A/D 横滚
`if (r||w)` / `if (l||s)` 加减速（48 m/s²，上限 120/−72）。A/D 改 `FLY_ROLL=1.7` rad/s 绕机头横滚 + `FLY_BANK_TURN=0.75` 绕径向协调转弯，松手 0.8/s 回正。`cam.up` 取机体 up，转向时画面真的倾斜（探针：机体 up 转 71°、机头同向转 32°）。

### ④ 星球方位指示（老板点名）
- 唯一只读出口 `M._flyNavState()`：把「战机→球心」投影到机体正交基 `head/right/up`，给出 `bearing/elev/dir8/vertical/alt/range/toward/bank`。HUD 与探针共读，绝不各算一套。
- HUD 收 `(v, nav)`：罗盘（▲=机头恒朝上、●=星球实时方位）+ 八方位 + 离地/球心距离 + 机头夹角 + 横滚角 + 新键位文案。飞行态**常驻**（静止也看得见参照），sig 去重含方位/海拔/横滚，转头即刷新。
- 极点处理：`|elev|>80°` 时 `front/side` 同时趋 0、bearing 是浮点噪声（实测基线在 0~18° 乱跳），改为直报「正上方/正下方」，罗盘画到对应上/下缘。

### ⑤ 双击右键回正平飞
从写 `camO.lookYaw/lookPitch=0` 改为机体 up 归径向、机头朝向不变（无人深空式 level out）。地表态仍用旧视线回正。

## 四、实机图抓出并修掉的两个真 bug

1. **极点罗盘画反**：文字写「星球 正下方」，橙点却画在罗盘正上方（bearing 被归 0 后罗盘照 0° 画）。修法：`dir8=正下方` → 罗盘 180°（下缘）。
2. **多行 HUD 盖住战舰**：底部居中 HUD 加高后压住第三人称战舰下缘。修法：HUD 移到右侧中部，战舰占屏约 1/12 且完整可见。

## 六、诚实缺口

- 无人深空的脉冲引擎 / 起飞降落 / 自动导航未照搬，本版只做「看哪飞哪 + 横滚 + 参照系」三件核心。
- 高空平视时星球在视野外，方位靠 HUD 罗盘而非画面内实体；罗盘给相对机体方位，不做星图绝对坐标。
- 横滚无限幅（按住 A/D 可连续滚 360°），松手才回正；若要求「最多倾斜 60°」需另加 clamp。
