# 三个"反人类"的坑：正方形视野 / 拖不动 / 建造看不见（v158.21）

> 老板 2026-11-26：
> 「为什么近地面的视野边界是个正方形？我没见过正方形的一个视野边界。为什么视野外不能点击？不能点击我怎么左键进行拖动。为什么现在地块一点就进入了这个什么占领啊什么的？那我怎么进行资源建筑的建造？我的建造呢？我的建造呢？朋友，我的建造呢？这每一步都是反人类啊。……以玩家为中心，而不是以你的狗屁代码和设计为中心。」

## 一、三个都是真 bug，不是设计分歧

我逐条查了根因，**全部是代码层面的硬缺陷**：

| 现象 | 根因 |
|---|---|
| 近地面正方形边界 | **两处方阵采样**：① 地块平台 `(2×22+1)²` = 2025 格方阵，四角伸到 112 米；② 地形层 `N×N` 方阵采样，四角伸到 half×1.41 |
| 视野外不能点击/拖动 | `mousemove` 里**两道地表拦截**：没抓到地面点就 `return`，地表模式整段跳过轨道拖拽。而贴地的相机朝向由 `M._surfDir` 决定 —— 改 `camO.quat` **等于白改**（实测拖 200px 只走 Δyaw=0.0008） |
| 点地块只有占领、没有建造 | `resBox` 被排在产量/材料/珠宝**之后**；生成时还有一行白名单**把平原和草原也挡掉了**；湖泊+沼泽占全图 **37%** 却什么都不显示；标题叫「资源地块」读不出"能建东西" |

## 二、改了什么

### ① 正方形 → 圆形（两处）

```js
// 平台：只生成圆内的格
var _di = i - g0.i, _dj = j - g0.j;
if (_di * _di + _dj * _dj > RANGE * RANGE) continue;

// 地形层：只生成圆心在圆内的三角
var _cu = -half + (i2 + 0.5) * step, _cv = -half + (j2 + 0.5) * step;
if (_cu * _cu + _cv * _cv > half * half) continue;
```

实测平台三角数 6068 ≈ **1517 格**（π×22² = 1520），方形应是 2025 格 × 4 = 8100。

### ② 贴地能拖了

删掉两道拦截，贴地时左键走**环视**这条唯一出口（改 `M._surfDir`，与右键 lookDrag 同一套四元数数学）：

```js
if (M._surf && drag && !lookDrag) {
  // 水平：绕站立者径向转视线
  // 垂直：绕当前右向转视线（可越过天顶）
  M._surfDir = _dS2;
  touch(); redraw(); return;
}
```

实测 `ΔsurfDir = 0.2146`（改前 0.0008）。

### ③ 建造入口从"看不见"变成"第一眼"

面板顺序从：

```
🏕️ 山地 Lv9 → 守军 → 产出/资源/产量加成/材料/珠宝 → [资源地块] → 侦查/掠夺/占领
```

改成：

```
🏕️ 山地 Lv9 → 守军 → 🏭 采集场 · 未勘探（勘探后即可建造） → 资源 → 🔍 勘探
          → 产出/材料/珠宝 → 侦查/掠夺/占领
```

三处具体改动：

1. `resBox` 提到 `prodBox` **之前**
2. 删掉这行白名单（它把平原/草原也挡了）：
   ```js
   if (!(rv.type === 'forest' || rv.type === 'hill' || rv.type === 'desert')) return;
   ```
3. 不能建厂的格（湖泊/沼泽，占 37%）也给一块说明：**"只能派军采集，不能建厂 —— 建厂要森林/山地/荒漠/平原/草原"**
4. 标题「资源地块」→「🏭 采集场」

## 三、验证

| 项 | 结果 |
|---|---|
| 野地面板逐行 dump | `🏭 采集场 · 未勘探（勘探后即可建造）` 在**第二行** · `hasResZone=true / hasBuild=true` |
| 贴地拖拽 | `ΔsurfDir=0.2146`（改前 0.0008） |
| 平台几何 | 6068 三角 ≈ 1517 格（圆），方形应为 2025 格 |
| smoke | **4612/0**（§586r / §607④ 按新规则重写） |

## 四、⚠️ 我没验证到的，必须说清

**headless 下 `M.surfaceMode(true)` 没能真正建起地表层**（玩家是滚轮拉近自动进的），
所以贴地截图看到的是光球的一个三角面，**不是真实地表**。

所以：**"贴地边界好不好看"必须你自己实机看一眼**。我只能保证代码层面采样范围从方形改成了圆形，
拖拽在数据层面确实有响应（ΔsurfDir 0.21）。

## 五、我承认的问题

老板那句「沉浸在你代码构建的快乐当中，不顾玩家的死活」是对的。这次三个坑里最刺眼的不是算法，
是**"功能存在但玩家看不见"**：

- 勘探/建厂整条链早就写好了（`RS.view` 对森林格 20/20 正常返回），
  但入口被一行白名单挡住、排在占领按钮后面、不能建的格一声不吭——**玩家体感就是"功能不存在"**。
- 我上一版还在纠结"面板文案怎么写"，却没先问一句"玩家点开第一屏看到的是什么"。

**面板顺序就是产品，不是排版细节。**
