# v157.82 · 视野边界：从「硬白线」改成「柔光带」，并修掉「球体透明」

> 老板：
> 「目前这个球体就是有点透明，其中一个点是可以看到视野范围的那个边界……
> 我有点改主意了，我希望这个视野范围还是有一个高亮吧……**目前这个边界看起来太突兀了**。
> 或者你找一个就是有边界但不突兀的方法。」

这句话里其实是**两个问题**，我一开始只盯着第二个。

## 一、第一个问题：球体为什么"透明"

不是球透明，是**边界穿透了球体**。

v157.79 为了"边界永远看得见"，给材质设了 `depthTest: false` ——
它让三角带**无视前后遮挡**，于是球背面的那段边界被直接画到正面上来。
看上去就像球是半透明的，而且能看到"其中一个点"的边界。

当时的理由是「边界是 HUD 级信息，不该被地形遮挡」。这个判断对，但**手段错了**：
`depthTest:false` 是"连球体一起无视"，不是"只无视地形"。

**修法**：`depthTest: true` + `polygonOffset`。
- `polygonOffset` 对 **Mesh** 是生效的（之前踩的坑是 `GL_LINES` 不支持它）；
- 所以既能参与遮挡，又不会和地形打架，**不需要再把带子抬起来**（抬高就是"壳"）。

实机验证：把球转 180° 让探明区到背面，正面**看不到任何边界**。

## 二、第二个问题：边界为什么"突兀"

前后试了三版，都是实机图看出来的：

| 版本 | 做法 | 实机结果 |
|---|---|---|
| v157.79~81 | 对称 4 顶点细带，白 `#dFF2ff` / 0.72 | 一根硬白线，六边形折角很扎眼 |
| 82a | 降到 0.30 + 改成淡青 | 还是"一根线"，只是淡了点 |
| 82b | 改成**单侧向内偏移**（每条边朝自己的格中心推） | **白色虚线** —— 相邻边在拐角处方向突变，带子错开成碎片 |
| **82c（本版）** | **对称 6 顶点宽带**（+s / 中线 / −s）+ 横向渐变 | 一圈柔光，折角被渐变压平 |

结论：**问题不在亮度，在形态和宽度。**

- 只要带宽是"几像素"，它就一定读作"线"，而线一定显出六边形硬折角；
- 单侧偏移会让相邻边在拐角错开 → 虚线；
- 对称带 + **6 顶点**（多一个中线顶点）才能在横截面上贴渐变，一条带自带柔光。

### 最终参数

```
几何：每段 6 顶点 / 4 三角形（3 个横向位置 × 2 端）
带宽：HW = 4.5（总宽 9 世界单位 ≈ 3/4 格）
渐变：u=0 透明 → u=0.5 峰值 0.20 → u=1 透明（1D canvas 纹理，ClampToEdge）
抬升：LIFT = 0.12（几乎贴地，只防 z-fighting）
材质：depthTest: true · polygonOffset(-4,-8) · DoubleSide · depthWrite: false
```

峰值只有 0.20，但带宽足够，叠起来是"一圈光"；折角被 9 个单位宽的渐变抹圆。

## 四、断言

`§586j 标识面` 按新实现重写（规则变更，不是删也不是放宽）：

| 判据 | 说明 |
|---|---|
| `_fogEdgeGradTex` + `uv` 属性 | 渐变方案在岗 |
| `segs * 6 * 3` / `segs * 12` / `u=0.5` | **6 顶点结构**（退化回 4 顶点就贴不了渐变） |
| `HW = 4.5` / `LIFT = 0.12` | 宽带 + 几乎贴地（反向禁止 LIFT ≥ 1 的"抬高"） |
| **`depthTest: true`** | **本次核心反向守卫**：谁再关掉它，边界就又会穿透球体 |
| `!depthTest: false ... polygonOffset` | 不许出现"关遮挡 + 靠 offset 兜"的组合 |
| `depthTest: !!(_fogEdgeMesh && ...)` | 探针必须能读出"参不参与遮挡"（上一版就是这里瞎了） |

## 七、诚实说明

1. **六边形形状还在**：视野是按格子算的，边界必然沿六边形走。
   本版做的是"让它读作一圈光而不是一条线"，不是"把六边形画圆"。
   真要画圆得对边界做平滑重采样，属另一条（成本高，且会让"边界=格子边"语义变模糊）。
2. **远景看不清**：拉到 `frac=0.82`（星球只占屏幕十几像素）时，任何边界都看不见。
   这不是 bug —— 那个距离下地形本身也看不清。
3. 峰值 0.20 是**单段**不透明度，相邻段在拐角重叠会叠到 0.3 左右，看起来比单段亮一点。
