# 新手视角全功能走查：卡点在哪、怎么修（v158.18）

> 老板 2026-11-25：「假设你对游戏任何设置均未知，新手玩游戏，探索所有功能，任何卡点都需要解决。」

## 一、怎么走查的

不调 `GAME.newGame()` 跳过界面 —— **清档**后走真实 UI 流程（打开页面 → 创角 → 点「开始新的征程」→ 逐屏），
用探针 `p_newbie.js` 把每一屏的**全部可见文案 / 按钮 / 输入框** dump 出来，再逐个点开 **69 个面板**看它们说什么。

判据一律用数值 / DOM 结构，截图只作人眼复核（headless 下 rAF 被节流，截图要等 ≥2.5 秒真帧）。

## 三、逐条怎么修的

### ① 任务链接到可见 HUD（`js/ui-mapui.js`）

新增 `ui.renderQuestHint()` —— 照 `#interact-hint` 的**既有范式**：

- 挂 `ui.layerRoot()` 唯一挂载点，独立 `#quest-hint`，出口挂 `GAME.ui.*`（不新增顶层全局）；
- **sig 去重**：只在步骤 / 视图变化时写 DOM，不每帧重写 innerHTML；
- 接线两处：`ui.setView`（切视图）+ `map3d` 渲染循环（跟随态 / 街区态实时跟）；
- 任务链走完 `Q.hint()` 返回空 → 自动收起。

### ② 城内给「去大世界」入口（同一条 HUD）

非跟随态时多一枚 `data-action="follow-toggle"` 的「🧍 去大世界走走」——
**走既有出口**（`setFollow` 同一开关，Tab 同键切换），不新开入口、不新建坐标系。

### ③ 创角文案改回如实（`index.html`）

「给这支队伍起个名」→「给君主起个名」；
「你还一座城都没有 —— 先把人带出去，活到能立城那天」→「你有一座刚立起来的城 —— 先让幸存者活下去，再把城做大。」

v116 那两句针对的是**前传**（50 人 / 两辆车 / 没城），v157.85 老板拍板前传整段退役后，文案没跟着更新。

### ④ 迁址去代码术语（`js/ui-space.js`）

| 原来 | 现在 |
|---|---|
| 只可迁到**平原**空地（球系：填格索引 ci） | 只可迁到**平原**空地（地图上点一格，面板里会显示它的格编号） |
| 格索引 ▭ | 目标格编号 ▭（填地图上那一格的编号） |
| 当前坐标 302°E -63°N（球系） | 当前坐标 302°E -63°N |

### ⑤ 围墙退役三条假承诺（`js/data.js` + `js/ui-build.js`）

desc 原来写「耐久 100×N 万，守军防御 +10N%，远程射程 +3N%」。

查实现：`domain.js` 只有 `var base = city.def + wallLvl * 20`，全库没有墙的 HP、没有百分比加成 ——
`tactic.js` 的注释自己就记着「另外两条从未落地」。

按老板口径「没有实质游戏内容支持 = 假动作，退役空设定」，改成与实现一致：
「铁皮石垒，御敌于外 —— 每级 +20 城防（守军减伤），城头火力随城防放大（守方射程）。」

### ⑥ 地形图例用全名 + 全名唯一出口（`js/ui-shell.js` + `js/ui-craft.js`）

新增 `ui.resFull(k)`（读 `DATA.RESOURCES`，与 v158.17 在 ui-mapui 里建立的 `resFull` 同一口径），
地形图例改用它 → 「可采：净水 / 生物质 / 电能 / 废钢」，不再是单字。

### ⑦ 建筑专精补门槛说明（`js/ui-build.js`）

「建筑专精 Lv12 → Lv24 → Lv36」→「建筑专精 **本建筑升到** Lv12 → Lv24 → Lv36」。
把 12/24/36 是**这座建筑的等级**这件事说清。保留 `Lv12 起` / `下一档 Lv24` 原字串（smoke 有逐字断言）。

### ⑧ 状态栏加悬停解释（`js/ui-city.js`）

- 民心/民怨：「民心 = 100 − 税率×100（±安抚）。民心低、民怨高会闹事：产出下降、兵源减少」
- 税率：「按百分比抽走产出：税率越高进账越多，但民心越低、民怨越高」

⚠️ title 放**外层 div**，内层 `<span class="lbl">民心 / 民怨</span>` 逐字不动（smoke 有断言锁）。

### ⑨ 十三区加悬停说明（`js/ui-modal.js`）

每枚区 chip 挂「首府 + 特产 + 风土」，走 `DATA.STATE_SPECIALTY` 唯一数据源（与选中后的预览同一份数据）。
随机模式补一句「选区只影响出生位置与周边特产，不影响难度」—— 新手最怕"选错就难很多"。

### ⑩ 星球生成器 title 说明"不影响当前星球"（`js/ui-report.js`）

名字是老板 v90.73 亲自定的，**不改**。只补 title：
「设置要素参数，生成一颗新星球作为独立副本（不影响你当前的星球；也能在这里查看 / 进入已生成的星球）」
—— 新手最容易把这个入口当成"会重置世界"而不敢点。

## 四、撤销的两条误判（取证时纠正自己）

1. **「税率± / 城市随机点了没反应」**：实测 `doSetTax` / `doRandomCityMove` **都有 toast**
   （`税率：50%　民心 50 / 民怨 50`），是我的探针只查了 modal 没查 toast。**卡点不成立，撤销**。
2. **「君主面板『点「」』文案截断」**：实际文案完整（「到目标城的政务厅点『设为主城』」），
   是我的 dump 截断到 110 字符造成的假象。真问题是**"政务厅在哪"**（它是开局自带的一座城内建筑，
   新手不知道）—— 已补「（城内那座 🏛）」。

## 六、没做/留待的

- **城市没让起名**（开局城名固定"新城市"）：改名入口在政务厅「📝 修改城名」，属于"知道路径就行"，
  没动创角流程（加一个城名输入框会动到 `newGame` 的入库路径，风险大于收益）。
- **顶栏 15 个页签**（含「插件」「空间站」「自动」）：这是既有系统分区，不是本轮新增；
  改分区名会牵动几十条 `querySelector('[data-view=xxx]')` 断言，未在无授权下动。
