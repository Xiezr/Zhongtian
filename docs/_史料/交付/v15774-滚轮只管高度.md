# v157.74 · 滚轮只管高度，不再自动转移相机方向

## 一、需求（老板逐字）

> 「滚轮只管高度，不要再自动转移那个相机的方向。」

## 二、根因：`placeCamera` 里的「交班偏移」

```js
// 退役前（v157.50 加的）
var _hEl = 0;
if (M._surfDir && !camO.lookPitch) {
  var _hm = _handoffMul(_rAlt);              // 62m = 1 → 95m = 0
  if (_hm > 0.0001) {
    var _elS3 = Math.asin(_surfDir · 径向);
    _hEl = (_elS3 + Math.PI/2) * _hm;        // 轨道基准（看球心）= −90°
  }
}
var _lpEff = camO.lookPitch + _hEl;
```

`_handoffMul(rAlt) = 1 − smoothstep(62, 95, rAlt)`：**离地 62 米满值、95 米归零**。
于是滚轮一动，视线就按高度被连续拉向「看球心」—— 这就是「自动转移相机方向」。

**它为什么存在**：v157.50 老板说「滚轮不能有距离跳变；视线在阈值处要全面平滑」，
它是为了消除「出地表那一下视线硬切 75°」而加的过渡。

**本轮为何必须删**：过渡的作用域是「离地 62~95 米」——那是一大片滚轮必经的区间，
所以它不是修一个瞬间，而是让**整个拉远过程**都在自动转视角。老板的诉求是
「高度归滚轮、角度归右键」，两者不能共存。

## 三、改法

| 项 | 处置 |
|---|---|
| `var _hEl` + 按高度融合 | 整段删除 |
| `_lpEff` | 改为 `= camO.lookPitch`（只等于玩家右键的偏移，无任何高度项） |
| `_handoffMul(rAlt)` 函数 | 整条删除（唯一消费者是 `_hEl`） |
| `M._handoffMulProbe` 探针 | 整条删除（唯一消费者是旧断言） |
| `§243①r` 断言 | **按反转后的规则重写**（不许删、不许放宽） |

### 断言新口径（规则变更三件套）

- **反向证据**：`function _handoffMul(` / `_handoffMulProbe =` / `var _hEl =` / `_hm = _handoffMul(`
  四种**定义/赋值形态**必须为零（墓碑注释里允许提到名字，所以按形态判、不按字样判）。
- **正向**：`var _lpEff = camO.lookPitch;` 必须在（没有叠加任何高度项）。
- **下限（防平凡解）**：`function placeCamera()` 与 `cam.quaternion.copy(camO.quat)` 必须仍在 ——
  证明不是把整段删空换绿。
- **保留面**：`var _tooSteep = _elPrev < (-65 * Math.PI / 180)` 与
  `M._surfDir = _prevF.clone().normalize()` 仍在 —— 进地表那一刻「接手当前真实视线」是
  模式切换的交接，与滚轮无关，不属本轮退役范围。

## 四、明确保留（与滚轮无关的转向）

- **右键拖动**：轨道 `camO.lookYaw/lookPitch`、地表转 `_surfDir` —— 唯一能改朝向的入口。
- **双击右键回正**：一次性操作，玩家主动触发。
- **进退地表的方向交接**：`_surfDir = _prevF`（进）/ `_wasSurfV` 清偏移（出）。
  这是**模式切换**（平视相机 ↔ 轨道相机），不是滚轮转向。
- **贴地模式的 `lookDistAt` / `pitchAt`**：只在地表链路用（4 处调用全在贴地分支），
  不参与轨道滚轮。

## 六、诚实缺口

1. **出地表那一刻仍有一次方向交接**（`_wasSurfV` 清 lookYaw/lookPitch → 视线回「看球心」）。
   这是模式切换不是滚轮转向，不属本轮范围；若觉得那一下突兀，正解是「一次性把地表朝向
   换算成轨道的 lookYaw/lookPitch」保住视角 —— 那是一次独立的交接改造，本轮没做。
2. **贴地模式看到的仍多是俯视**（`_surfDir` 继承进入前的轨道朝向 ≈ 看脚下），
   要看地平线得自己右键抬 —— 与 v157.60「滚轮只负责高度，右键负责角度」一致，是既有口径。
3. 模糊纹理（`agl=55/35` 截图里地表发糊）是 globe 384² 纹理放大所致，与小地图层无关，本轮未动。
