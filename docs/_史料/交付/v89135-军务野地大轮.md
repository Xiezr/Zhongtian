## 2. 过程抓出的真 bug（本轮自己埋自己抓）

1. **驻守把 `cityId` 置 null → 打穿全网"按城过滤"的界面**（江湖游历君主在城、任命候选…）。
   实机 e2e 的 v88/v89 江湖段**整条链 12 条红**（flaky：后台观战战斗落账时机不定）——
   诊断链：`DBG135`临时日志 → 定位"观战战斗的 `_settleBattle` 在 v88 段落账"。
   **修**：驻守**不改 cityId**（编制城保持，"人在野地"由 status 表达）+ `assignGeneral` 加硬闸（出征/采集/驻守中不可任命）。
2. **"占领/派驻"的驻留条件由观战结算共用**——属正常路径（那场仗确实打赢了），修好状态语义后自然闭环。
3. 实机脚本自身两个坑：摆野地没扫真地形格（平原不可采→无开采键）；官府 Lv1 时民房上限=1（无升级键）——脚本修正。
