## 二、逐条改了什么

### ① 街区里画「我自己」（`js/district.js` + `js/map3d.js`）

```
D.avatarOf() → { ci, local:[x,y,z], yaw, visible, scale }
```

- 主角网格 `buildAvatar(root)` 挂在街区 root 上（和载具/居民同一个父亲），局部坐标直接用 `D.pos/D.yaw`；
- 尺寸 1.21 × **1.42 ≈ 1.72 米**真人（实测包围盒 1.62m；NPC 1.21m、民房 ~3m，同一把尺子）；
- 背包摆在 +Z（正前方是 −Z），第三人称镜头正好看到后背 —— 一眼读得出"这是背对着我的我"；
- `syncAvatar()` 每帧跟位、走路摆腿摆臂、上车时收起；
- **同时** `map3d` 渲染循环里街区态 `figRoot.visible = false`：球面那只小人整组收起。
  不收起就会画两次 —— v158.16 实测"画面里有个人，离我 9.45 米"就是这个。

### ② 走出南边即回星球（`js/district.js`）

- `D.step` 末尾只举 `_out` 标记，收街区**仍走 `D.exit` 唯一出口**（不自己写 `active=false`）；
- 有墙的城：门线 `plan.outZ` + 门洞净宽（`|x| ≤ gateHalf−0.25`）双判据 —— 站在墙缝里也出不去；
- 无墙的城（城墙还没建）：`bounds.z1` 就是南界；
- 北/东/西只是夹边，**不举标记**（反向守卫钉住）；
- 地面往南铺到 `bounds.z1`（原来门外 2.6 米悬空，走出去像踩空）；
- 有墙的城补画围墙（1.5m 高 —— 低于第三人称视线在墙线的 1.75m，不挡人）+ 门楣；
- HUD 文案随 `plan.wall` 变：「走出南门即回星球」/「走到南边尽头即回星球」。

### ③ 导航按钮同时搬人（`js/ui-space.js` + `js/map3d.js`）

`回主城 / 回本城 / 灰烬城` 三个按钮补 `navMovePerson()` → `map3d.gotoXY()` → `setPlayerPose`。
`fort-goto`（定位据点）这类"看一眼"的跳转**半步不动人**。

**顺带修掉一个错位态**：`teleportTo` 换格时不撤街区 —— 会造出"人已到野地、街区还亮着"，
于是 `gotoXY` 看到 `D.active && D.ci === ci` 以为"我已经在这儿"，把「回本城」挡成空操作。
现在 `teleportTo` 换格先 `D.snapshot = null; D.exit()`（不还原旧位姿）。

### ④ 未探明格（`js/ui-mapui.js`）

区块标题 →「资源地块 · 未勘探」；提示 →「勘探不花资源、立刻给出丰度与储量；不勘探不能建采集场」。

### ⑥ 夜面底数（`js/map3d.js`）

`(1−term)+term*(0.35+0.65·sunL)` → `(0.55+0.45·sunL)`。

`sunL=1` 时仍是 1.0 —— **日面逐位不变**；夜面 0.7075 → 0.7975。
原来夜面还要再乘地形起伏的归一化系数（≈0.75）→ 只剩 **53%**，实机就是"整颗星球糊成一片暗"。

### 顺手记下的两个坑

1. **headless 截图可能是旧合成帧**：rAF 被节流时，手动改相机后立刻截图拿到的是几秒前的画面
   —— 本版头两张图就是"球面城市"的旧帧，差点被误判成"街区渲染全错"。判据一律用数值
   （投影 NDC / 包围盒），截图要等 ≥2.5 秒真帧。
2. **`§589bb` 的魔法窗口**：原判据 `slice(i, i+1200)`，本版在同一个函数里加了一段提示逻辑，
   把 `getElementById('follow-hud')` 挤出窗口 → 假红。改成"整段函数体"（到下一个函数名为止）：更严且不怕行数变化。
