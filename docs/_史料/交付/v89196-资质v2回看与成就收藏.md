## 四、雷达圈改地块边界折线（静态）（老板 6）

**病根**：v89.194 画的是**椭圆弧**＋相位呼吸（"晃眼"），且"圈"与"覆盖了多少格"不完全对应。

**改法**（`GAME.map.fortRingOf(R)` 唯一出口）：
- 边界 = 覆盖格集合（`dx²+dy² ≤ R²`，与 `fortAuraAt` **判定同源**）的**外轮廓**——
  每格 4 条边中"邻格不在集合内"的那几条；等距投影下每条格边都是菱形斜线 → 外周呈**锯齿折线**；
- **按 R 缓存**（段集合只与半径有关，渲染时平移 + 投影）；环连接供填充（无向走法）；
- **静态**：相位动画/内圈刻度整条退役；填充 `.055`、描边 `.55` 固定透明度。

**实测**：`fortRingOf(1).segs = 12`（手算锚）；段数 == 环长（同构）；缓存同对象。
实机：环带 g 增量 **74**（折线在）；**两帧 108 点像素 diff = 0**（真静态）。

## 五、成就型收藏（老板 7）

**两段式**：① **解锁**（完成特定任务，实时判定不存档）→ ② **激活**（花金币 = 原 price 入藏）。

- **条件池 16 类**（取值出口 `collectCondValOf`）：win/conquer/wild/gather/scout/fort/rank/lordLv/bldg/rep/
  itemKind/recruited/trades/forged/trained/buildDone —— 全部来自**单调累计**（`s.stats`）或可读现值；
- **18 系条件模板**（`cond: { type, base, step }`，件 n = base + step×件序）：
  名将系→军事（胜场/占城/野地/采集/侦察/前哨/爵位/官府/君主等级）；佳人系→人文（声望/品种/招募/市易）；
  器物系→建设（打造/练兵/高阶征服/建成）；
- **闸口**：`collectBuy` 未解锁**拒且不扣金**；`collectBuySeries` 全解锁预检（不做半套）；
- **UI 三态**：🔒（条件 + 进度 cur/n，卡暗化）/ 已解锁（「激活」按钮）/ 已入藏（金框）；
- **实测**：73 件全解析（0 无条件）；未解锁拒（扣金 0）；达成可激活；集齐闸正确拦截。
