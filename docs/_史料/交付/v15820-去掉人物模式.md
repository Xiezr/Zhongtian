# 去掉人物模式：点哪，小人就走过去（v158.20）

> 老板 2026-11-26：
> 「去掉人物模式。只提示人物位置。我要让场景可交互，要让人物真实的走动起来。」
> 「我说了用真实人类的玩法去测试，别走你那莫名其妙的机器内容。这就是你测试通过的内容，一吨垃圾。」

## 一、先认账：方向错了

v158.18 / v158.19 我在做的是"把第三人称人物视角修好"——摆腿、转向、HUD 提示。
**但那不是老板要的。** 老板要的是**根本不要这个模式**：战略视角下地图上有个小人标着位置，
点哪它就真的走过去。我修的那套东西，本质是在给一个不该存在的模式打补丁。

## 二、这一版做了什么

### ① 「🧍 人物」模式整条退役

三处一起删（都留了墓碑注释说明去向）：

| 位置 | 原来 |
|---|---|
| `js/ui-space.js` 底栏 | 「🧍 人物」按钮（进入/退出第三人称） |
| `js/main.js` 按钮分派 | `case 'follow-toggle'` |
| `js/main.js` 键盘 | `Tab` 进出跟随态 |

`setFollow` 本身**保留**：点城池进街区时仍需要它做相机接管。但那变成**自动行为**，
不再是"玩家要手动切的一个模式"。同时 v158.18 加的「🧍 去大世界走走」按钮也一并退役
（它点的是已删除的 follow-toggle，成了死按钮）。

### ② 点地图 = 小人真的走过去

新增四个出口（都在 `js/map3d.js`）：

```
M.walkTo(ci)      → 设目标格
M.walkStop()      → 停下
M.walkTarget()    → 读目标（探针/调试）
M.stepWalkTo(dt)  → 每帧推进，到达返回 {arrived:ci}
```

渲染循环在**战略视角**下每帧调 `stepWalkTo`，到了就把交互交回去（`_openCellPanel`）。
所以「点哪走到哪」和「点哪看信息」是**同时**发生的：面板立刻弹、小人在背景里走过去。

**关键修法：球面大圆插值（slerp）**
第一版用"线性插值再归一化"，大角度下弧长会缩水、近对跖直接退化 ——
实测点远处那一格会**越走越偏**（dot 0.26、距目标 392m）。换成 slerp 后单帧位移
0.0783m（`WALK_SPEED 4.5 ÷ 60 = 0.075`），1 秒 4.7m，精确。

### ③ 未探明的格子也能走过去

这一条是"点了没反应"的**真正原因**：原来 `pickAt` 里 `fogHides(ci)` 在开面板之前就 `return` 了，
点一块没探明的地只会弹「派一队过去」，小人**一步不动**。

v151 的老注释写着「前传里点地图只做一件事：走路 / 就地动手」——**走过去本身就是探路**。
v157.85 前传退役时这条一起删了。这版把它恢复：`walkTo` 放到 `fogHides` 判定**之前**。

### ④ 脚底光环标位置（只提示，不放大）

历史账：v157.96 老板说「从没看见过小人」→ 加了「放大 ×3.2 + 青色光环」；
v158.7 老板说「大地图人物比城市还大」→ **两样一起收了**。

但真正让人"比城还大"的是**放大**，光环只是标记。这版单独把光环加回来
（`RingGeometry(0.52, 0.68, 28)`，半透明金色），**模型比例一点不动**。
战略视角下远远就能找到自己。

## 四、两个把我坑了很久的点（记下来）

1. **测试格索引必须用 `M._collider.cells`（= `_tileCells`）**，不能用 `mapSphere.cells` ——
   那是另一套六边形索引（40962 vs 细分格）。我第一版混用，起点目标全是错格、距离 392m，
   看起来像"走路有 bug"，其实走得好好的。**这是测试工具的错，不是产品的错**，但浪费了很多轮。
2. **`#mapCanvas` 上有两个点击监听器**：`main.js` 的 2D 兜底（`GAME.map.pick` → `openLandModalCi`）
   和 `map3d` 的 `pickAt`。实测是 **2D 那条先响应**，所以只改 `pickAt` 等于没改。
   两处都接同一个 `walkTo` 出口才对。

## 五、还没做的

- **走远时镜头不跟**：小人会走出画面（相机是战略视角，不动）。如果老板要"一直看得见"，
  下一步做**镜头平移跟随**（不是贴脸第三人称，是"镜头缓缓跟着主角走"）。
- **街区里仍是 WASD + 第三人称**：这版只改了地图层。街区要不要也改成"点地走"，
  等老板看了效果再说。
