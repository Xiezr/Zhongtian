# v157.72 · 退役「任务型地块标色」+ 地块面板收到一层

## 一、需求（老板逐字）

> 「去除那些任务型地块标色并退役任务。地块统一一层菜单，不要加地块操作这一层」

两件事：① 地图上「任务型」的标色去掉，并把「任务」这一层退役；② 点地块只要一层菜单。

判据照 `AGENTS.md:313`：只改变文本 / 只多一次点击、不增加玩家能按的新东西 —— 就该退役。

## 二、取证

### 2.1 「任务型地块标色」的真身

`js/map3d.js` 的 `buildFlags()` 里，v151 加过一段「雾里有动静的格子自己发光」（注释原话
「地图自己就是任务板」）：在君主视野 ≤10 环内，把「有荒野事、且已探明」的格子涂成暗金
`[196,158,74]`、`cellKind='actspot'`、`cellRef={actspot:true}`。

`actspot` 全仓只有 3 处引用（写入 + 白名单 + 另一处检查），没有 UI 面板、没有独立数据表 ——
它纯粹是**地图上的一个颜色提示**，退役范围干净。

**决定性依据：这不是新决策，是补一个遗漏。** `state.js:6062` 的注释写着老板 v89.45 的原话：

> 「将野地的荒野行动板块**剥离，不体现在游戏中，但资产保留**」

实现是 `GAME.jianghuWildMounted = false`，注释明确列出它关掉的四处呈现：「面板区块 / 点选状态行 /
**地图青旗**」，并要求「底层资产与逻辑全部保留，后续改回 true 即可恢复」。
**2D 青旗、面板区块、状态行都老老实实遵守了这个开关；唯独 v151 后加的 3D 暗金块
（`buildFlags` 里只看 `jianghuActsAt` 存在与否）绕过了它** —— 所以地图上还留着任务点。
本轮删 3D 暗金块，等于把它拉回 v89.45 已拍板的口径。

⚠️ **「任务」在本项目的两套含义要分清**：
- 正式的 `questdata.js` 任务系统（`DATA.QUESTS` / 随机任务 / 任务汇总）**早在 v90.92 已整系统退役**
  （见 `data.js:5344`、`domain.js:8521/8531` 墓碑），现在没有第二套任务系统可退。
- 所以本轮「退役任务」= 退役**「地图即任务板」这一层提示**，不是再删一遍旧任务系统。

### 断言口径（按 §0.7 规则变更三件套）

旧断言要求「点击必须先经 `openCellMenu`」，本轮规则反转，于是：

- **正向**：`map3d` 里存在 `M.openCellPanel(ci);`（直达）；
- **反向证据**：`ui.openCellMenu` 无赋值、无调用；`main.js` 无 `case 'cell-menu-`；
  `ui-mapui.js` 无 `'🗺 地块操作'` 标题、无 `data-action="' + b[1]` 这种按钮生成形态；
- **下限（防平凡解）**：`§586n` 要求 `cellKind[...] = 'wild'` 仍在 —— 证明 `cellKind` 体系没被顺手删掉，
  不是「整段删空所以绿」。

## 四、明确保留（退役的是提示层，不是能力）

- **荒野行动内核 `GAME.jianghuActsAt` 未动**：它仍是前传探索 / 斗将 / 场景动手共用的唯一判据口。
  `§586n 保留面` 断言 `prologue.js`、`scene3d.js` 仍在消费它，而 `map3d.js` 已脱钩（仅墓碑提到）。
- **侦查 / 掠夺 / 占领 / 一键出征入口全部保留**：走详情面板的 `exp-open`。
- **`cellKind` / `cellRef` 体系保留**：`pickAt` 仍按 kind 分发到城市 / 攻打 / 据点 / 野地面板。
- 不改 `_markers` 的其他标记（据点 / 名城 / 行政城 / 己方城）—— 那些是**势力归属**，不是任务提示。

## 六、诚实缺口

1. **任务型标色删掉后，地图不再预告「哪格有荒野事」**。玩家要么点开地块看，
   要么靠 `cellBrief` 悬停情报。这是老板要的「不在图上做任务指引」的必然结果；
   如果之后觉得「找不到事做」，应该从「点开就能看到」这条路上补，而不是把标色加回来。
2. **前传（`prologue`）里原本也有同一层标色**，随同一段代码退役；前传的「往哪走」提示减少一处。
   前传默认不开（`newGame` 需显式 `prologue:true`），影响面有限。
3. 荒野行动内核保留，意味着**「能不能做事」没变，只是「地图上不再标出来」**。
   若老板要的是连内核一起退役（会影响前传立城前的唯一玩法、斗将入口、场景动手），
   那是另一个范围，需单独拍板 —— 本轮按「退役提示层」处理，未擅自扩大。
4. **2D 方格图的「灵机旗」不动**（`map.js drawJhPennant`）：它受 `GAME.jianghuWildMounted`
   控制，`state.js:6067` 初始化为 **false**，按 v89.45 已是「不体现」状态；
   而老板同一句拍板里明确要求**资产保留**（改回 true 即恢复），删它反而违背原话。
   它与地块面板的「荒野行动」区共用一个开关，所以本轮只删**绕过开关**的 3D 暗金块。
5. 地图上不再有任务点后，`jianghuActsAt` 仍会在**点开地块时**给出可做的事（受上述开关约束）。
   若之后觉得「找不到事做」，应从「点开就能看到」这条路补，不要把标色加回来。
