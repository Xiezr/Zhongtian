**老板原话（2026-11-16 11:54）**

## 一、取证：色块到底是什么

地图上的"色块"是**整格涂色层** `M._cellTint`（`MeshBasicMaterial`，`opacity 0.55`，`renderOrder 19`）。它有 **6 类来源**：

| 颜色 | 来源 | 含义 | 出现在 |
|---|---|---|---|
| 褐 `[150,112,70]` | `trace` | v92.6 **半信息痕迹**：迷雾边缘按概率泛色，表示"那边有东西" | **只在未探明格** |
| 金 / 绿 / 暗红 | `camp` | 幸存者营地（待交涉 / 已招募 / 已洗劫） | 已探明 |
| 暖白 / 亮绿 / 暗灰 | `village` | 村社（有人 / 你护着 / 空村） | 已探明 |
| 青 / 暗青 | `ruin` | 旧世界遗迹（待翻 / 已翻） | 已探明 |
| 旗色（蓝/绿/暗红） | `own` | 我方前哨 / 我方野地 / 阵亡纪念 | 已探明 |
| 暗红 | `memorial` | 阵亡地点 | 已探明 |

### 根因：`_tint` 只存颜色，不存"为什么上色"

- `buildFlags()` 里每一类都只写 `_tint[ci] = [r,g,b]`，**没有任何地方记录这是哪一类**。
- 悬停走 `M.cellBrief(ci)` → 未探明格的 `hidden` 分支**直接 return**：
  `facts: ['这一带还没有记载']`。而褐色痕迹**恰恰只出现在未探明格**（`if (fog.get(_ti) !== 0) continue`）
  → 于是悬停对着褐色块只能说"这一带还没有记载"，**一个字都没解释那块褐色**。
- 点击走 `_openCellPanel` → 未探明格 `kind` 是 `wild` → 开野地面板，里面也没有"这块色是什么"。

**这是"信息没接上"，不是"设计不给"**：v92.6 的设计是"知道有东西、不知是什么"，
但连"这块颜色代表有东西"都没说，玩家只能对着色块猜。

## 二、改法（同源记录 + 两处显示）

### 2.1 涂色时同源记来源

```js
var _tk = {}, _tkOwn = {};      /* v157.77：色块来源表 */
...
_tint[_ti] = [150,112,70];  _tk[_ti] = 'trace';
_tint[ci]   = col;          _tk[ci]   = 'camp';
_tint[_vci] = ...;          _tk[_vci] = 'village';
_tint[ci]   = ...;          _tk[ci]   = 'ruin';
place(ref, hex, kindW)  →  _tkOwn[ci] = kindW || 'own'
for (var _ok in _tintOwn) { _tint[_ok] = _tintOwn[_ok]; _tk[_ok] = _tkOwn[_ok] || 'own'; }
M._tintKind = _tk;             /* 悬停 / 面板共用，与涂色同源 —— 不会"颜色和说明不一致" */
```

选这个做法而不是"再写一份颜色→含义对照表"：对照表会和实际涂色**漂移**
（改了一个颜色忘了改表，就又回到"说不清"）。

### 2.2 悬停（老板给的二选一之一）

`_cellBrief` 的未探明分支拆成两种：

```js
if (_tkH === 'trace') {
  out.facts.push('地面泛着暖褐色：这一带似乎有动静（不知是什么）');
  out.tasks.push('派一队过去探明 —— 抵达后才知道是什么');
} else {
  out.facts.push('这一带还没有记载');
  out.tasks.push('派一队过去（点它 = 派队），抵达后周围显现');
}
```

**仍然不说"是什么"** —— v92.6 的半信息口径是设计（断言里有反向守卫，禁止把它写成"是营地/是遗迹"）。

另外在已探明分支末尾加**兜底**：任何上了色的格子，只要前面各分支没认出来，
就补一行 `地面标记：<来源名>`（`TK_DESC` 六类，`indexOf` 去重）。

### 2.3 点击（二选一的另一个，一起做了）

`_openCellPanel` 开头：未探明 + 痕迹格 → `ui.toast('这一带似乎有动静（未探明）—— 派一队过去才知道是什么')`，
**不改变任何流程**（该派队还是派队），只回答"这块褐色是什么"。
