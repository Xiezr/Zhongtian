# v158.57 · 高空飞行：平飞保高 / 引力下沉 / 着陆程序

## 一、老板原话

> 高空飞行在不改变海拔时，不应该相对固定高度吗？然后由于引力逐步下降。设计着陆程序

## 二、先取证：旧行为到底怎么错的

`.workbuddy/tmp/diag_v15857_alt.js`（真浏览器）实测：

| 场景 | 旧行为 | 判读 |
|---|---|---|
| 无输入 6s | 570.0 → 570.0 | 静止不动（正常） |
| 水平切向 v=80 飞 6s | 570.0 → **694.6（+124.6m）** | 沿切线走直线＝一点点飞出星球，**没有高度概念** |
| 鼠标纯水平右移 4s | 机头俯仰 **+37.67°**，alt +130m | 绕机体 up 转 yaw 带出径向分量，"左右看"变"往上爬" |

## 三、怎么改

### 机头拆成两件事

```
head = 切向方向 × cos(pitch) + 径向 × sin(pitch)
```

- **切向方向**：往哪飞，永远留在当地切平面里。
- **俯仰角 pitch**：相对当地水平面，单独按 `FLY_PITCH_RATE(0.9 rad/s)` 配平。鼠标有指示 → 取 aim 的仰角；松手 → 回 `FLY_TRIM(0)`。

配套三处修正（每一处都是实机/探针抓出来的）：

1. **偏航轴改回当地径向**：v158.55 为防极点翻转把 aim 的 yaw 轴设成机体 up，但机体 up 转向后有横向倾斜 → 水平输入带出 16.6° 俯仰。改 `setFromAxisAngle(rad, -yaw)`。
2. **俯仰角单独锁定**：`fly.aimPitch` 存一次算出的角度。若每帧从世界方向 `asin(aim·radial)` 反算，沿球面飞远后径向转 45°，同一世界方向的相对仰角会变（实测 15.8°）。
3. **位置贴回球面**：先沿机头推进得真实弧线，再 `pos.setLength(holdR)`；`holdR -= sink·dt`。

### 引力模型

```
sink = GRAV_SINK·cos(pitch) − v·sin(pitch)      /* GRAV_SINK = 1.0 m/s */
```

- 平飞（pitch≈0）→ sink≈1.0 m/s，**高度自然衰减**；
- 抬头把 `v·sinθ` 顶过引力 → sink<0 → **爬升**；
- 低头 → sink 变大 → 快速下降。

### 着陆程序

| 项 | 口径 |
|---|---|
| 触发 | 离地 < 26m 且仍在下沉 → 自动（toast「高度过低，自动着陆」）；空格也可手动 |
| 落点 | `max(R+眼高×1.5, 地形高+眼高)` —— 山上方落地，不是山里 |
| 时长 | `clamp(|r0−r1| / 26 m/s, 1.8, 7)`，随高度自适应 |
| 阶段 | 前 35% 压机头 + 减速归零；后 65% 按半径 smoothstep 下降 |
| 交班 | 结束显式 `surfaceMode(true)`，`phase='dock'`、`active=false` |

### 顺带修掉的真缺陷

| 缺陷 | 现象 | 修法 |
|---|---|---|
| 尾迹线 | 相机永远吊机尾，尾迹沿 −head 指向相机 → 贯穿半屏的**竖针**（三次实机图） | 整条退役（`_shipTrail`/`fly.trail`/`FLY_TRAIL_MAX` 全删 + 墓碑） |
| 相机 up 退化 | 俯冲/降落时视线与径向近平行，`lookAt` 退化 → **战舰从画面消失** | `\|Δ̂·camUp\|>0.97` 时改用机体 up |
| 飞行下限没吃地形 | 22m 高度直接**钻进山里**，战舰被地形吞掉 | 下限改 `max(R+2.7, camFloorAt(rad)+4)` |
| `flyProbe().pitch` 字段冲突 | 旧 `pitch: camO.pitch` 覆盖新加的机头俯仰（读到 +24.2° 而实际 −28.6°） | 相机俯仰改名 `camPitch` |
| `flyLand` 清 `autoLand` | 自动着陆标记被自己抹掉 | 改由 flyLaunch / 落地分支统一清 |

## 六、诚实缺口

1. **平飞仍看不到星球**：机头水平前飞，相机视线为把战舰压到下方 2/5 抬高约 11.8°，球在视野下缘之外。方位靠 HUD 罗盘 + 离地高度。若要看到球，需压低 `FLY_SCREEN_Y` 或让相机额外俯视 —— 与"战舰在下 2/5"冲突，需老板定。
2. **引力是稳态下沉率模型**（1.0 m/s 常量），不是 9.8 m/s² 自由落体。游戏要的是"高度自然衰减"的手感；要更真实可改 `FLY_GRAV_SINK` 或按 `1/r²`。
3. **没有独立悬停键**：贴地低飞靠"抬头抵消下沉"实现。
