## 四、第 ④ 件 · 版本三连治理（老板「形成一个更加稳健的解决方案」）

### 4.1 现状盘点：三处版本标识

| # | 位置 | 改前值 | 性质 | 不同步的后果 |
|---|---|---|---|---|
| ① | `js/main.js` → `GAME.VERSION` | `v89.240` | **自证标识**（设置页「🧩 运行版本」显示，供判断"要不要强刷"） | 版本显示与实物脱节 → **误判** |
| ② | `index.html` → `<!-- BUILD n -->` + 全部 `<script src="…?v=n">` | `9172`（**17 处**） | **缓存击穿号**（浏览器缓存 key 的一部分） | **功能真的不生效** ← 唯一卡死项 |
| ③ | 档案行（`项目地图` / `需求档案` / `需求台账`） | `v89.240` | **档案**（只给人看，不参与运行） | 溯源断链 → **档案失真** |

### 4.2 为什么只有 ② 会让改动"不生效"

浏览器把 `js/ui.js?v=9172` 当作**一个完整 URL** 做缓存（HTTP 缓存以 URL 为 key）。
它与 `js/ui.js?v=9173` 是**两个不同资源**。所以：

- 改了磁盘上的 `js/ui.js`，但 `index.html` 里仍写 `?v=9172` → **URL 没变 → 浏览器命中本地缓存，连请求都不发** → 页面跑的还是旧逻辑。
- 把 `?v=9172` 改成 `?v=9173` → URL 变了 → 缓存里没有 → 必须去拉新文件 → 新代码生效。

本项目是**本地双击 `index.html` 直开**（无 HTTP 头可配 `no-cache`），所以只能在 **URL 层**用 `?v=` 击穿。

**这个坑项目踩过一次大的**（`docs/AI工作备忘.md` §99 / v89.77，2026-09-20）：

> **老板连着三轮报「还是不对」，而每轮查代码都是对的**……真正原因是 `index.html` 的 99 个
> `<script src>` 没有任何版本号，浏览器吃缓存。
> **教训：「改完必须能立刻看到」要靠机制，不能靠人记得按 Ctrl+F5。**

### 4.3 旧发版脚本（`.workbuddy/tmp/cachebust.js`）的三处缺陷

| # | 缺陷 | 后果 | 证据 |
|---|---|---|---|
| ① | 正则前缀约束 `(?:js\|story)/` | **漏掉 `vendor/three.min.js`** → 跑完**混版** | 对照实测：旧正则 `?v=` 种类 = `['9172','9173']`；新正则 = `['9173']` |
| ② | `writeFileSync` 写在**自检之前** | 不自洽时**已落盘、无回滚** | 源码：写盘在第 27 行，自检在第 33 行 |
| ③ | 躺在 `.workbuddy/tmp/`（临时目录） | 有被清理、**机制蒸发**之虞 | 文档仍指向 tmp 路径 |

### 4.4 处置

| 处置 | 内容 |
|---|---|
| **脚本重写 + 迁址** | `.workbuddy/tmp/cachebust.js` → **`.workbuddy/tools/patch/bump_version.py`** |
| **修缺陷 ①** | 正则泛化为任意 `*.js`（含 `vendor/`），并保持**幂等**（先归一化再挂号） |
| **修缺陷 ②** | 改为**先自检、后落盘**：脚本数下限 `MIN_TAGS` · 全部同号 · BUILD 标记恰好 1 次且一致 · 自检未过**不写盘** |
| **修缺陷 ③** | 迁入正式工具位 `tools/patch/`（与其它发布/补丁脚本同处） |
| **补管第 ① 处** | 新增 `--version vX.YY` 参数，一次同步 `GAME.VERSION` |
| **原子落盘** | `tmp + os.replace` |

用法：

```bash
python .workbuddy/tools/patch/bump_version.py --bump                      # BUILD +1
python .workbuddy/tools/patch/bump_version.py --bump --version v90.94     # 一次同步代码侧两处
python .workbuddy/tools/patch/bump_version.py --check                     # 干跑（不写盘）
```

放宽为格式锁后，**版本号正确性**改由 §199⑥（必须录进档案）保证 —— 比原来**更强**，不是更松。
