# 星球自转时「半径闪烁」

> 老板 2026-11-02：「星球自转过程中半径闪烁」

---

## 一、先把"闪"量出来

肉眼说"闪"没法修，先做成数字。写了四个探针：

| 工具 | 干什么 |
|---|---|
| `probe_globe_flicker.js` | 强制起转（`_lastAct=0`），连拍 N 帧只截 canvas |
| `probe_globe_radius2.js` | 72 条射线量「最外层亮像素半径」，算**同一方向**的跨帧 std |
| `probe_flicker_ab.js` | 消元法：A 原样 / B 摘掉大气壳 / C 再关线框，各拍一组 |
| `probe_scene_objects.js` | 把 3D 场景里所有对象连包围球半径列出来 |

改前实测：

```
平均 std 10.94px    std ≥ 1.5px 的方向 50/72
抖动最大的方向：320° std 28.5（均值 404.6，最小 356 最大 427）
```

`427` 这个数很关键：球体本体半径在画面上约 **356px**，而大气壳半径 = 356 × (355/300) ≈ **421px**。
也就是说，抖动全部发生在**球外那圈雾**上，球体本身纹丝不动。

水平方向的最外边界也一样：连拍 8 帧，右边缘在 **1113 ~ 1125** 之间跳（12px）。

---

## 二、根因：噪声和"边界"耦合在一起

那层大气壳的 alpha 是这么来的：

```glsl
float dens = smoothstep(0.40, 0.70, c1 * 0.72 + c2 * 0.28);   // 球面 fbm
float a = dens * 0.300 * uFade;
```

**先排除一个错误猜测**：我一开始以为是 `uTime` 让噪声自己漂。算一下就否掉了 ——
`uTime * 0.008`，八帧（约 1.1 秒）里 `uTime` 只走 1，fbm 的输入位移 **0.008**，肉眼不可能看出来。

真正的原因是**图案与边界耦合**：

> `d` 固定在星球表面 → 自转时那团雾从轮廓线上**扫进扫出** →
> "哪一像素还算大气"每一帧都换答案 → 外圈可见半径逐帧跳。

所以这不是"噪声在动"的锅，是"用噪声决定边界在哪"的锅。风一吹就闪，不吹也闪（星球一转就闪）。

---

## 三、修法：边缘必须由**确定的东西**决定

```glsl
// 顶点：补世界法线 / 世界位置
vN = normalize(mat3(modelMatrix) * normal);
vW = (modelMatrix * vec4(position,1.0)).xyz;

// 片元：
float rim = clamp(dot(normalize(vN), normalize(cameraPosition - vW)), 0.0, 1.0);
float edge = smoothstep(0.0, 0.45, rim);          // ① 确定性：只跟视线夹角有关
float cloudMask = smoothstep(0.30, 0.85, rim);    // ② 噪声赶出边缘区
float a = (dens * cloudMask * 0.92 + 0.08) * edge * 0.300 * uFade;
```

两条缺一不可：

- **① `edge`**：轮廓处（rim→0）恒为 0。边界位置**只由几何决定**，星球怎么转都不变。
- **② `cloudMask`**：`rim < 0.30` 那一段噪声不参与，只留 0.08 的均匀底雾。
  噪声再扫，也扫不到"决定边界的那一段"。

先只加 ① 不够 —— 实测 std 只从 10.94 降到 10.52，因为 `smoothstep(0.02, 0.30)` 太窄，
外圈 20px 环带里 alpha 仍有 0.2 以上，噪声还在决定边界。加上 ② 才真正干净。

## 四、改后

```
平均 std 3.13px（10.94 → 3.13，-71%）
水平直径：1113~1125（跳 12px）→ 1052~1053（跳 1px）
```

残留的 3.13px 主要是**测量污染**：球外的「灰岗」文字标签、陨石带碎块会被射线打到
（抖动最大的 300°/305° 方向正好指向左上角那行标签），不是球体在闪。

> 顺带解释一个数字变化：可见半径从 1119 缩到 1052，不是"球变小了"，
> 而是**外圈那层假半径（雾）没了** —— 1052 才是球体本体的直径。

---

## 五、断言：§593 三条

不钉数值（那是快照，会变），钉**结构**：

```js
§593① fragment 里有 rim + edge（确定性边缘）
§593② dens 与 cloudMask 相乘（噪声不进边缘区）
§593③ 反退化：`a *= smoothstep(...)` 这种"直接乘在 fbm 上"的旧写法不许回来
```

③ 是这条的核心 —— 少了它，下次重构把 `a *= smoothstep(...)` 加回来，
①② 照样绿，闪烁照样回来，而且没人会发现。
