## 四、S4 欠俸降忠诚 + 0 忠诚禁出征

**口径反转**（v14.1「欠俸只警示不惩罚」→ 老板本轮拍板）：
- `settleGenSalary`：欠俸的城 → 该城将领忠诚 **−10/期**（`DATA.LOYALTY.salaryDrop`）× 期数，**单次封顶 −20**（`salaryDropMax`）；**君主豁免**（v89.40 同源）。

- 月俸/忠诚/欠俸三处同源：`genSalaryOf`（唯一读数）→ 结算/合计/详情。

**实测证据（probe_v89194b）**：1 期欠俸 → 忠诚 100→90（君主 100 不变）；连欠 3 期 drop=20（封顶）；忠诚 0 → marchBlockOf 拦 + 不在可出征列表；恢复到 30 → 可出征。

## 六、前哨雷达圈（地图渲染 + 判定口径）

**渲染**（map.js，图层在"地块之上、标记物之下"）：
- 以己方前哨（`cityId` 非空）为中心，椭圆（等距投影下的逻辑圆：半轴 √2·R·HW / √2·R·HH）；
- **浅色**：填充 `rgba(140,220,170,.055)`（地块纹理透出，"不遮盖原地图地块"）+ 内圈刻度 `.14`；
- **边缘相对清晰**：主圈描边 `rgba(168,235,188,.42~.62)`、`lineWidth 1.6`，**相位扫描**（500ms 交替 = "雷达"呼吸）；
- 半径 = `GAME.fortRadiusOf`（唯一出口，逐哨 6~14 格）。

**⚠️ 口径变更（透明记录）**：覆盖判定由**切比雪夫（方阵）→ 欧氏（圆）**——老板要"圆形"圈，按"显示=判定"（唯一出口原则）把判定改成圆，**圈画多大、覆盖就多大**。
- 同档半径的覆盖面积由 (2r+1)² 缩为 πr²（约 **−29%**）；半径档位数值**未动**（6/8/10/12/14）。
- 回退（一句话）：`fortAuraAt` 的 `d² ≤ R²` 换回 `max(|dx|,|dy|) ≤ R` + 渲染改画菱形。

**实测证据（实机 · 环对比法）**：Lv3（R=8）圈半轴 498px——**圈上比圈内外亮 68.7**（删哨对照 15.1）· Lv10 大圈半轴 871px（超出画布半宽 660px，"只见弧"是正常渲染）。
