## 三、三个根因与修法

### 根因 1：云雾层按"离云层多近"**持续显示**（状态，而非事件）

```js
_in = 1 − |agl − hC| / (0.35·hC)        // hC = atmH ≈ 55 米
M._cloudVeil = _in;                      // ← 直接当不透明度用
```

agl 36~74 之间 `_in > 0`，**55 米处 = 1.000** → 停在那儿就永远糊一层斑。

**修法（穿云是事件，不是状态）**

| 量 | 口径 |
|---|---|
| `_burst` | 只由「跨过 hC」那一下触发，0.9 秒**二次衰减**（`(1−t)²`） |
| `M._cloudVeil = 0.62 × _burst` | 2D 云斑只在穿越那 0.9 秒出现 |
| `M._cloudHaze` | 真停在 hC±5 米时给 **8% 均匀薄白**（无斑块纹理） |
| 滞回 ±2 米 | 停在云层高度时 agl 微抖不许反复触发 |
| 单帧 \|Δagl\| > 400 米 | 视为瞬移（切城/读档），不铺白幕 |

⚠️ **踩坑记录**：第一版写成 `M._cloudVeil = _in * _burst`，实测滚轮全程 `veil = 0.000` ——
因为跨层那一刻 agl 已掉到钟形窗口边缘（`_in ≈ 0`），乘上去把"穿云感"一起修没了。
峰值必须**不乘 _in**，衰减交给 `_burst`。

### 根因 2：大气云壳的云纹在**球面正面最强**

```glsl
rim       = dot(normal, viewDir)          // 正对镜头 = 1
edge      = smoothstep(0, 0.45, rim)      // 正面 = 1（只压边缘）
cloudMask = smoothstep(0.30, 0.85, rim)   // 正面 = 1
a = (dens * cloudMask * 0.92 + 0.08) * edge * ATM * uFade * (1 + uIn*1.35)
```

这套设计是给"从远处看整颗球"用的：背面被球体挡住的边缘淡出、正面有云层。
但玩家从 100~200 米**俯瞰海面**时，头顶那层 fbm 云正好盖在海上 —— 就是一片片云影斑。

**修法**：新增 `uClean`（近景云纹抑制）

```js
uClean = clamp((agl − 120) / 260, 0, 1)   // 120 米 → 0 ｜ 380 米 → 1
dens2  = dens * uClean                    // 云纹乘它
a = (dens2 * cloudMask * 0.92 + 0.08) * ... // 0.08 的均匀底雾保留
```

远景（>380 米）看整球云层照旧；中近景只剩 8% 均匀薄雾，不再有成团云影压在海面上。

### 根因 3：海面法线扰动 + 镜面高光过强

```glsl
amp  = 0.42 * vFar * (0.32 + 0.68*dFade)   // 法线扰动
spec = pow(dot(N,H), 42) * 0.34            // 镜面
```

amp 一强，`diff / fres / spec` 三项同时被放大 → 近景读作"亮蓝色斑团"（大团明暗）
加"白色麻点"（浪脊高光点）。

**修法**：`amp 0.42 → 0.24`、`spec 0.34 → 0.24`。浪纹仍在，但不再形成可辨认的团块。

## 四、100 组自检（老板要求的"100 遍"）

脚本：`.workbuddy/tools/show/scan_v15784_spots100.js`

- 取 **20 个纯海视角**（该格与 6 邻居全是 lake，且互相间隔 > 20°）
- × **5 档高度**（130 / 80 / 55 / 35 / 8 米）= **100 组**
- 每组读画面**中央 50%** 像素，判定：
  - 色斑 = **暖色块**（`r > b + 12`，陆地/沙）或 **亮白团**（`lum > 150 且 sat < 0.22`，云/雾）
  - 灰蓝色（海面明暗、浪纹、大气辉光的中间调）**不算** —— 那是海本身
  - 太空背景（`lum < 30 且低饱和`）不计入分母

## 八、诚实说明（自检里发现的、但**没改**的两类"非海色"）

1. **孤立小陆地格**：全星球 40962 格里，被海完全包围的陆地簇只有 8 个
   （3 个 2 格、1 个 4 格、2 个 5 格、1 个 21-100 格、1 个 100+ 格）。
   老板截图里那些米黄色小块就是它们 —— **是地图内容（岛/野地），不是渲染 bug**。
   删掉会影响玩法（岛屿上的野地采集点），所以没动。若要"海面绝对无杂色"，
   需要老板拍板是否把 ≤N 格的孤立簇并入海洋。
2. **深蓝色六边形块**（agl 35~60 可见）：是**格子边界的水深色差**（相邻 lake 格顶点
   高程不同 → `dep = −e/0.35` 压暗不同）。实测 640 个采样点格色全部一致
   （`[34,65,130]`），说明差异来自顶点级深度，不是 bug。要消除得对海底高程做平滑，
   属于"改地形"级别的操作，不在本轮范围。
