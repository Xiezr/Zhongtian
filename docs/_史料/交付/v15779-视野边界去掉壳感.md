## 一、丑在哪（先认账）

v157.76 的边界是 3D 三角带，参数：半宽 **1.7**（带总宽 3.4 世界单位）、沿径向抬 **4.0**、亮青 `#35ffe8`、opacity 0.9。

近距离就是：**一条浮在地面上方的粗青带**。抬 4.0 是球半径的 1.3%，在 300 米高度大约偏出 4px —— 肉眼直接看出"它不在地上"。

为什么当时要抬：`polygonOffset` 对 `GL_LINES` 无效、贴地只抬 0.05 会被地形深度吃掉大半。**但把"解决遮挡"的办法选成了"抬高"，方向本身就是歪的。**

---

## 二、这一版的改法

| 参数 | 旧（v157.76） | 新（v157.79） |
|---|---|---|
| 带宽（半宽） | 1.7 | **0.55**（总宽 1.1 世界单位 ≈ 900 米高处 1px） |
| 径向抬升 | 4.0 | **0.25**（视觉贴地） |
| 可见性来源 | 靠抬高压过地形 | **`depthTest: false`** |
| 颜色 | 亮青 `#35ffe8` / 0.9 | 冷白偏青 `#dFF2ff` / 0.72 |
| renderOrder | 23 | **40**（HUD 级，画在所有 3D 之上） |

关键改动只有一条：**边界线是 HUD 级信息，本来就该"永远看得见"，不该参与地形遮挡**。
一旦用 `depthTest: false` 解决可见性，"抬高"这个破坏观感的动作就完全不需要了 —— 抬 0.25 只为避开同面的 z-fighting。
