## 二、三处根因（都不是"参数没调好"，是算法选错）

### 1. 滚轮乘错了基准

v157.31 把缩放量乘在**球心距离**上：`camO.dist *= 1.06`。
贴地时 dist≈302（含球半径 300），看着只多 6%，但落到**离地高度**上是 1.7 → 20.4（×12）。
越近越弹射、越远越没感觉 —— 与"按高度"正好相反。

现在乘在 **agl（离地高度）** 上，灵敏度是连续曲线：

```js
k(agl) = 0.045 + 1.05 / (1 + agl / 6.5)     // 贴地 ~0.88 → 高空 ~0.05
newAgl = agl × exp(k × deltaY/100)
```

顺带删掉旧的 `_K = (_aglNow < 120) ? 0.0006 : 0.0012` —— 那条在 120 米处**硬切**，
同一格从 +25 米变 +55 米，是"距离跳变"的第二处来源。

### 2. 滚轮是"瞬移"，不是"滑动"

旧实现一次 wheel 事件**直接改** `camO.dist`，画面立刻到新位置。

现在滚轮只写**目标高度** `_zoomTarget`，`placeCamera` 每帧朝它阻尼逼近：

```js
agl += (target − agl) × (1 − e^(−dt/70ms))
```

用**时间**而不是固定系数：60fps / 20fps 都是同样的 70ms 收敛，掉帧不变手感。
下限（防穿模）作用在**目标**上，不再把当前位置一把顶到地形下限（那也是瞬移）。

⚠️ 所有"瞬移语义"的入口（跳城 / 正位 / 滑块 / 读档 / 探针）都必须调 `_syncZoom()`，
否则下一帧阻尼会把人拽回旧目标 —— 这类动画最常见的坑，已在 13 处补齐。

### 3. 视线在切模式处"换公式"

- 地表分支：视线是**自由向量** `_surfDir`（落地 −15°，为了让左右拖有反应）；
- 轨道分支：视线是**看球心**（−90°）。

62 米处直接换公式 = 一格 75°。现在轨道分支每帧算"与看球心的差"，再乘一条
**只与高度有关**的衰减：

```
_hEl = (地表视线俯角 + 90°) × (1 − smoothstep(62, 95, rAlt))
```

- 62 米：满值 → 画面与地表**一模一样**；
- 95 米：归零 → 完全回正成看球心；
- 上行下行共用同一条曲线（每帧派生，不是"出地表记一次"）—— 所以天然对称。

进地表时**接手当前真实视线**（不再强设 −15°）。只有视线陡于 −65°（几乎垂直看脚下，
左右拖会是空操作）才抬到 −15°，并保留 220ms 过渡 —— 那是操作的必要条件，不是装饰。

### 4. 附带：把淡出终点钉在切模式高度上

旧 `SURF_FADE_FAR = 62` 是"离地高度"，但判据里减了快照地形高。站在 10 米丘陵上时，
海拔 62 处 fade 还剩 0.4 —— **地表层半透明地叠在轨道视角上**，切模式那帧"地形突然换了
角度和比例"。这是硬切感的另一半，不只是视线。

现在 `f1 = 切模式海拔(62) − 地形高`：海拔一到 62，fade 恰好归零。
另外给退场加 200ms 上限（连滚三格 0.3 秒跨过阈值时，指数逼近跟不上会让地形滞留）。

## 四、诚实缺口

1. **跨阈值那三格，每格视线约 25~33°**（75° 分摊到 3 格）。这是"跟着滚轮自然低头"，
   不是硬切；嫌快把衰减窗口 62~95 改成 62~120 即可（`_handoffMul` 一行）。
2. **进地表时的小残差 ~1.5°**（接手的是交班曲线在 62 米附近的值，不是精确 −15）。
   远小于原来的 75°，肉眼不可见。
3. **阻尼让"滚到底"多花 ~70ms**。极端快滚（一次事件 deltaY=1000）仍受 1.9 倍封顶保护。
