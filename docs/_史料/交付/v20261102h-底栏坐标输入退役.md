# 底栏的经纬度输入组：删掉

> 老板 2026-11-02：「这个已无用，删去：球系坐标 / 经度 / °E / 纬度 / °N / 前往」

---

## 一、删的是哪一块

地图页底部导航条（`.map-dock`）里，info 和按钮之间原本夹着一组手输坐标：

```
[中心 244°E 17°N] [点选 —] │ 球系坐标 [经度]°E [纬度]°N [前往] │ 回主城 回本城 🌌星系 🚩前哨 🧱建造 灰烬城
                             └────────── 整组删除 ──────────┘
```

老板列的六项和 DOM 顺序**逐字对上**（`球系坐标` `placeholder=经度` `°E` `placeholder=纬度` `°N` `前往`），
所以删的就是这六个元素，一个不多一个不少。

---

## 二、连带清掉的（不留在原地当死代码）

| 位置 | 原来的东西 | 处理 |
|---|---|---|
| `js/ui-space.js` | `ui.mapGoto`（唯一读者是「前往」按钮） | 整个函数删除 |
| `js/main.js` | `case 'map-goto': ui.mapGoto();` | 删 |
| `index.html` | `#map-gx, #map-gy` 样式 | 删（v90.88 起就没有对应元素，空挂了好几个版本） |

**只删界面入口不够**：留着 `ui.mapGoto` 就是一段"永远点不到"的逻辑，
audit 也认不出它已经死了（它还有定义、还被 case 引用，看起来是活的）。

---

## 三、**没有**删的：坐标的"读数"

老板删的是"输入"，不是"坐标"这件事本身。以下四处读数原样保留：

- 底栏 `中心 244°E 17°N`（`ui.mapInfoText`）
- 地图左上角 HUD `【平原】灰岗 · 等级 3 · 球系坐标 12°E 34°N`
- 野地面板 / 地块弹窗 / NPC 城市面板的 `📍 球系坐标 …`
- `GAME.sphere.xyOfLonLat / lonLatOfXY` 两个纯函数（prologue / state / surge 三处都在用）

> 这条边界很重要：**删错了就是另一场事故**。所以下面的断言也按"输入 vs 读数"分开钉。

## 五、断言：五条翻转

原来钉"输入框在册"的断言必须同步翻转，否则绿着的是已经不存在的设计：

```js
// smoke §v90.88（原）
check('地图坐标输入改**球系坐标**', /id="map-lon"/.test(uiSrc22) && ...);

// 现在
check('v156.35：球系坐标输入组整组退役（标签/经纬框/°E/°N/前往 全不在）', ...)
check('v156.35：连带清掉 mapGoto 出口（不留"点不到"的死逻辑）', ...)
```

e2e 三条同样翻转（真 DOM：`#map-lon` / `#map-lat` / `[data-action="map-goto"]` 都不该在，
`typeof G.ui.mapGoto === 'undefined'`）。

原来那两条"经纬 → 视野中心"的**功能**断言直接删了 —— 功能没了，测它没意义。

### 写断言时踩的两脚

**① 查「球系坐标」四个字会误伤读数。**
第一版写成 `uiSrc.indexOf('球系坐标') < 0`，当场红 —— 因为野地面板、地块弹窗、城市面板
三处的坐标读数里都有这四个字。删的是输入组，不是这个词。
改成只钉被删的那几件：两个 input 的 id/placeholder、dock 里那个 `<span class="mk-lbl">球系坐标</span>`、前往按钮。

**② 查 main.js 的 `case 'map-goto'` 会被自己的注释绊倒。**
我写了一段沿革注释，里面带着 `case 'map-goto'` 这个字符串 —— `indexOf` 立刻命中。
断言必须先 `stripComment` 再判：**判的是代码，不是注释**。
