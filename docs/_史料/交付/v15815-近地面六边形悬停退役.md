# v158.15 · 近地面六边形地块悬停高亮整条退役

> 老板原话（2026-11-25）：「我觉得这个六边形地块有点有点碍事儿了，就作为一个可操作项来看。评估一下。」
> 评估后老板拍板：**近地面全退**（选项 B，不是我推荐的"缩成小圈"）。

---

## 一、先纠正一个认知：它不是可操作项

| 老板的直觉 | 实际情况 |
|---|---|
| "像一个可以点的操作框" | **点不了、选不中**。点地面走的是 `pickAt → _openCellPanel`（开地块面板），与这块高亮毫无关系 |
| "应该能操作这一格" | 它连状态都不写：不更新 `_standCi`、不设定行军目标、不参与交互半径判定 |
| "至少会告诉我这是什么地" | **一个字都没有**。地表模式为了它把地块简报浮签主动关掉了（`ui2.tipHide()`） |

结论：退役前它是**纯装饰 + 零信息**，却长成"选中框"的样子。

## 二、取证（退役前的实机数据）

| 项 | 实测值 |
|---|---|
| 触发条件 | 地表模式（近地面）下，**鼠标在画布上移动一次**就点亮，无任何前置动作 |
| 高亮尺寸 | 整格六边形；格径 ≈ **3.6 米**（`SURF_RINGS=12` → 469 格覆盖约 43 米） |
| 屏幕占比 | 跟随相机在身后 **6 米**、俯角 15° → 脚下整片草地被染青，占屏宽约 **90%** |
| 材质 | 填充 `#9fe8ff` 透明度 **0.20** + 亮边 `#bdf2ff` **0.95** |
| 遮挡行为 | 边线 `depthTest: false` → **无视地形遮挡**，山坡后面也会浮上来 |
| 坐标语言 | 六边形。而建造模式是**四边形**（v157.12 老板拍板"不再拾取六边形地块数据"）——同一地面上两套格子 |

证据图：`.workbuddy/tmp/v15815_hex/05_hover_follow.png`（退役前，整片染青）

## 三、判定：这不是新问题，是同一件事被判了三次

| 版本 | 老板原话 | 处理 |
|---|---|---|
| **v157.37** | 「近地面不应该再出现六边形地块的操作」 | 删掉悬停六边形 |
| **v157.56** | 「线条太杂，不要边线了，**只留悬停亮色**」 | 恢复悬停六边形（就是被退掉的这个） |
| **v158.15** | 「六边形地块有点碍事」 | 整条退役 |

根因不在"要不要有悬停反馈"，而在**把它实现成了整格染色**：v157.56 想要的是"一个亮色提示"，
落地成了"脚下铺一块青色地毯"。在 6 米视距下，"提示"和"染色"是两种完全不同的东西。

## 四、改动清单

`js/map3d.js`（唯一源文件，共 6 处）：

1. **删机制**：`M.surfHighlight` / `_surfHiBuild` / `_surfHiAt` / `surfHi` / `surfHiCi` / `surfHiSel` / `M._hiCi` 全部删除，原位留墓碑注释（2367 行）。
2. **悬停分支**：地表模式从"点亮整格"改为 `ui2.tipHide(); return;`（什么都不画）。
3. **建造模式入口**：不再清 `surfHighlight`（函数已不存在）。
4. **`destroySurf`**：删掉"退地表清亮格"的块（对象已不存在）。
5. **`mouseleave`**：不再调 `surfHighlight(-1)`。
6. **`SURF_LINES` 注释**：更新为"地表只剩地形本身"。

`smoke-test.js`：`§243①i` 按规则变更重写（标题写新规则 + 三层守卫 + 注释点明推翻 v157.56）：
- ① 剥注释后 `surfHighlight|_surfHiBuild|_surfHiAt|_hiCi` **零残留**
- ② 地表分支仍是 `tipHide(); return;`（不许"改回先清后画"）
- ③ 出口面 `GAME.map3d.surfHighlight === undefined`（防"换个名字留着"）

**没有**保留任何可调开关 —— 按项目纪律，退役就是整条清，不留半套。

## 六、口径与边界（不动的部分）

- **六边形拓扑不动**：`SP.adj` 六邻、`hopsWithin` 六环、行军/占领/建厂/勘探全部仍按六边格算 —— 那是数据模型，不是显示。
- **建造模式不动**：仍走四边形 `gridHighlight`（v157.12 口径），这次退役与它无关。
- **地表不弹浮签的口径不动**：`tipHide()` 保留（v157.56「线条太杂」同源）。
- **"我在哪一格"的表达**：地砖本身 + 底栏「E 交互」提示。如果后续觉得还不够，那是独立话题（要不要恢复近地面地块简报），不在本次范围。
