# v90.92 门派 + 任务系统整条退役

> 老板原文（逐字）：**「去掉门派还有纪事剧本还有修炼。」**
> 追问归属（多选全中）：**「纪事剧本」= 任务系统 + 全屏剧本 + 年号纪元** 三样。
> 本轮（v90.92）落地其中的 **门派** 与 **任务系统** 两件；
> 「年号纪元 + 全屏剧本」记于 v90.93（见 `v9093-纪事剧本退役.md`）；
> 「修炼/练功」与「君主突破」记于 v90.94（见 `v9094-练功移位与突破门槛.md`）。

## 一、边界判定（先划清再动手）

| 名称 | 判定 | 依据 |
|---|---|---|
| **门派 / 派系** | **整系统删除** | 老板确认「整系统删除」；项目内「门派」与「派系」是同物异名 |
| **任务系统** | **整条退役**（含 `js/questdata.js` 整文件） | 老板点名「任务系统」属纪事剧本 |
| **门派专属样式族** | 一并删除 | 无消费方即死样式 |

**明确未动**：`DATA.ENCOUNTERS`（奇遇遗迹 · 异系统）、场景机内核、`DATA.LORD_BREAK` 的其余三关。

## 二、改动（引擎 / 数据 / UI / 动作 / 样式 五层）

| # | 层 | 落点 | 处置 |
|---|---|---|---|
| ① | 数据 | `js/data.js` `DATA.FACTIONS` 等门派表 + 同格「⚔️ 派系」入口 | 整块删除 + 墓碑 |
| ② | 引擎 | `js/domain.js` 门派出口（含 7846 行段） | 整块删除 + 墓碑 |

| ④ | 数据 | **`js/questdata.js` 整文件删除** | 文件消失 + `data.js` 头注「⑬ 任务 ⛔ v90.92 整系统退役」 |
| ⑤ | 引擎 | `s.quests` 字段 · 任务面板重绘钩子 · `GAME.questMetric` · 随机任务与汇总 · `advanceConquer`（已占城计数） | 逐条删除 + 墓碑 |
