## 三、新发现（本轮新抓，未修）

### 发现 4：随机迁城没有二次确认

点 `🎲` → toast 立刻回「🎲 已随机迁至 336°E 5°N」——**城当场搬走了**。
这是不可逆的位置变更（影响补给连通、行军距离、地形加成），却没有"确定要迁吗"。
建议：和 `city-move-ask` 一样走二次确认（项目里已有这个动作，说明确认模式是现成的）。

### 发现 5（观感）：兵种名与城名风格割裂

驻军列表是「轨车 / 主机 / 雷机 / 电磁 / 无人 / 轨道 0 泰坦」，城内是「居所 / 政务厅」——
一边科幻机甲、一边废土聚落。不影响功能，但读起来像两个游戏拼的。
