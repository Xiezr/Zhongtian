# v20261101b · 球面 3D 沙盘：经度镜像，东在右、北在上

> 需求来源：老板「人物走动的上下方向正确，左右反了」
> 选向（AskUserQuestion 确认）：「3D沙盘东在左 → 改东在右」—— 东改到屏幕右侧，北极仍朝上（北不翻）。
> 性质：这不是某个坐标写反的 bug，而是**球面 3D 渲染的固有投影**：轨道相机看球心、北极朝上时，东（经度+）必然落在屏幕左侧（真地球仪现象）。修复是几何性的「经度镜像」。

## 改动文件（均改 `js/*.js` 源，改后必须重建 bundle）

| 文件 | 改动 |
|------|------|
| `js/sphere.js` | ① `icoSpheres(sub)` 在 `return { V: V, F: F }` 之前，对所有顶点做一次 z 镜像：`V[_vi] = [V[_vi][0], V[_vi][1], -V[_vi][2]]`。这是 icosphere 顶点的最源头，cell.dir/pos/rim/邻接/nearestCell 全派生自此，一处翻即全链路自洽。<br>② `SP.dirOfLonLat(lon,lat)` 返回 `[cl*cos(b), sin(a), -cl*sin(b)]`（与顶点镜像同源）。 |

## 断言（§585，4 条）

- ① 经度镜像之根：`icoSpheres` 顶点在 `return` 前翻 z（派生全链路自洽）
- ② 方向公式同步翻 z：`SP.dirOfLonLat` 与 `GAME.map.dirOf` 都返回 `-cl*sin(b)`
- ③ 运行期：`dirOf(90,0)` 的 z<0（东→-Z，东在右）、`dirOf(0,90)` 的 y>0（北仍朝上）、`dirOf(0,0)` 的 z≈0 且 x>0（本初子午线→+X）
- ④ 端到端：真实 cell 几何与镜像自洽 —— 东格（lon≈90）z<0、西格（lon≈270）z>0、北极（lat≈90）y>0

## 修复机理（一句话）

翻 z 后，东（lon+）落到 **-Z**；在「北极朝上」相机视角下 -Z 投影到**屏幕右**，且 y（纬度/南北）不动 → **北仍严格朝上**。满足「上下正确、左右反 → 改东在右」。
