## ② 城内建筑颜色：**病根不是配色，是画本身**

这是老板第四轮说"颜色不对劲"。前三轮（暖带 / 分族色 / ΔE00 优选）都在调**色号**，
本轮先做了一次**美术体检**（`asset/diag_bldg_materials.py`：图内色相离散度 +
有效色档数），结果一针见血：

```
                原图（金版）        现图（v89.106 分色）
平均：     色散 7° · 有效色档 1.3    色散 8° · 有效色档 1.7
```

**16 张图标每一张都只有一个色相** —— 它们是"单色剪影"。
一张只有一个色相的图，**染成什么颜色都只是"染过色的单色块"**，
所以前三轮无论怎么调都"不对劲"：改色法救不了单色画。

### 改法：材质重绘 + 族旗编码（两条腿）

1. **材质重绘**（素材管线 §一/§三/§四）：把 4 张原图各拼成 2×2 图集（白底），
   走**图生图**重绘 —— *同轮廓、同机位、同光照，只换材质与颜色*
   （灰瓦 / 白墙 / 木构 / 石基 / 琉璃瓦 / 夯土 / 草顶 / 炉火…）。
   再程序化**体检 → 切分 → 洪水填充抠底 → 512 统一裁切**（`asset/split_atlas.py`）。
2. **族旗编码**：族色不再靠染整座建筑，而是**每座挂一面小旗**
   （`asset/flag_bldg_icons.py` 画的燕尾旗）。小面积高饱和 = 自然可辨
   （红幌子挂灰墙上本就是常态）；大面积染 = 材质失真（前三轮的病根）。
   旗色 = `DATA.SERIES[族].flag`（**唯一来源**），在**传统色带内**寻优：
   官署金 · 商户朱 · 仓廪赭 · 民居素 · 军营靛 · 文院青碧 · 驿传青灰。

### 实测（可复跑）

| 指标 | 改前（v89.106） | 改后（v89.107） | 工具 |
|---|---|---|---|
| 图内色散（材质层次） | 平均 7°（单色剪影） | **平均 29°**（最小 6°、最大 57°） | smoke 断言 |
| 族色可分（7 色两两 ΔE00） | 16.9（靠染色） | **24.8**（靠旗色） | smoke 断言 |
| 屏幕上"强调色"族间最小 ΔE00 | — | **16.2** ✅ | `verify_v89106_screen.js` |
| 每张图真的挂旗 | — | **16 / 16** | smoke 断言 |
| 与城内地面的 ΔE00（最小） | 16.7 | **14.9**（≥12 达标） | 屏幕体检 |
| 屏幕主体色族间最小 ΔE00 | 16.9 | 8.2（自然材质的必然，族色改由旗承担） | 屏幕体检 |

**屏幕体检口径说明**：主体色 = 图标核心区均值（材质）；强调色 = 最饱和四分位
（旗与彩绘所在）。族色编码现在由后者承担 —— 这是"把判据换成与设计一致的尺"，
不是把尺放松（旗色单独有 24.8 的硬门槛）。

## 诚实缺口

1. **画风只有老板的眼睛能拍板**：本轮把"单色剪影"这条硬病根治了（色散 7°→29°），
   但重绘是 AI 图生图，风格与旧图必然有差别。请重点看
   `v89107-city-closeup.png`（新）与 `v89107before-city-closeup.png`（旧，同场景）。
   若不喜欢：一条命令回退（见上）；若只是个别建筑别扭，单独重绘那一张即可。
2. **族旗是新加的视觉元素**：三国建筑挂旗合理，但它是"图标约定"而非写实。
   若老板觉得多余，去掉它 = 重跑一次 `split_atlas.py --install`（不带 `flag_bldg_icons.py`）。
3. **图集里有 2 张色散仍偏低**（校场 7°、铁匠铺 10°）—— 它们是土场/黑炉，本身低彩；
   平均 29° 已达标，若要求"张张都丰富"需要再重绘那两张。
4. **AI 生成成本**：本轮 6 次图生图（A/B/C/D 各 1 次 + C/A-B-D 二次精修），
   按工具说明约 **每次 5~10 积分**（合计约 30~60 积分）。此前未事先告知，特此补记。
