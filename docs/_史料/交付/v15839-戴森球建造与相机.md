# v158.39 · 戴森球式建造 / 取消边缘转角度 / 抬头不钻地

> 老板原话：**「找个办法让在大地图上建造更加容易。就是类似戴森球计划那种模式。取消边缘转换角度。向上看时，相机位置不要沉入地下，相机与人的距离缩短，最终在眼睛与地面之间」**

## ① 结论

三条诉求全部落地，各用一条**唯一出口** + 一条**下限型行为断言**钉死：

1. **戴森球式建造**：建造栏物品 / 采集场工具接进同一套"幽灵预览 → 悬停落位 → 左键点击放置 → 按住左键拖过多个格连铺 → 右键取消"的连续流；采集场快建真正扣资源、进施工队列，不再只是面板假动作。
2. **取消边缘转换角度**：地表模式下，指针贴画面边缘**不再写任何镜头角度**（`_surfOrbitYaw` / `SURF_CAM_EL` 零写入），边缘推镜只在高空模式保留原语义。
3. **抬头不钻地 + 距离缩短**：仰角下限从 0.42rad 放宽到 0.06rad，相机距离从恒 16m 改成随仰角单调收缩（最低 3.2m），并加地面硬闸——相机底部永不沉入玩家脚下地面 + 镜头正下方地形取较高者之下。

**关键教训（别回退）**：
- 相机地面硬闸**不能靠"抬高仰角"实现**——坡地上会把 0.06rad 顶到 0.75、距离拉回 10m，玩家要的"眼睛与地面之间"就没了。正确做法是**保持方向、只沿径向抬到地面之上**（水平距离仍是 3m 级）。
- 建造落位**必须单一出口 `placeAtPoint`**——旧版 `pickAt` 内联一份 `place.add`、拖铺又写第二份，改一边漏一边。
- 采集场快建的**资源类型由地块自身决定**（`quickBuildPlant` 内部映射），玩家不用记"哪种房子配哪种地"。

## ⑤ 诚实缺口

- 「取消边缘转换角度」只改了**地表模式**；高空模式边缘推镜语义（平移观察点）按 v158.28 口径保留，未动。若老板要"高空也取消边缘推镜"，需另立口径。
- 相机"眼睛与地面之间"的"眼睛"高度目前按**玩家脚下地面 + 0.12m 硬隙**实现，未接入角色模型的实际眼高（角色眼高约 1.7m 是另一个语义，本需求要的是"贴地近景"而非第一人称眼高）。
- 采集场快建目前只覆盖 `DATA.EXT_BUILDINGS` 四种资源建筑（净化厂/水培温室/发电站/电弧熔炉）；装饰物（tree/bush/pond 等）仍走零成本 `GAME.place`，与经济建筑表未合并（两套并存是历史结构，非本轮引入）。
- 连续拖铺（按住左键）的落位间隔靠鼠标移动采样，极快甩动可能跳格；已用 dedupe 防同格重复放置。
