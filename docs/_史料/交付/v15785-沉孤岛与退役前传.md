## 二、米黄色格子 = 海上孤岛 → 沉没

### 现状（取证）

全星球 40962 格里，被海完全包围的陆地簇：

```
3 个 2 格 · 1 个 4 格 · 2 个 5 格 · 1 个 21~100 格 · 1 个 100+ 格
```

后两个是主大陆与次大陆，前 6 个是"海上小点"—— 就是老板截图里那几块米黄色。

### 修法（`sphere.js` · `_sinkIslets`）

```js
连通簇 ≤ SP.ISLET_MAX（默认 6）格 → 整簇
  · type 改 'lake'
  · eArr[i] = -0.012（压到海平面下）
  · V[i]._e = -0.012（cells[i].e 由它派生 → 几何/拾取/颜色同源）
```

⚠️ **只改类型不改高度 = 海面上留一个蓝色土包**，位置照样看得出，等于换汤不换药。
所以高度必须一起压，且要同步 `V[i]._e`。

⚠️ 位置必须在**类型产出之后、野地等级 BFS 之前** —— 野地等级按"离类型边界多远"算，
沉晚了会给已经不存在的岛评等级。

### 结果

| | 改前 | 改后 |
|---|---|---|
| 陆地簇 | 8 | **2**（只剩主大陆 + 次大陆） |
| 2 格簇 | 3 | **0** |
| lake 格数 | 19132 | 19152（+20） |
| zhaoze 格数 | 3329 | 3309（−20，沉掉的都是沼泽） |
| desert 格数 | 2836 | **2836（不变）** ← 大陆上的荒漠原样保留 |

### 旧档怎么办（**不能让人丢档**）

新增 `GAME.migratePrologueCity(st)`（`state.js`），在 `adoptState` 里 `GAME.state = st` **之后**调用：

```
prologue.on === true →
  ① 关标记
  ② 没有城 → 在君主站的那一格立城（cellOf → xyOfLonLat，算不出退回 map.startPos）
  ③ 将领 cityId 回填 + ui._cityId 指向新城
  ④ 把随身物资 res 搬进城，然后清空背包
```

为什么放在 `GAME.state = st` 之后而不是形状检查之前：`makeCity` 会读全局 state 发号。

`saveShapeChk` 里"无城也算合法"的分支**保留**，但语义改成「历史档兼容」——
只服务"旧前传档在补城之前过闸"，不再支持前传玩法。
