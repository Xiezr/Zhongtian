# v158.38 · 统一地块入口：未探明格先给一级详情，再进出征调配

> 老板原话：**「统一」**
> 背景：此前点未探明格直接进出征调配面板（将领 / 目标 / 兵力），点已探明格先弹地块详情面板，两套入口并存。

## ① 结论

所有地块统一为同一条行为链：

```text
点击地块 → 一级详情面板 →（点行动按钮）→ 统一出征面板
```

- 未探明格：一级面板明说"未探明"，只给坐标 + 「派队探索」；不泄露地形、守军、产出。
- 已探明格：仍是原地块面板（勘探 / 建厂 / 侦查 / 掠夺 / 占领 / 传送）。
- 两条链的行动按钮都复用 `exp-open` → `GAME.doOpenExp` → `ui.openExpModal`，不再有第二套出征入口。
