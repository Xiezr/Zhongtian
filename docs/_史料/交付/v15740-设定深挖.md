## 三、逐个查明原因（不是"没写"，是"没触发"）

| 系统 | 实测输入 | 判断 |
|---|---|---|
| **污染 taint** | `taint.of(city)=0`，等级「干净」 | 需要工业建筑才有污染源。基准玩法不建，所以永远 0 |
| **民怨 unrest** | `unrest.of(city)=0`，税率 50% / 民心 50 | 不到造反线。基准玩法不加税，所以永远 0 |
| **收缩圈 surge** | `rNow=55`、城距圈心 <14、`inCloud=false` | **配置 `startR 55 · shrinkPerMonth 0.9 · minR 14`** —— 缩 45 个月到 14 就停，而首城本来就在中心 14 格内 ⇒ **永远追不上** |
| 军阀 / 奇观 / 老兵 / 配给 / 暴露 / 终局 / 兵源 | 各自的 state 依赖前置（有兵、有奇观、有战事） | tick 首行条件不满足，直接 return |

## 四、核心诊断（这才是"深"的那层）

**正向系统全活着，惩罚系统全睡着。**

- 村社、竞争者、经济、遗物 —— 都是"时间越长越多"的正向循环，所以自己会长。
- 污染、民怨、收缩圈、军阀 —— 都是"你做了某个选择才咬你"的惩罚系统，
  而**游戏没有制造"不得不做错"的压力**：
  - 不缺粮（军队耗粮已废除）、不缺地（地图 4 万格）、不缺钱（25 年涨 4 倍）
  - 圈追不上你、外敌不来打你、民怨不到线
- 结果：12 个系统写得很完整，玩家一辈子碰不到。

## 五、建议（不是重写，是加"驱动"）

1. **收缩圈**：`minR` 从 14 提到能覆盖首城（或把圈心随机偏置，别总在城中心）。一行配置。
2. **民怨**：让"税率 > 55% 就每月 +N"，而不是只在极低民心时造反。当前税率滑杆拉到 45% 也毫无反应。
3. **污染**：给任意一座 3 级以上的工业建筑一个最小污染产出（现在似乎是 0）。
4. 军阀/奇观：需要"外敌真的会来"这个前提，属于大件，单独议。
