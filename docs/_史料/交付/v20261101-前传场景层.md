## 诚实缺口（待老板拍板/后续迭代）

1. **是字幕/卡片，不是真 3D 演出**：升级卡是 DOM 浮层淡入淡出，不是"将军在星球上走过来"那种演出。要更"场景"可后续接 `scene3d.js` 的演出钩子。
2. **文案未随昼夜/天气变化**：`crossLine` 目前是"地形名 + 固定感官后缀池"，`climate.js` 已具备昼夜/辐射/雨，可后续接入让同一格早/晚文案不同。
3. **升级卡无将形象**：只有名字/等级/资质 + 一句话，没接 `icons.js` 的将头像。后续可加头像增强"瞬间感"。
4. **未做真机视觉核对**：字幕位置 `bottom:16%`、卡片 300px 宽在窄屏/移动端需老板浏览器实看一眼。
5. **时长初值 2600ms**：觉得太短/太长改 `DATA.SCENE.captionMs/levelUpMs` 即可，逻辑不动。
