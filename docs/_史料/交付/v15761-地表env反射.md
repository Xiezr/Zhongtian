# v157.61 · 地表（map3d）接入程序化 env 反射（Phase 0.5）

> 关联：v157.58（Phase 0 PBR 解析器）、3D 资产质感升级路线方案 · 第八节决策③（接受程序化 env）
> 配套：Phase 1 pilot 见 `docs/_史料/交付/v15761b-phase1-pilot.md`

## 一、诉求

老板拍板的 3D 资产方案第八节决策③明确「接受程序化 env（无 HDRI 外链、零依赖）」。v157.58 给 `scene3d` 加了程序化 PMREM env，但**地表 `map3d` 仍是黑盒**——地表上的单位/建筑模型（`assets/wonders/*.glb`、`assets/actors/Soldier.glb`）经 `GAME.gltf.parse` 加载，因 `GTF._envOK=false` 被强制把 metalness 夹到 0.25，金属件发灰、无反射。

## 二、根因

- `map3d` 有独立 `R3`（WebGLRenderer）+ `scene`，但**从无 `scene.environment` / PMREM**（grep `map3d.js` 仅命中 `R3.render(scene, cam)`，无 env）。
- `GTF._envOK` 是全局布尔；v157.58 仅在 `scene3d.ensure()` 里 `setEnvAvailable(true)`。map3d/duel3d 从未设置 → 地表金属恒夹 0.25。
- 注：自 v157.58 起全局 `_envOK` 已是 `true`（scene3d 设的），duel3d 处于「true 但无 env」状态（非本版引入，老板未反馈变黑，影响可忽略）。

## 三、改动（源码 `js/map3d.js`，1 处）

在 `ensure()` 内 `scene` 创建后注入 `buildSurfEnv`——与 `scene3d` 同源逻辑（程序化天空 canvas + PMREMGenerator，零外链、无 HDRI）：

```js
(function buildSurfEnv() {
  try {
    var cv2 = document.createElement('canvas'); cv2.width = 512; cv2.height = 256;
    var g2 = cv2.getContext('2d');
    var sky = g2.createLinearGradient(0, 0, 0, 256);
    sky.addColorStop(0.00, '#0e151d'); sky.addColorStop(0.34, '#38434f');
    sky.addColorStop(0.50, '#9c8f78'); sky.addColorStop(0.62, '#5b5142');
    sky.addColorStop(1.00, '#241f19');
    g2.fillStyle = sky; g2.fillRect(0, 0, 512, 256);
    /* 太阳斑：偏高偏一侧，PBR 高光在此点亮 */
    var sg = g2.createRadialGradient(392, 96, 3, 392, 96, 104);
    sg.addColorStop(0.00, 'rgba(255,242,214,1)'); sg.addColorStop(0.22, 'rgba(255,208,142,0.62)');
    sg.addColorStop(0.55, 'rgba(240,178,110,0.16)'); sg.addColorStop(1.00, 'rgba(230,170,100,0)');
    g2.fillStyle = sg; g2.fillRect(286, 0, 212, 200);
    var eq = new THREE.CanvasTexture(cv2);
    eq.mapping = THREE.EquirectangularReflectionMapping;
    var pm = new THREE.PMREMGenerator(R3);
    pm.compileEquirectangularShader();
    scene.environment = pm.fromEquirectangular(eq).texture;
    if (GAME.gltf && GAME.gltf.setEnvAvailable) GAME.gltf.setEnvAvailable(true);
    eq.dispose(); pm.dispose();
  } catch (e) { /* 老版本无 PMREM → 退回纯直射光 */ }
})();
```

`smoke §586e` 双守卫：① `ensure` 内建造 `scene.environment = pm.fromEquirectangular(eq).texture` + `PMREMGenerator(R3)`；② 生成后 `setEnvAvailable(true)` 与 scene3d 对称。

## 五、诚实缺口（非阻塞）

1. **duel3d 仍走「全局 `_envOK=true` 但无 env」状态**（v157.58 遗留，非本版引入）。若决斗场景金属件需反射，单独给 duel3d 也加 env 是独立任务，按范围纪律本版不动。
2. **env 反射观感偏暗**：`map3d` 的 `R3.outputColorSpace = LinearSRGBColorSpace`（v154e，为顶点色不双重编码），envMap 反射走线性输出，比 scene3d 的 sRGB 输出更暗——这是既定设计差异（顶点色优先），非 bug。
3. 地表金属资产是否「够亮/够真」需老板实机拍板（AI 不代决观感）。
