# 2026-11-13 · 近地面左键拖拽「画面元素剧烈跳动」整改计划

> 老板逐字原文：「在近地面的时候，鼠标左键长按拖动，有时候会发生剧烈的这个呃整个画面元素的一个跳动。
> 确认一下，我需要一个。绝对我。定的我建议采用最保守的方法。就任何涉及到界面的问题发生不稳定
> 都是因为这会极大的影响玩家的一个感受并影响他继续游戏的这样一个心情」

## 一、目标

近地面（地表模式）按住左键拖动时，画面元素位移**连续、有界、无突跳**；不改左键的手感语义
（仍是「粘住地面一点、相机反向走」，v157.24 老板定义）。
**不做会怎样**：掠射角下射线求交被 `1/sin²θ` 放大几百倍，一帧能把相机推出几十米，
叠加重建与缩放阻尼回拉 —— 玩家会看到整屏地面/标记/景物一起跳，直接打断继续游戏的心情。

## 二、路径（先查标准与唯一出口，被否掉的路径逐条写理由）

**行业标准**：Three.js `OrbitControls` / Google Earth / Blender 的拖拽平移都是
`camera.position += right*dx*k + forward*dy*k`，`k` 在按下时按视口与 fov **一次算定**；
射线求交只做一次性拾取，**从不放进每帧伺服回路**（输入不能依赖自己的输出）。
反馈回路要么断开，要么加阻尼；本项目要求「绝对稳定」，选断开。

**仓库已有唯一出口**：`M._syncZoom()`（`map3d.js:5318`，注释明写
「外部改 `camO.dist` 的入口必须同时写 `_zoomTarget`，否则下一帧会被阻尼拉回旧目标」）；
`_groundPtAt` / `M.pickGroundPoint` 是拾取出口（保留给点击/悬停，不动）；
`M._panDrag` / `M._panA` 是本轮唯一要收口的状态。

| 被否掉的路径 | 为什么否 |
|---|---|
| 地表左键退回「纯转头」（v157.23 的旧正解） | 推翻老板 v157.24 明确要求「左键应该是移动相机本身」，属玩法取舍，AI 不擅自改 |
| 给现有回路加阻尼 / 低通 / 滤波 | `map3d.js:5426` 已写明这类手法「都是把跳摊成漂」；要的是绝对稳定，不是漂得慢一点 |
| 把单帧上限 40 调小、或提高 rebuildSurf 节流 | 治标：掠射病态与 `_zoomTarget` 拉扯仍在；还会偷偷改手感速度 |
| 重做相机架构 / 换四元数方案 | 超出「最保守」，改动面会炸到 placeCamera、淡出、模式切换 |

**定稿**：只断开反馈回路 —— 按下时用**一次**射线拾取算出「每像素地面位移」
（两个切平面向量 ex/ey）并冻结，之后每帧位移 = 鼠标增量 × 冻结向量
（纯线性、无射线、无自反馈）；限幅按眼高比例；非有限值跳过本帧。
**不改模式、不改相机架构、不新增机制、不动玩法语义。**

**取证后的两处修正（留痕，不是改需求）**：
- 「补 `_syncZoom()`」→ 改为**根本不写 `camO.dist`**：把新位置归一化到按下时冻结的
  半径后，`camO.dist` 与 `_zoomTarget` 的关系一分未动；反而补 `_syncZoom()` 会**打断
  正在进行的滚轮阻尼**（把用户设的目标改成当前值）。少一处写入 = 更保守，
  也更彻底地消除「方向已变、半径被拽回」。
- 冻结尺度改用「相邻一像素的**实测**地面位移」，不另写 fov / 视口 / 俯角公式：
  拾取出口 `_groundPtAt` 就是唯一口径，按下时一次采三个点；掠射时爆炸的值由硬上限收口。
  两个纯数学出口 `panBasisOf / panStepOf` 提到 THREE 守卫之前（照 v156.15 的先例），
  让 smoke 在 jsdom 里能**真调**，而不是只 grep 源码。

## 四、验收

**硬指标（自动判）**：
① 探针输出俯角 42°→2° 的每像素地面位移放大比 ≥100 倍（确认病态真实存在，防 0===0 平凡解）；
② 90 帧带手抖轨迹下，改前最大单帧位移 / 眼高 ≥1，改后 ≤0.5 且位移方向反转 0 次；
③ 平移分支**不写 `camO.dist`、不调 `_syncZoom()`**（源码级），且 `panStepOf` 返回值
   不含任何半径/相机量（数值级）—— 拖拽对滚轮阻尼零干扰；
④ 全程无 NaN/Infinity；`smoke_fast` 内环 0 红；`build_bundle.py --check` 三包与源码一致；
   `gate.py --full` 退出码 0。

**before 实测（探针，12/12 判据全绿）**：放大比 367.607 · 改前近地面单帧 7.883 米
（4.637 倍眼高）= 高空 42° 的 821 倍 · 方向反转 25 次 · 反馈回路反证（累积 vs 不累积）
逐帧差 34.763 米；改后单帧 0.178 米（0.105 倍眼高）· 反转 0 次 · 回路差 0.000 米。

**主观项（不由 AI 结案）**：拖拽是否仍「跟手」、画面是否还有可感跳动 ——
由老板 **Ctrl+F5** 后实机长按拖动判定；AI 只提供对比数值与回退路径，不代拍板。
