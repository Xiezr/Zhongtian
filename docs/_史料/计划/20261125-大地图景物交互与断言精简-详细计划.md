## 1. 目标（玩家感知）

- **走出城，世界既"满"又能"碰"**：星球表面陆地空白处自动长树、岩石、草丛（纯观感 + 可采集两档），走近会提示、按键能交互——像 3D 游戏一样"看见→走近→动手"。
- **断言回归真值**：清理假绿、同义重复、过度锁实现的断言，让"全绿"重新可信；保留下限/深拷贝/唯一出口这类真护栏。

## 2. 路径（行业标准 + 仓库出口）

**A. 景物交互（复用，不新建几何/不新建交互协议）**
- 行业标准：确定性散布（deterministic rng）+ InstancedMesh 批量绘制 + 视距 patch 剔除。
- 仓库出口：
  - 几何：`scene3d.js` 的 `gTree/gRock/gStump`（本轮范围**只植被+岩石**，不含芦苇/水域/探索点装饰联动）；
  - 落点：`cells[ci].type` 只取陆地（`plain/caoyuan/forest/desert/hill`，排除 `ocean/lake/zhaoze`），`heightAt` 取高；
  - 唯一出口：`M.nearestInteractable()` 复用，把散布物登记进 `_propAtCi`/`_interactKindOf` 的查询面；
  - 动作分发：点散布物 → 走 `_openCellPanel` 同一出口，`act` 复用 `cai`（伐树/采石），不新开按键分支（与任务链 P5-b"零新增按键"同纪律）。
- 否掉：

| 路径 | 否掉理由 |
|---|---|
| 给每棵树独立 Mesh | draw call 爆炸 → InstancedMesh |
| 全星球一次性铺满 | 40962 格 × 每格若干件 = 数十万实例 → 只铺视距 patch |
| 把量产物写进存档 | 纯派生、seed+地形确定，读档原地重建（存档梳理明令禁止派生回潮） |
| 新建第二套几何/交互协议 | scene3d 已有 17 几何 + act/label/hint 三件套，重复 = 双源真值打架 |
| 本轮铺水域/芦苇/探索点联动 | 老板拍板范围：**先植被+岩石** |

**B. 断言精简（只清假绿/重复/过度耦合，不动真护栏）**
- 可精简的三类（逐条列在 §4，附精确位置）：
  1. **假绿**：`intent_closure.js` `verKeys` 的 `slice(0,3)` 撞键 → 修对（去尾缀字母后按完整数字段匹配，不截断）；
  2. **同义重复**：同一行为被多个断言从不同角度各验一遍的，合并成一条带下限的；
  3. **过度锁实现**：锁内部变量名/中间态、一重构就翻红的，改成断言外部可观测行为。
- 不动：`≥1` 下限（防 `0===0`）、深拷贝（防自我清零）、唯一出口（`indexedDB.open`/E键分派）、同名函数重复定义（audit 真判据）。

## 3. 代价（文件 / 回退 / 最坏）

**A. 景物交互**
- 文件：
  - `js/scatter.js`（新，core 包）：唯一量产出口 `GAME.scatter`，按 patch 铺视距内植被/岩石，确定性 seed，InstancedMesh；
  - `js/map3d.js`：`M.SCATTER=true` 总开关；`_propAtCi` 增加程序化散布物查询（fallback 到 `GAME.scatter.at(ci)`）；`_interactKindOf` 认得 `scatter` 类型；
  - `js/scene3d.js`：把 `gTree/gRock/gStump` 暴露为可量产调用（经统一出口，不复制函数体）；
  - `js/modules.json`（+`scatter` → 重跑 gen_index）、`smoke-test.js` +N 条、`docs/项目地图.md` 模块数 93→94。
- 回退：`M.SCATTER=false`，回到 v158.6（只有探索点装饰）。
- 最坏：量产拖慢帧率 → InstancedMesh + 视距剔除 + 按地形降密度；交互误触 → 复用现有 30° 锥 + `hex≤1` 已有约束，不新增范围。

**B. 断言精简**
- 文件：`smoke-test.js`（合并/改写重复与过度耦合断言）、`intent_closure.js`（修 verKeys）、`e2e-test.js`（如涉）。
- 回退：全部改动走 `git checkout HEAD -- <file>` 可回滚；精简前先备份到 `.workbuddy/backup/`。
- 最坏：误删真护栏 → 精简全程**不删下限/深拷贝/唯一出口/重复定义**四类；每改一条先跑 `--check` 确认仍有行为断言覆盖。

## 4. 验收（可量化、可迭代、可验证）

**A. 景物交互（硬指标，探针/smoke 实测）**
- 视距内可观测植被实例 **≥200**，且非平凡解（采样顶点确有树/石，非仅数组长度）；
- 同 seed 两次进入同 patch，铺法**逐位一致**（确定性）；
- **交互闭环**：走到一棵散布树前，`nearestInteractable()` 返回 `{kind:'scatter', act:'cai'}`，E 键能进采集；走到空地不误触；
- 量产物**不入档**（`savePayload` 无 `scatter`/`scatterPos`）；
- 唯一出口不回归：`indexedDB.open` 仍只在 saveidb、E 键分派仍是 P3→P4→P1、几何真值仍只有 scene3d 一份；
- 地表 patch 重建 p95 ≤16.7ms（60fps 红线不破）。

**B. 断言精简（硬指标）**
- `intent_closure.js` 跑 `--last 12` 不再把 v158.x 与 v158xx 互相判绿（verKeys 修对）；
- 精简后 `smoke-test.js` 的 `§` 段数与 assert 数**下降**，且 `--check` 仍全绿、行为断言仍带下限；
- 精简过程不删任何 `≥1` 下限、深拷贝、唯一出口、同名重复定义断言。

**C. 主观（老板实机判定，不许 AI 结案）**
- 走出城转一圈：世界"满"且"能碰"，树能砍、石能采、空地不误触、不卡顿。

## 5. 需老板拍板（两条）
