## 1. 目标（玩家能感知到什么）

**贴地时，遗迹 / 村社 / 营地 是看得见、点得到的实物，不再是"只存在于面板列表里的一行字"。**

- 看得见：断柱（遗迹）/ 草屋（村社）/ 帐篷（营地），立在地表真实格点上。
- 点得到：点它 → 打开**原来那个面板**（不新增面板、不新增字段）。
- 不做会怎样：`_cellBrief` 里写着"🏚️ 可探索（给材料）"，但玩家在地表上永远找不到"它"在哪 ——
  探索只能靠点开面板读列表，世界没有形状。

## 2. 路径

### 2.1 现状（代码证据）

| 层 | 现状 |
|---|---|
| 数据 | `state.ruins = {ci: {...}}`（`R.sweep` 按 fog 发现）、`state.villages`、`GAME.camp.found()` |
| 战略视图 | 整格涂色 + `_openCellPanel(ci)` 点开面板（v156 已做） |
| 地表视图 | **零渲染** —— `_markers/_flags` 在地表 `visible=false`（v157.37）、地砖只按地形着色 |

### 2.2 方案：把地标挂到「切平面方格」上

地表层本来就是"以相机中心格为锚的 45×45 方格 patch"（`SURF_GRID_RANGE=22`，`BUILD_CELL=2` 米）。
所以地标不需要新坐标系：

```
ci → cells[ci].dir → 世界点 → M.gridAt(点) → (i,j) → seatProp(g,i,j) → 贴地
```

`seatProp` 是放置系统既有的唯一落座出口（v157.21 起走 `groundHAt`，含整平台面），
用它意味着**地标和玩家摆的树/屋在同一套贴合逻辑上**，不会再有一套"歪的"。

### 2.3 被否掉的路径

| 路径 | 否掉理由 |
|---|---|
| 用六边形网格画地标（回到 `_markers`） | 老板 v157.37 明确：近地面不许再出现六边形地块操作；且那是几十米一格的面片 |
| 每帧重建地标 | 每帧 new + dispose 一批准 mesh，GPU 抖死 |
| 在轨道（战略）模式也建地标 | 战略视图已有整格涂色做同一件事，重复 |
| "走过去自动触发"（进入 X 米自动开面板） | 这个游戏没有玩家化身，"走"= 左键平移相机；自动触发会把"平移看地形"变成"一路踩雷" |
| 让地标参与碰撞/占位 | 它们不该挡住建造；本轮只做"看得见、点得到" |

### 2.4 落地位置

1. `js/map3d.js`
   - `buildLandmarks(force)`：收集三源 → 按 dot 降序（离相机多近）→ 只留 `dot ≥ 0.985`（≈52 米）
     → `gridAt` 落 (i,j) → 越界跳过 → `lmMesh(kind)` + `seatProp` → 挂到 `lmRoot`。
   - 重建时机：`rebuildSurf` 末尾（**强制**：格锚变了，(i,j) 全作废）+ `_tickSurfFade` 里
     500ms 对一次"数量签名"（发现新遗迹时不用等平移）。
   - 点击：`M.pickAt` 里**先判 `lmRoot`**，命中就 `_openCellPanel(ci)` 并 return。
   - 清理：`destroySurf()` 里同生共死清 `lmRoot`（反向证据见验收）。
   - 探针出口：`M.landmarkStats()` / `M._lmObj()`。
2. `smoke-test.js`：`§243①l`（地标层在册、仅地表建）、`§243①m`（点击优先序 + 销毁时必须清）。

| 项 | 内容 |
|---|---|
| 改动面 | `js/map3d.js` ≈ +110 行（1 个构建函数 + 2 个钩子 + 1 段点击分支 + 1 段清理）；`smoke-test.js` +2 条 |

| 风险 2 | 只建不清 → 弹窗开着切走，mesh 留在场景里（**本轮实测踩到了**，已用 `destroySurf` 修） |
| 回退点 | `git checkout HEAD -- js/map3d.js smoke-test.js` 后重建分包 |

## 4. 验收

### 4.1 硬指标

| 指标 | 测法 | 阈值 |
|---|---|---|
| 落地即建 | 种 1 处遗迹在视线前方 → `landmarkStats().n` | **= 1** |
| 位置对得上 | 该 mesh 投影到屏幕的 \|NDC\| | **< 1**（在画面内） |
| 点它开面板 | 桩 `openRuinModal` 记录入参 | **= 种下的 ci** |
| 退出即清 | `surfaceMode(false)` 后 `landmarkStats().n` | **= 0** |
| 零异常 | 页面 error + console.error | **= 0** |
| 重建不拖慢 | `rebuildSurf` 耗时 | ≤ 改动前 + 10ms |

### 4.2 结构指标（反向证据）

- `destroySurf` 里**必须**有 `if (lmRoot) { scene.remove... }` —— 只建不清就判红。
- `pickAt` 里 `lmRoot` 判定**必须**在 `intersectObject(M._collider)` **之前**（顺序即语义）。
