# v157.57 计划 · 点地块「2 层菜单」（反向 v156.15b）

**日期**：2026-11-14
**触发**：老板「有的地块直接进strate出征、有的弹菜单，按说应该先有菜单界面吧」
**决策**：AskUserQuestion 选定「加回中间菜单（反向 v156.15b）」—— 点任意地块先弹「功能主菜单」，再开「功能详情菜单」。

## 一、现状（已取证）

`map3d.js:116 _openCellPanel(ci)` 按 `kind` 直接分派到对应面板，**没有任何中间层**：

| kind | 当前直达面板 | 老板感知 |
|---|---|---|
| `own` 己方城 | `openCityPanel` | 「菜单界面」(经营面板) |
| `wild` 野地 | `openLandModalCi` | 「出征界面」(底部带 侦查/掠夺/占领) |
| `npc`/`adm` 敌/行政城 | `openAttackModal` | 「出征界面」 |
| `fort` 据点 | `openFortModal` | 「出征界面」 |
| `camp`/`village`/`ruin` | 各自模态 | 详情面板 |

v156.15 曾加过 `⚔出征 / 🔍侦查 / 📜详情` 短条，v156.15b 老板以「这不是套娃吗」整条删去。本次反向。

## 二、目标

点任意地块 → **层 1 功能主菜单**（按 kind 给可用动作）→ 点动作 → **层 2 详情面板**（现有面板，零改动）。
层 2 全部复用既有 `openCityPanel / openLandModalCi / openAttackModal / openFortModal / openCampModal / openVillageModal / openRuinModal`，不重写逻辑。

## 三、实现（4 处，全在源码）

### 1. `js/ui-mapui.js` 新增 `ui.openCellMenu(ci)`
- 复用 `_openCellPanel` 的 kind 判定逻辑（own/wild/npc/adm/fort/camp/village/ruin）。
- 用 `ui.openShell({ title, sub, body, foot })` 弹小菜单；`body` 是按钮串，每按钮 `data-action` + `data-ci`。
- 按 kind 给按钮（详见第四节映射）。

### 2. `js/main.js` `GAME.action` 加 4 个 case（扩展点，仿 `case 'city-enter'`）
- `cell-menu-exp` → 出征/攻打：own 走 `openLandModalCi`；npc/adm 走 `openAttackModal(ref)`；fort 走 `openFortModal(ff)`；wild 走 `openLandModalCi`。
- `cell-menu-scout` → `GAME.doOpenExp(kind, 'scout')`（复用野地/敌城侦查入口，需带目标 ci）。
- `cell-menu-detail` → `GAME.map3d.openCellPanel(ci)`（既有分派器 = 层 2）。
- `cell-menu-dispatch` → `openCityPanel(ref)`（己方城派遣入口）。

### 3. `js/map3d.js:7862` 点击分发改道
`M.openCellPanel(ci);` → `if (GAME.ui && GAME.ui.openCellMenu) GAME.ui.openCellMenu(ci); else M.openCellPanel(ci);`
（保留 `openCellPanel` 作为层 2 出口，不删。）

### 4. `js/smoke-test.js` 补反向守卫
原 v156.15 守卫（若有「不得有中间菜单」类断言）需更新为「点击先经 openCellMenu」；新增一条断言 `ui.openCellMenu` 存在且按 kind 产出对应 `data-action` 按钮，防有人再把菜单删掉（复刻 v156.15b 的 smoke 反向守卫 §580）。

## 四、动作映射（层 1 按钮）

| kind | 层 1 按钮 | 命中动作 |
|---|---|---|
| `own` | 🏯 经营 · 🛡 派遣 | detail→openCityPanel · dispatch→openCityPanel(含派遣) |
| `wild` | ⚔ 出征 · 🔭 侦查 · 📜 详情 | exp→openLandModalCi · scout→doOpenExp('wild','scout') · detail→openLandModalCi |
| `npc`/`adm` | ⚔ 攻打 · 🔭 侦查 · 📜 详情 | exp→openAttackModal · scout→doOpenExp('npc','scout') · detail→openAttackModal |
| `fort` | ⚔ 攻打 · 📜 详情 | exp→openFortModal · detail→openFortModal |
| `camp`/`village`/`ruin` | 📜 详情 | detail→各自模态 |

> 注：`exp` 与 `detail` 对 wild 同开 `openLandModalCi`（面板底部本就有 侦查/掠夺/占领），`exp` 是其快捷入口；`scout` 走 `doOpenExp` 直接进侦查，是独立快捷。

## 五、风险 / 待拍板

1. **`doOpenExp(kind,'scout')` 是否带目标 ci**：需确认 `doOpenExp` 签名——若只读全局选中格，菜单 scou t 按钮要先把 `M._cell`(map3d:7849 已存) 设为当前 ci。实现时先读 `doOpenExp` 源码确认，再定接线。
2. **菜单样式**：复用 `openShell` 现成弹窗样式，无需新增 CSS（除非老板要径向菜单——本计划按「小弹窗条」做，最稳）。
3. **循环依赖**：`openCellMenu` 在 ui 层，`_openCellPanel` 在 map3d 层；层 1 只产菜单、层 2 调回 map3d，无环。
4. **回归**：门禁全量 `gate.py --full`（ui 域 + main 域跨域 → 强制全量）。

## 六、验收

- 点己方城 → 弹「经营/派遣」菜单 → 点经营 → 经营面板。
- 点野地 → 弹「出征/侦查/详情」→ 点出征 → 出征面板；点侦查 → 侦查模式出征界面；点详情 → 完整野地面板。
