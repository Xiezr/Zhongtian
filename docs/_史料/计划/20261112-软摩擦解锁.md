# 计划 · 软摩擦解锁（把 14 个被门关住的系统逐个放出来）

- 日期：2026-11-12
- 触发原因：老板「执行你认为正确的决定，但务必给出正确的评估」
- 上一轮遗留：v157.45 只把**空间站**一个 tab 从 mid 提前到 early；14 个账本小节仍等「赢 3 场」

---

## 1. 目标（玩家能感知到什么）

**不再出现「我明明在吃污染/民怨的亏，却找不到那一行」的情况。**

具体到可观察的三件事：

1. 建了会冒烟的作坊、地开始脏 → 账本里 **☢ 污染** 那一行当场可读（带数值），不是灰行。
2. 把税率拉到 55% 以上 → **🔥 民怨** 那一行可读。
3. 立了第二座城（且离得远，产出已经在打折） → **🛣 领土连通** 那一行可读。

不做会怎样：这三个机制**已经在运行**（`taint` / `unrest` / `land` 每月都在 tick），
但玩家看不到数值来源，只会觉得「产量莫名其妙变少了」——这是「世界不解释自己」。

---

## 2. 路径

### 2.1 先摆事实（代码证据）

`ui.gatedOut(need)` 是**唯一闸门**（`js/ui-bag.js`）：

```js
ui.gatedOut = function (need) {
  var rank = ui.gateRankOf(ui.phaseOf());
  return (need === 'late' ? 2 : 1) > rank;
};
```

消费点只有一个：`js/ui-view.js:777` 的 `sec()` —— 14 个账本小节全部经过它。

`ui.phaseOf()` 的出口只有一个判据：`n <= 1 && wins < 3 → early`。

### 2.2 关键发现（决定方案形状）

用 v157.40 的 25 年快进数据回查：**14 个系统里有 12 个从第 1 个月就在 tick**
（污染/民怨/收缩圈/军阀/奇观/老兵/配给/暴露/终局/兵源/叛军/天时）。

也就是说：**这道门不是在藏功能，是在藏"已经在跑的系统"的数值。**
空间站那种「8000 行代码看不到」是功能问题，这 14 个是**信息问题**，两者不该用同一把钥匙。

### 2.3 选定方案：把闸门改成「撞到才开 + 里程碑兜底」

在 `gatedOut` 里插一层软解锁：

```
late  → 仍按里程碑（奇观 / 谁看见了你）—— 它们确实是后期内容
mid 达成 → 全开（不变）
early → 逐条看 soft 触发；触发过（或正在触发）→ 开；否则仍灰
```

触发条件全部**只读 `GAME.state` 与 `city` 字段**，不调模块 API ——
因为模块改名/重构不会波及这里，且代价是常数级。

| 账本小节 | 触发（玩家第一次撞到它） |
|---|---|
| 🎯 作战目标 | 任一城 `army` 非空（出征前就该看见四档战场修正） |
| 🛣 领土连通 | 城数 ≥ 2 |
| ☢ 污染 | 任一城 `taint > 0` |
| 🔥 民怨 | 任一城 `unrest > 0`，或 `state.tax ≥ 0.55` |
| 🏴 竞争者 | `state.rival.teams.length ≥ 1` |
| ~~☁ 辐射云~~ | **执行时改成「直接放行」**：`SG.lineOf()` 永远非空，藏它等于藏时钟 |

**其余 6 条（废墟科技 / 伤兵老兵 / 守城工事 / 地下远征 / 指令牌 / 套装指令）保持里程碑。**
理由：我**没有**可靠字段能判定「玩家撞到了它」（要调 `relic` / `delve` / `cards` 模块，
一旦改接口就是第二份口径），按 §十三 G1/G2 不过就不动。

### 2.4 被否掉的路径（各一行 + 为什么否）

| 路径 | 否掉理由 |
|---|---|
| 直接把 `wins < 3` 改成 `wins < 1` | 一刀切：12 个系统同时放出来，信息过载；而且「打完第一仗」和「拉高税率」是两件事 |
| 全部 14 条都做软触发 | 其中 6 条没有可靠判据字段，只能猜；猜出来的谓词一旦误判就是「永久锁死」或「永久全开」 |
| 把空间站之外再提前 shop / collection | 没有可靠的「玩家需要它」判据；提前放出来只会看到空页，反而像坏了 |
| 干脆删掉整道门 | 会让「奇观 / 谁看见了你」这种真后期内容在第一天就露出来，那是真的剧透 |

### 2.5 落地位置（三处，都在 ui 层，不碰模拟）

1. `js/ui-bag.js`：`ui.SOFT` 表 + `ui.softOpen(title)` + `gatedOut(need, title)` 加第二参 + 持久化写 `state.gates`。
2. `js/ui-view.js:777`：`ui.gatedOut(need)` → `ui.gatedOut(need, title)`。
3. `js/ui-bag.js` 的 `gateWhyText()`：early 时不再笼统说「再打几场」，改成说清**这一条**缺什么。

> ⚠️ `js/ui-all.js` 是 `build_bundle.py` 生成的**拼接镜像**（19 个 ui-*.js 的只读视图），
> 改它无效（下次重建就被覆盖）。**只改 ui-bag.js / ui-view.js，然后重建。**

|---|---|
| 改动文件 | `js/ui-bag.js`（约 +70 行）· `js/ui-view.js`（1 行调用）· `smoke-test.js`（2~3 条断言）· 重建 4 个 bundle |

| 最坏结果 | 门禁红在 `§573` 系列（阶段锁断言）—— 按新口径重写断言，不删 |
| 回退点 | `.workbuddy/backup/v15746/ui-bag.js` / `ui-view.js`，整段覆盖后重建 |

## 4. 验收

### 4.1 硬指标（可自动判）

| 指标 | 测法 | 阈值 | 依据 |
|---|---|---|---|
| early 新档：6 条中已触发的可读 | 实机读 DOM，灰行数 | 触发几条就开几条 | 语义定义 |
| 未触发的仍灰 | 同上 | **必须仍灰**（防「全开」假绿） | 反向证据 |
| `late` 两条在 early/mid 始终灰 | 实机 | 2/2 灰 | 里程碑不变 |
| 解锁单调 | 造污染→拆掉→再读 | 仍可读 | 持久化语义 |
| 谓词异常不炸面板 | 断言里注入坏字段 | 面板仍渲染，该条判灰 | 容错要求 |
| 账本渲染耗时 | 面板打开 10 次 | ≤ 改动前 + 20ms | 一帧 16.7ms 量级 |

### 4.2 结构指标

- 唯一闸门：`gatedOut` 全仓只有 1 处定义、1 处调用（`grep` 计数）。
- 反向证据：断言里必须有「`ui-all.js` 被当作源文件改动」的防线（要么断言它含生成头，要么断言 `gatedOut` 只在 ui-bag.js 定义）。

### 4.3 主观项（老板判，AI 不结案）

- 打开账本，**能不能一眼看出「这行是因为我干了什么才出现的」** → 我出「触发前 / 触发后」两张截图。
- 灰色行的理由文案是否说得清「还差什么」——这句要你判，我只能保证它不再是笼统一句。

## 5. 执行结果（2026-11-12，已完成）

### 5.1 与计划的偏差（三处，都是执行中发现计划不对）

| 计划 | 执行 | 为什么改 |
|---|---|---|
| 5 条软触发（含辐射云） | **4 条软触发 + 辐射云直接放行** | `SG.lineOf()` 永远有话说（圈几格/还会收几个月/几座城在云里），它是全局时钟；藏起来等于藏时间压力 |
| 污染判据 `city.taint > 0` | `TN.stats().warn + bad > 0` | 摘要统计的是「越过 warn(60)/bad(120) 的城数」；`mutMulOf` 只在 `t≥bad` 才扣产出。用 `>0` 会出现「行放出来了但写 0 城变质」 |

### 5.4 结论

计划里的「代价」估得基本准（改动面、断言数），**但漏了一项**：
判据与**展示口径**是否一致。两次自我纠正都出在这里 ——
以后做「按值解锁」类改动，第一步应该是**去读那一行的渲染函数**，而不是先想谓词。
