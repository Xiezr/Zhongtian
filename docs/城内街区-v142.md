# 城内 3D：从俯瞰沙盘到能逛的街区（v142）

> 老板 2026-10-24「如何将城内外转成 3D」→ v140 交了第一版；
> 老板 2026-10-25「做，继续，直至无法继续」→ v142 把城内做成真的能走。

## 一、v140 交的是什么，为什么不算"进城"

v140 的城内 3D 是**把城的数据换成俯视模型**：

- 格子边长 2.1 米，建筑占 70% → 巷子只剩 **0.63 米**，比人（0.64 米）还窄；
- 所以相机只能钉在 20 米高空看全景，`cityView = true` 时 `updateCamera` **直接 return**；
- 房子没有碰撞，人能穿过墙；
- 门派弟子（玩家模型）**根本没被挂进场景** —— 相机跟着一个看不见的点跑。

一句话：那是一张"能点的沙盘照片"，不是"进城"。

## 二、v142 改了四个数、一条规则

| 项 | v140 | v142 | 为什么 |
|---|---|---|---|
| 格子 `CITY_T` | 2.1 米 | **3.0 米** | 8×6 的城从 16.8×12.6 变成 24×18，一屏（视口 9.5）看到约 4 格宽，才有"逛"的余地 |
| 建筑 `CITY_BW` | 1.47 米 | **1.40 米** | 巷道 1.60 米。1.14 米时贴墙距离只有 0.03 米，任何俯角都会把人挡没 |
| 玩家碰撞半径 `CITY_R` | 无 | **0.30 米** | 圆 vs 轴对齐盒，分轴推进（先 x 后 z），撞墙贴着滑 |
| 相机 | 固定俯瞰 20 米 | **跟随，65° 俯角，视口 9.5** | 65° 是"看得见房子正面"和"人能被墙挡住"之间的平衡点 |
| 围墙离格区 `CITY_PAD` | 0.9 米 | **2.2 米** | 城门内侧要有 2.5 米空地，否则出生点就站在门楣底下 |

## 三、几何真值只有一份：`cityPlan()`

```
GAME.scene3d.cityPlan(city) → {
  cols, rows, T, bw, walk, W, D,
  hw, hd, gateHalf, outZ, bounds, spawn,
  cells:  [{ idx, col, row, x, z, kind, bid, lvl, plaza }],
  solids: [{ x0, x1, z0, z1 }],     // 碰撞盒
  wall:   true|false
}
```

为什么非要抽出来：

- 渲染要 THREE，**门禁跑在 node 里没有 WebGL**；
- 如果"碰撞盒在哪、门洞多宽、出生点站不站得住"只在 `buildCityScene` 里算，
  这些问题就只能靠肉眼截图 —— 而截图看不出"这条路其实走不通"。

渲染照着 `plan.cells` 画、碰撞照着 `plan.solids` 用，**不是两本账**，是同一本账的两个读者。

## 四、门真的开了

v140 的城门是一块牌子：墙是整圈的，人走不出去，只能按 E。

v142：

- 南墙在 `|x| < 1.6` 处**真的断开**（左段到 -1.5、右段从 +1.5 起）；
- 门柱、门楣、发光门牌立在缺口里；
- 走到 `z > hd + 1.9` 就出城（不必回头按键）；
- 门洞两侧的墙都有碰撞盒，**只能从门洞出去**。

## 五、街道是怎么"读"出来的

正交投影没有透视，所以"这是街"全靠**颜色与遮挡**：

- **十字主街**：中央一纵一横铺浅色石板（0x8a8170），其余巷道保持本色 ——
  八条一样宽的巷子是迷宫，一条亮一点的路玩家自然会走；
- **檐口 + 屋脊 + 瓦垄**：只有墙的房子在 65° 下是"一排灰箱子"；
- **门雨棚、招牌、街边小物件**（桶/箱/花盆/拴马桩，贴墙放、不进碰撞表）；
- **分类配色**：民房米白、作坊锈红、兵营铁灰、农田土黄 —— 远看一片街，近看有区别；
- **政务厅重檐**：单层大锥在 65° 下是一整块纯色，重檐才有"屋脊"。

## 六、踩过的四个坑（都是截图发现的，断言一个都没拦住）

1. **政务厅被画了四遍**。`official` 字段是 `true`（不是 1/2/3/4），
   而 v140 写的是 `official === 1 || official === true` —— 后半句四格全中。
   现在按既有口径取"下标最小的那一格"做代表（domain.js:4841 同一条规矩）。
2. **玩家从来没被画出来**。`player = buildPlayer()` 后面漏了 `propRoot.add(player)`。
3. **玩家被自己身后的房子挡住**。巷子 1.14 米 → 贴墙 0.03 米 → 60° 时只剩一个头顶三角在飘。
   现在：巷道 1.6 米 + 只让头顶标记 `depthTest=false`（整个人置顶会变成"人浮在屋顶上"）。
4. **门楼高度两头都会错**。3.4 米时它的顶端在屏幕上压到玩家脚下（像站在屋脊上），
   2.1 米时把脑袋切断。2.7 米 + 出生点退到门内 1.75 米 = 门顶在玩家脚下 40px。

## 七、门禁怎么钉的

`smoke §352`（纯几何，跑在 node 里）：

| 判据 | 防的是什么 |
|---|---|
| ① 巷道 1.6 米 > 人直径 + 0.5 | 巷子比人窄 |
| ② 每栋房都有碰撞盒 + 政务厅恰好 1 座 | 穿模 / 一座衙门画四遍 |
| ③ 南墙缺口 ≥ 2.6 米 | "假城门"（墙没断） |
| ④ **BFS**：出生点 → 城外可达、每栋房门口可达 | 死胡同、被道具堵死的巷子 |
| ⑤ 两次生成完全一致 | 随机流串场 |

`audit_v125b_perf_ui.js`（实机，Playwright）：打开城内 → 量 `_debug()` 的俯角与玩家 NDC →
按 S 走出城门 → 断言场景真的关了。
