## 一、病根（一句话 × 三）

| # | 缺陷 | 病根 |
|---|---|---|
| ⓵ | 坏档能导入 | `importText` 只验「cities 是非空数组」，不验元素结构与其他字段类型 —— `[{}]` / `[null]` / 5000×`{}` / `generals:'oops'` / `map:null` 全部放行 |
| ⓶ | 静默坏状态被当正常档用 | `adoptState` 首行即 `GAME.state = st`；迁移中途抛错 → 内存停在半迁移态；`loadFrom` 吞异常返回 null —— 调用方以为「没有存档」 |
| ⓷ | 坏档连锁锁死 | `syncSeq`/`nextGenId` 用 `((s && s.generals)` `\|\| [])` —— `\|\| []` 只兜 null/undefined，**兜不住「非数组真值」**（`'oops'`）→ 连「新游戏」都开不了 |

## 二、改法（改前 / 改后）

| 项 | 改前 | 改后 |
|---|---|---|
| 形状抽检 | 无（只查数组真值+长度） | **`GAME.saveShapeChk`（唯一出口）**：数组类型 + 元素必填字段（id/name；城池另有 x/y 坐标）；`importText`（入口）与 `adoptState`（读路径）**双闸** |
| adoptState 原子 | 首行 `GAME.state = st`；失败留半迁移 | 先存 prev → 挂新档跑完整链 → 异常**回滚 prev 再抛**；成功路径零变化 |
| seq 守卫 | `((s && s.generals) \|\| [])` | `Array.isArray(s && s.generals) ? s.generals : []` + 元素防 null（两处：syncSeq / nextGenId） |
| 版本 | v89.207 | **v89.209**（评估轮占 v89.208） |

**为什么「把赋值挪到最后一步」行不通**（评估建议的字面形态）：
迁移链内的助手（`syncSeq` / `normalizeGuards` / `normalizeGenCities` / `migrate*` / `offlineCatchup`）
全部以**全局 `GAME.state`** 为读点（`syncSeq` 首行 `var s = GAME.state`）——赋值挪到最后，
它们读到的就是**上一个档**。等价原子形态 = 先存 prev + try + 回滚 + 重抛 ——
保住的不变量同样是「失败后内存不留半迁移态」。
