## 2. 三条硬约束：为什么"怎么调都没用"

这三条是这轮反复撞墙的真正原因，**都不是系数问题**。

### 约束① 射程是硬门槛 + 对双方对称的衰减

```
gap ≤ 120（贴身）→ 伤害 ×0.25
gap ≤ 射程/2     → 伤害 ×1.00   ← 唯一最优区
gap >  射程/2    → 伤害 ×0.50
```

衰减**对双方一样**：走近了你能多打，对方也能多打。所以"站位"没有取舍，
只有一个正确答案——**走到近半程**。这就是"全体推进"永远最优的原因。

### 约束② 战场纵深 1400 < 最远射程 1600

东风快递（1600）**第 1 回合就能打全场，永远不用走近**。于是"远程"这个位置被吃满，
任何 450~700 的中间档都夹在"肉搏不如主战、远程不如东风"的真空里。

### 约束③ 出征容量按人头

`marchCapOf = 练兵场等级 × 1 万（人头）`。所以**每兵价值**决定强弱：

```
泰坦 3050 · 东风 2504 · 主战 2425
轨道 1543 · 重装 1277 · 迫击炮 1070 · 步行机 520
```

按人头比，便宜量大的兵天生吃亏——**"多兵种有意义"在这里会被自动压平成"选每兵最强的那支"**。

## 5. 为什么"决策"这一项没做成（一句话）

> **在这个引擎里，"位置"不是决策变量。**
> 位置由 `adv` 连续决定、射程是硬门槛、衰减对双方对称 —— 所以"走到哪"只有一个正确答案，
> 玩家能选的（进/守/退）只是"要不要走到那个答案"。这不是数值没调好，是模型没有这个维度。

要让"站位"变成决策，必须让**距离对双方不对称**（例如遮蔽、地形、命中率随距离下降但只影响一方），
那是**加一条规则**，不是改一个参数。

| 路线 | 做什么 | 工作量 | 影响面 | 适合什么 |
|---|---|---|---|---|
| **A 收口**（推荐） | 承认"前中期主力"的定位，不再动战斗层；把中程兵接入 NPC 守军与 AI 配兵，转去做内容/留存 | 0.5~1 天 | 极小 | 想让游戏"完整"，不再追求战术深度 |

| **C 重做阵地层** | 真阵位格 + 地形 + 接触面绑定格子（不是全局 gap） | 2~3 周 | 结算层重写 | 想做成"战棋级"战斗 |

**我的建议：A + 一个小份的 B。**
A 先把这轮的成果收干净（中程兵进 NPC 守军表、AI 会配、界面能看懂）；
B 只做最小一条（远距离命中衰减 ×0.7，且只作用于**打人方**），验证"站位是否第一次出现取舍"，
再决定要不要铺开。C 在单机挂机定位下性价比最低。
