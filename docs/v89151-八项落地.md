## ⑤ 兵种悬停重做（老板 5）—— 本轮最贵：真根因是「快照漏字段」

**病根（探针实证）**：`tactic.snapUnits` 的 `cp(u)` 手写字段清单**只抄了 11 个**，漏了引擎结算链要读的 6 个：

```
❌ 快照漏抄字段 = ["start","hpPer","cover","sortie","atkPct","defPct"]
unitFinalOf.hp = NaN（→ 悬停显示「血 0（基础 1800）」· 全军血量 0）
```
`perHp(u) = u.hpPer × (1+科技) × hpMult(将)` —— `u.hpPer` undefined → **NaN**；
攻/防同样丢 `atkPct/defPct/cover` → 显示"无加成的兵种基础值"。
（§56.1 同族事故第二例：**手写字段清单的打包函数必须逐字段对账** —— 本轮补了对账断言 §131⑤。）

**改法**：cp() 补全 6 字段；`unitFinalOf` 加**规范化兜底**（外部构造/老档也不 NaN）+ 新 `totalDef`。

**悬停排版（严格按老板口径自上而下）**：

```
长枪兵                       ← 兵种
数量 6,000 名               ← 数量
射程 50　速度 310            ← 射程（并速度）
全军血量 1162.2万            ← 全军血量
全军攻击 92.4万              ← 全军攻击
全军防御 92.4万              ← 全军防御（新）
克制：轻骑兵 ×3 · 铁骑兵 ×3 …（我打他更狠）      ← 绿字
抗性：轻骑兵 ×5 · …（我挨他打更抗）               ← 绿字
被克：无 / 某某（他攻 ×N）                        ← 红字
带队 赵子龙（Lv1）· 已含科技 / 将领 / 装备加成
```
- 走**富浮层**（`data-tip-el` + `.tip-src`，兵牌与侧栏简称两处共用）—— title 装不下颜色；
- 克制反查唯一出口 **`ui.troopCounterOf(id)`**（读两张相克表，悬停/断言/探针同源）。

**「防御如何起作用？是否按整体计算？」**：
- **单位口径**（不乘人数）：`clashFactor = 2·A /(A+D)`（A=射手单位攻 · D=目标单位防，K=2）。
  A=D → 1.00，A 压制 → 趋近 2（封顶），攻不破防 → 趋 0（有"至少 1 人"保护，无绝对免伤）。
- 挨打方的实际损失 = 攻击方**整支**的攻量（perA×人数×射程衰减）× 该系数 ×（防御动作 0.5），
  再 ÷ 目标**单位**血 = 杀兵数。
- 也就是说：**防御是"单位质量"对冲，不随人数放大** —— 1000 个高防兵和 10 个高防兵，
  每个兵挨打时"被克制"的程度是一样的（人数只在攻方总量与血池上体现）。
- 另有防御向相克（`COUNTER_DEF[我][他]`）：挨特定兵种打时**我的单位防** ×N（刀盾挡箭 ×3 等）。

## 诚实缺口

1. **「队列回放」仍是兜底粒度**：replay 40 帧覆盖"每回合 1 帧的摘要"，不是逐兵种逐帧；
   逐兵种逐帧看画面请用**战报沙盘**（配方重跑）。若老板要"逐回合文字清单"式 UI，说一声即做。
2. **单枚按钮行留白**：半行宽规则下，单按钮行（如"放弃该野地"）右侧留空 —— 规格统一优先的取舍。
3. **悬停"克制"对无相克兵种**显示"无相克（凭硬实力对拼）"—— 象兵/义兵等按设计无相克（v89.118 老板令）。
4. **缩放限幅后画布居中**：`#app-fit` 是 `margin: 0 auto` —— 超宽屏两侧留深色边（符合"如图片缩放"）。
