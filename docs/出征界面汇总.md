# 出征界面汇总（v91.84 · 固定界面版）

> 结论先行：**全站只有一套出征界面**（`ui.openExpModal`），所有"派兵/用兵"入口都走它。
> **固定一个完整界面**：主档恒在，不适用项**置灰并说明**，不再按形态隐藏。
> **到达性限制由目标决定，出发性限制由派出城决定，通用内容恒在。**

## 二、固定主档（每个形态都有且只有一份）

1. **标题**：当前目标全称。
2. **一行形态摘要**：`ui.expShapeSummary`。
3. **目标行（单行）**：当前目标全称（左）+「其他目标」按钮（右，弹窗分类选择）。v91.77 起**不再重复渲染第二行目标**——「其他目标」并入首行右侧。
4. **相称建议** / **限制性信息**（到达性限制：领地上限、野地上限、据点每日掠夺）。
5. **派出城**：缺省当前城，可选**本星球全部己方城**（单城为静态名）。
6. **主将**：只列**派出城**的英雄（本城全部 + 置灰注明），另有「不派将」。
7. **出征方式**：恒列 7 种，不适用置灰并写原因（`ui.expModeAvailOf` 唯一出口）。
8. **探索层级 / 探索行动**（仅奇观目标出现）。
9. **方案 / 出征战术 / 计略**：恒在；非接战方式整块置灰。方案按派出城练兵场上限裁剪。
10. **可用道具**：恒在（作用于当前主将）。
11. **派遣兵力**：右列独占，14 兵种全列，每行「上限 / 清空」。
12. **预估**：恒在，内容按方式切换。
13. **辎重 · 资源调配**：仅「运输」展开，列 = 资源 / 现有 / **上限（不超过运力的最高数量）** / 起运 / 全 / 实收。
14. **确认**：文案随方式（探索/占领/派驻/派遣/起运）+ 推演 / 战备快购（仅战斗）/ 取消。

## 三、7 种出征方式

| 方式 | 目标 | 说明 | 无需英雄 |
|---|---|---|---|
| 侦查 | 野地/据点/名城 | 不接战，探守军+少量物资 | 否 |
| 掠夺 | 野地/据点/名城 | 不占城，财货最丰 | 否 |
| 占领 | 野地/据点/名城 | 野地就驻、据点收为前哨、名城易主 | 否 |
| 派遣 | 己方城市 | 英雄归属变化 + 两城兵种减增 | **是** |
| 运输 | 己方城市 | 用英雄/兵种负重调资源；送达后**原路返回**（耗时同去程） | **是** |
| 派驻 | 己方野地 | 藏兵；无将驻军**不可采集** | **是**（后果在摘要说明） |
| 探索 | 奇观 | 统一奇观入口；「探索层级」>0 = 挑战该层守卫，否则按探索行动采集 | 视行动 |

## 四、到达性 vs 出发性限制

- **到达性（由目标决定）**：方式候选项、领地上限、野地上限、据点每日掠夺、奇观层级未解锁、目标是否为己方。
- **出发性（由派出城决定）**：主将列表、方案、战术、计略、辎重、兵力与上限（练兵场 / 驻军上限 / 不限）。
- **通用**：出征战术、计略、道具、预估。
- 判定唯一出口：`ui.expModeAvailOf(modeId)`（界面置灰）与 `GAME.battle.prepare`（执行端）同源。

1. 出征面板**目标行去重**：原「目标（仅名称）」与「目标 + 其他目标按钮」两行合并为**单行**——名称在左、「其他目标」按钮在右（`.exp-one` 占满剩余宽度把按钮顶到右侧）。删掉重复的下方目标行。

## 五、v91.76 本次改动

1. 方式拆分：`transfer` 拆为 **派遣 `dispatch` / 运输 `transport`**（旧 `transfer` 保留为内部别名）；奇观统一为 **`explore`** + 探索层级。
2. 无将放行：派遣/运输/派驻可不带英雄（运输只按运力校验）。
3. 运输返程：`roundTrip` 标记；送达卸货后自动原路返回（耗时同去程）。
4. 固定界面：方案/战术/计略/预估恒渲染，非接战方式整块置灰。
5. 目标：「当前目标 + 其他目标」弹窗（本星球、按类型、名城按区分级）。
6. 派出城/主将/方案/预估/限制性信息统一按 `ui.expFromCity()` 读。
7. 辎重：新增「上限」列与输入封顶；只在运输展开；放在两列之后避免撑爆列高。
8. 顺修：方式粘滞（上次运输→这次点野地）、军务出征页把 (x,y) 当 ci 的候选 bug。

## 六、自动出征 / 自动探索（v91.79 ~ v91.84）

> 两者**不开出征界面**，走自动页配置 + 域层 `march.dispatch`。版面与取值口径如下。

### 6.1 编成组成（v91.79 起 · 玩家设定，不引用现存兵种）

- 右栏 **2 列：兵种 / 出征数量**（自动出征）。旧口径（引用某城现存兵种当取兵上限、显示"驻军数量"列）**已退役**。
- **自动探索是 3 列（v91.84）：兵种 / 探索数量 / 清层数量** —— 破层是真战斗，与"带多少兵采集"不是一套兵；
  **清层数量留空 = 沿用探索数量**（`GAME.autoExploreClearComp` 唯一出口）。
- **各城使用同一套设定**，但**按各城自身数据匹配** —— 唯一出口 `GAME.autoMarchMatchCity(city, comp)`：
  1. 逐兵种查该城驻军 → 不足 → `reason:'short'`，**该城跳过**；
  2. 再比 `GAME.battle.marchCapOf(city)`（**练兵场出征容量**）→ 超 → `reason:'cap'`，**该城跳过**。
     （例：设定步行机 150000、该城练兵场出征上限 14 万 → 该城不执行本次自动出征。）
- 界面右栏显示「**当前可达标城市 X / Y**」，按全星球城市实时统计。

### 6.2 执行英雄（v91.80 起 · 可不限 + 按城指定）

- 唯一出口 `GAME.autoMarchPickGen(cfg, city)`，**三级优先级**：
  **本城指定 > 全局指定 > 随机空闲（优先本城、排除君主）**；两级都不指定 = **不限**。
- 指定了一个**不在册**的 id → 返回 `null` 并报「已不在册」，**不静默随机顶替**。
- 存储 `cfg.cityGen = { cityId: genId }`，写入口 `doSetAutoMarch('cityGen:<cityId>')`（传空 = 该城不限）。
- 界面：执行英雄行右侧「**按城指定**」→ 弹窗**按星球分组列全部城市**，每行 = **勾选框 + 城市名 + 本城英雄下拉**
  （下拉首行「🎲 不限（随机空闲英雄）」）。**勾选 = 固定英雄，不勾选 = 不限**。
- **自动探索同构（v91.82 起）**：探索页「执行英雄」区同样有「按城指定」入口。
  两者**共用同一出口** `GAME.pickAutoGen`（`autoMarchPickGen` / `autoExplorePickGen` 都委托它），
  判据完全一致，杜绝两处口径漂移。已固定的城若该英雄**正在忙碌**或**已不在册** → **该城本次跳过**（不随机顶替）。

### 6.3 自动探索（v91.79 随机化 · v91.81 全域开放）

- **行动随机**：按**本星球奇观**的 `acts`，过滤掉 `wonderActLockOf` 未解锁项后**随机取一种**，
  不再手动指定、也不限当前星球。
- **仅英雄行动不带兵**：`needArmy === false`（采集 / 圣殿研读）**无论设了多少兵都 `army = {}`**。
- **探索范围（v91.81）**：域侧本就遍历全部星球（v91.41；`mapSlices` 已在 v91.74 归一进 `s.cities`），
  缺的是界面。现用**排除表** `cfg.offPlanets` / `cfg.offCities`，**默认空 = 全域**（兼容老档）。
  入口 `doSetAutoExplore('offPlanet:<pid>')` / `('offCity:<cityId>')`，传空 = 恢复参与。
- 界面新增「**探索范围**」区（「已选 X 星球 · Y 城」+「选择星球 / 城市」），弹窗照「其他目标」版面：
  **左 1/4 星球导航（带整球勾选框）+ 右 3/4 该星球城市勾选**，含「本星球全选 / 全不选」批量。
- 原「目标奇观（当前星球）」降级为「**当前星球奇观（参考）**」—— 只是参考，**不再代表探索范围**。
- **行为链：先算可行集，再随机**（v91.83 起）—— 唯一出口 `GAME.autoExploreActsFor(pid, city, cfg)`
  返回 `{ feas:[可行], blocked:[{why,kind}] }`：已解锁 ∩ 本城能力（编成 / 负重）都满足才进 `feas`。
  面板「行为链现状」块把每个行动标成 ✅可行 或 🔒受阻原因，**为什么没派队一眼可见**。
- **自动清层（v91.84 · 默认开）**：可行集为空 → 派兵破下一层（清层 → 解锁行动 → 采集）。
  · **安全阀**：编成总兵力 < 该层 `minTroops`（第 1 层 8000 … 第 6 层 40 万）→ **不出战**（防每轮送死）；
  · **不吃每日次数**：破层不占「每城每日 N 次」，且成功后**当轮立刻重试派队**，一次 tick 走完链；
  · 破层用**清层编成**，只做采集的玩家（探索编成 0）也能破层。

### 6.4 自动研究（v91.80 起 · 本城 6 格互不重复）

- 本城 6 个栏位**研究项目互不相同**；候选被占满时**留空**，不再重复塞同一个项目。
- 口径后果：候选 4 项 → 最多铺 4 格；**只勾 1 项 → 只铺 1 格**。
