## 十六、v90.22（老板：开着界面 + 息屏几天，回来募兵没进度）

**根因**：`GAME.loopPulse`（主循环时间推进唯一出口）的 `checkVisible===false` 分支
**仍无条件把 `_loopLastAt = now` 前移**，于是"不可见"期间的整段真实时间被**逐拍吞掉**。
老板场景 = **开着界面 + 电脑息屏几天**：息屏唤醒时 `#screen-game` 一旦判为不可见，
那几天就被丢弃 —— 队列停在原位。

**修复**：改为**只要已有对局（`GAME.state` 存在），无论可见与否都按真实钟补算**
（这是挂机游戏，时间本就该走）；只有"未开局"（创角 / 无 state）才只记账不补算。
- 实测：息屏 3 天后 `loopPulse` → gap 259200s → 补算 → 队列推完、兵入城。
- §199③ 用例同步改口径（原"hidden 只记账不补算"是这次的病根，已纠正）。
