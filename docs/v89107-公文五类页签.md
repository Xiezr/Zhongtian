# v89.107 · 公文重做：五类独立页签（战报 / 侦查 / 烽火 / 任务 / 系统）

> 老板原话：「**公文有几种报告类型，按军务那样整几个独立切换界面，
> 战报，侦查报告，烽火警报，系统消息，等**（别偷懒也别啰嗦）」

---

## 一、病根（一句话）

**消息没有"类别"这个字段** —— 旧公文是一条扁平流：战报、侦查回报、烽火预警、
内政提示混在同一串里，颜色还是**按文本正则猜的**
（`/战|攻|败|损/ ? 'war' : /任务|史册|改元/ ? 'task' : 'sys'`）。
"分类"从来没落到数据上，所以也**没法按类切成独立界面**。

先量了一遍 140 个发消息的点：**大量消息是拼出来的**（`'' + head + '：' + bits`），
文本判据只覆盖一半 —— **猜不准的分类等于没有分类**。所以本轮不做"按文本猜"，
改成**谁发消息谁声明类别**。

## 二、改法

| # | 改前 | 改后 |
|---|---|---|
| 1 | 类别靠文本正则猜（在 UI 里，两处各写一份） | **发射点声明**：`GAME.log.beacon('🔥 烽火：…')`；落库字段 `k`（`state.js`） |
| 2 | 类别值域没人管 | `DATA.MSG_KINDS`（5 类：id/name/icon/desc）—— **唯一来源** |
| 3 | 公文 = 一条扁平流 + 四个频道（系统/战报/任务/全部） | **五类独立页签**（战报/侦查/烽火/任务/系统），页签名/顺序都由类别表派生 |
| 4 | 侦查回报混在战报列表里；烽火预警一闪就没 | 侦查页 = 结构化回报（点开看分层情报）；烽火页 = 预警 + 击退/被破 + 防守计 |
| 5 | 军情（行军/调防/缴获/驻守 40+ 点）与内政提示混在一起 | 战报页**两段**：上=战报（全量留档 + 筛选 + 分页）／下=军情流水（滚动窗最近 20 条） |
| 6 | 每条消息没有时刻 | 流水行带 `HH:MM` 时刻列（一屏 15 行也扫得动） |
| 7 | 页签上不知道哪类有新东西 | 页签带**条数徽标**：`⚔️ 战报 3 ｜ 🔭 侦查 1 ｜ 🔥 烽火 2 ｜ 📜 任务 1 ｜ 📣 系统 13` |

类别归属（实测落地数）：

| 类别 | 已声明发射点 | 典型内容 |
|---|---|---|
| war | 42（battle.js 37 + domain.js 4 + state.js 1） | 得胜/受挫/撤退/占领/缴获/归降/行军/调防/驻守/治疗伤兵 |

| task | 5（domain.js 3 + story.js 2） | 完成任务 / 随机任务 / 改元 / 时代之志 |

> `battle.js` 是**零裸调用**：所有日志都走 `GAME.log.war/sys`（smoke 有断言钉住）——
> 军事模块不许出现"不知道属于哪类"的消息。

## 四、顺手修的一个真 bug

**`ui.DOC_PER` 从来没定义过**：

```js
var rPg = ui.pageOf('rep', repIdx.length, ui.DOC_PER);   // undefined → 回落 PAGE_SIZE(12)
if (repIdx.length > ui.DOC_PER) ui.pagerHTML(...);       // 12 > undefined → 恒 false
```

后果：**战报翻页条从来没登记过** —— 打过十几场仗以后，只能看到最早/最新的 12 份，
更早的翻不到（注释里写着"每页 8 份"，但那个常量不存在）。
本轮补上定义（`ui.DOC_PER = 10`）并加断言守住。

## 七、诚实缺口（需要老板定夺 / 下轮处理）

1. **旧档消息（本版之前写的）没有 `k`**：`GAME.msgKindOf` 按旧界面那套粗规则兜底
   （只分 war / task / sys 三档）→ **老消息不会出现在「侦查」「烽火」页**，
   会落在「战报（军情）」与「系统」里。新消息不受影响。
   若老板要"老消息也按新类别归档"，得跑一次性迁移（按文本重分类）—— 说一声就做。
2. **军情流水是滚动窗**（战报页下半段，最近 20 条）：消息本身按 10 游戏天 / ≤800 条裁剪，
   长期留档的是**战报（报告）**那一段（全量 + 分页 + 收藏）。这是有意的分工，不是漏做。
3. **页签还没有"独立未读"**：现在是"进公文即视为已读"（v41 的老口径）。
   做每个页签的红点需要给页签加未读游标 —— 本轮没动，等老板说要不要。
4. **侦查页暂时只有报告**：`GAME.log.scout` 出口已建好、样式已就位，
   但目前没有发射点（侦查内容全在结构化回报里）。将来若有侦查流水，直接落这一页即可。
5. **e2e 断言数 1043**（上轮 1044）：把旧的两条「频道切换」断言合并为一条「页签切换」
   （含点击验证），少的一条是**合并**，不是丢失。
