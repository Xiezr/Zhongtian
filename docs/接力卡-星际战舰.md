## v91.87 · 守将平衡套餐（默认关）

- 问题：野地 Lv10 守将 = 玩家的 **0.23 倍四维**，名城守将 = 1.00 倍（三把尺，跨度 4.3 倍）。
- 根因：资质封顶（进化体 grow 3）+ 折损（dim 0.5 / atkDim 0.25）两条口径相乘。
- 改法：`DATA.GUARD_FOLD_V2`（0.8/0.9/0.8）+ `GUARD_RANK_LADDER`（按野地等级爬梯）
  + `GUARD_POWER_COMP`（守军数量补偿，总战力持平）。
- 开关：`state.settings.guardBalance`（默认 false）。全链走 `GAME.guardBal` 唯一出口。
- 验收：属性比 0.23→0.82，守军 33965→19292，难度偏差 1.3%（`tools/guard-accept.js`）。

## v91.88 · 守将：取消差异系数 + 装备等效（默认生效）

- 老板指令：取消将领属性差异系数；玩家还有装备，而装备占输出 **89.5%**。
- 折损全 1.0；守将按野地等级配**等效装备**（q1→q6，取玩家同档 70%），走同一条 atkPct 链。
- 守军数量逐级实测补偿（野地 Lv10 ×0.194、据点 ×0.20）——"兵海"变"精兵"，总战力不变。
- 补偿**必须有守将**才生效（无将野地不减兵）。
- 结果：野地 Lv10 守将 四维 307→1330 · 攻击 +20%→+736% · 守军 33965→6590。
- 想保住兵数就压玩家装备刻度（第七/八节软饱和），那是另一轮。
