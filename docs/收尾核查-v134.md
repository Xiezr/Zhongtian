### ① 斗将面板

不是布局问题，是**弹窗档位**：`md` 固定 660×620，而斗将的内容随合数增长（1 合 → 5 合差 4 行），
根本没有一个稳定高度可以对。加 `.modal.modal-auto { height: auto }` + `openModal({size:'auto'})`。

实测两种状态：刚开 **297** 高 / 打完 5 合 **428** 高，留白都是 13、溢出都是 0。
内容再长仍有 `--app-h` 与 `.inner-panel` 既有兜底（那条链没动）。

### ② 前传档跨版本

读档链路跑了 `saveShapeChk` + 一堆 v6x/v8x 迁移，**没有一处补 `prologue` 的字段**，
而 `res / steps / dueled / subdued` 全是 v131~v133 期间才加的。

新增 `GAME.migratePrologue`，挂在 `adoptState` 的 `attachRes` **之前**（attachRes 要读 `prologue.res`），幂等。
三条口径都不放宽：

- 只在 `on === true` 且**无城**时补 `res`（`P.end()` 立城后置 null 是合法态）
- 补的是 `INITIAL_RES` **开局量**——这是止损，不是回补；已花掉的不凭空长回来
- 已有 `res` 只补缺失 key，不覆盖现有数量

## 二、最该说的一条：上一轮的「4128/0 全绿」不可复现

做完 ①② 跑 smoke，5 条战报沙盘用例全红（`no target`）。
按纪律先 `git stash` 全部改动跑基线 —— **基线同样红 5 条**，才判定与我无关。

根因在测试，不在产品：

```
wildLevelNow(ci) = (wildLevelBase(ci) + floor(Date.now() / 86400000)) % 11
```

野地等级**每天整体平移一级**（v91.89 的设计）。这组用例按 `wildLevelNow` 筛 3~6 级：

| 今天（2026-10-24） | 值 |
|---|---|
| day | 20750 |
| day % 11 | **4** → base 3~6 全被推到 7~10 |
| 该 seed 图的 base 分布 | 只落 3~9（没有 10/0/1/2） |
| 结果 | **一格都扫不到** → `expedition` 无目标 → 5 条连锁红 |

也就是**每 11 天必红一轮**。修法是选地改用固有等级 `wildLevelBase`（稳定、与日期无关），
实际战斗难度仍由日盐值决定 —— 这组用例要的是"打一仗、出配方、能重跑"，不是"必须打 3~6 级"，判据强度不变。

> **这条对我自己的要求**：以后报绿灯要说清是"该日期下的绿"还是"结构性的绿"。
> 我把上一轮那个 4128/0 当成了后者，其实它是前者。
