## 二、逐项改法与设计要点

### ① 数字键 Shift+1-5（main.js）

| 改前 | 改后 |
|---|---|
| 1-9 → 前 9 页签 | 1-9 不动；**Shift+1-5 → 史册 / 故事集 / 公文 / 自动 / 设置** |

- 判定用 **`e.code`**（`/^Digit([1-5])$/`）——Shift 下 `e.key` 会变 `!@#$%`，不能按字符判（布局无关）。
- 让行规则完全复用 v89.207：输入/选择态、组合键、弹窗打开时不触发。
- 设置页加键盘帮助行（1-9 切页 · Shift+1-5 续号 · Esc 关弹窗 · Tab/Enter 弹窗内导航）。

### ② 弹窗键盘流（ui.js + main.js）

三个**具名出口**（唯一出口纪律）：

| 出口 | 职责 |
|---|---|
| `ui.modalFocusables()` | 收集顶层弹窗内可交互元素（可见/未禁用）；`div[data-action]` **现场补 `tabindex=-1`** 才能被 `.focus()` |
| `ui.modalFocusInit()` | 开窗 / 弹栈 / 回层时给焦点（**焦点已在窗内则不动**——防同级刷新抢焦点） |
| `ui.modalKeyNav(e)` | Tab 手动循环（末→首回卷）· Enter 只激活 `div[data-action]`（真 button 交给浏览器默认；输入框内 Enter 不劫持；IME 不触发） |

配套两处回填（键盘流"手感连续"的关键）：

1. **live 面板焦点回填**：`_liveSnap` 记焦点**稳定描述**（id → 否则 tag+data-action+同类序号），`_liveRestore` 重建后重查回焦（每秒重建不再丢焦点）。
2. **弹栈快照**（顺带修的老短板）：压栈时记「输入值 / 滚动位 / 焦点」快照，弹栈时回填——**从子面板回来，输入框里打的字不再被复原**（出征面板打字 → 推演 → 返回，数字还在）。

### ③ 环境状态条（ui.js + main.js + index.html）

- 出口 `ui.skyBadgesOf()`：至多 3 枚、**仅非默认态**（没有消息就是正常）：

| 优先级 | chip | 数据出口（全是现成唯一出口） | 显示条件 |
|---|---|---|---|
| 1 | `⚔ 29分` | `invasionDueAt`（含开关/解锁/轮转全部口径） | 有排期 |
| 2 | `💔 许都 0%` | `cityHeartsOf` | 任一城 ≤ 40 |
| 3 | `🔥 逾溢折损` | `overflowRotOf` | 任一城有资源超仓容 |

- 点击跳转（`data-action="sky-go"`）：来犯→军务·烽火页 · 民心→该城 · 逾溢→仓库面板。
- **落地后调整（重要）**：原设计第 3 位是「天候 chip」——落地实机发现「天时」行**本来就显示季节/天候/年号**（`syncHeader` 实测 `天时建安·元年 春 🌧雨`），同屏双显违"不重复"原则 → **天候 chip 撤销**（sky-weather 档位与 CSS 同步退役，留注释说明）。
- 「离线补偿」**不做常驻 chip**（发生时有「归来报告/离线纪要」弹窗，常驻无意义）。

### ④ 战前推演（battle.js + ui.js + main.js）

- **架构要点（唯一出口）**：把 `_expeditionRun` 抵达段的「守方输入构造」**逐字节搬成** `GAME.battle.defenseInputsOf(t, modeId, opts)`（defBonus / tWallLv / scArmy·scVal·scGen·scNote / 计谋效果 / 围攻缩放 / simOpts）——**结算与推演共用同一份**，杜绝"推演一套、实战一套"的漂移。
- `GAME.battle.previewOf(target, modeId, atkArmy, genId, opts)`：`prepare` 校验 → `defenseInputsOf` → `boostSnapshot` 快照内跑 `simulate`（兵/将**深拷贝**传入）→ 零落账返回 `{ result, def, t, ... }`。
- UI：出征面板底键 `[出征][🎬 推演][快购][取消]`（仅战斗方式显示）→ 推演面板：**结果 / 双方损失 / 围攻推进（民心 100%→80% · 第 N 波）/ 计略注**，并写明未计入项。
- **诚实口径（面板里对玩家写明）**：未计入 行军期间天时/科技变化 · 战前斗将（seed 含时间，落地时不可预知）。

## 五、诚实缺口

1. **推演不是"全知"**：未计入 斗将（seed = 坐标+到达时刻，落地时不可预知）与行军期间加成变化——面板已对玩家写明；
2. 弹窗键盘流的 live 焦点回填按"稳定描述"（id 或 data-action+同类序号）——同描述多元素极端场景回退到同类首个；
3. 数字键键位是"按顺序续号"（Shift+1-5）而非"按功能起名"——中文项目里字母映射不直觉，续号零记忆成本（v89.209b 规划稿已论证）。
