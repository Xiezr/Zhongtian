# v89.186 宝具挂件 · 伤兵体系 · 据点剥离

> 老板 4 条（原文见「需求档案 · v89.186」）：
> ① 掉落"宝具"（替代奇珍异兽）——与装备并行的增幅物品体系，作为**模块挂件**嵌入将领体系，
> 能加能拿走、可复用为后续模块框架；
> ② 野地/据点/名城将领属性真实 + 体力相称且比玩家稍逊色 + **提高固定伤兵比例** +
> 调整商品 + 出征界面快购按钮 + 战力差距大时提示购买；
> ③ 据点采用 1、2、3、5、6 五项功能；
> ④ 折损比例释义 + 验收「每场战役治疗后净损 ≤ 0.10~0.20」。

---

## 一、④ 先说"折损"——两个同名概念，别混

| 名 | 是什么 | 现状 |
|---|---|---|
| **守将折损**（`DATA.GUARD_FOLD`） | **敌方守将属性的折扣**（v89.185 引入）：四维 ×0.5、体力取 50% 池 —— 防"据点 Lv10 满配守将不可胜" | 本轮 **staPct 0.5 → 0.8**（见下）；dim 0.5 不动 |
| **战损/伤兵回收**（`EXPEDITION.woundedRate`） | **玩家自己**打一仗的阵亡里有多少"只是受伤"（花金可归队）——净损失 = 阵亡 ×（1−回收率） | 本轮 **0.45 → 0.75** |

老板验收「每场战役治疗后净损 ≤ 0.10~0.20」→ 落点 = 伤兵回收率（下表）。

## 二、② 伤兵体系（核心）

**病根（探针取证 · probe_v89186a）**：rate=0.45 时，"玩家将领前期还不如野地"的真实场景
（Lv15 良才 1.0× 兵力打有将野地）阵亡 84~100% → **净损 29~34%**，远超老板上限；
且伤兵系三档商品是**替换语义**：青囊书 0.30 < 基础 0.45（**买了反而亏**）、续命书 0.45（**等于没买**）。

**改法**：

| # | 改前 | 改后 |
|---|---|---|
| 基础回收率 | 0.45 | **0.75**（净损 = 阵亡 × 0.25） |
| 唯一出口 | 三处各写一份（returnArmy 全链 / applyWounded 缺 schemeKeep+sect / 守城**只有基础**） | **`GAME.woundedRateOf(result)`** 一处；三消费点 + 界面全读它；`woundCap 0.9` 进表 |
| 商品语义 | **替换**（`rate = buff值`） | **加法**（`rate = 0.75 + buff`）→ 0.80/0.85/0.90 三档 |
| 商品值 | 青囊 0.30 / 续命 0.45 / 医圣 0.6 / 万全策 0.4 / 天时令 0.3 | +5% / +10% / +15% / +10% / +15% |
| 守将体力 | staPct 0.5（50% 池） | **0.8**（80% 池 —— "比玩家将领稍逊色"） |
| 旧档 buff | — | 语义反转迁移：`wound > 0.2`（旧绝对值）一律作废（幂等） |

**实测（probe_v89186a/b/c · 引擎真跑）**：

| 场景 | 阵亡 | 净损 @0.75 | 净损 @0.90（+医圣书） |
|---|---|---|---|
| 优势仗（1.5× 兵力 · 据点 Lv10） | 36% | 9.0% ✓ | 3.6% |
| 苦仗（Lv15 良才 1.0× · 有将野地 Lv5） | 88% | **22%**（提示购买场景） | **8.8%** ✓ |
| 全灭档（1.0× 打 Lv10） | 100% | 25% | 10% ✓ |

→ **正常/苦仗 ≤ 0.2 达标；全灭档靠"提示购买"兜底**（正是老板"战力差距大时提示"的设计闭环）。

**界面（出征面板）**：
- 苦战判定（我方最好情形仍弱于守军）→ 显示「💊 此战恐伤损较重 —— 伤兵回收 **75%**…购兵书最高可提至 **90%**　🛒 快购兵书」；
- 面板底部常驻「🛒 战备快购」（军事宝物全类）；「快购兵书」= 伤兵系过滤（`qb-cat` + `scope='wound'`，零新 case）；
- 伤兵行注册为面板 `live`（主循环每秒 + 从快购弹栈回来各刷一次；内容不变不重建）。

## 三、① 宝具 —— 挂件体系（框架 + 第一个模块）

**框架形状**（"后续参考开发类似功能模块"的兑现）：

| 层 | 落点 | 新增一个挂件模块要改什么 |
|---|---|---|
| 数据 | `DATA.ATTACH_SLOTS`（槽位表）+ 物品条目（type=槽位 itemType） | 只加数据，**玩法代码零改动** |
| 加成 | `GAME.attachBonusOf(g)`（同 `genEquipBonus` 形状）→ `genAttrs` **同层相加** | 自动汇总 |
| 装卸 | `GAME.attachEquip / attachUnequip`（库存守恒：装 −1 / 卸 +1 / 更换 = 旧还新扣） | 通用 |
| 界面 | `ui.genPane` 挂件行（按表遍历）+ `ui.openAttachPick`（通用选择窗） | 自动多一行 |

**宝具（8 件 4 档 · 数值对齐装备单件量级）**：玉犀符/铜雀令（凡）· 青囊玉枢/白虎符节（良）
· 八卦羽扇/虎头盘蛟枪（珍）· 赤霄剑/传国玉玺（神）。

**获取**：**打据点/名城缴获**（唯一渠道 · 不进商城）——`GAME.grantBaoDrop`：
据点 55% / 名城 40%；档位随目标等级上抬（Lv1-3→档1 … Lv7-9→档3、Lv10+→档4），低档更常见。

**实机（shot_v89186_gates · 真点）**：佩上玉犀符 → `genAttrs.tong 53→59`（+6）· 库存 2→1 ·
面板回显「🔮 宝具 · 玉犀符（统率 +6　内政 +6　体力 +120）[更换][卸下]」· 卸下 → 库存 1→2 ✓。

## 四、③ 据点剥离（采用 1/2/3/5/6）

**改前**（v89.103）：拔除据点 = **就地转成一座城**（建筑转正 + 人口归附 + **占领地上限名额**）。

**改后**：占据 = **我方前哨**（野外建筑 + 归属）——**不转城市、不占名额**；
数据 `s.forts['x,y'] = { x, y, lv, name, day }`；覆盖半径 **6 格**（切比雪夫）。

| # | 功能 | 落点（唯一出口 `GAME.fortAuraAt` 的五个读点） |
|---|---|---|
| 1 | 前哨效应 | `decayWilds`：覆盖内衰减**减半**（-2/日 → -1/日；与驻军**取档不叠加**，不为 0） |
| 2 | 采集增产 | `_rawGatherYield` 采力产出 ×1.35（仍受负重上限）+ `gatherTreasureChance` +15% |
| 3 | 兵站 | `wildGarrisonCap(lv, x, y)` 覆盖内 ×1.5（签名向后兼容） |
| 5 | 情报站 | `ui.expPowerOf` 覆盖内**误差归零**（显示「🗼 情报站覆盖：情报确凿」） |
| 6 | 商旅税所 | `GAME.fortTaxSettle`：每游戏日 Σ(据点 Lv × 40) 金（锚点约定同月俸；在线+离线两处接线） |

**界面**：据点面板按钮改「🚩 拔除并收为前哨」+ 提示行改写（v89.108 的"领地闸置灰"随语义退役）；
出征面板据点方式注同步。存量档：**已转正的据点城不追溯**（保留为城市）。
