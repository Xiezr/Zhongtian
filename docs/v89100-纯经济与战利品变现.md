# v89.100 · 两条假设的实测：「不发展军事只攒资源+买经验」与「战利品按购买价 75% 变现」

> 老板两问：
> 1. 「如果一直不发展军事，专注资源积累和商场经验道具会如何？」
> 2. 「如果攻击获得的道具能以购买价 75% 出售会如何？」
>
> 两条都用**真实推演**回答（1× 口径 = 300 现实小时 = 18.75 游戏年，同 seed 对照）。
> 第二问按假设**实装了机制**（道具寄售通道），再用 4 seed × 3 模式批量对照。

---

## 结论先行

### 假设 A（纯经济）：能活、能养将，但**结构性锁死**——三个天花板全在"军事之外"

| 维度 | 纯经济 18.75 年战绩 | 评价 |
|---|---|---|
| 城池 | **1 座**（永远） | 建城需先占野地（军事）→ 扩张线全断 |
| 爵位 | **平民（0 档）** | 晋爵第 1 档就要求「占城 ≥2」→ 永远卡死 |
| 军事 | 0 | 实测 **0 次入侵**——不设防无任何代价 |
| 建筑 | 全部 **Lv7**（和 76） | 瓶颈不是资源（粮堆 538 万），是**单城 3 格建造队列的吞吐量** |
| 将领 | **君主 Lv178**（天授）· 7 将 | 书 4 本 + 内功铺满——"养大神"这条线**完整可用** |
| 金结构 | 税收 ~50 万 >> 卖资源 10.4 万 | **人口税才是金主引擎**，"卖资源赚钱"是零头 |
| 消费 | 书 33 万 + 内功 17.6 万 = 50.6 万 | 金全部投入"经验道具"，终局余额 1.5 万（花光） |

**一句话**：纯经济能做到"单城满配 + 一个 Lv178 的君主 + 7 名将领"，但**爵位与扩张两条最长线的入口都在军事侧**——这不是"慢"，是"断"。

### 假设 B（战利品 75% 变现）：机制已实装——**安全、有小额真实收益、但不足以改变格局**

- **实装**：`DATA.ITEM_SELL.rate = 0.75` · 唯一出口 `systems.consign*` · 市集面板「寄售战利品」区块（逐项 + 一键全卖）· 15 条冒烟断言。
- **实测（4 seed × 两批配对）**：寄售**真实入账 7~15 万金/跑**（≈ 现金总量的 25~30%）；
  但对"军力/经验书"的配对差**方向不定、统计不显著**（第一批均值 −405、第二批 −182，t≈−0.5）。
- **三条机制级解释**：① 寄售来钱 → 市场自动少卖（置换掉约一半）；② 现金只是众多瓶颈之一（人口/队列/体力/野地同样卡）；③ 军力是滚雪球指标，±10 万金的边际影响 **<<** 路径分叉噪声（同模式跨 seed 差 6 倍）。
- **一句话**：值得加（战利品有了出口、以战养战闭环、零伤害），但**别指望它成为经济引擎**。

## 1. 假设 A：纯经济全记录（econ_1x · 300 小时 = 18.75 游戏年）

### 1.1 时间线

| 时点 | 事件 |
|---|---|
| 开局 | 书院开建 → 民房×7 → 客栈/市场/招贤馆/仓库/驿站/铁匠铺/工匠作坊/鸿胪寺 全部 Lv7 |
| +1.5 年 | 阶段切至 E1b（此后一生不变——扩不了张） |
| +0.6 年 | 首位 Lv100（赵子龙，书喂的）|
| 全期 | 金收入 ≈ 税收（人口引擎）+ 卖粮 16 笔 10.4 万；支出：书 4 本 33 万、内功 17.6 万 |
| 终局 | 1 城 · 军 0 · 建筑和 76 · 人口 5458/1.9万 · 粮 538 万 · 金 1.5 万 · 声望 10090 · **平民** |

### 1.2 三条被锁死的线（都是结构性的，不是数值问题）

**① 爵位线**（最狠）：晋爵第 1 档 = 「城池 ≥2 + 珠宝」。纯经济没有第二城 → **22 档爵位链在入口就断了**。
爵位带着产/税 +1%/档、建造位、将格、野地上限——**纯经济从开局就被判了"无期徒刑"**。

**② 扩张线**：建城 = 先占野地（要出兵）。而占野地又需要兵（征兵=军事）。环环相扣，无口可入。

**③ 建造吞吐线**：建筑上限是 12（官府闸 + maxLevel），econ 只到 **7 级**——
不是没资源（粮终局 538 万），是**单城 3 格队列在 300 游戏小时里只能升 76 级**。
对照 rush 的 3 城 242 级：**城数 ≈ 建造吞吐量的乘数**。

### 1.3 意外发现

- **0 次入侵**：18.75 年里烽火/入侵事件 **0 行**。不设防无代价——"不发展军事"在现版本里**没有外部惩罚**（削弱了"必须建军"的动机；也是纯经济流能安稳跑完的原因）。
- **金主引擎是人口税**：`税 = popCap × 民心 × 税率(0.35) × 0.3`。民房 7 级（上限 1.9 万）→ 满税 ≈ 1995 金/时 → 300 小时 ≈ 60 万金封顶。
  **"资源变现"（卖粮）只贡献 10.4 万**——比设计预想的弱得多（卖价折损 0.6~0.9 + 保价门槛 + 粮产爬坡慢）。
- **门派白送将**：7 将 = 初始 2 + 入门派（牧云庄）后给的 3 名史实将（鲁肃/孙权/贾诩）+ 2 名杂号。
  纯经济下"将领来源"没断——门派的将池是免费入口。
- **粮 538 万堆仓**：产出（10 万粮/时终局）远超消耗（0 军 + 建筑已封顶）→ 一旦建筑停了，资源全变死库存。

### 1.4 纯经济的"最优战绩表"（该模式下 18.75 年的天花板）

```
城池 1 · 建筑 11×Lv7 · 人口 5458 · 粮 538万 · 金 1.5万
将领：Lv178（天授）· Lv140 · Lv131 · Lv100 · 英杰×3
养成：书 4 本 · 内功 3~4 门 · 声望 1.0 万
缺口：爵位 0 档 · 军 0 · 第二城 0 · 装备 0
```

## 2. 假设 B：机制实装（战利品寄售通道）

### 2.1 规格（已入游戏，全部走唯一出口）

| 项 | 实现 |
|---|---|
| 价格 | `DATA.ITEM_SELL.rate = 0.75` · 单价 = `price × 100 × rate`（与商城 `doShopping` 同口径） |
| 覆盖 | 所有有购买价的道具：**珠宝 / 材料 / 种子 / 图纸**（战利品四类）+ 宝箱 / 经验 / 丹药等（玩家全权） |
| 不覆盖 | 装备实例（走拆解）· `price=0` 道具（灵草 / 灵气精华）· 未知道具 |
| 出口 | `systems.consignCfg / consignPriceOf / consignList(opts) / consignItem(id,n) / consignAll(opts)` |
| 过滤 | `opts.keep`（id 保留）· `opts.only`（类型白名单——**"攻击获得的道具"语义**） |
| UI | 市集面板「🎒 寄售战利品」区块（价值前 12 项逐项寄售 + 一键全卖 + 说明文案） |
| 断言 | 冒烟第 100 节 **15 条**（价格 / 拒绝 / 对账 / keep / only / 装备不入列 / UI 出口） |

### 2.2 战利品的真实变现价值（实测单价）

| 战利品 | 单价（金）| 75% 回收 |
|---|---|---|
| 珍珠 / 珊瑚 | 200 / 400 | 150 / 300 |
| 琉璃 / 夜明珠 | 700 / 4800 | 525 / 3600 |
| 凡铁 / 精铁 | 1000 / 3400 | 750 / 2550 |
| 名将套图纸 / 倚天套图纸 | 6000 / 32000 | 4500 / 24000 |
| 凡植种子 / 化龙种子 / 天授种子 | 3000 / 120000 / 360000 | 2250 / 90000 / 270000 |

> 单场战斗（Lv1 据点）的珠宝+材料+图纸期望 ≈ **1~3 万金当量**（75% 后）。
> 高强度攻城（州城/帝都）单场可达 **10 万+**（图纸 40%+55% 概率、四阶材料）。

### 2.3 实测效果（单 seed 配对，18.75 游戏年 · 军力用「城内快照」口径）

| | loot（真卖） | lootx（寄售空转） | rush（同 seed 基准） |
|---|---|---|---|
| 军力（城内快照 / 总兵力） | **446** / 927 | **295** / 610 | 4198 / 5076 |
| 城池 | 2 | 3 | 3 |
| 经验书 | 6 | 5 | 27 |
| 寄售累计 | 10.4 万金 / 50 件 / 13 轮 | —（空转） | — |
| 卖资源 | 20.1 万 | 24.9 万 | 135.7 万 |

**读法**：loot vs lootx = **+51%**（寄售是正收益，两口径一致）；但两者 vs rush = **÷9~14**。
```
真相：consignBrain 每次执行附带 setCity(richCity()) —— 一个副作用切走"当前城"。
     同 seed 下，仅此一扰动就让 18.75 年后的轨迹完全分叉（军力 9~14 倍差）。
     → 单 seed 无法定量"寄售效果"；必须配对（loot vs lootx）且多 seed。
```

**确定性验证**（配对对照的前提）：同 seed 同模式两跑**逐位一致**
（`loot_1x` ≡ `b20260922_loot`：446/2/14306/6/201037/187；`rushG_1x` ≡ `b20260922_rush`：4198/3/64842/27/1356614/205）
→ 同 seed 内的 loot↔lootx 差异**必然**来自"卖不卖"这一个变量。

## 3. 路径分叉：本轮最重要的方法论发现

同一份 seed、同一份代码，只差"每 2 分钟多一次 setCity"：
- rush 军 **4198** vs lootx 军 **610**（**6.9 倍**）
- 历史同类证据：v89.98 系列同 seed 下 rushA→rushG 的军力 161 → 4198（**26 倍**，跨版本策略微调）

**根因**：军事是**滚雪球系统**——早期一次"占野地成功/失败"或"征兵窗口"的差异，
经体力/兵力/野地/声望的连环放大，18.75 年后差出数量级。**这不是 bug，是长线战略游戏的固有属性**。

**方法论含义**（已写进工具）：
1. 任何"策略 A vs 策略 B"的长线对比，**必须配对跑 + 多 seed**，单跑数字不可引用；
2. 报告中的"军力/建筑"等滚雪球指标，**只看同 seed 配对差**，跨 seed 绝对值无意义；
3. 想降低分叉噪声，应统计**不滚雪球的指标**（如：寄售金总额、书的本数——线性量）。

## 5. 设计建议（按优先级）

### 5.1 关于「战利品 75% 变现」

**建议采纳**，但把"预期"定准：
- **75% 的回收率是合适的**：直接买-卖亏 25%（杜绝套利）；实测每跑真实入账 7~15 万金——它是**补充线**，不是引擎（对军力/书的影响统计不显著）；
- **语义要按"攻击获得"限定**（`only` 白名单）：首测脑把买来的投资品（生产宝物/体力药/加速）也卖了 → 产线断裂（军力 4198→927 的一半原因）。游戏 UI 建议"一键寄售"默认只勾战利品类（珠宝/材料/种子/图纸），投资品要玩家手动选；
- **若希望"有感"**（可选加大）：回收率 75%→85% · 或提高高级城掉落（州城/帝都本就单场 10 万+）——否则它只是一个"仓库清了 100 万金"的体验改良。

### 5.2 纯经济流暴露的三个设计问题（建议排期）

| # | 问题 | 建议 |
|---|---|---|
| 1 | **爵位第 1 档 = 2 城**（军事）→ 纯经济被判无期徒刑 | 给纯经济一条晋爵支线：如"声望/经营达标"可晋前 3 档（不占城），或第 1 档改为"声望 ≥X" |
| 2 | **不设防无代价**（0 次入侵） | 加"流寇/岁贡/劫掠"轻压力事件（对纯经济流形成软约束，不必真打） |
| 3 | **卖资源金收入远弱于设计预期**（10.4 万 vs 税 50 万） | 若希望"种田卖钱"成为一条真路线：提升卖出折损率或加"大宗贸易"渠道（参照通商券） |

### 5.3 顺带发现的两个小问题

- **门派将池是纯经济的"后门"**：3 名史实将免费入队——若设计上不希望纯经济白拿将，需要把门派收徒与"城池数/声望"挂钩；
- **粮 538 万死库存**：建筑封顶后资源无出口——这正是 v89.93 已列的"消耗侧缺口"（P1），纯经济把它放大了 5 倍。
