# v89.169（城墙 0 级虚影环）

> **老板原文**：「城墙0级的时候不明显，整得明显一点」

一句话交付：**城墙 0 级（未修建 / 破城掉回 0）从此在城内视角画一圈"虚线虚影"**
（墙基土垄带 + 虚线墙线 + 四角虚影角楼位）——这是"点它 = 修建城墙"的可见入口；
几何与实墙**同源**（`wallRingGeom`，逐字节一致），配色跟着主题金走（四套主题自适应）+ 悬停提亮。

---

## 一、病根（改前取证）

城墙 0 级有两个来源：

1. **从未修建**（新城 / 一直没修）；
2. **破城掉回 0** —— `state.js` 破防得手时：
   ```js
   var _nl128 = Math.max(0, wl - (L.wallDrop || 1));
   _ws128.build = _nl128 <= 0 ? null : { id: 'chengqiang', lvl: _nl128 };   // 掉到 0 直接置 null
   ```

而城内视角的墙环是"修了才画"（v89.128 口径）：

```js
wall: !!(c.wall && c.wall.build)     // ⛔ 0 级 → falsy → isoWallSVG 整段不画
```

叠加 v89.128 的另一条："**城墙不在空格菜单候选里**（入口 = 环城热区）" —— 于是 0 级时：

| 元素 | 0 级状态 |
|---|---|
| 墙环（城墙的视觉） | 不画 |
| 环城热区（唯一入口） | 存在，但**隐形** |
| 空格建造菜单 | 城墙已被剔除（v89.128："从候选剔除"） |

= **棋盘上找不到墙**。想修墙的人无迹可寻。改前探针（`probe_v89169_wall.js`）逐条实证：
0 级 HTML 中 `iso-wall` 不存在、`dasharray` 不存在、热区 4 条隐形。

## 二、修法（0 级 = 虚线虚影环）

| # | 改前 | 改后 |
|---|---|---|
| 视觉 | 0 级整圈不画 | **虚线虚影环**：墙基土垄带（18px 极淡金）+ 虚线墙线（`stroke-dasharray="10 7"`）+ **四角虚影角楼位**（虚线方框 ×4，与实墙角楼同位同尺寸） |
| 几何 | 只在 `isoWallSVG` 内算 | 抽 **`ui.wallRingGeom`** 唯一出口 —— 带参数（`WALL_PX`）与四角（带中心线）只算一次，实墙与虚影共用（输出**逐字节一致**；改 `WALL_PX` 只动一处） |
| 三态 | `!!build` 二值 | `isoBoard` 的 `wall` 认三态：`'ghost'` = 虚影 / 其余真值 = 实墙 / 假值 = 不画；`cityHTML` 传 `build ? 'full' : 'ghost'` |
| 配色 | —— | `rgba(var(--gold-rgb), α)` **主题金**（暗底发亮 / 浅底加深 —— 墨玉 201,162,75 · 素绢 138,101,22 · 青竹 125,106,28 · 夜黑 192,150,64）+ 悬停 `brightness(1.45)` 再提一档 |
| 热区 | 隐形但可点 | **不变**（点虚影 = 打开「🧱 城墙（未修建）」面板 · `data-build="chengqiang"`） |

**口径**：实墙（完整形制）↔ 虚影（待修建）—— 虚影**不表示等级**（等级只看面板）。

## 四、边界与诚实缺口

- **破城掉回 0 与从未修建同态**（都画虚影）——来源不同，但"待修建"语义相同，视觉统一是对的；
- **施工中**（`wall.pending`）与 0 级同画虚影（进度看"在办" chip）——"施工中"专属形制
  （如半透明实体）**未做**，需要可加（这轮不做：老板只要"0 级明显"）；
- 虚影醒目度以**静帧**为准（虚线 + 四角 + 悬停提亮）；不做呼吸/流动动画
  （全站除烽火告警外无动画惯例，避免又把 `prefers-reduced-motion` 牵扯进来）；
- 若老板觉得"还不够明显"（想要发光/动画/文字"待修建"标签），一句话即可加码——
  当前留了克制的一档。
